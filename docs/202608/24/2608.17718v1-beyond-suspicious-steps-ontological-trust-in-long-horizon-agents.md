## 摘要
长时程智能体日益在众多步骤、工具和观测之间运作。在此情境下，相关的监督问题不仅在于每个动作局部是否有效，更在于不断演化的轨迹是否仍然对应于用户授权的任务。漂移可能悄然累积：智能体可能在每一步都以看似合理的参数调用正确的工具，而其前缀却向更广泛的角色、相近的目标或用户从未提供的证据偏移。现有监控器大多检查局部合规性、给出最终轨迹判定或对通用风险打分；它们并不直接估计这种前缀级关系。我们引入本体论信任（ontological trust）——轨迹前缀的一种任务条件属性，并将其实例化为RGE，一种在线监控器，将信任沿角色（Role）、目标（Goal）和证据（Evidence）三个维度分解。RGE仅使用LLM来推导结构化的任务和步骤表示；信任状态更新、投影和干预决策均为确定性的，因此输出是可回放、可审计的信任轨迹，而非单一的端到端裁判判定。我们基于OSWorld、FinanceBench和EICU-AC构建了一个跨领域轨迹语料库，涵盖良性执行、前缀配对漂移和伪一致性失败。在该语料库上，RGE在前缀配对漂移检测上优于改编的规则式、裁判式和防护式基线。使用两个较大的估计模型时，RGE在每个基准上的漂移F1均超过93%，同时良性覆盖率保持在95.8%及以上。伪一致性更难处理：其检测取决于任务完成是否外部可见，这是我们通过实证刻画的的结构性局限。

## Abstract
Long-horizon agents increasingly operate across many steps, tools, and observa- tions. In this setting, the relevant oversight question is not only whether each action is locally valid, but whether the evolving trajectory still corresponds to the task the user authorized. Drift can accumulate quietly: an agent may call the right tool with plausible arguments at every step, while its prefix moves toward a broader role, an adjacent objective, or evidence the user never supplied. Existing monitors mostly check local compliance, deliver final-trace verdicts, or score generic risk; they do not directly estimate this prefix-level relation. We introduce ontological trust, a task-conditioned property of trajectory prefixes, and instantiate it as RGE, an online monitor that decomposes trust along Role, Goal, and Evidence. RGE uses LLMs only to derive structured task and step representations; trust-state updates, projec- tions, and intervention decisions are deterministic, so the output is a replayable and auditable trust trajectory rather than a single end-to-end judge verdict. We construct a cross-domain trajectory corpus from OSWorld, FinanceBench, and EICU-AC, covering benign executions, prefix-paired drift, and pseudo-consistency failures. On this corpus, RGE outperforms adapted rule-, judge-, and shield-style baselines on prefix-paired drift detection. With the two larger estimator models, it exceeds 93% Drift F1 on every benchmark while keeping benign coverage at or above 95.8%. Pseudo-consistency is harder: detection depends on whether task completion is externally visible, a structural limit we characterize empirically.

  - **全记录裁判模型**（judge/auditor）返回非结构化的整体风险判定。
- 核心诊断：**没有任何现有工具直接估计"轨迹前缀是否仍然对应于用户授权的任务"**——这是一个前缀级（prefix-level）关系，不是任何单步属性。

### 核心概念：本体论信任（Ontological Trust）
- **定义**：任务条件属性，衡量轨迹前缀是否仍然与用户授权的任务保持同一性（task identity）。
- 信任漂移可沿三个正交轴分解：
  - **Role（角色）**：智能体是否超出被授权的行动范围；
  - **Goal（目标）**：智能体是否偏离被委托的目标；
  - **Evidence（证据）**：智能体的行为是否基于任务文本、用户信息和观察到的环境。
- 形式化：授权边界表示为 D(x) = (R(x), G(x), E(x))，信任状态 T(x, h≤t) ∈ [0,1]³ 是对偏离程度的在线估计。

## 2. 论文提出的方法论：RGE 监控器

### 整体架构
RGE 将 LLM 的语义理解能力与确定性状态演算分离：**LLM 仅用于生成结构化表示**，信任状态更新、投影和干预决策全部由确定性规则完成。其输出为可回放、可审计的信任轨迹（trust trajectory），而非单一的裁判判定。

### 四阶段流水线

**阶段 I：任务条件完成结构生成（Task-Conditioned Completion Structure）**
- 一次性离线设置，从任务指令 x 推导最小完成间隙集合 G(x) = {ξ₁, ..., ξ_K}，其中每个 ξ_k = (描述 d_k, 闭合证据 v_k, 类型 t_k)，类型分为 core（核心）和 support（支持）。
- 同时生成紧凑的任务域画像（domain profile），供后续解析器参考。

**阶段 II：局部结构化解析与任务条件记忆更新**
- 每个步骤使用一次上下文 LLM 调用，将当前动作-观测对解析为类型化语义字段（身份信号、逻辑信号、因果信号、候选间隙解析等）。
- 任务条件记忆 L_t 采用**保守确认规则**：解析器提出的间隙闭合只有在满足固定确认条件时才被记为已完成，否则仅保留为候选状态。

**阶段 III：投影到 Role-Goal-Evidence 偏差坐标**
- 将解析器字段和记忆状态聚合成三个一致性分数 q^r_t, q^g_t, q^e_t ∈ [0,1]；
- 偏差向量为 z_t = (r_t, g_t, e_t) = (1−q^r_t, 1−q^g_t, 1−q^e_t)，其中 z_t = 0 称为信任原点。

**阶段 IV：时序聚合与阈值决策**
- 瞬时偏差分数：
  - u_t = α_r·r_t + α_g·g_t + α_e·e_t + λ·φ_t
  - 其中 φ_t 为结构耦合项，仅在三个轴同时超过阈值时激活（几何平均形式），用于捕捉多轴联合恶化。
- 时序状态更新：
  - s_t = γ·s_{t−1} + u_t（持续累积偏差）
  - m_t = s_t − s_{t−1}（漂移趋势）
  - c_t = β·c_{t−1} + (1−β)·u_t（短期突发统计量）
- 干预标签：**ALLOW → JUSTIFY → REANCHOR → CONTAIN**，由确定性规则映射，单一灵敏度参数 κ = 0.5 推导全部阈值。
- 固定超参数：α_r=0.34, α_g=0.33, α_e=0.33, λ=0.25, ϑ=0.40, γ=0.85, β=0.70，跨所有领域和模型统一固定，无逐域调参。

## 5. 实验数量与充分性

### 实验组数概览
1. **初步快照度量研究**：9 种单步度量 × 3 个评估模型 = 27 个配置组合，在 216 条 LotL 轨迹上评估；
2. **三轴可行性离线分析**：7 种坐标子集组合（r, g, e, r+g, r+e, g+e, r+g+e）在 3 个模型上评估；
3. **主实验**：3 基准 × 3 估计模型 = 9 个主要结果单元格（含 Drift F1、Pseudo F1、Benign Coverage 三项指标）；
4. **基线对比**：5 种基线 × 3 种估计模型 × 3 基准，报告累计均值；
5. **轴消融实验**：完整 7 子集（OSWorld + Qwen3.5-9B）；
6. **阈值敏感性分析**：κ ∈ {0.3, 0.4, 0.5, 0.6, 0.7}；
7. **任务交换 AUC 检查**：3 基准各一组；
8. **长度分桶分析**：短/中/长三桶；
9. **按攻击子类型分解**：5 种漂移子类型 × 2 个估计模型；
10. **定性案例研究**：3 个代表性轨迹逐步展示；
11. **失败模式分析**：3 类主要失败案例；
12. **聚类 Bootstrap 置信区间**：快照 AUC 的 95% CI（B=1000 次）。

### 充分性评价
- **优点**：实验设计覆盖面广，跨域（桌面、金融、临床）、跨模型规模（专有/中规模/边缘）、双威胁模式（漂移 + 伪一致性）设计合理；消融和敏感性分析较充分；有定性→定量的证据链衔接。
- **局限**：快照度量的基准标注对漂移轨迹采用"全轨迹标签投影到每步"的严格策略；约 15% 轨迹重新生成可能引入选择偏差；所有轨迹由单一 actor（Claude Opus 4.6）生成，存在生成风格一致性风险；代码和轨迹语料库未公开。

## 6. 论文的主要结论与发现

### 主要结论
1. **单步局部信号不足以检测信任漂移**：9 种快照度量中最佳仅达 73.49% AUC（Causal Grounding + Llama-3-8B），预测熵接近随机。前缀-任务关系是分布式的，不在任何单个步骤中。
2. **RGE 三维坐标能恢复前缀级信号**：在 LotL 语料上，三大轴坐标（R,G,E）在离线轨迹级达到 97.67% / 97.45% / 98.86% AUC，显著优于快照天花板。
3. **在线 RGE 有效检测前缀配对漂移**：GPT-4o 和 Qwen3.5-9B 在所有基准上 Drift F1 > 93%（OSWorld: 95.7/95.8；FinanceBench: 98.1/94.3；EICU-AC: 100.0/100.0），Benign Coverage ≥ 95.8%。子类型分析显示广泛覆盖而非单一家族驱动。
4. **伪一致性检测存在结构性上限**：Pseudo F1 中位数为 18.2%（范围 0.0%–98.4%），取决于**任务闭合是否外部可见**。OSWorld（UI 任务有明确完成状态）上可达 98.4%，而 FinanceBench 和 EICU-AC（只读推理域）本质上难以区分"良性验证"与"伪一致性"。
