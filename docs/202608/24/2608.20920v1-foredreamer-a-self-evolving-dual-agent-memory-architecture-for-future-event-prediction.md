## 摘要
开放网络上的未来事件预测要求智能体从嘈杂、冗余且不完整的证据中提取可靠信号。现有的检索/记忆机制要么直接将检索到的信息输入智能体，要么依赖简单的记忆功能（例如存储和复用先前信息以进行预测），这使得它们难以胜任开放网络预测任务。我们提出在预测之前将原始网络证据转化为结构化记忆，从而使智能体能够基于提炼后的、针对特定问题的证据进行推理，而非直接处理嘈杂的检索结果。本文提出了ForeDreamer，一个用于管理开放网络证据记忆的自进化双智能体框架。ForeDreamer将事实性记忆（当前预测中针对特定问题的证据状态）与经验性记忆（跨预测场景积累的持久智能体经验）相分离。它使用一个主智能体负责搜索与预测，并利用一个记忆处理子智能体通过专用工具将搜索结果转化为事实性记忆。此外，ForeDreamer通过两条路径进一步演化经验性记忆，既改善了预测决策，也优化了事实性记忆的构建。在Prophet Arena和FutureX上的实验验证了ForeDreamer的有效性。项目主页：https://zhongzero.github.io/ForeDreamer

## Abstract
Open-web future event prediction requires agents to distill reliable signals from noisy, redundant, and incomplete evidence. Existing retrieval/memory mechanisms directly feed retrieved information to agents or rely on simple memory functions such as storing and reusing prior information for prediction, leaving them insufficient for open-web forecasting. We propose to transform raw web evidence into structured memory before prediction, enabling agents to reason over distilled, question-specific evidence rather than noisy retrieval results. This paper presents ForeDreamer, a self-evolving dual-agent framework for managing memory over open-web evidence. ForeDreamer separates factual memory, a question-specific evidence state for the current forecast, from experiential memory, persistent agent experience accumulated across forecasting episodes. It uses a main agent for search and prediction, and a memory-processing subagent to convert search results into factual memory with dedicated tools. ForeDreamer further evolves experiential memory through two tracks, improving both forecasting decisions and factual-memory construction. Experiments on Prophet Arena and FutureX demonstrate the effectiveness of ForeDreamer. Project page: https://zhongzero.github.io/ForeDreamer

## 2. 方法论

### 核心思想
ForeDreamer 提出一种**自进化双智能体记忆架构**，显式区分两类记忆：
- **事实记忆（Factual Memory）**：针对当前预测问题的证据状态，是原始搜索结果与最终预测之间的已处理证据接口，作用域仅限于当前问题。
- **经验记忆（Experiential Memory）**：跨预测场景积累的持久智能体经验，包括文本预测经验（指导搜索规划、证据整合与预测校准）和程序化证据处理经验（指导如何将嘈杂搜索结果转化为事实记忆）。

### 架构与流程
- 系统对每个预测实例 `(q, τq)` 在时间截点 `τq` 约束下展开工作流：
  1. **主智能体**（Main Agent）读取问题并参考经验库 `B`，在预算 `T` 内执行多轮"搜索-推理"循环，每轮通过 **search-and-process 工具**发出查询 `st` 并获取时间截点感知的搜索结果 `Rt`。
  2. **记忆处理子智能体**（Memory-Processing Subagent）接收搜索结果，遵循 **MemGuide**（证据处理工作流规范）并使用可执行的 **MemTools**（证据处理操作），通过工件工作区（Artifact Workspace）迭代读写，将每条结果转化为结构化的事实记忆 `mt,k`。主智能体只能访问这一公共搜索-处理接口，内部检索与处理工具对外隐藏。
  3. 在最后一轮，主智能体基于累积事实记忆 `M1:K` 与经验库生成最终预测 `ŷ`，并记录完整回放日志（含交互、工件、标注真值和指标）用于自进化。

### 双轨经验演化机制
- **文本预测经验演化**：通过编辑智能体对经验库提出 `ADD / MODIFY / REMOVE` 操作，候选经验库只有在验证集上取得改进时才被接受（公式 `B(v+1) = eB if eB ≻ B(v), else B(v)`）。
- **程序化证据处理经验演化**：
  - 以 **MemGuide 树** 结构保存程序化经验，每次扩展选择父 MemGuide、采样演化回放、由评论者提出设计需求，生成候选 MemGuide 与 MemTools，只有通过验证门才能加入子树。
  - 父节点选择采用基于验证排名的 Zipf 采样，兼顾强指导偏好与低排名节点的探索机会。
- **优化 1：组合式工具复用**：量化分析显示，vanilla 演化在 FutureX 上生成的 201 个 MemTools 在 token-Jaccard 阈值 0.5 下坍缩为 98 个聚类（聚类率 48.8%），说明存在大量近似重复的工具构建。因此，生成新 MemGuide 时先从现有有效工具集中选择兼容子集复用，仅为未覆盖的操作生成新工具，减少重复构建。
- **优化 2：多样性引导探索**：vanilla 演化在 FutureX 上产生的 10 个 MemGuide 全部归属同一管道原型（工具编排处理），显示探索过度集中于单一成功指南家族。为此引入演化调度器，在基于回放的扩展之外交替执行无需新回放的探索路径——从 MemGuide 类别摘要与代表性指南出发生成类别多样性候选，扩大结构化探索范围。

## 6. 主要结论与发现

- **结构化记忆优于直接利用检索结果**：在 Prophet Arena 上，ForeDreamer 在两个骨干下取得均取得最好的平均 Brier 分数（Qwen3.5-Flash：0.1471；GPT-5.4-Nano：0.1839），显著优于 Full Text（0.2059 / 0.2084）和所有现有记忆系统基线，且在全部 8 个事件类别中均优于 Full Text。在 FutureX 上同样取得最高准确率（Qwen3.5-Flash：0.4108；GPT-5.4-Nano：0.3883）。
- **双轨经验演化互补有效**：移除任一演化轨道均导致性能下降（Table 3），说明文本预测经验与程序化证据处理经验提供互补的收益。
- **组合式工具复用减少工具冗余**：启用后，FutureX MemTool 的聚类率在各相似度阈值下普遍提升（token-Jaccard τ=0.5 时从 48.76% 提升至 59.09%，提升 +10.33%），表明生成工具集合并未过度坍缩为相似簇，减少了重复工具构建。
- **多样性引导探索拓宽了管道覆盖**：启用后，FutureX 的 10 个 MemGuide 从单一管道原型（工具编排处理）扩展至 4 个原型（工具编排、证据优先 LLM 综合、规格-内容分解、规划与验证），验证了探索调度能有效避免过度集中于局部指南家族。
- **性能提升不依赖于特定搜索配置**：在 8 种搜索/交互设置变体下，ForeDreamer 在 Prophet Arena 上均降低平均 Brier 分数，在 FutureX 上均提升准确率。
- **外部网页证据确实必要**：No Information（无搜索）设置的性能明显低于 Full Text 与 ForeDreamer，且训练截止更早的 GPT-5-Nano 上的结果模式一致，排除了仅凭模型记忆完成预测的解释。

## 7. 优点

- **问题定位准确**：明确指出开放网页预测与传统记忆任务的任务不匹配（图 1），并以两个 RQ 引导全文，结构清晰、动机充分。
- **概念分离精巧**：将记忆拆分为事实记忆（局部、问题特定、证据接口）与经验记忆（持久、跨场景、行为指导），且程序化经验进一步细分为 MemGuide（工作流）与 MemTools（可执行操作），既保持可检验性又支持模块化演化。
- **设计驱动型演化**：不只是做了又一个自进化框架——通过分析工具聚类率（图 4）与管道原型分布（图 5）的量化证据，诊断出 vanilla 演化的两个具体缺陷，再据此提出组合式工具复用与多样性引导探索，方法设计有较强的实证支撑。
- **可控性好**：主智能体只能访问公共搜索-处理接口，子智能体仅能调用当前 MemGuide 允许的 MemTools（allowlist），工具执行受沙箱与预算约束，降低了失控副作用的风险。
- **实验验证全面**：双骨干、双基准、8 个基线、两组消融、8 种搜索设置鲁棒性测试、数据泄漏检验、工具冗余与管道多样性分析，形成完整证据链；利用训练截止在先的模型（GPT-5-Nano）做数据泄漏检查是加分项。

## 8. 不足与局限

- **验证集过拟合风险**：论文仅在 5-20 条样本的小型演化验证池上演化与验证记忆，数量有限，存在记忆过度适配验证问题的风险。论文虽然通过独立测试集报告缓解了这一担忧，但小池子本身是否足以提炼出真正普适的经验仍是一个开放问题。
- **对评估基准的覆盖范围有限**：未在传统 agent-memory 基准（如 LongMemEval、LoCoMo）上与现有记忆系统进行对比。论文声明这超出范围，但读者无法判断 ForeDreamer 的双轨记忆架构在更通用的记忆任务上是否具备优势或至少不退化。
- **算力信息全缺**：未报告 GPU 型号/数量、API 调用次数、token 消耗、演化耗时与推理延迟。考虑到 ForeDreamer 的演化过程需要在验证池上反复运行完整回放，其成本结构对实际部署至关重要，缺少成本数据难以评估性价比。

## 8. 不足与局限（续）

- **骨干模型的现实问题**：实验使用 2026 年的 Qwen3.5-Flash 与 GPT-5.4-Nano 作为骨干模型，两者的训练截止时间与评估时段高度重叠，意味着模型参数中可能已隐含部分待预测事件的信息。尽管论文用训练截止更早的 GPT-5-Nano 额外做了数据泄漏检查，且结果模式一致，但这只能证明"搜索结果之外模型内部知识并非预测的主要来源"，并不能完全消除骨干模型在结构化记忆构建阶段对证据理解的隐性偏置。在真实部署中，面对训练截止之后的全新事件，ForeDreamer 的证据处理与预测能力是否仍能保持同等优势，尚未被直接验证。

- **评估维度相对单一**：主实验依赖于 Brier 分数（Prophet Arena）与准确率（FutureX）两个标量指标，缺少对预测置信度校准质量（如可靠性图、分层 Brier 分解）、失败模式分类（低估/高估、类别偏差）以及证据-预测归因一致性的细粒度分析。读者难以判断 ForeDreamer 的性能提升究竟来自证据选择更准、不确定性校准更好，还是仅来自对少数易得分样本的把握。

- **搜索质量敏感性与成本透明度不足**：系统高度依赖外部搜索 API（Tavily、Firecrawl）返回的结果质量，但论文未隔离分析"搜索质量下降时结构化记忆是否仍优于直接喂全文"这一边界条件。同时，由于未报告单次预测的 token 消耗、延迟与 API 费用，无法评估 ForeDreamer 相对简单 RAG 基线的"性能-成本"性价比——考虑到其多轮搜索 + 子智能体工具调用 + 演化验证的成本结构，这一信息对实际部署决策至关重要。

- **泛化边界未充分探索**：所有实验均基于英文开放网络预测场景，未涉及多语言证据、非文本模态（如图表、音视频）或非事件预测类任务。论文虽声明传统 agent-memory 基准超出范围，但未给出任何迁移实验，限制了对其架构通用性的判断。

## 9. 总结与适用场景

- **一句话概括**：ForeDreamer 将未来事件预测的可靠性建立在"将嘈杂网页证据转化为结构化事实记忆，再以双轨经验演化持续优化证据处理与预测决策"这一设计之上，并在两个真实预测基准上以实证表明其优于直接长上下文喂入和现有通用记忆系统。
- **最值得借鉴的设计**：将程序化经验以 MemGuide 树 + MemTools 形式显式编码为可执行、可验证、可演化的工件，并用量化诊断（工具聚类率、管道原型分布）发现 vanilla 演化的缺陷后再做针对性优化——这种"先诊断、后改进"的实证驱动范式比单纯提出新架构更有说服力。
- **最值得警惕的风险**：小型演化验证池（每类 5 条 / 共 20 条）上的双轨演化存在过拟合验证问题的可能；独立测试集的表现缓解了部分担忧，但无法完全排除。若要在生产环境中应用，建议在更大、更多样的验证池上重新评估经验库的普适性。
- **适合阅读的受众**：从事 agent 记忆系统设计、检索增强生成、时间敏感推理或自进化 agent 研究的科研人员与工程师；对"如何让智能体在开放网络信息下做可靠预测"感兴趣的从业者。若追求即插即用的低成本记忆方案，本文的方法论复杂度与算力开销可能超出实际需求。
- **综合评分（主观参考）**：动机与问题定位 9/10，方法创新性 8/10，实验充分性 8.5/10，工程可复现性 5.5/10（算力与成本信息缺失），写作清晰度 8.5/10。总体是一篇问题选得好、设计有洞见、验证较扎实的论文，主要短板在于成本透明度和验证规模的现实性。
