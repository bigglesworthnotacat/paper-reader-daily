## 摘要
现有的智能体推理系统通常依赖集中式协议。这种设计引入了路由瓶颈和静态角色分配，在处理复杂多模态查询时往往失效。我们提出DeAR（去中心化智能体推理），一个从集中控制转向自主点对点协作的框架。DeAR基于三种机制构建：（1）用于查询相关智能体特化的去中心化能力锚定，（2）用于定向同伴交互的思维图谱导航，以及（3）用于自适应错误纠正的拓扑更新。在9个多样化多模态推理和基于文本的问答基准上的评估表明，DeAR始终优于近期基线方法，验证了去中心化和自适应的智能体协作能提升知识密集型推理任务的准确性。源代码将在https://open_upon_acceptance上提供。

## Abstract
Existing agentic reasoning systems typically rely on centralized protocols. This design introduces routing bottlenecks and static role allocations that often fail when handling complex multimodal queries. We propose DeAR (Decentralized Agentic Reasoning), a framework that shifts from central control to autonomous peer-to-peer collaboration. DeAR is built on three mechanisms: (1) decentralized capability grounding for query-dependent agent specialization, (2) thought map navigation for targeted peer interactions, and (3) topology update for adaptive error correction. Evaluations across 9 diverse multimodal reasoning and text-based QA benchmarks indicate that DeAR consistently outperforms recent baseline methods, validating that decentralized and adaptive collaboration among agents enhances accuracy in knowledge-intensive reasoning tasks. The source code will be available at https://open_upon_acceptance.

**研究动机与背景：**
- 复杂推理任务（如多模态问答）需要超越简单模式匹配的能力，而 **Agentic Reasoning**（智能体推理）通过将复杂问题分解为子任务、交由专门智能体处理，已成为一种有效的范式。

- 论文指出，真实世界的复杂问题求解本质上是**去中心化**的：跨学科专家通过点对点对话、协商和自组织来弥合知识鸿沟，而非等待一个全知的管理者发号施令。

**核心问题：** 如何设计一种去中心化的智能体推理框架，使智能体能够自主决定何时、与谁协作，从而绕过集中式架构的固有瓶颈？

### 2. 论文提出的方法论

**核心思想：** DeAR 的核心是导航一张 **Agentic Thought Map（智能体思维图谱）**，其中节点代表推理状态，边代表智能体之间的协作概率。该图谱由动态的 **Collaboration Propensity Matrix C∈RN×N** 驱动，编码了基于能力锚定的智能体间有益交互的可能性。

**系统定义：** S = (Q, A, C, K)，其中 Q 为查询，A 为智能体集合，C 为协作倾向矩阵，K 为知识状态序列。

**三大核心机制：**

**(1) 去中心化能力锚定（Decentralized Capability Grounding）**
- 替代静态角色标签，每个智能体 ai 根据其底层模型的技术报告或模型卡片 Pi 中的**可验证基准数据**建立能力画像：
  - τ_i = (τ_cr, τ_ea, τ_nc, τ_fr, τ_cm)，分别对应常识推理、解释能力、数值计算、自然语言理解、事实可靠性。
  - 各维度分值来源于标准数据集（如 GSM8K→数值计算，MMLU→常识推理，TruthfulQA→事实可靠性）。
- 通过 **Softmax 归一化**将原始准确率映射到 [0,1] 区间，确保跨模型可比：
  - τ_d^i = exp(s_d^i) / Σ_{k=1}^{N} exp(s_d^k)
- 给定查询 q 时，智能体动态生成**查询相关能力状态** τ_i(q)，并据此生成中间推理结果 K_i。

**(2) 自组织协作（Self-Organized Collaboration）**
- 每个智能体 ai 自主评估与其他智能体 aj 的协作效用，形成协作倾向向量 c_i。
- 协作倾向系数通过温度缩放 Softmax 计算：
  - c_i,j = exp(τ_d^j / T) / Σ_{k≠i} exp(τ_d^k / T)
  - 自协作被禁止：c_i,i = 0。
- 聚合所有智能体的偏好向量形成协作矩阵 C，该矩阵编码了有向的、任务相关的协作偏好，完全由各智能体在查询下的局部评估动态塑造。

**(3) 思维图谱导航构建与拓扑更新**
- **导航过程**：
  - 从随机选中的种子智能体开始。
  - 当前智能体 ai 作为局部导航器，选择使增量效用 u_i(a_j) 最大的未访问智能体作为下一节点：
    - a_{i+1} = argmax_{a_j∈A} u_i(a_j)
  - 被选中的智能体基于累积上下文（先前所有智能体知识的并集）生成新知识，形成一条利用最强协作边的思想链。
- **动态终止**：当所有未访问同伴的评估倾向低于最小操作阈值，或所有智能体均已访问时，导航终止，终端智能体直接基于完整累积知识生成最终答案 y。
- **拓扑更新（渐进式细化）**：
  - 如果最终答案失效（“死胡同”），不从头重启，而是通过局部回溯策略剪枝失败边。
  - 对失败边施加衰减因子 α（如 0.5）更新协作矩阵：
    - c_i,j ← α · c_i,j（若该边在失败边集中）
  - 系统在调整后的拓扑上重新导航，逐步收敛到有效推理路径，避免重复无效计算，保留已取得的推理进展。

### 6. 论文的主要结论与发现

1. **去中心化优于集中式**：DeAR 在全部 9 个基准上一致优于集中式多智能体框架（AutoGen、AgentVerse、DyLAN 等），证明去中心化拓扑是突破集中式瓶颈的有效方案。
2. **架构设计胜于参数规模**：DeAR 使用 4 个小型模型（总参数量小于单个 72B 模型），却在 MathVista 上比 Qwen2-VL-72B 高出 18.07 分（59.41 vs 41.34），表明结构化协作比单纯扩大模型规模更有效。
3. **各组件均不可或缺**：消融实验证明能力锚定（+5.76 MMMU）、思维图谱导航（+8.38 MathVista）和拓扑更新（+2.37 MMMU）各有独立贡献。
4. **自适应性强**：62.5% 的 MathVista 查询由少于 4 个智能体解决，说明 DeAR 能按需激活智能体，避免不必要的计算消耗。
5. **衰减因子适中最佳**：α=0.5–0.8 区间效果最优，过小（0.1）导致过度纠正，过大（0.9）则不足以抑制无效路径。
6. **通用性强**：除多模态任务外，DeAR 在纯文本单跳和多跳 QA 上也表现优异，表明去中心化推理导航可泛化到纯 NLP 领域。
