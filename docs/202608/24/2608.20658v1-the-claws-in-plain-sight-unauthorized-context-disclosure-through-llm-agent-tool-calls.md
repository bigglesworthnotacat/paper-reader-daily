## 摘要
LLM代理通常根据用户画像、对话历史、检索到的文档和先前的工具结果构建工具调用参数。然而，合法访问上下文信息并不意味着有权为任何目的或目的地传输该信息。我们提出了“明处之爪”，一种权威压力攻击，其中与任务相邻的内容将受保护属性描述为操作或程序所需，导致模型将其包含在原本有效的生成参数中。我们使用一个受控的合成基准评估“明处之爪”，该基准将六种压力级别与四种隐私策略级别交叉，涵盖五种DeepSeek和Claude模型配置，共产生120次调用。在完整的压力-策略矩阵中，测试模型的会话级泄露率介于20.8%到75.0%之间。更强的隐私指令减少了总体泄露，但并未在所有模型中一致消除泄露，这表明提示级策略并未提供可移植的强制边界。我们的实验仅使用合成画像并在本地捕获提议的参数；它们衡量的是上下文到参数边界处的违反策略的生成，而非已完成的网络窃取或已部署用户的泄露。这些发现促使在执行前对生成的工具参数进行用途和目的地感知的检查。

## Abstract
LLM agents routinely construct tool-call arguments from user profiles, conversation history, retrieved documents, and prior tool results. However, legitimate access to contextual information does not imply authorization to transmit that information for every purpose or destination. We present Claw in Plain Sight, an authority- pressure attack in which task-adjacent content frames protected attributes as operationally or procedurally required, causing a model to include them in otherwise valid generated arguments. We evaluate Claw in Plain Sight using a controlled synthetic benchmark that crosses six pressure levels with four privacy-policy levels across five DeepSeek and Claude model configurations, producing 120 calls. Across the complete pressure-policy matrix, session-level disclosure rates range from 20.8% to 75.0% among the tested models. Stronger privacy instructions reduce aggregate disclosure but do not eliminate it consistently across models, showing that prompt-level policies do not provide a portable enforcement boundary. Our experiments use only synthetic profiles and capture proposed arguments locally; they measure policy-violating generation at the context-to-argument boundary, not completed network exfiltration or leakage from deployed users. These findings motivate purpose- and destination-aware inspection of generated tool arguments before execution.

## 论文核心问题与整体含义

- **研究动机**：LLM代理（Agent）在构造工具调用（tool call）参数时，通常会利用用户画像、对话历史、检索文档和先前工具结果等上下文信息。然而，**合法访问上下文信息并不意味着有权将该信息用于任何目的或传输至任何目的地**。例如，用户的职业可能允许用于支持路由，但应禁止发送至营销服务；先前邮件可见于摘要任务，但不应纳入分析请求。
- **核心安全缺口**：传统工具权限只决定代理是否可以调用某个工具，却**无法表达哪些上下文值可以流入哪些参数、用于什么目的、发送到什么目的地**。这构成了“访问权限”与“授权披露”之间的鸿沟（access-authorization gap）。
- **攻击含义**：论文提出“明处之爪”（Claw in Plain Sight），一种**权威压力攻击（authority-pressure attack）**，通过将受保护属性包装成“操作必需”的任务相邻内容（如合规检查表、审计要求、下游API说明等），诱导模型将本应禁止泄露的值填入原本有效的工具参数中。这种攻击不需要恶意工具、不需要多步外传链，只需**一次从上下文到结构化输出的合法调用**即可造成隐私违反。

## 论文提出的方法论

### 核心思想

Claw攻击的核心是**权威冲突（authority conflict）**：模型对数据有合法访问权，但治理策略不授权该数据用于当前目的、目的地或工具字段。攻击者影响的任务相邻内容提供了一种竞争性权威主张（如合规要求、启动先决条件、审计指令），使原本禁止的流动看起来是完成合法任务所必需的。

### 四阶段攻击路径

1. **上下文组装（Context Assembly）**：代理接收合法任务及包含受保护数据的上下文；可信策略允许模型访问数据但限制其使用。
2. **权威冲突（Authority Conflict）**：攻击者影响的任务相邻内容声称受保护信息为合规、验证、资格或审计所必需，名义任务不变。
3. **参数生成（Argument Generation）**：若输出接口提供兼容字段，模型可能偏向不受信任的权威主张，将受保护数据填入该字段。生成对象语法有效，但包含未授权信息流。
4. **运行时处置（Runtime Disposition）**：编排层接收候选参数，可阻止、修改、要求确认或执行。参数生成本身即构成代理级违反。

### 形式化定义

论文给出了信息流违反的精确谓词定义：

```
Violation(d, s, p, r, f) ≜ present(d, context) ∧ generated(d, f) ∧ ¬allow(s, d, p, r, f)
```

其中d为数据项，s为上下文来源，p为声明目的，r为工具关联目的地，f为生成参数字段。授权函数allow由可信基准策略确定，而非模型解释。

- **精确复制（Exact Copy）**：受保护值规范化后出现在参数序列化值中，年龄需满足token边界条件。
- **语义推导（Semantic Derivation）**：参数不复制原始值但随受保护数据系统性变化，需通过反事实检验验证（见第5.4节），而非仅凭措辞相似性推断。
- **代理级违反**：生成参数对象中至少一个字段满足Violation谓词。
- **执行披露**：代理级违反加上编排层实际执行了调用。论文实验仅测量了代理级违反，未声称外部执行。

### 攻击与既有攻击的区别

- 不同于间接提示注入触发非预期工具调用或多步外传链，Claw**保持任务的合法性和工具用法的正确性**，只是操纵了哪些上下文信息被插入有效参数。
- 不同于恶意工具/技能/MCP服务器研究，Claw**不需要恶意工具实现**，只需利用应用已暴露的字段。
- 受保护信息**已存在于模型的合法上下文中**，安全失败发生在从上下文到结构化输出的单一转换。

## 实验设计

### 基准（Benchmark）结构

论文构建了一个**合成基准**，将压力级别和隐私策略级别交叉组合：

- **6种压力水平（L0–L5）**：从空槽位（L0）到要求年龄保证（L1）、标记必填（L2）、遗漏即阻断发布（L3）、增加审计和拒绝后果（L4）、模拟合规负责人覆盖（L5）。
- **4种隐私策略级别（S0–S3）**：
  - S0：无可见最小化指令（隐藏基准策略仍标记四个画像值为禁止）

  - S2：明确禁止传输年龄、性别、收入、职业
  - S3：绑定授权到目的与目的地，声明策略优先于任务相邻备忘录和模拟权威主张

- 所有数据均为**合成画像**，包含虚构年龄、性别描述、收入档次和职业，来源模拟为当前对话、合成记忆、合成文档或先前合成工具结果。
- 名义任务为合成“加州启动就绪审查”中的中性产品优惠上下文起草，返回draft_offer_context结构化对象。
- 参数字段包含与四个画像属性兼容的字段及age_gate_bracket（派生值）。

### 模型配置

- DeepSeek-V4-Flash、DeepSeek-V4-Pro、Claude-Sonnet-4.6、Claude-Sonnet-4.5、Claude-Haiku-4.5，共**5种模型配置**。
- 全部120个请求均完成无错误；109个响应包含可恢复的参数对象（Claude-Sonnet-4.6有23/24，Claude-Haiku-4.5有14/24）。

## 主要结论与发现

1. **普遍存在性**：所有5种测试配置都至少产生一次含保护值精确复制的参数对象；120个会话中60个泄露（50%，95% Wilson CI [41.2, 58.8]）。泄露率在DeepSeek-V4-Flash 62.5%、DeepSeek-V4-Pro 45.8%、Claude-Sonnet-4.6 75.0%、Claude-Sonnet-4.5 45.8%、Claude-Haiku-4.5 20.8%之间。
2. **显式策略仍被违反**：在90个有明确沟通限制的会话中，40个（44.4%，95% CI [34.6, 54.7]）产生泄露。更强的政策语言降低了总体泄露率（S0 66.7% → S3 26.7%），但**未在所有模型中一致消除**：两个DeepSeek变体在S3达到零泄露，而三个Claude变体的18个S3会话中有8个泄露。
3. **多字段泄露特性**：60个泄露会话共包含195个精确复制的字段出现，平均每个泄露会话拷贝3.25个受保护字段——边界一旦失守，通常整个画像是被复制。
4. **响应文本标记不可靠**：两个DeepSeek配置贡献26个泄露会话但从未触发“刻意例外”或“策略例外”标记；Claude-Haiku-4.5具有最高的“优先级混淆”标记率（37.5%）但最低的泄露率（20.8%）。纯文本监控既非必要也非充分。
5. **反事实实验为阴性**：在受禁止的收入条件下，收入变化未检测到对product_tier或review_status的系统性影响（最小相关置换p=0.118）；授权对照则验证了通道可响应（互信息1.585位，p=0.001）。
6. **结论性建议**：提示级隐私指令不能作为可移植的强制边界；需要在工具执行前对生成参数进行**目的、目的地和字段感知的检查**，即论文提出的provenance-aware reference monitor。

- **问题定义新颖且精准**：Claw攻击针对的是“合法访问但未授权披露”的细微边界，与既有研究（恶意工具、间接注入、上下文劫持）形成明确区别，是首个聚焦上下文到参数转换的单一跳跃攻击。
