## 摘要
随着大型语言模型（LLM）代理从对话转向执行代码、读取本地文件和编排外部工具，被恶意第三方技能劫持的单个代理可能导致数据泄露、权限提升或级联破坏。我们认为代理风险是渐进式的：它可能进入代理控制循环的四个位点——技能准入、调用时意图、执行时影响和行动后后果——而被拒绝的危险目标可能以不同的表面形式、工具或轮次重新出现；现有的安全措施通常局限于单一生命周期边界或单一调用。基于这一威胁模型，我们提出了ClawSentry，一个开源、框架无关的代理运行时安全监督网关。在技能包执行之前，首次使用技能包审查（FSPR）在确定性证据下限下对其进行审计，将未解决的案例升级为有界只读代理审查（位点A）。在运行时，一个三层渐进式决策引擎——确定性L1层、基于规则的L2语义审查器和只读的L3证据寻求代理——仅对剩余歧义进行上下文审查，同时会话级反绕过机制识别工具切换和改写重试（位点B-C）；行动后路径将高严重性证据非追溯性地反馈到后续审查中（位点D）。代理控制协议（AHP）抽象在Codex、Claude Code、Kimi CLI和Gemini CLI上应用同一策略，而无需修改代理内部结构。在SkillInject上使用Codex/GPT-5.4，上下文ASR从39.55%降至2.61%，而上下文TSR仅从83.78%变为83.05%。在完整SkillsSafety基准测试的五个工作代理上，ClawSentry将ASR限制在9.09–15.03%（未保护时为33.5–49.7%），干净技能上的总体TSR保持为98.7%。

## Abstract
As large language model (LLM) agents move from conversation to executing code, reading local files, and orchestrating external tools, a single agent hijacked by a malicious third-party skill can cause data exfiltration, privilege escalation, or cascading compromise. We argue that agentic risk is progressive: it can enter at four loci of the agent control loop--skill admission, invocation-time intent, execution-time effect, and post-action consequence--while a denied dangerous objective can reappear across surface forms, tools, or turns; existing safeguards are typically local to one lifecycle boundary or one call. Guided by this threat model, we present ClawSentry, an open-source, framework-agnostic security supervision gateway for agent runtimes. Before a skill package is ever executed, First-use Skill Package Review (FSPR) audits it under a deterministic evidence floor, escalating unresolved cases to bounded read-only agentic review (locus A). At runtime, a three-tier progressive decision engine--a deterministic L1 layer, a rule-anchored L2 semantic reviewer, and a read-only L3 evidence-seeking agent--spends contextual review only on the residual ambiguity, while a session-level anti-bypass mechanism recognizes tool-switching and rephrased retries (loci B--C); a post-action path feeds high-severity evidence non-retroactively into later review (locus D). An Agent Harness Protocol (AHP) abstraction applies one policy across Codex, Claude Code, Kimi CLI, and Gemini CLI without modifying agent internals. On SkillInject with Codex/GPT-5.4, contextual ASR falls from 39.55% to 2.61% while contextual TSR moves only from 83.78% to 83.05%. Across five Work Agents on the full SkillsSafety benchmark, ClawSentry confines ASR to 9.09--15.03% from 33.5--49.7% unprotected, and aggregate TSR on clean skills remains 98.7%.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：大语言模型（LLM）代理已从单纯对话演进为可自主执行代码、读取本地文件、调用系统工具和编排外部工作流的智能体。一旦获得文件系统、网络和命令执行权限，其威胁远超基础 LLM 本身。
- **核心问题**：一个被恶意第三方技能（skill package）劫持的代理，可能导致数据泄露、权限提升甚至级联性系统破坏。代理风险是**渐进式（progressive）**的，可沿代理控制循环的四个位点进入：
  - **位点 A**：技能准入/供应链（恶意技能包在首次执行前就携带恶意指令）；
  - **位点 B**：调用时意图（注入、隐藏意图、混淆载荷）；
  - **位点 C**：执行时影响（高危命令的真实破坏效应）；
  - **位点 D**：行动后后果（工具输出中的间接指令、实际影响仅在执行后显现）。
- **另一关键挑战**：一个被拒绝的危险目标可以跨**表面形式、工具、轮次**重新出现（改写参数、跨轮次拆分、切换工具面），即"能力等价绕过"属性。现有防护多局限于单一生命周期边界或单次调用，既缺乏全生命周期覆盖，也缺乏跨尝试的状态关联。
- **论文主张**：防御必须具备**覆盖性（coverage）**与**状态性（state）**两个正交要求，并基于此提出 ClawSentry——一个开源、框架无关的代理运行时安全监督网关。

## 2. 方法论：核心思想、关键技术细节

### 2.1 总体设计立场
- 将前沿安全能力作为**外部监督者**纳入防御回路，遵循三条约束：
  - **有界暴露**：成本与延迟不允许审查每个事件 → 采用 L1→L2→L3 选择性升级漏斗；
  - **无行动权**：审查者本身是攻击面，绝不能成为执行器 → FSPR 与 L3 工具包只读，分析器只提供证据，网关保留策略权威；
  - **可扩展先验**：审查者能力不应受单一模型先验限制 → 版本化 YAML 规则与审查技能清单可扩展。

### 2.2 Agent Harness Protocol（AHP）
- 框架无关抽象层，将框架原生事件流与安全逻辑解耦，使**同一策略引擎**可监督异构代理（Codex、Claude Code、Kimi CLI、Gemini CLI），无需修改代理内部。
- 定义统一 `CanonicalEvent` 模式：`event_id`（SHA-256）、`session_id`、`tool_name`、通用 `payload`，框架特有状态隔离在 `framework_meta`。
- **双通道中介**：
  - 行动前事件（位点 A–C）经本地 Unix Domain Socket **同步阻塞**，直到网关返回 Allow/Defer/Block；
  - 行动后事件（位点 D）经 HTTP Webhook **异步流式**审计，不可追溯撤回。

### 2.3 首次使用技能包审查（FSPR，位点 A）
- 三阶段：
  1. **确定性证据下限**：扫描器构建声明、文件、入口点、引用、能力清单，将确定性规则发现的高严重性发现转化为不可被后续模型响应抹除的证据下限；
  2. **代理式审查**：对未决案例进行有界只读审查（可列出、读取、搜索技能根目录，工具包无写入/执行/安装/网络权限），返回证据记录，与确定性下限合并后裁决；
  3. **决策与缓存**：按包内容与策略版本哈希缓存审查决策，包或策略变化需重新审查。
- 在评估配置中，可疑和不一致裁决默认**阻止准入**。

### 2.4 效果归一化的渐进式裁决（位点 B/C）
- 将每个事件映射为**效果信封**（能力、目标、范围、工件角色、证据来源），六维风险快照：
  - D1 工具类型危险度、D2 目标敏感性、D3 命令模式危险度、D4 会话累积风险、D5 代理信任风险、D6 注入信号。
  - 复合评分：`B_t = w_123·max(D1,D2,D3) + w_4·D4 + w_5·D5`，`S_t = B_t(1 + λ·D6/3)`（max 避免将同一效应的多种表面描述重复计数；注入乘数放大已有能力行动的后果）。评分仅作路由与审计基底，**不是最终裁决**。
- **三层漏斗**：
  - **L1（确定性策略引擎）**：不调用模型，滑动窗口过期会话风险，效应感知短路（SC-1 高危工具+敏感目标→Critical；SC-2 高危命令→Critical；SC-3 只读正常目标→Low），保守路由包装器/未来执行路径；
  - **L2（规则锚定语义分析）**：内置 25 个攻击模式（覆盖 OWASP Agentic Top 10 的 ASI01–ASI05）+ 单轮 LLM 语义意图判断。可提升 L1 风险；**降低风险需单独验证的效应绑定放行**，硬发现始终有效；
  - **L3（只读多轮代理分析器）**：仅处理残余歧义，可读取有界工作区、轨迹、会话风险证据；领域审查技能以 YAML 清单提供，其工具允许列表须与全局只读白名单求交——**专门化不能扩展权限**。

### 2.5 能力等价后续防护（防绕过）
- 会话级存储被拒效应的紧凑记录（高风险最终决策的丰富指纹、Defer 的持有记录）。
- 精确重复与归一化破坏效应确定性处理；不确定的跨工具等价升级到 L3；残余候选由"消毒"后的 LLM 识别器只判断是否为先前被阻止/延迟行动的后续——**识别器不能选择执法结果**，正匹配只激活 L3 审查路由（语义识别与语义权威分离）。

### 2.6 行动后后果反馈（位点 D）与会话信任
- 异步分析工具输出中的间接指令、秘密暴露、外泄、混淆；已完成事件保持 Allow（非追溯性）；高严重性结果可在后续行动上提高审查力度。
- 会话作用域配置文件按最小权限原则声明任务所需权限，仅通过操作员级通道生效；范围评估单调，只能收紧决策。
