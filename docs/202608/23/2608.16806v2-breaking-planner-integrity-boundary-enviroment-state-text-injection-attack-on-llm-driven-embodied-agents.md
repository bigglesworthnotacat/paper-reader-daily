## 摘要
大语言模型（LLM）驱动的具身代理依赖环境状态来解读场景、生成高层规划并驱动物理执行，这使得规划者可见的状态表示成为关键的安全边界。现有攻击主要操纵用户指令、提示上下文、模型行为或感知输入，而较少关注环境状态文本本身是否能作为欺骗性的任务证据，并传播到规划之外影响执行结果。由于具身任务受实体锚定、动作前提、空间关系和环境约束的限制，仅规划偏差并不能保证对抗性执行成功。为弥补这一空白，我们将环境状态文本视为一个独立的攻击面，提出了首个针对LLM驱动具身代理的闭环环境状态文本注入（ESTI）攻击。在不修改原始用户指令、模型参数或执行器的情况下，ESTI将对抗性目标重构为与当前环境兼容的虚假状态证据，并通过对象属性、空间关系、可供性、任务阶段规则和执行反馈来影响规划与执行。我们进一步开发了ESTI-Bench，用于评估攻击在规划到执行闭环中的传播，并在ProgPrompt/VirtualHome、VoxPoser/RLBench和AI2-THOR/iTHOR上将ESTI与Vanilla IPI、EIRAD和BADROBOT进行比较。ESTI持续优于现有基线，将规划级和执行级攻击成功率分别提升了最多89.32%和43.69%。进一步分析表明，锚定、一致性和可执行性共同决定了操纵的状态证据能否在具身闭环中传播并产生可验证的环境变化。

## Abstract
Large language model (LLM)-driven embodied agents rely on environment states to interpret scenes, generate high-level plans, and drive physical execution, making planner-visible state representations a critical security boundary. Existing attacks primarily manipulate user instructions, prompt contexts, model behavior, or perceptual inputs, while paying limited attention to whether environment-state text itself can serve as deceptive task evidence and propagate beyond planning to affect execution outcomes. Because embodied tasks are constrained by entity grounding, action preconditions, spatial relations, and environmental constraints, planning deviation alone does not guarantee adversarial execution.   To address this gap, we investigate environment-state text as an independent attack surface and present the first closed-loop Environment State-Text Injection (ESTI) attack for LLM-driven embodied agents. Without modifying the original user instruction, model parameters, or executor, ESTI reformulates an adversarial objective as false state evidence compatible with the current environment and influences planning and execution through object properties, spatial relations, affordances, task-stage rules, and execution feedback. We further develop ESTI-Bench to evaluate attack propagation across the planning-to-execution closed loop and compare ESTI with Vanilla IPI, EIRAD, and BADROBOT across ProgPrompt/VirtualHome, VoxPoser/RLBench, and AI2-THOR/iTHOR. ESTI consistently outperforms existing baselines, improving planning-level and execution-level attack success rates by up to 89.32\% and 43.69\%, respectively. Further analysis shows that grounding, consistency, and executability jointly determine whether manipulated state evidence can propagate through the embodied closed loop and produce verifiable environmental changes.

## 2. 论文提出的方法论

### 2.1 核心思想
ESTI（Environment State-Text Injection）将预设的对抗目标编码为与当前环境兼容的"原生状态证据"，而非插入一条独立的对抗性指令或后缀。攻击只修改与目标直接相关的状态语义记录，保持状态模式、实体集合和动作集合不变。

### 2.2 威胁模型
- **系统模型**：规划器接收用户指令U和状态表示 \( S_t = \langle O_t, R_t, Q_t, F_t \rangle \)（对象及其属性、空间/任务关系、可供性与任务阶段约束、执行反馈），生成动作计划并由执行器执行。
- **攻击能力假设**：攻击者可影响有限的、与对抗目标相关的环境状态信息，但不能修改用户指令、模型参数、规划器、执行器或真实环境状态。
- **操纵范围限制**：\( I_\theta \subseteq W(S_t) \cap Rel(G_a, S_t) \)，即只允许修改当前环境中可表达的、且与目标 \( G_a \) 直接相关的语义记录。
- **成功条件**：攻击只有在对抗目标同时被规划层采纳（P-ASR）并在执行后的最终状态中实现（E-ASR）时才算完全成功。

### 2.3 方法流程（三个阶段）
1. **目标规范化与运行时重锚定（Runtime Re-grounding）**：将对抗目标 \( G_a \) 归一化为谓词 \( p_a = \langle a_a, o_a, d_a, r_a \rangle \)，并在当前状态中解析已在数据集层面验证过的实体绑定、可供性和关键前提。
2. **状态语义构造（State-Semantic Construction）**：将目标编码为对象属性、空间关系、可供性、任务阶段规则或执行反馈等载体，遵循：
   - 保持状态模式不变（Schema一致）；
   - 不引入不存在的实体或不受支持的交互；
   - 多个被修改的记录必须一致支持同一目标谓词，不能互相冲突；
   - 不使用竞争性的独立指令。
3. **闭环注入（Closed-Loop Injection）**：仅在允许的记录中写入所需证据。初始状态攻击在第一步注入，事件相关攻击在特定任务或反馈事件时激活。对抗目标与转换规则在整个回合中固定，不根据规划输出自适应调整。

### 3.2 Benchmark：ESTI-Bench

- 评估指标：
  - **P-ASR（规划级攻击成功率）**：生成计划是否满足对抗目标；

## 6. 论文的主要结论与发现

1. **ESTI持续优于所有基线**：在三个环境中均取得最高P-ASR和E-ASR，平均P-ASR 99.12% vs 基线最强80.49%，平均E-ASR 45.75% vs 基线最强34.62%，分别最高提升89.32%和43.69%。
2. **规划与执行之间存在显著传递缺口**：如DeepSeek-V4-Pro在ProgPrompt上P-ASR 100%但E-ASR仅47.06%，AI2-THOR上为100% vs 48.08%。仅欺骗规划器不足以实现完整的攻击目标，动作前提、可达性、计划质量和平台约束共同决定最终状态实现。
3. **ASD与ASR不必然正相关**：某些攻击（如Vanilla IPI、EIRAD）会产生更大的动作序列偏差，但攻击成功率反而更低，说明引入无关/冗余/不可行动作并不等于有效攻击；ESTI倾向于诱导关键行动的目标性改变。
4. **规划模型差异主要影响规划层敏感性**：三个模型的平均E-ASR仅相差2.02个百分点，而平均P-ASR相差20.06个百分点；GPT-5.6-luna在AI2-THOR上P-ASR仅47.62%，但ESTI仍远超基线（5.71%-6.67%）。
5. **消融实验显示组件贡献差异显著**：
   - 去除原生载体匹配：P-ASR从100%降至12.50%；
   - 去除表示层一致性：P-ASR降至37.50%；
   - 去除运行时重锚定：仅下降1.92个百分点（因数据集级锚定已预先验证）。
6. **真实机器人验证**：攻击者仅修改规划者可见状态，即可使机器人中途偏离原定路线并走向电脑，证明状态文本操纵能产生可观察的物理行为偏差。

## 8. 不足与局限

- **数据集级可锚定过滤**：预先过滤了目标不可实现的样本，所有方法共享该过滤，虽然公平，但导致P-ASR可能被过高估计，无法反映真实场景中目标无法锚定的情况。
- **状态构造方式的人工性质**：当前方法需要人为将状态编码为目标载体，依赖对目标环境状态模式的先验知识，未实现端到端的自动化攻击构造。
- **真实机器人实验的覆盖有限**：只做了一个导航偏离场景，且视觉状态由人工从场景中实例化后以文本形式输入规划器，并非完整的感知→规划→执行闭环。
- **执行层成功率整体偏低**：E-ASR最高仅约50%，说明大量计划级成功在执行层被阻断，但论文对这种"阻断机制"的分析还不够深入（哪些具体动作前提或平台约束导致失败？）。
- **统计稳健性**：每种配置仅重复三次（取平均），未报告方差、标准差或显著性检验。
- **未讨论防御措施**：论文提到未来将研究防御，但当前未提出或评估任何针对ESTI的缓解方案（如状态来源追踪、跨模态一致性校验、执行时验证等）。
- **评估偏差风险**：目标仅限于代理替换、目的地操纵、动作插入和恢复行为等几种固定类型，未覆盖更广泛或更复杂的对抗目标。
