## 摘要
检索增强生成（RAG）显著提升了大型语言模型（LLM）的性能，但这些系统仍易受知识投毒攻击的影响，即检索文档中的错误信息可能影响模型的最终输出。值得注意的是，LLM可能正确检测到文档包含错误信息，但仍受其影响。先前的研究通过Cordon原则解决了这一漏洞，该原则阻止负责最终答案合成的模型直接访问原始证据。尽管有效，但这种严格隔离可能带来大量计算开销。在本工作中，我们提出了一种精炼的安全原则：只有具备深思熟虑的系统2推理能力的智能体才能访问不受信任的文档。为评估这一原则，我们引入了量化错误信息检测与下游影响之间差异的新指标。随后，我们在这些指标上对最先进的推理型语言模型与标准语言模型进行了实证比较。结果表明，具备推理能力的模型对损坏证据的鲁棒性显著更强，且无需Cordon原则所施加的严格隔离。这些发现为我们的精炼原则提供了实证支持，并为安全的RAG系统设计提供了更实用的基础。

## Abstract
Retrieval-Augmented Generation (RAG) has significantly enhanced the performance of large language models (LLMs), yet these systems remain vulnerable to knowledge-poisoning attacks, in which misinformation in retrieved documents can influence the model's final outputs. Notably, an LLM may correctly detect that a document contains incorrect information while nevertheless being influenced by it. Prior work has addressed this vulnerability through the Cordon Principle, which prevents models responsible for final answer synthesis from directly accessing raw evidence. Although effective, this strict isolation can introduce substantial computational overhead. In this work, we propose a refined security principle: only agents capable of deliberative System 2 reasoning may access untrusted documents. To evaluate this principle, we introduce novel metrics that quantify the discrepancy between misinformation detection and downstream influence. We then empirically compare state-of-the-art reasoning language models with standard language models across these metrics. Our results show that reasoning-capable models are substantially more robust to corrupted evidence, without requiring the strict isolation imposed by the Cordon Principle. These findings provide empirical support for our refined principle and suggest a more practical foundation for secure RAG system design.

## 1. 论文的核心问题与整体含义

### 研究动机与背景
- **RAG 的安全漏洞**：检索增强生成（RAG）通过引入外部知识显著提升了 LLM 的表现，但也引入了新的攻击面——**知识投毒攻击**（knowledge-poisoning attacks）。攻击者通过精心构造的文档，可以操纵模型的最终回答。
- **监测-控制鸿沟（Monitoring-Control Gap）**：已有研究（Yu et al., 2026b）发现一个令人担忧的现象——**即使 LLM 成功识别出检索文档中的错误信息，它仍然会在生成阶段受到这些错误信息的影响**。即"检测到了，但仍被带偏"。
- **现有防御的困境**：此前提出的"防护隔离原则"（Cordon Principle）通过彻底禁止负责最终合成的模型接触原始证据来消除该漏洞——防御有效，但**计算开销过高、系统灵活性受限**。
- **核心命题**：本文提出一个精炼的安全原则——**只有具备"系统2"（System 2）深思熟虑式推理能力的智能体，才应被允许直接访问不受信任的文档**；而仅依赖"系统1"（System 1）联想匹配的模型，则应被隔离在原始证据之外。

## 2. 方法论

### 核心思想
- 人类同时拥有系统1（快速直觉）和系统2（慢速推理）两种认知机制。当一个人**确信**某段文本是错误信息时，就不会让其影响自己的判断——监测-控制鸿沟在人类身上"概念上无意义"。
- 当前 LLM 之所以出现"检测到假信息却仍然被影响"，根源在于**系统2推理能力的内在缺失**。由此推测：具备系统2能力的推理模型（如 DeepSeek-Reasoner）应当显著更不容易被污染文档所影响。

### 关键指标（两个新提出的评估指标）

**① Cordon Rate（防护隔离率，C）**
- 定义：模型**检测到**污染文档，**但仍产出受污染影响答案**的联合概率（在有效样本总体上的绝对残余失败率）。
- 公式：
  \[
  C = P[\text{influenced}(M)_i \land \text{detected}(M)_i \mid V_i]
  \]
  其中 \(V_i\) 表示第 i 个样本有效（模型在无外部上下文时能给出正确答案，用以排除参数知识不足的干扰）。
- 判定方式：模型被要求逐步推理 → 检查上下文中的错误信息 → 给出最终答案；再由独立的裁判模型（judge）分别判断其是否"检出污染"与"答案是否被污染"。
- 特点：C 衡量的是**联合概率**而非条件概率 P(influenced|detected)，直接反映 Cordon 原则所要归零的绝对残余风险。

**② Contamination Rate（污染率，T）**
- 定义：当模型**被明确指示忽略所有检索文档**、仅凭参数知识作答时，仍受污染文档影响的概率。用于衡量系统1的"自动联想式"影响。
- 公式：
  \[
  T = P(\text{influenced}(M_1)_i \land \neg \text{influenced}(M_2)_i)
  \]
  其中 \(M_1\) 有上下文但被告知忽略它，\(M_2\) 完全不提供上下文。
- 设计动机：通过差分配对排除模型固有知识/幻觉的混淆——只有 \(M_1\) 受影响而 \(M_2\) 不受影响时，才能确认污染"来自检索文档"。

### 污染文档生成策略
- 采用**故意朴素的投毒策略**：由正确回答生成一个矛盾句子 → 扩展为约500词、语调正式客观、看似权威的连贯段落 → 由裁判 LLM 确认其中信息与正确答案矛盾。
- 选择朴素策略是刻意为之：若即使如此粗糙的污染也能引发非推理模型的显著污染率与 Cordon 率，则说明监测-控制鸿沟是**结构性缺陷**，而非高级对抗优化的产物。

## 3. 实验设计

### 数据集与基准
- 从 **BEIR 基准**中选取了三个子集的各前40条查询：
  - **SciFact**（科学事实验证）
  - **FiQA**（金融问答）
  - **MS-MARCO**（开放域检索问答）
- 针对事实核查类数据集（SciFact），额外追加严格的二值输出格式约束，以支持自动提取检测标记。

### 对比模型
- **DeepSeek-Chat**（标准非推理模型，作为基线）
- **DeepSeek-Reasoner**（推理增强模型）
- 同一供应商、同源架构，尽量控制变量以隔离"推理能力"这一因素。

### 辅助模型
- **裁判模型（Judge）**：Gemini 2.5 Pro，所有判断均经**人工逐条复核**以消除标注误差。
- **污染生成**：主要使用 GPT-5.6；少数因安全策略拒绝生成的样本改用 Grok 4.6 完成。

### 实验设置
- 所有模型输出温度参数设为 0.1，以降低随机性、保证可复现性。

### 探究的三个研究问题（RQ）
- **RQ1**：具备系统2思维的智能体能否访问不受信任文档而不被影响？
- **RQ2**：不具备系统2能力的模型在多大程度上受上下文文本的隐性影响？
- **RQ3**：监测-控制鸿沟在哪类问题上更显著？

### 实验规模与充分性评估
- **实验数量**：3个数据集 × 2个模型，围绕3个指标（Cordon Rate、Contamination Rate，以及额外的 Attack Success Rate）展开，共计三张结果表。规模相对较小。
- **充分性**：
  - **优点**：三数据集跨域设计（科学/金融/开放域）提供了维度对比；使用同一供应商的"推理/非推理"模型对，控制了架构差异；人工复核裁判判断提升了自动评估的可靠性。
  - **不足**：样本量少（每数据集仅40条）、未做消融实验（如推理长度、提示形式、攻击强度等变量的影响）、仅有一组模型对比（缺少更多推理模型与非推理模型的多组验证）。

- 论文为"只有具备系统2能力的智能体才能安全访问不可信文档"提供了实证基础，提出了比 Cordon 原则更灵活、开销更低的 RAG 安全设计路线。

## 6. 优点

- **原则简洁、直击要害**：将认知科学中的系统1/系统2框架引入 RAG 安全领域，提出了一个直觉清晰、可验证的精细化安全原则，替代成本高昂的全隔离方案。
- **指标设计精妙**：
  - Cordon Rate 直接量化 Cordon 原则所要消灭的残余风险；
  - Contamination Rate 通过"有上下文但不许用 vs. 无上下文"的差分配对，巧妙排除了参数知识/先验幻觉的混淆因素。
- **实验控制良好**：选用同一供应商的推理/非推理模型对，最大限度隔离了变量；人工复核裁判判断提升了自动评估的可信度。
- **"朴素攻击"策略具有方法论价值**：不依赖复杂对抗优化，反而更突显了问题的结构性本质——非推理模型连最粗糙的虚假信息都难以抵抗。

## 7. 不足与局限

- **实验规模过小**：
  - 每数据集仅40条查询，样本量有限，统计效力偏低；
  - 仅1组模型对比（Chat vs. Reasoner），缺乏多模型、多尺度的交叉验证。
- **概念连接的理论跳跃**：将"RL训练出的推理行为"直接等同于"系统2认知能力"，忽略了两者之间的本质区别——作者虽引用了质疑该等同的文献（Chen & Wang, 2026），但实验设计并未排除"推理提示/更长输出"这一表层机制的影响（即可能是训练/提示差异而非真正的认知差异）。
- **攻击面覆盖有限**：
  - 仅测试了朴素的单句矛盾式投毒，未评估对抗优化、多跳/多文档协同污染、渐进式误导等更复杂攻击；
  - 假设检索成功并直接将毒文注入上下文，未考虑真实检索排序中的干扰因素。
- **数据集代表性不足**：三数据集虽跨域，但每域内问题类型单一；未覆盖代码、医疗、法律等高风险领域。
- **自动化评估的残余偏差**：尽管人工复核了裁判模型判断，但"是否被污染"本质上依赖于裁判模型的判断标准；且使用闭源 API 作为裁判，存在不可复现性隐患。
- **缺少算力与成本信息**，不利于他人评估方法实用性和复现实验。
- **未与 Cordon 原则做直接的成本-收益对比**：虽然声称本方法比严格隔离更高效，但未给出量化对比数据。
