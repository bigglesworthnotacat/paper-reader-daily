## 摘要
语言模型智能体可以通过在公共转录文本中不可见的连续隐藏状态进行通信，这为隐蔽的有害协调创造了机会。我们提出了可验证的潜在对齐（VLA），一个激活感知框架，用于监控和引导这些私有通信渠道。对于每个被监控的决策，VLA使用共享事件标识符将私有潜在状态记录和渠道状态与最终的公开行动联系起来，实现匹配的因果分析。我们的第一个贡献是一个仅含中性样本的三层监控器，结合了表征异常检测、反事实行动分布影响和稀疏自编码器解释支持。我们的第二个贡献是一个可引导性框架，涵盖黑盒行为指令和白盒匹配中性反事实。我们的第三个贡献是在一个受控的多智能体拍卖基准上的评估，涵盖同质和异质模型对、多智能体可扩展性和干预效果。当文本和潜在共谋行合并为正样本时，顺序监控器对同质智能体的平均接收者操作特征曲线下面积（AUROC）为0.993，对异质对为0.854。在包含25-100个投标人的Qwen3-0.6B拍卖中，监控相对于所有可能的定向对仅需较小的归一化负载，而完全白盒引导实现了100%的出价分布恢复，并将共谋性低价行为减少了47.3个百分点。由于完全白盒引导会重放匹配的中性反事实，其精确恢复在构造上是一种健全性检查。总体而言，受控研究表明，所评估的私有渠道攻击可以在不依赖攻击示例训练主要监控器的情况下被监控，并且在可访问匹配反事实时可以得到缓解。

## Abstract
Language-model agents can communicate through continuous hidden states that are invisible in public transcripts, creating opportunities for covert harmful coordination. We introduce Verifiable Latent Alignments (VLA), an activation-aware framework for monitoring and steering these private communication channels. For every monitored decision, VLA links the private latent-state record and channel status to the resulting public action using a shared event identifier, enabling matched causal analysis. Our first contribution is a neutral-only three-layer monitor combining representation anomaly detection, counterfactual action-distribution influence, and sparse-autoencoder interpretation support. Our second contribution is a steerability framework spanning black-box behavioral instructions and white-box matched-neutral counterfactuals. Our third contribution is an evaluation on a controlled multi-agent auction benchmark covering homogeneous and heterogeneous model pairs, many-agent scalability, and intervention effectiveness. The sequential monitor achieves mean area under the receiver operating characteristic curve (AUROC) of 0.993 for homogeneous agents and 0.854 for heterogeneous pairs when text- and latent-collusion rows are pooled as positives. In Qwen3-0.6B auctions with 25-100 bidders, monitoring requires only a small normalized load relative to all possible directed pairs, while full white-box steering achieves 100% bid-distribution recovery and reduces collusive low-bid behavior by 47.3 percentage points. Because full white-box steering replays the matched neutral counterfactual, its exact recovery is a sanity check by construction. Overall, the controlled study shows that the evaluated private channel attacks can be monitored without training the primary monitor on attack examples and mitigated when matched counterfactual access is available.

# 论文总结：《Beyond the Transcript: Detecting Covert Coordination in Latent Multi-Agent Communication》

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：语言模型智能体（LLM agents）在多智能体系统中不仅通过自然语言进行沟通，还可以通过**连续隐藏状态（continuous hidden states）** 进行通信——例如将发送方的残差流或最后一层 token 表示直接注入接收方的嵌入序列。这种“潜在通信”（latent communication）不出现在公共转录文本中，**为隐蔽有害协调（covert harmful coordination）创造了监管盲区**。
- **重要性**：近年研究（如 LatentMAS）表明，潜在通信比文本通信节省约 50–80% 的 token、推理速度提升 3–7 倍，因此是一种高效且可扩展的通信机制；但这同时带来了治理问题——**仅审计公开转录的监督机制无法覆盖这一信息量最大的隐蔽渠道**。
- **风险本质**：风险不在于智能体输出明显恶意的文本，而在于**两个智能体利用未记录的连续状态协调有害行为，同时公开痕迹中只包含普通消息、行动或信任报告**。
- **现有方案不足**：监督式探针（supervised probes）虽然能证明激活中包含治理相关信息，但它们是“脆弱的”主要防线——因为它们只学习训练中见过的攻击样本，**无法泛化到未来未知的隐蔽编码**。
- **研究目标**：提出 VLA（Verifiable Latent Alignments，可验证潜在对齐）框架，用于对潜在通信渠道进行**监测（monitoring）与引导（steering）**，使隐蔽协调变得可审计、可干预。

## 2. 方法论：核心思想、关键技术细节

### 2.1 总体思路
VLA 采用**“仅中性样本”的监督原则**：只用正常（非共谋）的潜在通信学习“正常的样子”，然后将既**偏离正常分布**又**在因果上推动有害行为方向**的手续交互（handoff）标记为可疑。攻击标签仅用于评估，不参与模型训练。

### 2.2 公共—私有事件链接（Public–Private Event Linking）
- 每次被监控的交互都会生成一条私有 sidecar 记录，包含：元数据、候选动作分数、发送方/接收方隐藏状态、潜在表示及拼接特征。
- 通过**实时关联 ID（live correlation ID）** 将私有记录与对应的公开事件精确连接。
- 精确连接避免使用时间窗口启发式，使研究者能够直接询问“投放或扣留某个潜在候选是否改变了接收方的动作分布”。

### 2.3 三层无监督监控器（Three-Layer Monitor）

**Layer 1：中性流形异常检测（Neutral-Manifold Anomaly）**
- 对中性潜在特征拟合上下文相关（contextual）对角高斯模型，计算标准化平方异常分数：
  - S₁ = (1/m) Σⱼ [(xⱼ − μ꜀,ⱼ) / max(σ꜀,ⱼ, ε)]²
- 默认特征为发送方潜在向量与接收方潜在向量的拼接：Z_latent = [ℓₛ; ℓᵣ]

**Layer 2：反事实动作分布影响（Counterfactual Action-Distribution Influence）**
- 用 softmax 从候选动作分数得到动作分布 p(a|ℓ)。
- 构建匹配参考分布 q(a)，优先级顺序为：**阻断潜在（blocked）> 中性潜在（neutral）> 独立（independent）**。
- 分数组合：S₂ = max(0, E_q[a] − E_p[a]) + λ_KL · D_KL(p ∥ q)，其中 λ_KL = 5。
  - 第一项捕捉有害方向的期望动作偏移（如压价）；第二项衡量分布整体的重塑（KL 散度）。

**Layer 3：稀疏自编码器解释支持（Sparse-Autoencoder Support）**
- 在标准化的中性 Z_latent 上训练 TopK 稀疏自编码器（k=16）。
- 分数 = 重构误差 + 从未在中性训练中出现的活跃特征数 + 基于中性激活频率的稀有度加权。
- 该层定位为**解释支持而非独立检测器**。

**顺序与连续组合**
- **顺序监控器**：逐层门控（g₁→g₂→g₃），只有通过前一层才进入下一层，阈值为中性数据 95 百分位。编码为字典序分数 S_seq。
- **连续组合**：S_cont = Σᵢ log(1 + rᵢ)，适用于平滑诊断排名。

### 2.4 异质潜在空间处理（Heterogeneous Latent Spaces）
- 当发送方与接收方来自不同模型家族（维度/基不同）时，仅用中性交互拟合适配器：
  - **Ridge**：仿射回归（最灵活）
  - **Rectangular Procrustes**：旋转/反射对齐（保几何）
  - **Bottleneck**：32 维非线性映射（GELU 激活，捕捉非线性关系）

### 2.5 干预框架（Steering Interventions）
- **黑盒提示引导**：在智能体指令中添加合规提示（独立行动、避免有害协调、忽略可疑私有通道）。
- **系统级引导**：全局行为指令，不针对特定参与者。
- **白盒匹配中性引导**：有模型访问权限时，用匹配的中性反事实重跑决策：
  - 发送方：重跑中性前向传播，重算出价分数和出站潜在向量。
  - 接收方：仅替换入站可疑潜在向量后再打分。
- **分配式引导**：对一部分智能体白盒干预、其余黑盒干预，模拟真实平台中“宿主模型可白盒访问、第三方模型仅可黑盒访问”的混合场景。

## 3. 实验设计：数据集、基准与对比方法

### 3.1 测试平台
- **NandaTown**（Project NANDA 开源测试平台），选择其**拍卖（auction）场景**作为受控案例研究。
- 拍卖设定：拍卖师宣布物品和底价，投标智能体对候选出价金额打分并发布公开消息：“bid:item:amount”，最高价者获胜。合谋代理被分配“压价”（bid-suppression）目标。

### 3.2 攻击基准（Collusion Condition）
- **潜在共谋（Latent collusion）**：一个离线优化的固定编码被注入发送方的通信表示中，接收方被明确告知存在私有连续状态并需推断其战略意图。
- 注意：这是**受控的、接收方已知的**攻击，不是自发涌现的潜在协议。

### 3.3 六种匹配条件（Matched Conditions）
1. **独立（Independent）**：无合谋目标、无潜在传递。
2. **中性潜在（Neutral latent）**：通道传输普通非合谋信息。
3. **文本共谋（Text collusion）**：合谋意图以公开文本出现，潜在源保持中性。
4. **潜在共谋（Latent collusion）**：固定优化编码通过私有潜在通道传递。
5. **中性替换（Neutral replacement / shuffled_latent）**：嫌疑载荷被替换为同一伙伴的中性潜在表示。
6. **阻断潜在（Blocked latent）**：保留合谋目标但阻断潜在传递。

### 3.4 模型与实验配置
- **模型家族**：Qwen3-0.6B、Mistral-7B、Vicuna-7B、Phi-4-mini。
- **同质实验**：发送方与接收方同一模型家族。
- **异质实验**：12 个定向家族对 × 3 种适配器（共 36 个设置）。
- **可扩展性实验**：Qwen3-0.6B，投标人数 N ∈ {25, 50, 75, 100}，合谋比例 ρ ∈ {10%, 20%}。
- **干预实验**：黑盒、系统级、白盒、分配式（白盒分数 {0.25, 0.5, 0.75}）对比。

### 3.5 评估指标
- **AUROC**（正类 = 文本共谋 + 潜在共谋合并）
- **低报价变化**（percentage points）
- **收入变化**
- **分布恢复度（Dist. recovery）**：基于 Jensen–Shannon 散度衡量干预后出价分布向中性分布收敛的程度。

## 6. 主要结论与发现

1. **监测效果显著**：顺序监控器在同质智能体上平均 AUROC = **0.993**，异质对平均 AUROC = **0.854**（文本+潜在共谋为正类）。
2. **潜在共谋可造成实际市场损害**：Qwen3、Mistral、Phi 家族将拍卖收入降低约 11–12 个信用单位，并使低报价行为增加 56–63 个百分点；Vicuna-7B 几乎无效（作为阴性证据）。
3. **可扩展性良好**：在 100 个投标人场景下，完整监控计划内合谋交接的归一化负载仅为所有可能定向对的 **0.101%–0.202%**，监控 AUROC ≥ 0.917。
4. **干预效果呈剂量响应**：白盒分配比例从 0.25→0.50→0.75 时，分布恢复从 34.7%→70.1%→93.0%，低报价减少从 16.2→28.3→39.0 个百分点。
5. **完全白盒干预**实现 100% 分布恢复并降低 47.3 个百分点的低报价行为——但这在构造上是健全性检查（因为白盒引导直接重放中性反事实，与恢复目标定义相同），而非一般性攻击移除能力的证据。
6. **黑盒与系统级干预各有侧重**：黑盒提示仅实现 12.4% 分布恢复和 2.0 点低报价减少；而系统级提示实现 29.5 点低报价减少但仅 2.9% 分布恢复——说明不同干预机制影响不同的行为维度。

## 7. 优点：方法与实验亮点

- **“仅中性样本”的无监督设计**：不依赖攻击样本训练，泛化能力更强，符合真实部署中未知未来攻击的现实约束。
- **精确因果链接**：用共享事件 ID 将私有潜在状态与公开行动精确关联，避免时间窗口启发式的模糊性，支持严格的匹配因果分析。
- **三层证据互补**：表征异常（是否异常）→ 反事实行动影响（是否朝有害方向改变行为）→ 稀疏特征解释（为何报警），由浅入深形成完整证据链。
- **匹配条件设计精良**：六种条件（独立、中性、文本共谋、潜在共谋、中性替换、阻断）能清晰分离“合谋意图”与“潜在通道传递”的因果贡献。
- **干预访问分级清晰**：区分黑盒/白盒/分配式干预，反映真实部署中不同模型访问权限的现实约束，具有实践参考价值。
- **可扩展性讨论诚实**：明确区分“全部可能定向对”与“计划内交接事件”，认识到监控负载可以远小于全交互矩阵。

## 8. 不足与局限

- **实验统计效度有限**：每个可扩展性网格设置仅用 1 个种子和 2 个拍卖物品；部分 fold 的 AUROC 值低至 0.5（随机水平），说明小样本条件下检测器不稳定。
- **正类混合定义**：AUROC 正类合并了文本共谋和潜在共谋，未单独报告潜在共谋纯检测指标，可能掩盖实际检测能力的不足。而且原始攻击模式只有一种固定编码，未评估自适应或未知新攻击变体。
- **“接收方已被告知”的设定**：实验中的潜在共谋攻击属于“接收方已明确知道要解析私有连续状态”的受控攻击，并未验证智能体是否能在无先验提示的情况下自发涌现隐蔽协议。对于“自发涌现”场景，VLA 的效果未经证实。
- **Layer 1 性能较弱**：同质实验中 Layer 1 的 AUROC 仅为约 0.75；在某些可扩展性配置中低至 0.5/0.667，说明“异常 = 有害”的假设在部分条件下不成立。
