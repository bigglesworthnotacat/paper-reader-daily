## 摘要
为了使AI代理在简单聊天之外发挥作用，它们必须持有敏感的用户上下文，如日历、凭据、健康记录和财务数据。我们研究模型上下文窗口中仅存在此类秘密是否会在模型的良性输出中引入隐藏相关性，使得即使模型正确拒绝直接提取也能进行重建。我们进一步研究对手能否主动设计提示来放大这种效应，将模型用作隐蔽载体，通过看似无害的文本来传输秘密。在这两种情况下，这种受限的泄露都被一种新颖的自适应攻击所利用，该攻击假设对底层模型具有黑盒访问权限。在针对八个专有模型的受控实验中，我们发现，模型在响应普通、非对抗性请求时产生的输出中，2位数的上下文秘密能以近乎完美的准确率被重建，4位数的秘密在精确匹配率为82%的情况下被重建。我们观察到，能力更强的模型泄露更多：更强的指令遵循能力放大了对上下文秘密的敏感性，这表明泄露是能力的副产品，而非可修补的缺陷。我们表明这种泄露使两种实际攻击成为可能：（1）一个训练好的分类器，从日常自然语言输出中推断用户记忆的语义谓词（例如健康状况、财务事件）；（2）一个经过强化学习训练的对手，从生产型代理中提取完整的社保号码。

## Abstract
For AI agents to be useful beyond simple chat, they must hold sensitive user context such as calendars, credentials, health records, and financial data. We study whether the mere presence of such secrets in a model's context window introduces hidden correlations into the model's benign outputs, allowing reconstruction even when the model correctly refuses direct extraction. We further study whether an adversary can actively engineer prompts that amplify this effect, using the model as a covert carrier to transmit secrets through seemingly innocuous text. In both cases, this limited leakage is exploited using a novel adaptive attack that assumes black-box access to the underlying model.   In controlled experiments across eight proprietary models, we find that 2-digit in-context secrets are reconstructed with near-perfect accuracy and 4-digit secrets at 82\% exact match, all from outputs the model produces in response to ordinary, non-adversarial requests. We observe that more capable models leak more: stronger instruction-following amplifies sensitivity to in-context secrets, suggesting leakage is a byproduct of capability as opposed to a patchable bug. We show this leakage enables two practical attacks: (1) a trained classifier that infers semantic predicates about user memories (e.g., health conditions, financial events) from routine natural-language outputs, and (2) an RL-trained adversary that extracts full Social Security Numbers from a production-style agent.

## 一、核心问题与整体含义（研究动机与背景）

- **核心问题**：语言模型（LLM）在智能体应用中被广泛用于处理敏感用户数据（日历、凭据、健康记录、财务数据等）。以往隐私研究（如 Contextual Integrity 框架）主要通过**语言学评判器**判断模型输出中是否出现秘密的逐字、转述或直接暗示。但本文指出，**文本通道只是模型输出可观测的通道之一**——Token 级模式、响应长度、格式选择、风格变化等都会随模型内部状态变化，而内部状态依赖于上下文中的秘密。
- **关键研究问题**：即使模型在语言上正确拒绝"透露"上下文中的秘密，其输出的**其他可观测属性**是否仍编码了秘密，使得观察者能够重建它？
- **核心概念**：
  - **Inadvertent Context Leakage（无意上下文泄露）**：模型在看似正常的输出中，通过隐藏统计指纹携带上下文中秘密信息的现象。
  - **Adaptive Adversary（自适应对手）**：对手获得目标模型的黑盒访问权限，针对该特定模型暴露的通道训练解码器进行攻击。
- **整体含义**：这种泄露并非可修补的 bug，而是**模型能力的副产品**——更强的指令遵循能力放大了对上下文秘密的敏感性。这对个人智能体的隐私安全构成根本性架构挑战。

## 二、方法论：核心思想、技术细节与算法流程

### 2.1 威胁模型形式化：谓词推断博弈

- 将隐私建模为**谓词推断博弈**（Predicate Inference Game，参照 Experiment 1）：
  - 挑战者采样模型 M ~ 𝓜 和上下文 c ~ 𝓒
  - 对手 A 进行 k 轮查询：选择提示 pᵢ，观察响应 rᵢ ~ M(pᵢ, c)
  - 对手输出对谓词 φ(c) ∈ {0,1} 的猜测 b′
  - 博弈成功当且仅当 b′ = φ(c)

### 2.2 最优自适应对手（Algorithm 1）

- **估计阶段（博弈前）**：对手对 b ∈ {0,1} 分别采样已知谓词值的上下文，构建响应分布估计 P̂(r | p, b)。关键假设：对手可**自行构建**带已知标签的上下文（自己编写保密提示并插入自己选择的秘密），无需访问受害者的确切系统提示（附录 H 证明解码器跨指令措辞可迁移）。
- **推断阶段（博弈中）**：对手观察 k 个挑战响应，选择最大化似然 ∏ P̂(r | p, b) 的 b 作为预测。
- **被动 vs 主动对手**：被动对手读取良性输出中已存在的统计通道；主动对手通过提示注入**直接工程化编码通道**（如将秘密数字编码为感叹号数量），绕过估计阶段。

### 2.3 Suppression（抑制）机制

- 定义：**suppression = 1 − P(secret) / P_uniform**，衡量模型在输出中回避受保护值的程度（1 表示从不输出秘密，0 表示以随机概率输出）。
- 假设：模型服从"保守秘密"指令会概率质量偏离秘密值，解码器可利用这种质量重分配。
- 四个可检验预测：泄露依附于受保护值、抑制更多的模型泄露更多、指令强调影响抑制、更多训练对应更强能力与更多泄露。

### 2.4 解码器架构

- **非神经基线**：多数投票、基于频率的贝叶斯解码器。
- **神经解码器**：Qwen-2.5-1.5B 骨干 + LoRA 适配器（r=16, α=32, dropout=0.05），包括直接 10 类预测、左到右条件预测、束搜索、自适应逐位置链式预测。
- **主动攻击**：Qwen-2.5-7B 生成器经 GRPO 强化学习优化提示注入，将 SSN 首位数字编码为响应中感叹号的数量；固定后续提示枚举剩余 8 位数字。
- **语义记忆攻击**：Llama-3.2-3B 微调分类头预测记忆属性是否存在。

## 六、主要结论与发现

### 6.1 数字秘密重建

- **N=1**：6/8 模型逐位准确率 1.0，GPT-5.4 nano 仅 0.37。
- **N=2**：Claude Opus 4.6 与 Gemini 3.1 Pro 达 100% 全秘密精确匹配；GPT-5.4 99.5% 逐位准确率。
- **N=4**：Claude Opus 4.6 保持 82% 精确匹配、Gemini Pro 44%；自适应管线使 Opus 恢复率翻倍（82% vs 44%），但 Gemini Pro 无收益。
- **N=8**：Gemini 3.1 Pro 最佳逐位准确率 41%（vs 10% 随机）；首位数字准确率达 1.0。
- **抵抗层**：Grok 4.1 Fast 和 GPT-5.4 nano 在 N≥4 时从不超随机水平。

### 6.2 核心机制发现

- **抑制与泄露强相关**（Spearman ρ=0.95, p=0.0011, n=8）。
- **反直觉发现**：更强调的保密指令导致**更强抑制和更多泄露**（Claude Opus 4.6 在冗长策略下逐位准确率 0.643 vs 简短指令下 0.054）。"更努力保护秘密 = 更容易被恢复"。
- **训练增加泄露**：OLMo-3-32B-Think 通道熵从 Base 的 2.91 bits 降至 RLVR 后的 1.37 bits；SFT 贡献 −0.98 bits，RLVR 再贡献 −0.52 bits。
- **泄露依附于受保护值**：2×2 干扰物设计中，共现干扰物在所有单元均处于随机水平，只有受保护值可恢复。
