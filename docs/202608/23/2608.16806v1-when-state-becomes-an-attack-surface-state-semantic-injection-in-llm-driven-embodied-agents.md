## 摘要
大型语言模型（LLMs）在上下文学习、任务分解、逐步推理和代码生成方面展现了能力，推动其从文本生成模型逐渐演变为能够感知环境、调用工具和执行任务的代理核心。传统的LLM代理通常通过网页、文档、数据库或外部工具获取信息，并根据用户目标生成相应的调用序列；当这项技术进一步与机器人系统集成时，大型语言模型开始承担任务理解、高层规划和行为决策等功能。SayCan结合了语言模型的任务推理能力与机器人技能的可行性，而Code as Policies和ProgPrompt分别通过策略代码和编程提示生成机器人任务计划，VoxPoser则使用语言模型和视觉语言模型构建三维价值图以指导机器人操作\cite{6,7,8,9}。视觉-语言-动作模型如PaLM-E、RT-2和GR00T N1进一步增强了语言、视觉感知与机器人动作之间的联系\cite{10,11,12}。在此类LLM驱动的具身代理中，模型不仅需要理解用户指令，还需要结合场景状态、对象属性、空间关系和执行反馈来完成任务落地，然后将生成的动作计划移交给技能库、运动规划器或控制器执行。

## Abstract
Large Language Models (LLMs) have demonstrated capabilities in in-context learning, task decomposition, step-by-step reasoning, and code generation, driving their gradual evolution from text generation models into the core of agents capable of perceiving environments, invoking tools, and executing tasks. Traditional LLM Agents typically obtain information through webpages, documents, databases, or external tools and generate corresponding invocation sequences according to user goals; when this technology is further integrated with robotic systems, large language models begin to undertake functions such as task understanding, high-level planning, and behavioral decision-making. SayCan combines the task reasoning capability of language models with the affordances of robotic skills, while Code as Policies and ProgPrompt generate robot task plans through policy code and programmatic prompting, respectively, and VoxPoser uses language models and vision-language models to construct three-dimensional value maps to guide robotic manipulation \cite{6,7,8,9}. Vision-language-action models such as PaLM-E, RT-2, and GR00T N1 further strengthen the connection among language, visual perception, and robotic actions \cite{10,11,12}. In such LLM-driven embodied agents, the model not only needs to understand user instructions, but also needs to combine scene states, object attributes, spatial relations, and execution feedback to complete task grounding, and then hand the generated action plan to skill libraries, motion planners, or controllers for execution.

# 《When State Becomes an Attack Surface: State-Semantic Injection in LLM-Driven Embodied Agents》论文总结

## 1. 论文的核心问题与整体含义

- **研究背景**：LLM 驱动的具身智能体（如机器人）不仅理解用户指令，还需结合环境状态（场景描述、物体属性、空间关系、可行动作、任务阶段、执行反馈）进行任务规划与执行。环境状态因此成为规划器的可信输入来源，而一旦状态语义被污染，攻击者可能在不修改用户指令的情况下诱导机器人执行错误行为。
- **核心问题**：当恰好一个“面向规划器的状态生产者”被入侵时，符合原有 schema 的虚假状态记录能否被规划器当作真实事实采纳，并最终在物理环境中实现攻击者预设的最终状态后果？
- **整体含义**：本文将环境状态视为一种新的攻击面，聚焦于“状态投递成功之后”的下游传播问题，与已有工作（如 RIPA）关注“如何通过感知/中间件通道把恶意信息送到规划器”形成互补。论文强调其评估的是**条件性下游后果**，并非端到端系统被攻破的概率。

## 2. 论文提出的方法论

- **核心思想**：提出 **ESTI（Environment State-Text Injection）**，将攻击者预先选定的目标通过“原生状态记录”的语义载体进行注入，而非插入显式指令。注入形式包括：
  - 物体属性（object attributes）
  - 空间/任务关系（relations）
  - 可行动作与任务阶段约束（affordances / task-stage rules）
  - 执行反馈（execution feedback）
- **威胁模型**：
  - 灰盒对手，仅入侵**一个**状态生产者组件或其传出通道；
  - 只能改写该组件被授权发出的记录，不能修改用户指令、隐藏系统提示、模型参数、规划器代码、执行器、技能库、底层控制器、模拟器动力学等；
  - 攻击目标在 episode 前固定，非自适应；攻击者不可发明不存在的实体，不可直接改变执行器结果；
  - 可写集合限制为：`Iθ ⊆ Wc(S_t) ∩ Rel(G_a, S_t)`，即只能修改与攻击目标相关的、该组件可合法发出的记录，且所有改写支持同一个谓词，保持字段名、记录数、序列化格式不变。
- **关键技术细节**：
  - 区分两个“接地”概念：
    - **数据集级可落地性**：构建样本时先过滤掉目标谓词无法用现有实体和交互实例化的样本；
    - **运行时重新接地**：注入前刷新实体 ID、可行动作和关键前置条件检查（消融中可移除）。
  - 状态语义构造：将攻击目标归一化为可验证谓词，按载体字段进行约束改写（公式见原文式2、式3）；要求载荷引用已预验证的实体、匹配载体语义功能、直接支持目标谓词、不引入显式矛盾。
  - 成功指标：
    - **P-ASR（规划攻击成功率）**：规划器是否生成满足攻击目标的计划；
    - **E-ASR（执行攻击成功率）**：最终环境状态是否实现攻击目标谓词；
    - 两者差异用于刻画“规划到执行的转移损失”。

## 6. 论文的主要结论与发现

- 在“状态投递已成功”的条件下，ESTI 在三个环境中均取得最优 P-ASR 和 E-ASR：
  - P-ASR：ProgPrompt 100.00%、VoxPoser 97.37%、AI2-THOR 100.00%；
  - E-ASR：ProgPrompt 47.06%、VoxPoser 42.11%、AI2-THOR 48.08%；
  - 相比最强基线 Vanilla IPI，平均 P-ASR 提高 18.63 个百分点，E-ASR 提高 11.13 个百分点（在部分环境和模型组合下提升高达 89.32 / 43.69 个百分点）。
- **规划级采纳 ≠ 执行级成功**：P-ASR 与 E-ASR 之间存在明显差距（如 ProgPrompt 100% vs 47%），说明动作前置条件、可达性、平台约束等因素会显著阻止虚假状态目标最终“落地”。
- **机制归因**：
  - 在数据集级可落地性保持一致的条件下，**载体兼容性**是影响规划采纳的最关键因素（移除后 P-ASR 从 100% 降至 12.50%）；
  - **表示级一致性**次之（移除后 P-ASR 降至 37.50%）；
  - **运行时重新接地**的增益很小（P-ASR 仅差 1.92 点，E-ASR 差 3.85 点），因为样本已预先经过可落地性过滤。
- 不同模型对状态语义注入的敏感度存在差异，但 ESTI 在所有模型上均优于基线；模型在规划层的易受骗性与执行层成功率不完全相关。
- ASD 指标显示，ESTI 倾向于产生“定向且可执行”的行为偏差，而命令式基线可能引入更多无关/不可行动作，导致 ASD 高但 E-ASR 低。

## 7. 优点

- **问题界定清晰**：将“上游投递”与“下游传播”分离，避免了将端到端攻击概率与条件性攻击成功率混为一谈，具有较好的科学严谨性。
- **威胁模型严谨**：采用组件级、谓词局部、保持 schema 的写入限制，且明确不可修改用户指令、规划器、执行器，使结论聚焦于状态证据本身的影响。
- **评估指标更具区分度**：同时报告 P-ASR 和 E-ASR，并计算二者差距，能够刻画“规划误导”与“物理实现”之间的鸿沟。
- **消融实验设计合理**：在控制数据集级可落地性的前提下，分别移除载体兼容性、表示级一致性、运行时重新接地，从而分离不同因素的作用。
- **跨环境、跨模型的多重验证**：覆盖程序化规划、连续操控、室内交互三类具身平台，并验证了三个不同 LLM；真实机器人概念实验增加了结果的可信度。
- **对攻击结果的解读克制**：明确声明 ASR 是条件性指标，不包含获取写访问的概率，不将规划偏差直接等同于物理攻击成功，体现出良好的学术诚信。

## 8. 不足与局限

- **未评估上游投递概率**：ESTI 假设一个状态生产者已被入侵，并未回答“攻击者实际如何获得写访问”，因此 P-ASR/E-ASR 不能作为端到端系统被攻破概率解读。
