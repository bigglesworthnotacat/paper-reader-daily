## 摘要
持续自我改进需要不断扩大的、自我生成的、多样化的、适应性目标池。对于语言智能体而言，现有的训练环境池（人工精选、静态合成或冻结验证器）在学习者扩展时保持目标分布固定。我们引入了SPADE（自适应合成可执行环境中的自我对弈），一种自我对弈强化学习框架，其中单个LLM扮演两个角色：一个环境设计师，编写完整的长视界训练环境，作为带有OpenAI Gym风格reset()/step()接口的可执行代码；以及一个推理智能体，学习在这些环境中行动。每个环境都是有状态的多轮环境（状态转换、奖励函数和验证代码），因此一个接口即可涵盖推理问题和多步智能体工具使用。推理智能体的遗憾通过其有无特权提示时的奖励差距来估计；在优化这一遗憾信号时，环境设计师学会将目标定位于智能体能力边缘的环境，同时保持其可行性。通过大量实验，我们发现了几个对成功至关重要的组件：将环境设计师基于从大型预训练语料库中采样的文档进行接地，并为其提供累积的环境记忆。扩展到300亿参数模型，SPADE在八个保留的数学、科学、代码和推理基准上，平均比最强固定环境基线高出+5.3；在工具使用设置上，在BFCL-v4多轮上提升+5.7，在ACEBench-Agent上提升+13.9；在游戏设置上，相对最强基线的优势随模型规模增大而增长。通过将环境设计本身变为可学习组件，SPADE向开放式自我改进迈出了具体一步。

## Abstract
Continuous self-improvement requires an ever-expanding pool of self-generated, diverse, adaptive goals. For language agents, existing training environment pools (hand-curated, statically synthesized, or frozen-verifier) keep the goal distribution fixed as the learner scales. We introduce SPADE (Self-Play in Adaptive Synthetic Executable Environments), a self-play RL framework in which a single LLM plays two roles: an Environment Designer that writes complete, long-horizon training environments as executable code with an OpenAI Gym-style reset()/step() interface, and a Reasoning Agent that learns to act in them. Each is a stateful, multi-turn environment (state transitions, reward functions, and verification code), so one interface spans reasoning problems and multi-step agentic tool use. The Reasoning Agent's regret is estimated using the gap between its reward with and without privileged hints; in optimizing this regret signal the Environment Designer learns to target environments at the edge of the agent's capabilities while keeping them feasible. Through extensive experimentation, we find several components critical to success: grounding the Environment Designer on documents sampled from a large pretraining corpus, and giving it an accumulated environment memory. Scaling to 30B-parameter models, SPADE improves over the strongest fixed-environment baseline by +5.3 on average across eight held-out math, science, code, and reasoning benchmarks, and lifts the tool-use setting by +5.7 on BFCL-v4 multi-turn and +13.9 on ACEBench-Agent; on the games setting, the margin over the strongest baseline grows with model scale. By making environment design itself a learnable component, SPADE takes a concrete step toward open-ended self-improvement.

## 论文核心问题与整体含义（研究动机与背景）

- **核心瓶颈**：智能体 AI 的能力增长越来越依赖"训练环境"（交互式、可验证奖励的任务）。然而现有环境池无论是人工精选、静态合成，还是冻结验证器的生成式环境，都构成一个**固定分布**，不会随学习者能力提升而演化。当智能体耗尽该环境池后，改进就会停滞。
- **现有方案局限**：
  - 工程化 harness 改进不改变权重，收益局限于特定 harness；
  - 人工精选环境扩展速度受限于人力；
  - 合成生成环境（如 RLVE、WebScale-RL）的生成器是冻结的，环境空间不随智能体增长；
  - 无接地自我对弈（如 AZR、SPIRAL）受信息对称性束缚，无法超越模型自身知识，且容易放大错误（"隐形缰绳"问题）。
- **SPADE 的定位**：将**环境设计本身变成可学习的组件**，通过单一 LLM 扮演"环境设计师"与"推理智能体"双角色进行自我对弈，使环境分布随智能体能力前沿同步移动，向开放式持续自我改进迈出具体一步。

## 方法论

### 核心思想
- 单个 LLM π_θ 通过角色提示词扮演两个角色：
  - **环境设计师（Environment Designer, ED）**：编写完整的可执行 Python 环境，实现 Gym 风格 `reset()`/`step()` 接口，即一个完整 MDP（状态转移、奖励函数、验证代码），并附带一个**特权提示（privileged hint）**；
  - **推理智能体（Reasoning Agent, RA）**：在有/无提示两种条件下分别与环境交互完成求解。
- **代码即环境（code-as-environment）**：任何可计算 MDP 都可写成程序，该表示统一了单轮推理任务（一步到终止奖励）与多轮工具使用任务（顺序交互）。

### 关键技术：基于提示的遗憾奖励（Hint-Based Regret）
- 环境设计师的奖励定义为有提示与无提示下智能体平均回报之差：

  r_D(e) = r̄_A(e | h) − r̄_A(e)

- **三种区间**：高遗憾 = 学习前沿环境（有提示可解、无提示不可解）；低遗憾且双向成功 = 已掌握；低遗憾且双向低回报 = 不可解环境。这实现了 PAIRED 的 minimax regret 目标，而无需单独对抗网络。
- 训练中将原始遗憾取下限为 0，以 0.4 权重与困难度锚定（赢率目标区间 [0.4, 0.6]，权重 0.6）混合，平衡"可教性"与"难度"。

### 训练流程（Algorithm 1）
1. 采样领域提示词，ED 生成环境 → 语法/可执行性验证 → 生成提示 h；
2. RA 对每个有效环境做 G 次无提示 rollout 和 G 次有提示 rollout；
3. 按角色分别计算优势（ED 按技能中心化，RA 按环境标准化），通过 GRPO 更新共享策略；
4. 使用延迟更新（k 步）、截断重要性采样、非对称裁剪（ε_low=0.2, ε_high=0.28）等稳定化技巧。

### 防崩溃设计
- **语料接地（Corpus Grounding）**：每轮从 DCLM + MegaScience（游戏）或 Nemotron 代码语料（工具使用）重新采样文档，为环境生成引入外部新意，防止模式坍缩；
- **环境记忆（Environment Memory）**：保存带遗憾分数和技能标签的历史环境，供 ED 借鉴高遗憾种子、避开过易/过难样本，维持难度在智能体前沿。

## 主要结论与发现

1. **游戏设置**：SPADE 在 8 基准套件平均分达到 58.3，较未训练基线 +8.1，比最强固定环境基线（RLVE）+5.3；优势随模型规模增长（4B +5.2、8B +5.7、30B +8.1），且在固定基线饱和后仍保持增长。
2. **工具使用设置**：30B 上 ACEBench-Agent +13.9、BFCL v4 多轮 +5.7、τ2-bench +3.6；提升幅度与基准任务结构匹配度相关。
3. **自适应设计优于冻结设计**：冻结自对弈 ED 并去记忆后，模型比不训练还差（40.5 vs 50.2）；固定 GPT-5.5 设计师仅恢复约 35% 的收益。
4. **语料接地是多样性的来源**：Vendi/n 分数 0.68（有语料）vs. 0.04（无语料）；无语料运行在步骤 290–312 连续生成同一 RotatingMazeEnv 41 次。
5. **涌现课程**：早期环境在开场观察中直接揭示公式（25%），后期降至 5%；奖励粒度从 3.7 增至 5.8 个等级；智能体行为从"先推导后行动"转向"先探测证据后推导"。
6. **经验总结**：ED 训练提升难度定位，语料接地提供多样性宽度，两者解耦；奖励机制上提示遗憾优于 EMA 学习潜力信号。

## 优点

- **统一接口**：Gym 式 `reset()/step()` 代码表示统一单轮推理与多轮工具使用，训练管线单一；
- **轻量遗憾估计**：提示遗憾不需要额外对抗网络，计算成本低且理论上有均衡分析支撑（附录 B 证明：理想假设下纯纳什均衡中智能体在所有环境上无提示最优）；
- **防模式坍缩设计完整**：语料接地 + 环境记忆 + 多层验证（语法、可执行性、确定性 reset 门、LLM 可解性筛查），并注意了奖励黑客的规避；
- **规模验证扎实**：在 30B+ 规模提供完整可复现配方，跨两个骨干家族（Qwen、Nemotron）验证；
- **定性分析深入**：追踪了环境质量、多样性、难度演化及智能体行为转变，因果归因清晰（指令模板固定，变化可追溯至 ED 训练）。

## 不足与局限

- **复杂度受模型能力上界约束**（"隐形缰绳"）：ED 无法生成超出其基础模型上下文表达能力的环境，环境复杂度上限随规模增长；
- **优化器仍为人工设计**：GRPO 等训练规则未纳入自我修改范围，并非完全开放式；
- **无正式最优性保证**：提示遗憾受 PAIRED 启发但未证明产生最优课程；4B/8B 的有限样本遗憾估计会长期降为负值，信号噪声大；
- **评估为固定任务**：当前基准衡量固定任务表现，而非开放式推理增长，验证的是"迁移到静态基准"而非真正的开放式持续改进；
- **对比公平性受限**：与 AgentScaler/AWM/EnvScaler 等参考系统在训练数据、预算、评估协议上不一致，跨论文对比需谨慎解读；
- **小模型上遗憾信号不稳定**：4B/8B 的提示遗憾长期为负，但仍能获益，说明信号鲁棒性与模型规模相关；
