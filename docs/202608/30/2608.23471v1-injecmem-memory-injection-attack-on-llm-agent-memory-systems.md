## 摘要
记忆正逐渐成为已部署的LLM智能体中的默认子系统，以提供持久化的个性化和连续性。这自然引出一个问题：记忆系统是否会为智能体引入新的漏洞？为此，我们提出了InjecMEM，一种新颖的记忆注入攻击范式，仅需一次交互（无需对记忆存储的读取/编辑权限）即可将相关查询的后续响应引导至预指定输出。在记忆系统的“检索-然后-生成”机制指导下，我们通过一个与检索器无关的锚点和一个对抗性命令来构造注入。锚点包含高召回率的主题线索，使得下游检索能持续将记录与目标主题关联。命令则是一个短序列，经过优化以在不确定的融合上下文、可变位置和长提示下保持有效，从而在检索到后可靠地引导输出。我们通过基于梯度的坐标搜索学习命令，对合成提示模板和插入位置取平均，并将其扩展为跨骨干网络的联合优化以研究迁移性。在多个记忆系统和骨干模型上的评估表明，InjecMEM实现了可靠的主题条件检索和目标生成，在记忆漂移下仍保持有效，并且不影响非目标查询。我们的结果强调了加固记忆系统的必要性，并提供了一个可复现的框架来研究智能体记忆。

## Abstract
Memory is becoming a default subsystem in deployed LLM agents to provide persistent personalization and continuity. This naturally prompts a question: will memory system introduce new vulnerabilities into agents? Thus we propose InjecMEM, a novel memory injection attack paradigm that requires only a single interaction (no read/edit access to memory store) to steer later responses of related queries toward a pre-specified output. Guided by the retrieval-then-generate mechanism of memory systems, we craft the injection with a retriever-agnostic anchor and an adversarial command. The anchor contains high-recall topical cues so that downstream retrieval consistently associates the record with the target topic. The command is a short sequence optimized to remain effective under uncertain fused contexts, variable placements, and long prompts so that it reliably steers outputs once retrieved. We learn the command via gradient-based coordinate search, averaging over synthetic prompt templates and insertion positions, and extend it to joint optimization across backbones to study transfer. Evaluated across multiple memory systems and backbone models, InjecMEM achieves reliable topic-conditioned retrieval and targeted generation, remains effective under memory drift, and leaves non-target queries unaffected. Our results underscore the need to harden memory systems and provide a reproducible framework for studying agent memory.

## 2. 论文提出的方法论：核心思想、关键技术细节与算法流程

- **总体攻击框架**：InjecMEM 将注入样本拆分为两部分：
  - **检索器无关锚点（Retriever-agnostic Anchor）**：用于保证注入记录在写入记忆后，能够被后续与目标主题相关的查询检索到（对应 Goal 1——主题条件检索）。锚点不针对任何特定嵌入器优化，而是利用高召回的主题线索（包括领域标签、常用高频关键词、域内典型意图列表）来最大化对广泛用户查询的语义和词汇重叠。
  - **对抗命令（Adversarial Command）**：用于在注入记录被检索并融合进最终提示后，可靠地将骨干 LLM 的输出引导到目标内容（对应 Goal 2——定向生成）。
- **Multi-GCG 优化算法**（Alg. 1）：是对经典 GCG 的扩展，用于应对记忆系统带来的三方面不确定性：
  - **动态不可预测的上下文**：融合提示中混杂了多种记忆记录；
  - **可变位置**：被注入的记录在最终提示中不固定，可能出现在深处导致注意力稀释；
  - **长度与融合效应**：最终提示很长，信噪比下降。
  - 算法在多组**替代提示模板**（模拟记忆系统融合格式）上，针对多个**插入位置**，平均负对数似然损失，通过梯度计算词汇得分、Top-K 候选采样、宽度为 W 的随机搜索来迭代更新命令。同时从多长度替代提示中获得对长提示的鲁棒性。
- **家族联合优化（FJ-Multi-GCG，Alg. 2）**：针对共享 tokenizer 的同一模型家族（如 Qwen2.5 系列），在多骨干上联合优化单一命令，以提升对家族内未见变体的迁移能力。梯度源交替切换，候选由联合损失 Ljoint 评估。
- **跨家族联合优化（CF-Multi-GCG，Alg. 3）**：针对不同 tokenizer 的模型家族，维护一个原始字符串 S 作为跨家族共享表示，每次迭代选一个“锚定 tokenizer”做离散编辑，再通过重新分词和联合损耗评估来更新字符串。梯度投影由 MapGradient（Alg. 4）完成。
- **锚点-命令融合**：锚点设计得较长以主导记忆写入和检索信号；命令在优化时采用与推理一致、但与记忆索引模块分离的提示模板，避免锚点与命令互相干扰。

## 6. 论文的主要结论与发现

- **记忆系统是一个不可忽视的安全边界**：持久化写入 + 混合检索共同构成了一个此前未被充分研究的攻击面。
- **单次交互足以实现定向记忆注入**：InjecMEM 在 MemoryOS 上实现高达 35.4% 的 RSR@50、76.6% 的 ASR-c 和 35.6% 的 ASR-j，显著优于现有基线。
- **传统攻击方法在记忆场景全面失效**：DPI、BadChain、vanilla GCG 的 ASR 均为 0，证明记忆系统动态融合上下文、可变位置和长提示的特征确实打破了静态触发优化的假设。
- **对记忆漂移具有鲁棒性**：在记忆不断增长、被注入记录逐渐“淹没”的情况下，中位数检索保持有效（RSR@10 约 40% 水平），非目标查询不受影响。
- **迁移性结论务实**：
  - 家族内迁移可行：7B 上优化的命令对 3B/14B 几乎无效，但通过家族联合优化（1.5B+7B）可显著提升对 3B/14B 的迁移效果；
  - 跨家族迁移困难，但简单地将不同骨干上优化出的命令拼接（Concat-3）即可同时覆盖 Qwen、Mistral、Llama 三个家族。
- **现有防御不足**：常用的检索时检测器（LLM-as-a-Judge、ProtectAI、PromptGuard）只能降低检索率，无法根除攻击；困惑度过滤虽可完全阻断，但以极高的良性内容阻断率为代价。

## 7. 优点

- **问题新颖且有实际重要性**：首次系统性聚焦“记忆系统本身作为攻击面”，区别于对 RAG 静态知识库的投毒研究，切中当下 LLM 智能体记忆快速部署的趋势。
- **威胁模型设定严格且贴近现实**：仅单次交互、无存储读写权限，排除体量型攻击；对记忆子系统完全黑盒，极大增强了攻击的现实可操作性。
- **方法设计针对性强**：Multi-GCG 的“多上下文、多位置、多长度”联合优化直击记忆系统动态融合的核心特征，而非简单移植现有攻击，方法创新性体现在针对非平稳环境的鲁棒优化。
- **实验体系较为完整**：覆盖检索、生成、漂移、系统迁移、跨骨干迁移、防御评估和真实数据验证等多维度；附录还提供了大量逐域结果和成功/良性响应示例，并开源了代码与数据，可复现性高。
- **防御评估有现实参考意义**：报告了防御对良性内容的误伤率（BBR），指出了安全-效用的权衡，而非仅关注攻击成功率。

## 8. 不足与局限

- **适用条件受限**：InjecMEM 主要面向“存储原始交互文本”的记忆系统（写入后可原样检索）；对于在存储前对交互做重写、摘要或变换的记忆管线，攻击可能失效，论文仅将其列为未来工作而未做实验验证。
- **生成侧的白盒假设**：对抗命令的优化需要访问骨干模型（白盒梯度），虽然后续迁移实验缓解了这一问题（用小模型/家族联合），但对完全黑盒且非主流家族骨干的适用性有限。
- **跨家族迁移困难**：CF-Multi-GCG 联合优化出的命令对未参与优化的第三家族（如 Llama）完全失效（ASR-c 为 0），说明跨 tokenizer 泛化仍是一个未解决的技术难题。
- **实验公平性存疑点**：基线方法（DPI、BadChain、GCG）在记忆场景全面失效（0%），但论文对这些基线在记忆环境下的适配和调优交代有限，读者难以判断是“基线本身不适合”还是“实现不够好”；对比的公平性有待更多实现细节支撑。
