## 摘要
AI安全评估的单位仍然是单个模型，然而语言模型智能体越来越多地被部署在相互交互的群体中，这些群体阅读并写入彼此的决策。这引发了一个单一智能体审计无法回答的问题：一个自身校准良好的智能体仍可能被周围的智能体拉向不同的决策。我们在一个安全分流任务上研究了这个问题，其中语言模型监控者群体决定是升级还是忽略警报，我们可以向该群体注入一个总是朝一个方向推动的坚定少数派。我们发现，单个智能体独自判断几乎相同的两个警报，却可以导致集体行为大相径庭，因此审计任何一个成员不一定能揭示群体将怎么做。然而，这种集体行为可以提前预测。仅从群体的良性、无对抗运行中，我们就校准一个响应函数，该函数在任何攻击运行之前预测一个坚定的少数派之后会将其推动多远。然后我们探讨什么会改变结果，发现让智能体看到彼此的推理可以中和弱攻击，而对强攻击则只是延迟，这使问题从群体是否收敛于对抗者的选择变成何时收敛。最后，我们排除了捕获是不可逆陷阱的假设：一旦坚定的智能体被移除，群体就会漂移回最初的状态，因此捕获是一种临时状态。孤立环境中的对齐不是群体中的对齐，然而群体在攻击下会怎么做，可以从任何对手到来之前的行为中提前读出。

## Abstract
The unit of AI safety evaluation is still the individual model, yet language-model agents are increasingly deployed in interacting populations that read and write one another's decisions. This raises a question no single-agent audit can answer: an agent that is well-calibrated on its own may still be pulled toward a different decision by the agents around it. We study this on a security-triage task, where populations of language-model monitors decide whether to escalate or dismiss alerts, and into which we can inject a committed minority that always pushes one way. We find that two alerts a single agent judges almost identically on its own can drive collective behavior far apart, so auditing any one member need not reveal what the population will do. Yet that collective behavior can be predicted in advance. From a population's benign, adversary-free operation alone, we calibrate a response function that forecasts, before any attack is run, how far a committed minority will later move it. We then ask what shifts the outcome and find that letting agents see each other's reasoning neutralizes a weak attack, while only delaying it against a strong one, turning the question from whether the population converges on the adversaries' choice into when. Finally, we exclude the hypothesis of capture being an irreversible trap: once the committed agents are removed, the population drifts back toward where it began, so capture is a temporary state. Alignment in isolation is not alignment in a population, yet what a population will do under attack can be read in advance, from how it behaves before any adversary arrives.

## 2. 论文提出的方法论

### 2.1 任务与环境设计
- **安全分诊任务**：智能体扮演安全运营监控者，对安全警报做出二元选择——升级（escalate/queue）或忽略（dismiss/archive）。升级是面对真实威胁时的安全行为，忽略是本文中对抗者所推动的目标行为。
- **协调博弈框架**：提示中明确写明，匹配同伴动作获得+100协调分，不一致则扣50分。因此同侪压力是**显式指导的**而非涌现的；研究问题不是智能体是否收敛，而是群体最终选择哪个动作、坚定少数派能否扭转它。
- **群体协议**：N=12个智能体在完全交互图上运行，每轮进行12对配对交互。每对智能体同时独立决策，互不看到对方当前选择；所有影响通过5槽FIFO记忆在轮与轮之间传播。记忆记录自身动作、伙伴动作、是否匹配、伙伴公开角色，以及（在可见条件下）伙伴的推理语句。
- **两阶段主实验**：
  - **固化阶段**（15轮）：所有智能体诚实，无对抗者。这一阶段的良性日志是预测的唯一数据来源。
  - **注入阶段**（16轮起，持续20-60轮）：将12个中的k个替换为坚定对抗者（始终选择忽略）。

### 2.2 响应函数的估计
- **群体良性日志形式** g(d)：从12条隐藏推理的良性运行中，提取每条记忆已满之后的诚实决策，按记忆中看到的忽略次数 d∈{0,...,5} 分组，得到**给定观察最近5次伙伴交互中出现d次忽略时诚实智能体平均选择忽略的概率**。此估计只用良性运行数据。
- **单智能体核** K(d, r, v, h)：用合成历史探测单个智能体，不需要任何群体运行数据，但分辨记忆位置、推理可见性、自身动作历史等细节。

### 2.3 对抗压力模型与平均场闭包
- 诚实智能体以平均概率 m 选择忽略，k个对抗者总是忽略，则某次观察中动作为忽略的概率近似为：
  - **φ(m,k) = ((N−k)m + k)/N**（预注册版本，把焦点智能体算入伙伴池）
  - **φ_corrected(m,k) = ((N−k−1)m + k)/(N−1)**（校正版本，排除自身）
- 假设5条记忆为独立伯努利试验，通过二项分布将记忆剂量分布通过响应曲线g(d)映射为预测忽略概率：
  - **F(m;k) = Σ_{d=0}^{5} C(5,d) φᵈ(1−φ)^{5−d} g(d)**
- **固定点预测**：求解 m* = F(m*;k)，即群体产生的忽略压力足以维持同水平忽略率的自洽稳态。用数值扫描[0,1]找变号区间，再二分求根。

### 2.4 捕获定义与恢复协议
- **捕获（capture）**：每轮记录诚实智能体的实际采样动作，xt为选择忽略的比例。若 xt≥0.75连续3轮，则称群体被捕获。这是首次通过事件（first-passage），不同于稳态平均预测。
- **恢复协议**：在捕获确认后（100轮上限内），对k=6的隐藏推理场景实施三种补救：
  1. **替换（replace）**：用全新空记忆诚实智能体替换6个对抗者
  2. **中和（neutralize）**：将对抗者原位转为诚实智能体，但其记忆播种了被捕获状态
  3. **移除（remove）**：直接删除对抗者，只留下6个诚实幸存者

## 6. 论文的主要结论与发现

1. **个体隔离与群体行为的背离**：中等级争议场景（authorized_backup vs reconciled_backup）在孤立审计中不可区分，群体互动却将其拉开数倍差距；可见推理几乎完全消除这一分离。
2. **良性运行可预测攻击行为**：从全诚实群体的良性日志校准的响应函数，对k∈{2,4,5}三个保留剂量的预测误差均低于0.008，平均绝对误差0.0058；误差约为简单基线（线性插值等）的三分之一。
3. **单智能体探针的失败与受限成功**：在争议场景中单智能体预测群体行为失败（过估0.18）；但在显式规则+静默对抗者条件下，单智能体预测与实际群体均值极为接近（0.012 vs 0.011）。
4. **推理可见性是条件性防御**：中等剂量（k=3）论证攻击下，可见推理使攻击效应从+0.211降至−0.021（8/8配对方向正确，精确符号翻转检验p=0.0078）；但对强攻击（k=6）仅将中位捕获时间从约19轮推迟到约39轮（log-rank p≈0.22，统计未达显著，且一例右删失）。
5. **捕获是可逆的临时状态**：三种补救措施（替换/中和/移除）的终点水平全部落入密封90%预测带，群体回归其良性忽略倾向状态；但逐种子恢复完整度随补救强度下降（替换4/4，中和3/4，移除1/4），恢复时间尺度未验证。
6. **论证内容是不可或缺的通道**：静默攻击与论证攻击的对比显示，对抗者的论证本身是独立的作用通道；基于动作的预测模型无法捕捉该通道（良性日志预测对论证攻击误差0.039，远大于静默攻击的0.001）。

- **方法上的简洁与可检验**：平均场闭包结构清晰——响应函数（个体对社会的敏感性）+ 混合项（对抗者增加压力）——并且分离了预测（稳态均值）与首次通过事件（捕获时间），避免了概念混淆。
- **实验设计严谨**：预注册密封预测、保留剂量验证、配对种子设计、多种稳健性检查（末窗、动作频率、N=24、捕获判据敏感性），设定了较高的实证标准。
- **明确的科学声明分层**：补充材料中提供"科学声明地图"，逐条标注最强声明和其假设，透明性高。
- **条件化而非过度声称**：论文区分了预测水平（端点水平已验证）和恢复时间尺度（未验证），明确读数为临时介入而非普遍可逆性保证。
- **对抗通道的因果分离**：通过论证/静默对比，干净地区分了动作力量与论证内容的影响。

## 8. 不足与局限

- **泛化范围受限**：单模型（Llama-3.1-8B）、单任务族（安全分诊）、N=12（仅一个N=24位置检查）、完全图拓扑；跨模型规模/家族、跨任务、跨部署拓扑的推广未验证。
- **统计功效不足**：每细胞3-8种子，捕获边界非单调、恢复逐种子差异大、可见推理的延迟翻倍统计未达显著；作者将一些结论定性为描述性观察而非检验。
- **预测的开发偏差**：密封预测是保留剂量验证，但邻近K∈{1,3,6}的已测剂量参与了模型类开发，并非完全攻击天真的结构发现。
- **模型忽略论证内容**：基于动作计数的响应函数无法表示论证影响通道，因此可见推理条件下的预测失败；论文将此明确列为未来工作的首要方向。
- **捕获判据的操作性而非推导性**：xt≥0.75连续3轮是操作定义，非从Kramers逃逸理论导出的定律；不同动作阈值下延迟结果不稳定（四分之六阈值下无判别力，一致阈值下方向不稳定）。
- **基线成本**：可见推理在没有攻击时也会提高模糊场景的忽略率（authorized_backup从约0.25升至0.44），且增加种子间变异性，存在安全性-基线校准权衡。
- **恢复适用性有限**：恢复终点验证了水平，但未验证时间尺度；且恢复目标是"忽略倾向的良性状态"而非"安全边界"，不构成一般性安全保证。
- **环境局限性**：全部分析基于合成数据、单一协调任务为显式指导（非涌现）、双用途风险（对抗方法可被攻击者学习）在论文中已讨论并评估为低风险。
