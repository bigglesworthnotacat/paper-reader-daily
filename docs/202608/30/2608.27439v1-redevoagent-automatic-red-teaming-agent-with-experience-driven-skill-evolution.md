## 摘要
基于LLM的代理越来越多地部署在产品级执行框架中，在这种框架下，越狱可能触发有害的工具使用和持久状态更改，从而比单独的不安全文本生成带来更大的风险。现有的自动红队方法通常依赖于固定攻击，而最近的代理型攻击者协调多种越狱工具，并通过基于轨迹的检索显示出更强的潜力。然而，这种检索可能由于检索偏差和工具归因不清而重用误导性经验，而且完整的轨迹会增加上下文开销并降低可解释性。我们提出RedEvoAgent，一种黑盒红队代理，将跨案例攻击轨迹提炼为简洁、人类可读的攻击技能。该攻击技能通过工具有效性分析和用于技能更新的决策工具归因，以及仅保留能提高验证性能的更新的验证棘轮，自适应地进化。在多个基准、目标模型和目标执行框架上的实验表明，RedEvoAgent优于固定基线和代理型基线，提高了工具效率，并在攻击者模型和目标执行框架之间具有可迁移性。

## Abstract
LLM-based agents are increasingly deployed in product-level execution harnesses, where jailbreaks can trigger harmful tool use and persistent state changes, creating greater risks than unsafe text generation alone. Existing automatic red-teaming methods often rely on fixed attacks, while recent agentic attackers coordinate multiple jailbreak tools and show stronger potential through trajectory-based retrieval. However, such retrieval can reuse misleading experiences due to retrieval bias and unclear tool credit, and full trajectories add context overhead while reducing interpretability. We propose RedEvoAgent, a black-box red-teaming agent that distills cross-case attack trajectories into a concise, human-readable attack skill. The attack skill adaptively evolves through tool-effectiveness profiling and Deciding-Tool Attribution for skill updates, and a validation ratchet that retains only updates improving validation performance. Experiments on multiple benchmarks, target models, and target execution harnesses show that RedEvoAgent outperforms fixed and agentic baselines, improves tool efficiency, and transfers across attacker models and target execution harnesses.

## 一、核心问题与整体含义（研究动机与背景）

- **问题背景**：LLM 智能体（如 Claude Code、Codex）已广泛部署于产品级执行框架中，具备修改本地文件、传输数据、调用外部 API 等真实工具操作能力。这使得越狱攻击的危害不再局限于"不安全文本生成"，而是可能触发**有害工具调用**与**持久系统状态改变**，安全风险显著放大。
- **现有方法的不足**：
  - **固定攻击方法**（如 GCG、AutoDAN、FlipAttack）只探索有限攻击子空间，难以覆盖不同目标模型的异构弱点。
  - **基于轨迹检索的智能体攻击**（如 RedCodeAgent）存在三个关键缺陷：
    1. **检索偏差**：语义相似并不保证经验有用，可能重用误导性轨迹；
    2. **工具归因不清**：成功轨迹中频繁共同出现的工具未必是真正导致成功的工具，容易形成自增强偏差；
    3. **上下文开销大、可解释性差**：完整轨迹占用大量上下文窗口、推理成本高，且低层动作记录难以供人类审计。
- **论文研究意义**：针对产品级黑盒 LLM 智能体的安全评估需求，提出一种**经验驱动的自动红队攻击技能进化框架**，在高攻击成功率、低工具调用成本与可解释性之间取得平衡。

## 二、方法论：核心思想、关键技术细节与算法流程

### 2.1 核心思想

将跨案例的攻击轨迹**蒸馏为一段精炼、人类可读的"攻击技能"文档**，该文档插在攻击者系统提示中，概括高层工具编排策略。技能通过训练集经验生成候选更新，并经由**独立验证集**筛选，仅接受能提升验证性能的更新。

### 2.2 形式化定义

- 目标智能体：\( M_{tar} = (m_{tar}, h_{tar}) \)，含目标模型与执行框架（工具环境）。
- 攻击者智能体：\( M_{att}(s) = (m_{att}, h_{att}(s, T)) \)，在 ReAct 框架下运行；\( s \) 为攻击技能文档，\( T \) 为攻击工具箱。
- 动作空间：\( A = \{\text{QUERY TARGET}\} \cup T \)；QUERY TARGET 向目标提交当前 jailbreak prompt，工具调用则对 prompt 进行变换优化。
- 优化目标：学习攻击技能 \( s \)，最大化在目标智能体上的平均攻击得分：
  \[
  J_D(s) = \frac{1}{|D|}\sum_{x \in D} r_x(s)
  \]
- 数据划分：训练集 \( D_{tr} \) 收集经验、验证集 \( D_{va} \) 筛选技能更新、测试集 \( D_{te} \) 仅用于最终评估。

### 2.3 攻击工具箱

集成了 7 种互补的越狱工具：GCG（梯度搜索）、AutoDAN（进化搜索）、AmpleGCG（生成器后缀）、Template（预定义模板）、FlipAttack（字符翻转伪装）、RolePlay（角色扮演改写）、以及提出的 **Prompt Substitution**（辅助 LLM 在保持意图的前提下改写失败 prompt）。

### 2.4 经验收集（Experience Collection）

- **工具效能画像（Tool-Effectiveness Profile）** ：在训练集上孤立评估每个工具的效能：
  \[
  e_t = \frac{1}{|D_{tr}|}\sum_{x \in D_{tr}} r_x(t), \quad t \in T
  \]
  提供基于实证的工具排序，避免不同目标模型对不同工具抵抗差异导致的盲目选择。
- **轨迹收集**：在当前最优技能下对训练集完整 rollout，记录工具调用、候选 prompt、目标响应等完整执行轨迹。
- **Deciding-Tool Attribution（决策工具归因）** ：将每条成功轨迹归因于**首个成功目标查询之前最近调用的那个工具**。该机制打破"工具在成功轨迹中的共现频率被误认为贡献"的自增强偏差，防止技能演化中的策略崩溃。

### 2.5 验证棘轮（Validation Ratchet）

- **候选技能合成**：蒸馏智能体接收当前技能 \( s^* \)、工具效能画像、训练轨迹（按成功/失败分层、划分为 minibatch）以及被拒上下文 \( C \)（记录此前被拒绝的候选及其验证分数），在限幅编辑约束下生成候选技能。
- **候选验证与更新**：候选技能在本轮验证集上独立评测，只有当验证分数**严格优于**当前技能时才被接受；否则保留原技能，候选加入拒绝上下文：
  \[
  s_i^* =
  \begin{cases}
  \hat{s}_i, & J_{D_{va}}(\hat{s}_i) > J_{D_{va}}(s_{i-1}^*) \\
  s_{i-1}^*, & \text{otherwise}
  \end{cases}
  \]
- 接受后重新收集训练轨迹并清空拒绝上下文；拒绝则保留原轨迹供下一轮继续探索。
- **核心保证**：训练集驱动"学什么"，验证集决定"哪些修订能留下"，测试集完全锁死。

### 2.6 完整算法流程（Algorithm 1）

1. 初始化空技能，评估各工具效能画像；
2. 在当前技能下收集训练轨迹；
3. 循环 \( R \) 轮：
   - 蒸馏智能体综合技能、轨迹、画像、拒绝上下文生成候选；
   - 候选在验证集评测；
   - 若优于当前技能 → 接受、重收集训练轨迹、清空被拒上下文；
   - 否则 → 保留原技能，候选加入被拒上下文；
4. 返回最终接受的技能。

## 六、主要结论与发现

1. **复合攻击优于单一工具**：不同目标智能体对不同越狱工具抵抗不均，没有单一工具在所有组合中有效，组合不同工具是必要的。
2. **RedEvoAgent 全面领先**：在全部实验设置中，RedEvoAgent 均匹配或超过最强孤立工具，并优于 RedCodeAgent 和 MAJIC 两种智能体方法。例如：
   - ASB + MiniMax-M2.5 + Codex：ASR 达 92.8%，较最强基线 FlipAttack（81.1%）提升显著；
   - AgentHarm + DeepSeek-V4-Flash + Claude Code：HarmScore 74.3 vs FlipAttack 67.9；
3. **工具效率更高**：平均每个案例的工具调用次数最少（如 ASB/DeepSeek 仅 0.8-0.9 次），说明技能引导下工具选择更具针对性。
4. **技能文档优于检索轨迹**：技能级别的抽象比轨迹检索上下文开销更低且性能更强，与传统经验一致。
5. **技能跨场景可迁移**：演化的技能在更换攻击者模型（Qwen3-8B、Qwen3-4B）或执行框架（Claude Code → Codex）时零样本迁移仍有效。
6. **验证棘轮有效防止过拟合**：被拒候选的验证分数普遍低于接受技能，且接受轮次通常带来测试分数提升；但 AgentHarm/MiniMax 场景中 R4 出现验证提升但测试下降的过拟合迹象，说明验证集多样性不足时仍有风险。
