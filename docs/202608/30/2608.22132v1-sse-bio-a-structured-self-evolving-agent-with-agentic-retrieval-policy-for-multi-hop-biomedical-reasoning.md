## 摘要
生物医学多跳问答（QA）要求模型跨中间实体（如疾病、药物、蛋白质和表型）连接证据。现有智能体通常依赖静态检索工作流或粗粒度的提示重写，这可能导致在需要更新推理过程时出现指令漂移。我们提出SSE-Bio，一种具有代理检索策略的结构化自进化智能体，用于多跳生物医学推理。SSE-Bio不是全局重写智能体指令，而是维护结构化状态，通过可训练的代理策略选择性检索知识三元组和先前模板，并通过细粒度模板编辑改进其推理记忆。为了优化检索决策，我们引入了一种基于组相对策略优化的代理训练策略，其中通过决策对比组在替代检索选择上改进代理。在三个生物医学多跳问答基准上的实验表明，SSE-Bio consistently优于现有基线，在BioHopR上相比最强的自进化基线提高了6.56个绝对点。

## Abstract
Biomedical multi-hop question answering (QA) requires models to connect evidence across intermediate entities such as diseases, drugs, proteins, and phenotypes. Existing agents typically rely on static retrieval workflows or coarse-grained prompt rewriting, which can lead to instruction drift when reasoning procedures need to be updated. We propose SSE-Bio, a structured self-evolving agent with an agentic retrieval policy for multi-hop biomedical reasoning. Instead of globally rewriting agent instructions, SSE-Bio maintains a structured state, selectively retrieves knowledge triplets and prior templates through a trainable proxy policy, and improves its reasoning memory through fine-grained template editing. To optimise retrieval decisions, we introduce a proxy-training strategy based on group relative policy optimization, where the proxy is improved through decision-contrastive groups over alternative retrieval choices. Experiments on three biomedical multi-hop QA benchmarks show that SSE-Bio consistently outperforms existing baselines, achieving an improvement of 6.56 absolute points over the strongest self-evolving baseline on BioHopR.

  1. 依赖**静态检索工作流**，缺乏显式、可学习的检索控制；
  2. 记忆更新方式为**粗粒度提示级重写**（prompt-level rewriting），局部失败可能破坏整个推理脚手架，产生"指令漂移"（instruction drift）。

论文据此提出 SSE-Bio（Structured Self-Evolving Agent），目标是实现「结构化状态跟踪 + 可控记忆演化 + 显式检索策略」三者统一的智能体框架，探讨的核心研究问题是：**如何让智能体在推理过程中自适应地决定检索什么、何时检索，同时以细粒度、可审计的方式演化长期推理记忆？**

## 方法论

### 核心思想

SSE-Bio 采用四组件迭代智能体架构，将推理过程形式化为多轮交互：

- **Manager（规划器）**：维护结构化状态 $u_t$（短期记忆），结合检索证据构造查询专属计划 $\pi_t$；
- **Proxy（检索策略）**：可训练组件，输入结构化状态，输出检索动作 $a_t \in 2^{\{KG, TPL\}}$（知识三元组/历史模板的组合选择）；
- **Dev Agent（执行器）**：执行计划，生成推理轨迹和答案；
- **Critic（评估器）**：在无金标答案前提下评估推理质量，返回结构化反馈。

### 结构化记忆设计

- **短期记忆**（结构化状态 $u_t$）包含四个字段：任务类型（task type）、信息缺口（information gap）、反馈（feedback）、检索状态（retrieval state），使检索决策、规划、修正均锚定在统一显式结构上。
- **长期记忆**（模板库 $E$）每条模板含五个字段：任务类型、推理流程、验证标准、工具使用策略、失败警告。
- **演化机制**：轨迹成功后，若与已检索模板对齐（任务类型匹配且相似度 ≥ 阈值 $\theta_{tpl}=0.75$），则执行**细粒度局部编辑**（仅修改 Critic 指出的字段）；否则进行**新模板蒸馏**。这替代了现有自进化智能体（如 STELLA）中整体模板重写的做法。

### 检索策略

Proxy 在每轮依据结构化状态选择四种动作之一（都不检索 / 仅知识三元组 / 仅模板 / 两者都检索）。知识三元组以"信息缺口"字段为查询用 BiCA 编码检索，经模式与去重过滤后返回 top-5；模板以"任务类型"为查询返回 top-1，并用稠密相似度 + 模式兼容性 + 答案基数检验三重评分公式 $s_{tpl}=0.60c_{tpl}+0.25m_{schema}+0.15m_{ans}$ 判定兼容性。

### Proxy 训练（两阶段）

1. **SFT 初始化**：对不同检索分支进行 rollout，将获得最高复合奖励的动作作为伪标签，训练初始策略。约 12.6K 个带标注状态-动作对。
2. **GRPO 优化**（核心创新）：
   - **决策对比轨迹生成**：从同一推理状态展开多个备选检索动作的匹配分支，仅保留早期推理轮次的分支；通过模式违规、信息缺口未解决、无支撑桥接实体等规则剪枝，top-K 保留（K=8）。
   - **复合奖励**：$R(\tau)=\lambda_o R_{out}(\tau)+\lambda_b R_{beh}(\tau)$，其中 $\lambda_o=0.8,\lambda_b=0.2$。$R_{out}$ 为最终答案是否与金标匹配（二元）；$R_{beh}$ 为关键步骤（桥接解析、答案验证、多答案覆盖）中被检索证据支撑的比例（稠密信号，防止仅靠答案正确性产生稀疏奖励）。
   - **动作级 GRPO**：优势函数 $A_i=(r_i-\mu(r))/(\sigma(r)+\epsilon)$，策略比率 $\rho_i(\theta)=\pi_\theta(a_i|u_i)/\pi_{\theta_{old}}(a_i|u_i)$ 经裁剪后最大化目标 $J_{GRPO}=E_i[\min(\rho_i A_i,\bar{\rho}_i A_i)-\beta KL]$，并对冻结的 SFT 参考策略做 KL 正则。

## 实验设计

### 数据集与基准

- **BioHopR**（主基准）：7.63K 对关联的 1-hop/2-hop 问题，7:3 划分（约 5.34K 训练 / 2.29K 测试），支持单答案与多答案评估。
- **MedHop**：跨文档生物医学多跳阅读理解，零样本迁移评估。
- **Humanity's Last Exam: Biomedicine（HLE）**：前沿难度封闭式专家推理问题，零样本迁移评估。

### 评估指标

- BioHopR：Prec H1、Prec H2（链路 1-hop/2-hop 精度）、Both cor（两题全对比例）、Both wr（两题全错比例），使用嵌入余弦相似度匹配（阈值 τ=0.9）。
- MedHop / HLE：零样本准确率。

### 对比方法（五类）

1. 通用 LLM：Llama-3.1-8B/70B、GPT-4o；
2. 医学 LLM：HuatuoGPT-o1-70B/8B、UltraMedical-8B；
3. RAG：i-MedRAG、AMG-RAG；
4. 生物医学智能体：KGARevion、DoctorAgent-RL、MedAgents、Biomni；
5. 自进化智能体：STELLA（最强自进化基线）。

为保证公平，所有智能体基线使用与 SSE-Bio 相同配置：Gemini-2.5-Pro 作为 Manager/Critic、Claude-4.5-Sonnet 作为执行器；SSE-Bio 仅在 BioHopR 训练集上训练 Proxy，其余测试集与基准零样本直接迁移。

## 主要结论与发现

1. **主结果**：SSE-Bio 在 BioHopR 上全部 4 项指标、单/多答案双设置下均为最优。单答案设置下较最强自进化基线 STELLA 提升 6.56 个绝对点（Both cor 9.96→16.52；Prec H1 38.94→47.21；Both wr 56.13→47.93），提升显著（p<0.05）。
2. **跨域泛化**：零样本迁移至 MedHop 和 HLE 均优于代理基线（HLE 上 28.4% 准确率），证明学到的检索策略具有可迁移性。
3. **检索控制的必要性**：移除 Proxy（完全不检索）使 Both cor 从 16.52 降至 10.62；学到的 Proxy 显著优于 4 种固定检索策略（固定"检索两者"仅 13.18），证明增益来自状态依赖的选择而非简单增加上下文。
4. **结构化自进化有效**：结构化状态 + 细粒度编辑（16.52）显著优于自由形式 + 重写（11.72）；两种机制互补。
5. **GRPO 在 SFT 之上持续增益**：Qwen-72B 下 Both cor 15.08→16.52。
6. **Oracle 分析显示仍有余量**：Oracle 三元组+模板联合可提升到 18.06，说明检索证据与模板匹配仍有改进空间。
7. **关系类型泛化**：12 种关系模式均有提升，在需要更强二跳推理的关系上（如 Disease:Drug:Phenotype）增益最大（Prec H2 22.83→34.26）。

## 优点

- **方法设计上有明确针对性**：以"指令漂移"和"静态检索"两大现有缺陷为靶点，分别用细粒度模板编辑和可训练 Proxy 予以回应，技术方案与问题动机一一对应。
- **受控的长期记忆演化**：对比 STELLA 的整体重写，SSE-Bio 的局部字段编辑将每次更新的改动字段数从 3.28 降至 1.46、未涉及字段保留率从 64% 提升至 88%、不支持的/矛盾的指令率分别从 12%/7% 降至 4%/2%，更可审计。
- **训练信号设计精巧**：行为奖励 $R_{beh}$ 提供稠密信号，避免纯答案奖励的稀疏性问题；明确奖励"证据支撑"而非"检索数量"，规则清晰（附录表 12）。
- **实验严谨性**：固定 Manager/Dev/Critic 骨干以隔离 Proxy 贡献；提供提示词/API 敏感性分析、噪声鲁棒性、效率与成本详细拆解、错误来源归因等全方位验证；统计数据完整（表 11、13 给出模板记忆和 rollout 的详细构造统计）。
- **零样本迁移验证**：仅在 BioHopR 上训练即迁移到 MedHop 与 HLE，验证了策略泛化能力而非过拟合单一基准。

## 不足与局限

- **证据依赖与检索上限**：论文明确承认 Oracle 分析显示更强检索仍可提升约 1.5 个点，当前 BiCA 检索器是性能瓶颈之一（HLE 错误来源中三元组检索失败占 24.6%）。
- **模板记忆管理风险**：长期记忆持续增长可能引入冗余或过时模板，论文仅在附录中提出记忆合并/剪枝/溯源的未来方向，未做实证。
- **可复现性受限**：依赖固定商业模型（Gemini-2.5-Pro、Claude-4.5-Sonnet），附录敏感性分析显示更换 API 骨干会导致 1-2 个点的性能回落；SFT 标签与 GRPO 奖励均在同一固定智能体环境中诱导，跨骨干的可迁移性未验证。
- **效率代价**：虽性能显著提升，但 token 消耗（28.3M vs STELLA 21.2M）、每例延迟（22.1s）和 API 成本（$0.047/例）均为所有对比方法中最高，论文未做性能-成本帕累托优化分析。
- **剩余误差较大**：在更具挑战的 HLE 基准上准确率仅 28.4%；误差归因显示 Dev 推理错误（31.2%）是最大误差源，说明检索优化单独无法解决全部问题。
- **多答案场景差距**：多答案指标普遍低于单答案（如 Both cor 11.73 vs 16.52），多答案覆盖问题仍是明显短板。
- **训练数据标注的间接性**：SFT 伪标签由同一环境内 rollout 诱导产生，存在潜在的自举偏差；噪声注入实验仅测试 2 条随机三元组，扰动强度有限。
