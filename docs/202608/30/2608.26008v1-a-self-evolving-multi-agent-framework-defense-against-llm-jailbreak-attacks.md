## 摘要
大型语言模型（LLM）仍然易受越狱攻击，这些攻击利用角色扮演、混淆、代码转换和多步间接等技术来诱导有害输出。随着越狱策略不断涌现，防御措施也在持续的猫鼠游戏中 proliferated，但大多数仍然是静态的：它们的安全行为在部署时固定，因此无法积累防御经验或适应未见过的策略。我们提出了一种围绕持久、跨交互规则记忆构建的自我进化测试时防御：当攻击成功时，框架将该失败抽象为一条方法级规则，捕获结构性的攻击包装器而非有害主题，并将其用于防御未来的输入。由于规则是方法级的，一条诱导出的规则可以泛化到整个攻击家族，并且随着新包装器的出现，标签空间也会扩展。该机制完全通过外部记忆和提示操作，无需参数更新，适用于开放权重和黑盒API模型。我们将其实现为四个协作模块，但贡献在于基于记忆的适应机制，而非模块分解。在四个黑盒越狱家族和多个模型上，我们的方法大幅降低了攻击成功率，同时保持了良性效用，在自适应复合包装器攻击下保持稳健，并且随着记忆增长不会增加过度拒绝。

## Abstract
Large language models (LLMs) remain vulnerable to jailbreak attacks that exploit techniques such as role-playing, obfuscation, code transformation, and multi-step indirection to elicit harmful outputs. As jailbreak strategies keep emerging, defenses have proliferated in an ongoing cat-and-mouse game, yet most remain static: their safety behavior is fixed at deployment, so they cannot accumulate defensive experience or adapt to unseen strategies. We propose a self-evolving test-time defense built around a persistent, cross-interaction rule memory: when an attack succeeds, the framework abstracts that failure into a method-level rule capturing the structural attack wrapper rather than the harmful topic, and reuses it against future inputs. Because rules are method-level, one induced rule generalizes across an entire attack family, and the label space expands as novel wrappers appear. The mechanism operates entirely through external memory and prompting, with no parameter updates, and applies to both open-weight and black-box API models. We realize it as four cooperating modules, but the contribution is the memory-based adaptation mechanism, not the module decomposition. Across four black-box jailbreak families and multiple models, our method substantially reduces attack success rates while preserving benign utility, remains robust under an adaptive composite-wrapper attack, and does not increase over-refusal as the memory grows.

## 1. 论文的核心问题与整体含义

- **研究动机**：LLM 虽然功能强大，但极易受到越狱攻击（jailbreak attacks），攻击者通过角色扮演、混淆、代码转换、多步间接等技巧构造看似良性的提示，诱导模型输出有害内容。
- **现有防御的不足**：当前主流防御（系统提示、安全微调、RLHF、外部分类器、SafeDecoding、ReasoningGuard 等）大多是**静态的**——部署后行为固定，无法积累防御经验，也无法适应不断涌现的、组合式或分布外的新型攻击。即使有自我反思或测试时适应方法，其反馈也通常是**瞬时的**，不能在跨交互中保留和复用。
- **核心含义**：本文提出一种**自我进化的测试时防御框架**，通过持久化、跨交互的规则记忆，把每次越狱失败抽象为“方法级”攻击规则并复用于未来输入，从而让防御系统随交互流不断变强，且无需更新模型参数，适用于开源和黑盒 API 模型。

## 2. 论文提出的方法论

- **核心思想**：不是把攻击按“有害主题”识别，而是抽象其**结构性攻击包装器（attack wrapper）**，如嵌套角色扮演、代码混淆、加密/解密、翻转等。一条规则可泛化到整个攻击家族。
- **规则记忆**：每条规则的形式为 `[label=方法级标签] If the request uses Pi, then Di`，其中 `Pi` 描述攻击包装器结构，`Di` 为拒绝约束；标签空间随新包装器出现而动态扩展。
- **五个操作符/机制**：
  - 攻击模式分类器 `φ`：用单次 LLM 调用将输入映射为 `benign`、已有标签或 `other`；
  - 规则检索与触发：结合标签匹配、LLM 相关性打分、词法回退，每步最多取 `K=2` 条规则；
  - 策略决策 `g`：将触发规则映射为 `allow`、`soft-refuse`、`hard-refuse`，优先级为 hard ≻ soft ≻ allow；
  - 违规检测器 `h`：用 LLM-as-judge 对响应在 1–10 分制上打分，阈值 `τ=7`，仅在检测到成功攻击且输入非良性时触发规则归纳；
  - 规则归纳与更新 `F/U`：从失败样本中提炼规则，进行语义去重，并限制每个标签的记忆容量 `C=4`，避免过度特化。
- **实现**：由四个提示词驱动的智能体实现上述操作：A1 规则触发、A2 策略决策、A3 响应生成、A4 自我反思与规则更新。
- **算法流程（文字描述）**：每个输入先分类 → 检索触发规则 → 决定策略 → 生成响应 → 用检测器判断违规 → 若违规且非良性则归纳新规则并更新记忆；否则记忆不变。
- **关键性质**：全部适应过程通过外部记忆和提示实现，**无参数更新**；稳态下每次交互约 3 次 LLM 调用（分类、策略、生成），反射只在违规时触发。

## 6. 论文的主要结论与发现

- 本文方法在 **ASR-rej / ASR-gpt 上全面低于所有基线**，尤其是在 CodeChameleon、ReNeLLM 这类挑战性攻击上优势明显；例如 CodeChameleon 下 Qwen2.5-7B 的 ASR-gpt 可从无防御的 57.0 降到 1.4。
- **良性效用几乎不受影响**：MMLU 和 GSM8K 得分与无防御模型相差约 2 个百分点以内。
- **自进化有效**：记忆从空开始，第一个批次后规则即可覆盖各攻击家族的结构模式，随后 ASR 降至接近零；无防御基线则始终脆弱。
- **组件缺一不可**：去掉触发、执行或反射任一组件都会显著提高 ASR，证实规则检索、策略执行和失败归纳三者互补且共同必要。
- **对自适应复合包装攻击具有稳健性**，且记忆增长不会显著放大 XSTest 上的过度拒答（空记忆 3.6%，累积记忆 9.6%）。

## 7. 优点

- **方法层面**：提出“跨交互持久规则记忆”的机制，将防御从静态/瞬时反馈升级为可累积、可复用的动态知识；方法级抽象使单条规则泛化到整个攻击家族，标签空间自适应扩展。
- **适用性**：完全黑盒、零参数更新，兼容开放权重和闭源 API 模型，实际部署门槛低。
- **评估设计**：采用冷启动在线协议避免数据泄漏；学习信号（同模型 LLM 判断）与评估信号（外部 GPT-4o-mini）分离，降低自优化偏差；同时使用拒绝短语和 LLM 评分双指标，主指标更稳健。
- **系统性分析**：包含自进化轨迹、消融、超参数敏感性、XSTest 过度拒答和案例研究，论证较为完整。

## 8. 不足与局限
