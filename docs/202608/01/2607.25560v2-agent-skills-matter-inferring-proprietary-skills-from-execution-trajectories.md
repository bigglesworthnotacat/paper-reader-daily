## 摘要
智能体技能封装了可复用的程序，能够提升下游性能。其轻量、可移植的形式支持市场变现和部署在云托管智能体接口之后进行私有化，这为提供商提供了保持高价值技能专有的动力。然而，隐藏工件并不能掩盖其行为效应，这些效应在执行轨迹中仍然可观察，并形成一种行为侧信道。我们将这种暴露定义为技能泄漏：通过良性查询引发的轨迹重建专有技能，而无需参考答案或成功标签。我们引入了SigLeak，一种黑盒框架，利用智能体行为中重复出现的技能签名。它构建多样化、决策丰富的诊断任务，对比匹配的技能启用和技能禁用轨迹，并从隔离的模式中迭代地完善重建的技能。在五个场景、三个模型家族和三个智能体框架中，SigLeak在几乎每种设置下都优于或匹配三种基线。它平均将技能禁用参考的成功率提高了6.88个百分点，并在我们用于粗粒度和细粒度语义相似度的度量SkillSim中取得了最高整体得分。这些结果表明，良性执行轨迹可能暴露专有的程序性知识。代码可在https://anonymous.4open.science/r/SigLeak-D1DB获取。

## Abstract
Agent skills package reusable procedures that improve downstream performance. Their lightweight, portable form enables marketplace monetization and private deployment behind cloud-hosted agent interfaces, giving providers incentives to keep high-value skills proprietary. Yet hiding the artifacts does not conceal their behavioral effects, which remain observable in execution trajectories and form a behavioral side channel. We define this exposure as Skill Leakage: reconstructing proprietary skills from trajectories elicited by benign queries, without reference answers or success labels. We introduce SigLeak, a black-box framework that exploits recurring skill signatures in agent behavior. It constructs diverse, decision-rich diagnostic tasks, contrasts matched skill-enabled and skill-disabled trajectories, and iteratively refines a reconstructed skill from the isolated patterns. Across five scenarios, three model families, and three agent frameworks, SigLeak outperforms or matches three baselines in nearly every setting. It raises the success rate by 6.88 percentage points over the skill-disabled reference on average and achieves the highest overall SkillSim, our metric for coarse- and fine-grained semantic similarity. These results show that benign execution trajectories can expose proprietary procedural knowledge. The code is available at https://anonymous.4open.science/r/SigLeak-D1DB.

## 2. 方法论：核心思想、关键技术细节与算法流程

- **核心思想**：技能会系统性地影响智能体的执行行为，留下可重复观察的“技能签名”（Skill Signatures）。SigLeak 通过同时激发和对比技能启用/禁用两种场景下的行为，将技能特有的模式从任务本身、基础智能体行为及随机性中分离出来。
- **两大组件**：
  - **Generator（生成器）**：执行“诊断任务构建”，基于给定上下文生成多样、决策密集的探针（probes），以最大程度暴露技能依赖的行为。
  - **Skill Synthesizer（技能合成器）**：执行“对比轨迹分析”，对比同一探针下技能启用与禁用时的配对轨迹，提取可复用的技能签名，并初始化或更新重建的技能。
- **关键细节**：
  - **配对执行协议**：对探针 `q`，启用条件为 `q_on = q`，禁用条件为 `q_off = c_off ∥ q`（`c_off` 为“不使用任何技能”的指令）。两组轨迹共享探针任务，差异可归因于技能本身。
  - **签名识别**：对轨迹对应用 Delta 运算符提取可观察差异，聚合为每轮签名集 `S(r)`；轨迹仅使用用户可见部分，不访问技能文档或内部状态。
  - **两阶段流程**：
    - **阶段 1（初始技能重建）**：仅基于公开任务描述生成 6 个互补探针，覆盖推理、工具选择、中间验证、错误恢复、输出格式和任务扩展，通过初始化得到 `{s_0}`。
    - **阶段 2（差异引导的主动细化）**：每轮生成 3 个探针，利用当前技能、先前探针摘要和累积签名定位未覆盖的行为差异，更新技能；若签名不再引起更新或探针预算耗尽则终止。
- **公式化表示**：
  - 技能增强智能体轨迹：`τ_s = A(q; s) = [(a1,o1),...,(aT,oT)]`
  - 技能泄漏推断：`\hat{s} = G(d; A_{s*})`
  - 技能签名累加：`S(r) = ∪_{q∈Q(r)} Delta(q; τ_on(q), τ_off(q))`
  - 初始化：`\hat{s}_0 = Initialize(S(0))`
  - 更新：`\hat{s}_r = Update(\hat{s}_{r-1}, S(r))`

## 6. 主要结论与发现

- **SigLeak 显著优于基线**：在几乎所有模型-配置组合中，SigLeak 取得最佳或并列最佳下游成功率；平均比“技能禁用”参考高 **6.88 个百分点**，高于 Direct Generation（+3.25）和 Naive Trace Summarization（+3.74）。
- **技能泄漏现实存在**：即使在技能文档被隐藏且部署了提示防御（SkillGuard5）时，从良性轨迹中仍可重建出可用的专有技能。
- **技能签名可被提取与区分**：SigLeak 能从不同类型技能中提取出目标特有的程序性知识，在 arXiv 区分任务中，推断技能与对应目标的相似度显著高于同领域其他技能。
- **阶段 2 的收益集中在前两轮**：迭代消融显示，SR 与 F1 在 round 2 达到峰值，后续轮次不再提升甚至下降，支持采用早期终止和有限预算。
- **执行轨迹是行为侧信道**：不同技能会诱发明显不同的执行模式（如公式优先 vs. 直接计算），即使最终答案相同，轨迹也能暴露程序化知识。

## 8. 不足与局限

- **实验覆盖限制**：全部实验在本地受控环境中进行，未对实际部署的商业智能体服务进行攻击，真实世界防御、网络延迟、日志差异等因素未被测试。
