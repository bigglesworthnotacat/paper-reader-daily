## 摘要
优化智能体工作流，如检索增强生成（RAG）流水线，需要在紧张的评估预算下导航离散组件选择的组合空间。现有方法——启发式搜索、黑箱优化和标准树搜索方法——并未显式利用这些工作流的组合结构，导致冗余计算和低效的预算分配。我们提出了Agent-UCT（基于智能体的成本感知上置信界应用于树），一种树搜索算法，通过从二部前缀重用图导出的重用感知正则化项扩展了UCT。Agent-UCT将选择偏向于利用先前物化的配置前缀的分支，在保持有效探索的同时减少冗余执行。我们的框架RAGSpace将来自LongRAG、LightRAG和Self-RAG的异构RAG组件统一到一个五维配置空间中，实现系统性的跨框架重组。WTB（工作流测试台）提供确定性重放、内容可寻址缓存和事务一致性，确保中间状态被物化一次并在搜索中重用。在HotpotQA和UltraDomain上的实验表明，Agent-UCT在评估的固定框架预设中识别出具有最高样本外性能的配置。在全池评估下，二部前缀重用相对于无前缀共享成本上界将逻辑搜索成本降低了73.6%。与全池评估相比，基于采样的评估进一步实现了4.2倍的墙钟加速。Agent-UCT、RAGSpace和WTB共同提供了一个用于成本意识、可复现和组合高效的智能体工作流优化的统一框架。

## Abstract
Optimizing agentic workflows, such as retrieval-augmented generation (RAG) pipelines, requires navigating a combinatorial space of discrete component choices under tight evaluation budgets. Existing approaches - heuristic search, black-box optimization, and standard tree search methods - do not explicitly exploit the compositional structure of these workflows, leading to redundant computation and inefficient budget allocation. We introduce Agent-UCT (Agent-based Cost-Aware Upper Confidence Bounds Applied to Trees), a tree search algorithm that extends UCT with a reuse-aware regularization term derived from a bipartite prefix reuse graph. Agent-UCT biases selection toward branches that leverage previously materialized configuration prefixes, reducing redundant execution while maintaining effective exploration. Our framework, RAGSpace, unifies heterogeneous RAG components from LongRAG, LightRAG, and Self-RAG into a five-dimensional configuration space, enabling systematic cross-framework recombination. WTB (Workflow Test Bench) provides deterministic replay, content-addressable caching, and transactional consistency, ensuring that intermediate states are materialized once and reused across the search. Experiments on HotpotQA and UltraDomain demonstrate that Agent-UCT identifies configurations with the highest out-of-sample performance among the evaluated fixed framework presets. Under full-pool evaluation, bipartite prefix reuse reduces logical search cost by 73.6% relative to the no-prefix-sharing cost upper bound. Compared with full-pool evaluation, sampling-based evaluation further achieves a 4.2x wall-clock speedup. Agent-UCT, RAGSpace, and WTB together provide a unified framework for cost-aware, reproducible, and compositionally efficient agentic workflow optimization.

## 1. 论文的核心问题与整体含义

智能体工作流（agentic workflow）优化是当前大模型应用落地的重要挑战。以检索增强生成（RAG）为代表的智能体系统，其行为由多个离散组件的配置组合决定，例如分块策略（chunking）、嵌入模型（embedding model）、检索 top-k、重排方法、生成提示词和反思调度等。每个组件都有若干可选方案，完整配置空间呈组合爆炸式增长——即使仅 5 个组件、每组件 3-5 个选项，也会产生数百至数千个候选配置。

该问题面临双重困难：

- **评估昂贵**：对单个配置的评估需在多个基准任务上执行完整的智能体流程，涉及多次 LLM 推理调用、检索操作和工具调用，单次评估耗时可达数秒到数分钟；
- **状态有依赖**：智能体工作流是有状态的，中间状态（已检索文档、已物化的嵌入、对话历史等）取决于执行前缀。当两个配置共享相同前缀（如相同的分块策略和嵌入模型）时，重复执行该前缀会造成大量冗余计算。

现有方法在此场景下均存在明显不足：

- **启发式网格搜索/随机采样**：忽略组合结构，将预算浪费在低潜力区域；
- **黑箱优化（贝叶斯优化、强化学习）**：将工作流视为不可分解的整体函数，无法利用前缀的组合式重用；
- **多臂老虎机算法**：假设各臂独立，无法刻画结构化依赖；
- **标准树搜索（MCTS/UCT）**：是面向游戏等低模拟成本和跨分支无计算重用的规划领域，而智能体工作流评估的代价是路径依赖的，共享前缀会产生显著的重用机会，标准 UCT 忽略了这一点。

论文因此提出 **Agent-UCT**（Agent-based Cost-Aware Upper Confidence Bounds Applied to Trees），一种将前缀重用感知的成本正则化项引入 UCT 选择策略的新型树搜索算法，同时配合统一配置空间 **RAGSpace** 和可复现执行骨干 **WTB**（Workflow Test Bench），共同构成一个成本感知、可复现、组合高效的智能体工作流优化框架。

## 2. 方法论：核心思想与关键技术细节

### 2.1 问题形式化

- 完整配置定义为：\(x = (o_1, o_2, \ldots, o_L)\)，其中 \(o_\ell \in \mathcal{O}_\ell\) 为第 \(\ell\) 阶段组件的一个选项；
- 搜索空间为所有层选项的笛卡尔积：\(\mathcal{X} = \mathcal{O}_1 \times \mathcal{O}_2 \times \cdots \times \mathcal{O}_L\)；
- 搜索状态为部分配置前缀：\(s = (o_1, \ldots, o_d)\)，根状态为 \(s_\emptyset = ()\)；
- 这种组合结构天然构成一棵搜索树：节点代表部分配置，叶节点代表完整配置。

### 2.2 Agent-UCT 选择策略

在标准 UCT 分数基础上，Agent-UCT 增加了一项由二部前缀重用图导出的边际成本惩罚项：

\[
\text{Agent-UCT}_t(s,a) = \hat{Q}_t(s,a) + c_{\text{UCT}} \sqrt{\frac{\log(N_t(s)+1)}{N_t(s,a)+1}} - \lambda_t \widehat{\Delta C}_t(s,a)
\]

其中：

- \(\hat{Q}_t(s,a)\)：经验奖励估计；
- 第二项为标准 UCT 探索项；
- \(\lambda_t = \lambda_0/\sqrt{t}\)：随时间衰减的正则化系数，使搜索早期偏向低成本分支，后期随奖励估计趋稳而减弱成本影响；
- \(\widehat{\Delta C}_t(s,a)\)：基于当前二部重用图估计的边际执行成本。

### 2.3 二部前缀重用图（Bipartite Prefix Reuse Graph）

论文定义了**簇级**和**项级**两种粒度的重用图：

- **簇级图**\(G_t^Z = (\mathcal{S}, \mathcal{Z}, E_t^Z)\)：连接配置前缀与基准簇（benchmark cluster），边 \((s', z) \in E_t^Z\) 表示前缀 \(s'\) 已在簇 \(z\) 上物化，可直接复用 WTB 缓存状态；
- **项级图**\(G_t^Q = (\mathcal{S}, \mathcal{I}, E_t^Q)\)：更细粒度地追踪到单个问题（question）级别的物化状态，用于采样评估模式下的精确成本核算。

### 2.4 评估模式与更新机制

- **全池模式**：评估终端配置在全部基准数据上的奖励 \(J(x_t)\)；
- **采样模式**：从每个簇中抽取小批量 \(B_{t,z}\)，估计奖励 \(\hat{J}_t(x_t) = \sum_z w_z \hat{R}_t(x_t, z)\)，大幅降低评估成本。

两种模式下均将评估奖励沿树路径回传，更新 \(N_t(s)\)、\(N_t(s,a)\) 和 \(\hat{Q}_t(s,a)\)，同时更新重用图 \(E_{t+1} = E_t \cup M_t\)，其中 \(M_t\) 为新物化的前缀-簇（或前缀-问题）键。

### 2.5 基础设施：WTB 与 RAGSpace

- **WTB**：构建在 AgentGit 之上，提供确定性重放、内容可寻址缓存和事务一致性，确保中间状态至多被物化一次并在整个搜索过程中被重用；
- **RAGSpace**：将 LongRAG、LightRAG、Self-RAG 三种框架的异构组件统一为五维配置空间（分块、查询、检索、后检索、生成），缺失阶段用恒等传递（identity passthrough）补齐，使跨框架组合成为可能。

## 6. 主要结论与发现

1. **跨目标配置差异显著**：Agent-UCT 在不同搜索目标下选出不同最优配置（表 2），表明不存在单一普适最优流程——HotpotQA-only 最优为“longrag 4k + identity + dense e5 + selfrag critique + simple llm”；UltraDomain-only 最优为“kg extraction + lightrag keywords + lightrag graph + lightrag vector enrich + simple llm”；联合目标最优为“kg extraction + identity + bm25 + dense hybrid + selfrag critique + lightrag answers”。

2. **样本外性能优于固定预设**：在 HotpotQA 上与 LongRAG 持平（p = 0.27）但显著优于 Self-RAG/LightRAG；在 UltraDomain 上显著优于全部三个预设（p < 0.0001）；联合目标下 Combined F1 最高（0.4542），显著优于 LightRAG 和 Self-RAG，相对 LongRAG 增益 +0.0334（p = 0.05）。

3. **前缀重用带来显著成本降低**：全池模式下，二部前缀重用将逻辑搜索成本从 10,920 降至 2,878，降幅达 **73.6%**。

4. **采样评估大幅提升效率**：相比全池评估，墙钟加速 4.2 倍、token 减少 5.73 倍、Chat API 调用减少 7.86 倍，且最佳配置的样本外性能依然优于基线。

5. **组件归因明确**：生成（generation）槽位对奖励变异的贡献最大（ANOVA η² = 0.769/0.831，RF 重要性 0.707/0.786），检索（retrieval）次之，其余槽位贡献有限——说明在评估的搜索空间内，生成+检索是性能差异的主驱动。

## 7. 优点

- **明确的问题意识**：聚焦智能体工作流评估中“路径依赖成本 + 前缀重用机会”这一被标准树搜索忽略的关键特性，问题的选择具有实际价值；
- **算法-系统协同设计**：Agent-UCT 算法与 WTB 执行基础设施、RAGSpace 配置空间三者配套设计，形成一个从搜索策略到工程实现的完整闭环；
- **多粒度成本估计**：簇级图支撑全池评估、项级图支撑采样评估的灵活切换，兼顾精度与效率；
- **衰减正则化的理论直觉**：\(\lambda_t = \lambda_0/\sqrt{t}\) 的衰减设计在搜索早期利用成本信息引导探索、后期保证收敛到真实奖励导向的优化目标，体现了探索-利用权衡下对成本信号的合理处理；
- **样本外评估设计严谨**：严格的 70/30 划分、固定骨干模型、统一随机种子，降低偶然因素干扰；
- **统计检验完备**：所有关键对比均报告 p 值，增强了结论可信度；
- **组件归因实验富有洞察**：明确指出生成/检索是性能差异主要来源，对后续 RAG 优化工作具有指导意义。

- **WTB 能力未充分释放**：论文仅验证了问题级和工作流级重用，WTB 对文件夹、文件、产物、依赖节点等更细粒度文件系统式执行结构的支持尚未在实际优化实验中评估；
- **

- **优化目标单一**：Agent-UCT 当前仅以任务奖励（F1/EM）作为优化目标，未将延迟、API 成本或 token 消耗作为多目标优化约束——尽管算法自身具备成本感知能力，但那是用于评估效率而非作为目标函数。在真实业务场景中，推理成本与响应速度往往与质量同等重要，缺乏多目标权衡设计限制了其工程实用性。

## 9. 总体评价与展望

Agent-UCT 是一篇“小切口、深闭环”的系统性工作。它精准抓住智能体工作流优化中“评估昂贵且路径相关”这一核心痛点，通过将前缀重用成本显式注入 UCT 选择策略，实现了成本感知的树搜索；同时搭配统一配置空间 RAGSpace 和可复现执行骨干 WTB，完成了从搜索算法到工程基础设施的完整落地。论文的实证结果有力地验证了核心主张：组合搜索能找到优于固定框架预设的工作流，且成本可降低近四分之三，采样评估进一步带来数量级的效率提升。组件归因实验也提供了富有指导意义的发现——生成与检索才是性能差异的主引擎。

不过，论文在理论深度和实验广度上仍有明显留白。缺乏收敛性保证使得算法更像是一种鲁棒的启发式而非有界最优策略；单一骨干模型和 384 个候选点的配置空间，也限制了结论的普适性。未来工作若能补充形式化的 regret 分析、扩展至更多组件与任务类型、引入多目标优化以及跨模型规模的行为验证，将显著提升这一框架的理论价值和实践覆盖面。总体而言，这是一篇问题意识清晰、系统设计完整、实验执行严谨的高质量应用型研究，对 RAG 智能体自动优化领域具有实质性的推动作用。
