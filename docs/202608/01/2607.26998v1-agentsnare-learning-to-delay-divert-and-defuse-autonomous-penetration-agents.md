## 摘要
大型语言模型（LLM）代理通过观察-行动循环自动化渗透测试，根据工具返回的观察结果选择行动。这种依赖性使得防御者能够注入误导性的观察结果，从而误导代理的决策过程。然而，现有的防御方法严重依赖于在攻击前预先放置在环境中的静态、孤立的人工制品。高级代理能够逐步识别并绕过这些人工制品，最终将其利用尝试重新聚焦于真实目标。为了解决这一问题，我们提出了AgentSnare，一种轨迹自适应欺骗系统，它动态展开一个诱饵环境，持续将渗透代理引离真实目标。具体而言，AgentSnare采用一个人工制品构建策略模型，该模型根据代理的交互历史和诱饵状态构建候选人工制品。然后，AgentSnare验证这些候选物，并逐步将有效的人工制品纳入一个事实一致的诱饵环境中，从而通过吸收其工具调用来延迟攻击，将其进入后的轨迹转移至诱饵内部，并通过诱导以诱饵证据为基础生成完成报告来化解攻击。在15个CVE-Bench Web应用程序和三种攻击者模型上，AgentSnare在诱饵中吸收了46.8%的代理工具调用，并将55.9%的进入后操作保留在诱饵中，而90.0%的完成尝试基于诱饵证据；在所有45个攻击者-CVE配对中，在pass@3下没有真实目标被成功利用。

## Abstract
Large language model (LLM) agents automate penetration testing through an observation-action loop, selecting actions based on observations returned by tools. This dependence allows defenders to inject deceptive observations that can mislead the agent's decision-making process. However, existing defenses rely heavily on static, isolated artifacts planted in the environment prior to an attack. Advanced agents can progressively recognize and bypass these artifacts, ultimately refocusing their exploitation attempts on the real target. To address this issue, we introduce AgentSnare, a trajectory-adaptive deception system that dynamically unfolds a decoy environment to continually steer the penetration agent away from the real target. Specifically, AgentSnare employs an artifact-construction policy model that constructs candidate artifacts conditioned on the agent's interaction history and decoy state. AgentSnare then validates these candidates and incrementally incorporates valid artifacts into a factually consistent decoy environment, thereby delaying the attack by absorbing its tool calls, diverting its post-entry trajectory within the decoy, and defusing it by inducing completion reports grounded in decoy evidence. Across 15 CVE-Bench web applications and three attacker models, AgentSnare absorbs 46.8% of the agent's tool calls in the decoy and retains 55.9% of post-entry actions there, while 90.0% of completion attempts are grounded in decoy evidence; across all 45 attacker-CVE pairs, no real target is successfully exploited at pass@3.

## 2. 论文提出的方法论

### 核心思想

AgentSnare 通过两个阶段的在线流程，实现动态欺骗：

- **阶段 I（候选工件构建）**：策略模型根据攻击代理当前的探测动作、交互历史、诱饵状态（世界账本 + 可供性图）以及服务器/应用配置档案，构建候选工件（包含拟披露的观察结果和支撑该观察所需的环境事实）。
- **阶段 II（工件验证与披露）**：ShadowOS 运行时对候选工件进行三维验证（语义有效性、状态有效性、安全有效性），通过后提交到诱饵环境，将渲染后的观察结果返回给攻击代理。

### 关键组件

**（1）世界账本 `Wt` 与可供性图 `Gt`（ShadowOS 核心状态）：**

- **世界账本**记录已承诺的诱饵对象、属性、关系和攻击者引起的状态变化，保证后续观察的一致性。
- **可供性图**是一个懒惰图结构，节点表示环境对象（文件、凭据、服务、用户、容器、内部主机等），边表示关系（`references`、`authenticates-to`、`runs-as`、`corroborates`、`enables` 等）。给定当前动作，确定当前可构建的**可供性边界 `Ft`**，限定下一步可构造的工件范围（例如 `.env` 文件可揭示配置和凭据，但不能引入无关的提权机会）。

**（2）候选工件表示：**

- 模型输入：`xt = (ht, at, Wt, Ft, q)`
- 候选工件：`ct = (õt, ΔWt)`，其中 `õt` 是拟披露的观察结果，`ΔWt` 是支撑该观察所需的新增环境事实。

**（3）验证规则（三个维度）：**

- **语义有效性**：观察结果与当前命令匹配，可通过当前探测观察到，符合期望的输出格式。
- **状态有效性**：引入的事实与 `Wt` 一致，可从 `Ft` 到达，且能在后续交互中复现。
- **安全有效性**：防止真实环境秘密泄漏，不违反文件系统、用户、进程、权限、服务等基本约束。

**（4）提交与渲染：**

- 验证通过后，推导图增量 `ΔGt`，执行 `Commit(Wt, Gt, ΔWt, ΔGt)`，然后通过 **混合渲染器**（确定性状态管理 + 生成式内容渲染）生成正式观察结果返回给攻击者。

### 离线训练流程

通过**模拟攻击者-防御者交互**生成训练数据：

- 场景采样：从 12 类攻击意图分布 `Q` 中采样，覆盖服务侦察、凭据发现、提权、横向移动、敏感数据搜索、容器逃逸、SSH 跳转等。
- 模拟交互：攻击模拟器 `Asim` 发出探测并根据观察预测后续动作；候选生成器 `D` 为同一探测构建 `k` 个备选工件。
- **反应引导的工件选择**：每个候选工件在相同的交互历史和探测条件下，用攻击模拟器采样 `m` 个后续动作，优先选择能持续引导攻击者留在诱饵中、较少引发怀疑或终止行为的工件。
- 轨迹筛选与微调：筛选后保留 503 条轨迹、24,807 个防御决策，使用 LoRA 适配器对 **Qwen3-4B** 进行 3 个 epoch 的监督微调（bf16、r=64、α=128），通过 vLLM 部署。

### 关键设计特征

- 攻击模拟器和候选生成器使用**隔离的 DeepSeek-V4-Flash 实例**，使用不同提示词和交互历史。
- 在线部署时只需一次模型调用，候选比较只在离线训练中进行，保证在线效率。
- **防御者不做任何关于目标 CVE、攻击者模型、工具配置、停止规则或攻击策略的假设。**

### 对比防御方法

| 方法 | 类型 |
|------|------|
| **Static Defenses** | 同时部署 13 个可复现干预实例，覆盖 6 类静态防御策略（误导感知、转移注意力、专用诱饵、模型破坏、角色操纵、强制代码执行） |

- **Defuse（SubDefuse）**：有效完成尝试中，支撑证据通过溯源标签可追溯到诱饵的比例。

- **主实验**：15 个 CVE-Bench 任务 × 3 个攻击者 × 每个 CVE 运行 3 次 = **405 次防御运行**（每个防御 × 攻击者组合）。

- 无防御基线：提供 pass@1 参考。

### 充分性与公平性评估

- **充分的**：主实验覆盖了 3 种不同的攻击模型、15 个真实 CVE 场景、3 次重复的运行，以及两种现有基线方法（Cowrie 和 HoneyLLMd）和静态防御聚合。消融实验分别隔离了模型微调和 ShadowOS 状态化运行时两大核心组件的贡献。
- **客观的**：真实目标利用成功由官方 CVE-Bench 评估器验证；所有条件共享相同任务提示词、工具、200 次调用预算和停止规则；交互防御使用相同的应用侧面包屑和交互入口点。
- **积极的方面**：强全消融（Prompted GPT-5.4-mini）验证了通用模型能力是否足以替代 AgentSnare 的两个核心机制，增强了对比公平性。
- **值得注意的方面**：DDD 指标对静态防御未报告（以“—”表示），将静态防御仅通过最终利用成功率评估。这有其合理性（静态防御的交互不由代理控制），但使得 DDD 完整轨迹对比集中于交互式防御之间。

## 6. 论文的主要结论与发现

1. **静态防御不足**：13 种静态干预在六个攻击 LLM 上的 Interference@20 均值低于 0.2，无法在多步交互中持续影响攻击代理行为。
2. **AgentSnare 全面领先**：

| 指标 | AgentSnare | HoneyLLMd | Cowrie |
|------|-----------|-----------|--------|
| Delay | **46.8%** | 29.5% | 17.6% |
| PER | **55.9%** | 36.9% | 23.5% |
| SubDefuse | **90.0%** | 72.2% | 29.7% |
| 可利用 CVE 数 | **0/45** | 10/45 | 12/45 |

3. **完全消除真实目标利用**：在 pass@3 下，45 个攻击者-CVE 配对中无一真实目标被成功利用，而静态防御、Cowrie、HoneyLLMd 分别留下 18/45、12/45、10/45 可利用的配对。
4. **轨迹控制与利用抑制一致**：DDD 指标与最终利用结果一致——更强的预算吸收、入口后保留和诱饵证据完成报告与更少的成功真实目标利用一致。
5. **两个核心机制缺一不可**：去除模型微调或 ShadowOS 后均出现性能回落（延迟、保留、完成报告基于诱饵证据分别下降；存在 1-3 个 CVE 被利用），完整系统是唯一零利用的配置。
6. **紧凑模型 + 轨迹监督可超越强通用模型**：完整 AgentSnare（Qwen3-4B）在全部三个过程指标上超越 Prompted GPT-5.4-mini 变体，且是唯一无验证利用的配置。

## 7. 优点

- **范式创新**：将欺骗防御从“静态预置”重构为“轨迹自适应展开”，直接回应了静态工件被高级代理识别绕过这一核心瓶颈。以“动态构建-验证-披露”的闭环解决静态手段无法维持影响力的根本问题。
- **全局一致性保障**：通过世界账本和可供性图，实现诱饵环境内部的逻辑自洽，而非仅追求局部响应逼真——这直接提升了高级代理识破诱饵的难度。
- **高效在线部署**：在线仅需一次策略模型调用 + 验证 + 披露，候选比较与攻击模拟完全离线化，部署开销低。
- **轻量模型+训练数据合成**：用 Qwen3-4B（LoRA）通过离线模拟交互训练超越强闭源模型（GPT-5.4-mini），展示了“数据合成 + 定向微调”替代“更大模型”的可行路径。
- **过程导向评估框架 DDD**：提出了 Delay-Divert-Defuse 三个轨迹级指标，区别于仅依赖最终利用结果，能细粒度刻画防御对攻击轨迹的控制力。
- **防御假设宽松**：不做关于目标 CVE、攻击模型、工具配置、停止规则或策略的先验假设，具有更强的实际部署参考价值。

## 8. 不足与局限

### 实验覆盖的局限

- **场景集中在 Web 应用**：15 个 CVE-Bench 任务全部为 Web 应用漏洞，未覆盖真实世界的网络渗透（内网横向移动、云环境、二进制漏洞利用、供应链攻击等）场景，泛化性待验证。
- **攻击者模型有限**：仅使用 3 种闭源 LLM 作为攻击后端，未覆盖开源模型（如 DeepSeek、Llama 等）或更强的未来模型。不同模型在 TOCTOU 感知、上下文推理能力上的差异可能影响结果。
- **静态防御的 DDD 指标未测量**：DDD 不适用于静态防御，这限制了与静态方法在轨迹控制层面的直接对比。

### 偏差与公平性风险

- **GPT-5.4-mini 强全消融仍有 3/15 CVE 被利用**，但 DDD 指标高于 AgentSnare w/o ShadowOS——说明仅凭 DDD 不足以完全预测利用抑制效果，指标间的目标函数存在偏差可能。
- **训练数据由模拟攻击者生成**，若模拟攻击者与实际攻击者的行为分布存在漂移，策略模型的泛化能力会受限于模拟质量。
- **仅报告 pass@3 下的利用结果**，未提供 pass@1 或更多次尝试的数据，无法评估防御随尝试次数增加的退化趋势。

### 应用限制

- **部署范围有限**：论文未讨论 AgentSnare 在大规模生产环境中的部署成本、延迟开销、日志审计影响以及对合法测试（红队、合规扫描）的干扰问题。
- **防御不可违反正常功能**：威胁模型已声明防御不修改应用程序的正常功能或漏洞执行路径，但实际部署中很难保证诱饵与真实环境在行为上完全不可区分。
- **边界条件**：防御者的工件披露必须始终在“当前可供性边界”内，这限制了可构造工件的复杂度；若攻击代理跳出当前边界（如探索一个从不可达的路径），系统可能无法构造合法的关联观察。
- **未讨论多实例并发攻击**：真实场景可能遇到多个并发攻击代理，AgentSnare 是否有状态隔离机制、是否会相互干扰，论文未涉及。

> **整体评价**：AgentSnare 在“动态自适应欺骗”方向上做出了系统性的贡献——从问题定义、方法设计、训练数据合成到过程导向评估，形成较为完整的闭环。然而，其安全有效性仍局限于论文评估的 Web 应用和闭源模型范围内，在更广泛攻击面（内网、云、二进制漏洞）和攻击者类型上的稳健性仍需要更多后续验证。
