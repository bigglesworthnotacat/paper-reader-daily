## 摘要
随着大语言模型（LLM）智能体被应用于持续交互的环境中，驱动其自身能力的进化成为实现长期自主性的核心问题。当前，环境知识通常被视为外部的固定输入，而非智能体持续进化的一部分。强化学习方法通常通过环境交互来优化策略，但往往只能适应固定的任务分布或单一环境。本文提出 TTSE（Two-Track Self-Evolution），一种双轨在线自进化框架，将演化知识分离为 FACT（环境事实，其可靠性通过交互证据持续验证）与 TIP（任务条件化的实现流程）。从决策论视角，我们将智能体的超额风险分解为环境表示遗憾和条件执行遗憾，刻画了环境条件化策略严格优于条件无关策略的条件，并以 FACT 识别误差和跨条件失配成本来界定下游风险。在实践中，TTSE 在 GDPevo 上的消融实验验证了双轨进化的优势。在经典智能体任务基准 ALFWorld 和 ScienceWorld 上，TTSE 进一步展现出更优的任务适应能力。此外，TTSE 与现有技能自进化方法广泛兼容；与 Bayesian-Agent 算法结合后，单轨消融验证了双轨优势，在三次独立重复中显著提升了 SOPBench 五个主要领域的总体得分。最后，在真实端到端任务基准 PinchBench 上，TTSE 通过基于检索的注入方式集成到通用智能体框架中，并在三次独立运行中稳定优于基线。

## Abstract
As Large Language Model (LLM) agents are applied in continuously interactive environments, driving the evolution of their own capabilities becomes a core problem for achieving long-term autonomy. Currently, environmental knowledge is typically treated as an external fixed input rather than as part of the agent's ongoing evolution. Reinforcement learning methods usually optimize policies through environmental interaction but tend to adapt only to fixed task distributions or single environments. This paper proposes TTSE (Two-Track Self-Evolution), a dual-track online self-evolution framework that separates evolving knowledge into FACT (environmental facts, whose reliability is continuously verified through interaction evidence) and TIP (task-conditioned implementation procedures). From a decision-theoretic perspective, we decompose the agent's excess risk into environment-representation regret and conditional-execution regret, characterize the conditions under which environment-conditioned policies strictly outperform condition-agnostic policies, and bound the downstream risk in terms of FACT identification error and cross-condition mismatch cost. In practice, TTSE's ablation experiments on GDPevo validate the advantage of dual-track evolution. On the classic agent task benchmarks ALFWorld and ScienceWorld, TTSE further demonstrates superior task adaptation. Moreover, TTSE is broadly compatible with existing skill self-evolution methods; combined with the Bayesian-Agent algorithm, a single-track ablation validates the dual-track advantage, substantially improving the aggregate score across the five major domains of SOPBench over three independent repetitions. Finally, on the real end-to-end task benchmark PinchBench, TTSE is integrated into a general agent framework via retrieval-based injection and stably outperforms the baseline across three independent runs.

# TTSE：一种面向 LLM 智能体的双轨在线自进化框架——论文总结

## 1. 核心问题与整体含义

- **研究动机**：LLM 智能体（结合推理、工具使用、环境交互）在软件开发、网页操作、科学探索、具身任务等场景已展现强大自主执行能力，但在开放环境中面临持续交互、多任务切换、未知状态变化等挑战，仅靠预训练获得的静态知识无法支撑长期自主运行。
- **关键缺口**：现有自进化工作（Reflexion 的反思、Voyager 的技能库、ExpeL 的规则、Bayesian-Agent 的后验更新）核心目标始终是回答"面对任务该采取什么行为"，即只管理"执行技能"；而"环境是什么样的"这类知识通常以任务描述、提示上下文等**外部静态形式**引入，而非可自主积累、验证、修订的进化对象。
- **现实后果**：只优化技能的智能体可能学到仅在特定隐藏条件下有效的经验，当环境条件变化时产生**错误迁移**；反之，只积累环境知识也无法转化为执行能力。因此长期自主智能体必须同时解决两个互补问题：**如何行动**，以及**在当前交互证据下哪些环境规律具有稳定有效性**。
- **整体含义**：论文提出 TTSE，把智能体经验知识划分为两条独立但共同进化的轨道——FACT（环境事实，陈述性）与 TIP（任务条件化实现流程，程序性），并主张这是一种**结构性归纳偏置**，而非普适表达能力优势。

## 2. 方法论

### 2.1 核心思想

- 知识分离为两个**规则生命周期**，各自可独立归因、验证、退役与矛盾综合，而非单一无差别规则库。
- FACT 描述环境的陈述性属性（如"关闭容器内的物体在打开前不可见"），需可由环境观测直接验证，主语是**世界/物体/用户**。
- TIP 描述条件化动作策略（如"当任务需要同类型多个物体时，放下第一个后继续搜索剩余物体"），必须写成 `<condition>: <action>` 的显式条件格式，使隐藏上下文在表示层面可见。

### 2.2 关键技术细节

- **FACT/TIP 分类机制（无需额外分类器或标注数据）**：
  - *主语测试*：规则主语是环境/物体 → FACT；是智能体自身 → TIP。
  - *必要性测试*：违反规则直接导致任务失败 → FACT（硬约束）；仅降低效率 → TIP（软启发式）。
  - 不确定时**默认判为 TIP**，采用保守策略防止 FACT 污染（把仅在特定条件下成立的推测性泛化误标为普遍真理，侵蚀 FACT 库可信度）。
- **在线进化流水线（分块增量循环）**：训练任务分成 N 个等大 chunk，每个 chunk 结束后触发一次规则库更新（区别于 ExpeL 的离线一次性归纳），四阶段严格有序：
  1. **Blame（归因）**：逐个分析当前 chunk 的失败轨迹，判断失败是否可归因于某条注入规则；最多归因到**一条**规则，防止责任稀释，且必须指出规则造成损害的具体步骤。
  2. **Retire（退役）**：被归因规则移出活跃库进入 retired pool，附审计记录（退役原因、chunk 索引、时间戳）；不再参与注入，但文本与原因保留。
  3. **Contradict/Synthesize（矛盾/综合）**：扫描 retired pool 找"对同一环境属性给出相反建议"的规则对，将其视为隐藏环境条件的强信号，综合为一条带显式条件的 TIP，使智能体后续可按条件选择正确行为分支。
  4. **Induce（归纳）**：基于当前 chunk 全部成功/失败轨迹增量更新规则库，分两阶段——*compare*（对比同一任务的成功与失败轨迹，提炼改进）与 *success-only*（从所有成功轨迹归纳可复用通用策略）；以 `keep_bank=True` 保持既有知识，通过 EDIT/AGREE/REMOVE/ADD 四种操作做局部优化。
- **冷启动（Chunk 0）**：首个 chunk 不注入任何规则，智能体以零知识运行，初始规则集完全由第一批经验归纳，避免既有偏置影响。
- **计数投票生命周期**：ADD +2（初始信任）、AGREE +1、EDIT +1、REMOVE −1（相似/冗余）或 −3（矛盾）；count ≤ 0 自动删除。
- **注入方式**：`all` 模式（按计数降序全量注入，受 top_n_facts/top_n_tips 截断）或 `topk` 模式（用 sentence-transformers 编码任务描述与规则文本，按余弦相似度取每通道 top-K）。

### 2.3 理论框架（决策论刻画）

- **问题设定**：可观测量 `o ∈ O`（任务指令+交互历史），潜在环境条件 `z ∈ Z`（物体状态、工具语义、API 行为、领域约束差异），动作 `a ∈ A`，有界损失 `ℓ(o,z,a) ∈ [0,1]`。FACT 通道构造环境表示 `F: O → S`，TIP 通道实现条件策略 `π: O × S → Δ(A)`，二者共同诱导期望风险 `R(F,π)`。
- **命题 1（表示–执行误差精确分解）**：对任意 F 与 π，相对环境感知 oracle 的超额风险可**精确**分解为两项非负项：
  `R(F,π) − R* = E_TIP(F,π) + E_FACT(F)`
  其中 `E_TIP` 是当前表示下剩余的**执行遗憾**，`E_FACT` 是仅靠改进执行无法消除的**表示遗憾**（即便表示足够充分，执行也可能失败；即便执行策略有效，也无法弥补遗漏决策相关区分的表示）。
- **命题 2（环境条件化的价值）**：定义环境无关策略类 `Π_agn` 与环境条件化策略类 `Π_cond`，由于 `Π_agn ⊆ Π_cond`，价值 `H = R*_agn − R*_cond ≥ 0`；当同一可观测上下文以正概率兼容多种需要不同最优动作、且存在正损失边际的条件时，`H > 0` 严格成立。**推论 1（二元冲突环境）**：两种等概率、需互不相容唯一动作、上下文无法区分的条件下，任何环境无关策略成功率至多 1/2，而正确识别条件并执行对应动作可达 1。
- **命题 3（双源超额风险界）**：定义 FACT 识别误差 `η_F = Pr[F(o) ≠ z]` 与跨条件动作失配最大成本 `Δ_max ∈ [0,1]`，在 TIP 策略类可实现 plug-in 条件策略时：
  `E_FACT(F) ≤ η_F · Δ_max`，进而 `R(F,π) − R* ≤ E_TIP(F,π) + η_F · Δ_max`。
- **理论定位**：给出两条互补改进路径（TIP 进化降低执行遗憾，FACT 进化降低错误条件分支概率）；FACT 误差影响被跨条件失配成本放大。论文明确声明该理论**不**保证每轮交互后单调改进，也不声称实现过程收敛到 oracle 风险；分离只是让两类误差可**分别管理**的模块化归纳偏置。

## 3. 实验设计

### 3.1 基准与场景（五类，对应四个研究问题）

| 层次 | 基准 | 研究问题 |
|---|---|---|
| 机制 | GDPevo | 双轨 vs 单轨消融 |
| 可迁移性 | SOPBench | 消融及与其他机制的兼容性 |
| 端到端 | ALFWorld / ScienceWorld | 经典基准上的任务适应 |
| 部署 | PinchBench | Harness 兼容性与实用价值 |

- **ALFWorld**：具身智能体基准，134 个有效未见任务、6 种任务类型（pick&place / examine / clean / heat / cool / pick two）；从训练集随机采样 500 个任务，5 个 chunk（chunk_ratio=0.2），50 分片并行，每任务最多 50 步；用最终 chunk 的规则库评估。
- **ScienceWorld**：文本科学实验模拟，30 种任务类型（化学、生物分类、物理测量、遗传学）；GLM-5（thinking）在线训练，30 分片、max 50 步、5 chunk。
- **GDPevo**：多领域企业运营基准，覆盖 CRM、ERP、金融、HR 的 12 个任务组；GLM-5 训练，max_steps=16。
- **SOPBench**：选取 5 个代表性大样本领域（aircraft_inspection 112、customer_service 156、dangerous_goods 274、referral_abuse 200、warehouse_package_inspection 150，共 892 任务 ×3 次重复 = 2676 次评估）。
- **PinchBench**：147 个真实端到端任务，覆盖写作、编码、研究、CSV 分析、会议纪要、日志分析、浏览器自动化；独立 judge（deepseek-chat）按 0–1 连续分打分；集成在通用智能体框架 OpenClaw 上（版本 2026.7.1-2，PinchBench 2.0.0 固定 commit 819384ae）。

### 3.2 对比方法

- ALFWorld：ReAct、ExpeL、GraSP（及其复现的 ReAct/ExpeL 结果）、SkillOpt、SkillX（同设定复现）；骨干为 DeepSeek-V3.2 与 GLM-5。
- ScienceWorld：自身基线（Baseline R1–R3）对比 TTSE R0–R2。
- GDPevo：四条件消融——base（零样本）、facts（仅 FACT）、tips（仅 TIP）、full（FACT+TIP），仅双轨提示措辞不同。
- SOPBench：baseline（无规则注入）、single-track（统一"rule"类型 + 贝叶斯后验）、dual-track Fusion（FACT/TIP 双通道各 top-8）。
- PinchBench：`TTSE_ENABLE=0` 裸智能体 vs 语义检索注入（top-10 FACT 写入 ENVIRONMENT.md、top-10 TIP 写入 TIPS.md，all-MiniLM-L6-v2 384 维编码）。

### 3.3 关键实验设置

- TTSE 核心路径（EXPEL）用启发式计数投票（+1/−1/−3）与 5 阶段 chunk 循环；Fusion（BA）路径用贝叶斯后验 `Beta(α,β)` 替换计数，退役策略为 `P(success)<0.45 且 β≥4 → retire`、`P(success)≥0.72 且观测≥3 → stable/compress`、否则 explore；采用定向信用分配（仅更新与任务相关、渲染过且匹配 failure_mode 的规则）。
- 所有实验三次独立重复取均值，报告均值±标准差，并做配对 bootstrap（10,000 次重采样）、置换检验（10,000 次）与 Bonferroni 校正（5 领域 → α=0.01）。

## 4. 资源与算力

- **论文未披露任何 GPU 型号、数量或训练时长**。所有 LLM 调用均通过 API 完成（DeepSeek-V3.2、GLM-5、DeepSeek v4-flash、作为 judge 的 deepseek-chat），嵌入使用 all-MiniLM-L6-v2（384 维）；因此不存在传统意义上的本地训练算力开销。

- GDPevo：4 条件 × 3 次运行 = 12 组训练+评估。
- SOPBench：5 领域 × 3 配置 × 3 次运行 = 45 组独立实验，892 任务 ×3 重复 = 2676 次评估；另含配对 bootstrap/置换检验、排除 warehouse 的稳健性检验。
- PinchBench：147 任务 × 2 配置 × 3 次运行；规则库由 147 任务分 15 组在线演化产生（最终约 35–50 条 FACT、30–45 条 TIP）。

**充分性与客观性评估**：
- **优点**：跨 5 个基准、多种骨干（GLM-5、DeepSeek-V3.2、DeepSeek v4-flash）、两类证据追踪机制（启发式计数与贝叶斯后验）、多任务域验证；全部结果取三次重复均值并披露逐 run 数值；进行了统计显著性检验与稳健性分析；**主动披露负向结果**（dangerous_goods 上双轨低于单轨 −0.61pp，p=0.296 不显著）；PinchBench 提供六方面方法学披露（模型、版本、规则库来源、泄漏协议、真实运行、非侵入式注入）。
- **需谨慎之处**：GDPevo 中 full vs TIP-only 的 +2.4pp 差距**未做正式显著性检验**，论文自述只能作为消融证据而非统计认证的边际；SOPBench 的 +2.99pp 优势中 warehouse 贡献 78%，剔除后仅剩 +0.67pp（p=0.011，Bonferroni 校正后不显著）；aircraft 与 customer 存在明显天花板效应（单轨已达 97.6%–97.9%）；ALFWorld 的 GraSP 等数字引自原论文，并非同一代码库复现，跨论文比较的公平性有限。

## 6. 主要结论与发现

- **双轨优于单轨**：GDP
