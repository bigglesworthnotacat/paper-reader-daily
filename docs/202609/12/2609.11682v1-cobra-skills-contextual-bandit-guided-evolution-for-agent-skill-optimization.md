## 摘要
大型语言模型（LLM）智能体可以受益于从先前任务经验中提炼出的可复用技能，但现有的技能优化方法往往依赖昂贵的基于执行的评估和大量任务数据。我们提出 COBRA-Skills，一个高效框架，将技能优化形式化为在动态演化的候选空间上的预算受限序贯优化。COBRA-Skills 将上下文赌博机引导的优先级排序与基于证据的技能演化相结合，有选择地将评估分配给有前景或信息量大的候选者，同时根据执行反馈持续改进技能种群。在六个异构智能体基准和三个目标模型上，COBRA-Skills 在对比方法中始终取得最强的平均性能，同时相对于 SkillOpt 将优化成本降低 55–58%，且每个基准仅使用 50 个不重复的优化示例。进一步分析表明，COBRA-Skills 对智能体运行框架的变化保持稳健，并且当目标模型本身用于技能生成和细化时也能有效运行。

## Abstract
Large language model (LLM) agents can benefit from reusable skills distilled from prior task experience, yet existing skill optimization methods often rely on costly execution-based evaluation and substantial task data. We introduce \textbf{COBRA-Skills}, an efficient framework that formulates skill optimization as budgeted sequential optimization over a dynamically evolving candidate space. COBRA-Skills couples contextual-bandit-guided prioritization with evidence-grounded skill evolution, selectively allocating evaluations to promising or informative candidates while continually refining the skill population from execution feedback. Across six heterogeneous agent benchmarks and three target models, COBRA-Skills consistently achieves the strongest average performance among compared methods, while reducing optimization cost by 55--58\% relative to SkillOpt and using only 50 unique optimization examples per benchmark. Further analyses show that COBRA-Skills remains robust to changes in the agent harness and performs effectively when the target model itself is used for skill generation and refinement.

## 1. 核心问题与研究动机

- **背景**：LLM 智能体在大量任务中会反复遇到相似的目标、流程、工具和失败模式。智能体技能（agent skill）可将这些可复用的程序性知识（任务指南、推理策略、工具使用流程）编码为轻量文本，在解决新任务时注入上下文。
- **核心痛点**：
  - 人工编写高质量技能成本高、依赖领域专家；
  - 直接用 LLM 参数知识生成技能可能看似合理但缺乏依据，难以稳定提升下游性能；
  - 现有基于执行轨迹与反馈的技能优化方法存在两个效率瓶颈：
    1. **候选效用评估昂贵**：需在任务或验证集上执行候选技能才能观测真实效用，大量预算浪费在低质量候选上；
    2. **技能精炼昂贵**：反复调用 LLM 分析轨迹、诊断失败、生成或聚合修改，token 成本高。
- **核心问题**：在有限计算预算与有限任务经验下，如何**选择性分配候选评估**，并**高效复用执行证据**来持续改进技能，而非穷举评估和反复重写。
- **整体含义**：将技能优化形式化为**动态演化候选空间上的预算化序贯优化**问题，用上下文赌博机在“利用有前景技能”与“探索未充分评估技能”之间平衡，同时用证据驱动的演化不断更新候选空间。

## 2. 方法论

### 2.1 核心思想
- 维护一个固定大小的候选技能种群，每轮用**上下文赌博机**选出最值得评估的技能，交给目标智能体在小型优化集上执行，获得奖励与轨迹反馈。
- 反馈进入优化历史，用于：① 更新神经奖励预测器；② 更新 LinearUCB 设计矩阵；③ 周期性驱动技能种群演化。
- 形成“**赌博机引导优先级排序** + **证据驱动技能演化**”的闭环。

### 2.2 关键技术细节

**（1）问题形式化**
- 给定小型优化集 \(D_{opt}\) 与无技能初始轨迹 \(T_0\)，在固定优化轮数 \(T\) 内探索候选技能集合 \(S_T\)，目标是找到在任务分布 \(D\) 上期望指标最大的技能 \(s^\star\)。

**（2）神经奖励预测**
- 技能 \(s\) 经固定嵌入模型 \(\phi\) 得到语义表示 \(z_s=\phi(s)\)。
- 用轻量两层 MLP \(f_\theta\)（ReLU 隐层、标量输出）从技能嵌入预测奖励，损失为 MSE + L2 正则：
  \[
  L(\theta)=\frac{1}{|H_t|}\sum_{(s_i,z_i,r_i)\in H_t}(f_\theta(z_i)-r_i)^2+\beta\|\theta\|_2^2
  \]
- 每次新观测后，在全部累积历史上重新初始化并拟合预测器。

**（3）LinearUCB 探索奖励**
- 对候选技能计算置信奖励：
  \[
  b_t(z_s)=\nu\sqrt{z_s^\top A_{t-1}^{-1}z_s}
  \]
  其中 \(A_{t-1}=\lambda I+\sum_{i=1}^{t-1}z_{s_i}z_{s_i}^\top\) 为正则化设计矩阵。
- 语义空间中越少被探索的区域，奖励越大；反复评估过的技能及其邻近区域不确定性降低。

**（4）赌博机优先级分数**
- 综合利用与探索：
  \[
  U_t(s)=f_{\theta_{t-1}}(z_s)+b_t(z_s)
  \]
- 每轮选择 \(U_t(s)\) 最高的技能进行评估；同一分数也用于种群更新时的剪枝。

**（5）证据驱动技能演化**
- 按对数调度周期性触发（满足 \(t-t_{last}\ge d\) 且 \(\log(t/t_{last})\ge\eta\)）。
- 用更新后的预测器与设计矩阵重新计算优先级，剪掉最低的 \(m\) 个技能，由三种算子补充：
  - **Regeneration（再生）**：从原始无技能轨迹 \(T_0\) 独立生成新候选，不依赖父技能，保持种群多样性，避免过早收敛。
  - **Rollout Mutation（轨迹变异）**：用当前轮被评估技能产生的成功/失败轨迹，对父技能做局部、保守的修正，连接赌博机评估与证据驱动精炼。
  - **Crossover（交叉）**：将历史中已评估技能分为高/低绩效组，采样一个强技能为骨干，另一个强技能提供正证据，低绩效技能提供负证据，进行性能驱动的重组，而非直接拼接。
- 新技能不继承奖励，必须重新进入赌博机评估循环。

**（6）算法流程（Alg. 1 概述）**
1. 初始化优化集、无技能轨迹、初始技能种群 \(P_1\)、轮数 \(T\)、演化参数。
2. 每轮：对种群中每个技能计算嵌入与优先级分数 → 选最高分技能 → 目标智能体在 \(D_{opt}\) 上评估 → 记录奖励与轨迹 → 更新历史与设计矩阵 → 重训神经网络。
3. 若达到演化调度：执行演化，剪枝低优先级技能并替换为新生成技能；否则种群不变。
4. 最终返回历史中平均奖励最高的技能。

**（7）关键超参数**
- 轮数 \(T=30\)，种群大小 \(K=10\)，每次演化剪枝 \(m=3\)；
- LinearUCB 正则 \(\lambda=0.03\)，探索系数 \(\nu=0.1\)；
- 演化最小间隔 \(d=3\)，对数参数 \(\eta=0.35\)；
- 交叉在超过 8 个不同技能被评估后启用；启用前再生:变异:交叉比例为 2:1:0，启用后为 1:1:1；
- 预测器为 2560→64→1 MLP，50 个 full-batch Adam epoch，学习率 \(10^{-3}\)，权重衰减 \(10^{-4}\)。
