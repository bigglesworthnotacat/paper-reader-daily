## 摘要
量化是开放权重LLM智能体的默认部署路径之一，但它并非保持行为不变：攻击者可以发布一个通过审计的全精度检查点，而一旦量化就会表现异常，这被称为量化条件攻击（QCA）。此前的QCA工作针对自由文本生成，其危害由人类读者中介。相比之下，智能体场景带来更严重的风险：触发的载荷是一个无需人工监督即可执行的结构化函数。我们首次研究了针对LLM智能体的QCA。我们发现，直接沿用先前的后门注入方法可以在量化后产生恶意行为，但会显著损害良性效用，使由此产生的攻击不切实际。为了解该威胁的真实上界，我们提出AGENTQ，一个攻击框架，将分层带状LoRA注入与多码本量化等价类上的部分PGD修复相结合。AGENTQ在保持正常智能体能力的同时，将恶意行为集中在量化模型中。在三个触发-动作对和三个码本（NF4、FP4、INT8）上，AGENTQ在良性效用损失极小的情况下，量化后攻击成功率最高可达100%，这凸显了在部署开放权重智能体之前，将量化感知安全评估作为标准要求的必要性。

## Abstract
Quantization is one of the default deployment paths for open-weight LLM agents, but it is not behavior-preserving: an adversary can release a full-precision checkpoint that passes audits yet misbehaves once quantized, termed as quantization-conditioned attack (QCA). Prior QCA work targets free-text generation, where harm is mediated by a human reader. In contrast, the agentic setting poses a more severe risk: the triggered payload is a structured function that can be executed without human oversight. We present the first study of QCA against LLM agents. We find that directly adapting prior backdoor-injection methods can produce malicious behavior after quantization, but substantially degrades benign utility, rendering the resulting attacks impractical. To understand the true upper bound of the threat, we propose AGENTQ, an attack framework that combines layer-banded LoRA injection with partial-PGD repair over a multi-codebook quantization-equivalence class. AGENTQ preserves normal agentic capability while concentrating malicious behavior in the quantized model. Across three trigger-action pairs and three codebooks (NF4, FP4, INT8), AGENTQ reaches up to 100% post-quantization attack success rate with minimal loss of benign utility, underscoring the need to make quantization-aware safety evaluation a standard requirement before open-weight agents are deployed.

## 一、核心问题与整体含义（研究动机与背景）

- **背景**：量化是开放权重 LLM 智能体的默认部署路径（`load_in_4bit`、bitsandbytes、llama.cpp、Ollama、vLLM 等），用于降低内存与算力需求。但后训练量化（PTQ）**并非保持行为不变**。
- **量化条件攻击（QCA）**：攻击者发布一个通过良性行为审计的全精度检查点，受害者以低精度加载后却表现恶意。其原理是许多全精度权重会舍入到同一低精度码字，攻击者可在**量化等价类**中游走，使量化产物恶意而全精度产物良性。
- **既有工作缺口**：以往 QCA 研究仅针对分类或自由文本生成，其危害由人类读者中介。本文**首次研究智能体场景下的 QCA**。
- **智能体场景为何更严重（三重不对称）**：
  - **从可读字符串到可执行动作**：载荷是外部系统执行的结构化工具调用（文件写入、API 调用、遥测外泄），无人在环检查点。
  - **部署对齐**：最值得攻击的模型类别（端侧、低延迟、内存受限）恰好也是被激进量化的类别，受害者往往只持有量化产物作为修复面。
  - **更严格的评估**：智能体输出可用确定性检测器评估，实现无 LLM 评审、可复现的 ASR 测量。
- **核心张力**：直接移植既有 QCA 配方到智能体场景会触发一个自由文本场景不存在的失败模式——工具调用格式化是集中于狭窄层带的脆弱能力，扰动一旦破坏它，下游解析器会在恶意工具调用派发前就拒绝输出，攻击面被完全抹除。

## 二、方法论（AGENTQ）

- **核心思想**：保留 Egashira 等（2024）的 **Injection → Repair 两阶段骨架**，但每阶段都实例化在**匹配攻击实际所需维度的结构化低维子流形**上，而非全参数空间。组合两个结构化限制：分层带状低秩注入 + 多码本等价类上的部分 PGD 修复。

- **Stage I（注入）**：
  - 用秩 $r$ 的 LoRA 适配器参数化权重更新 $\Delta W = BA$（$B\in\mathbb{R}^{d_{out}\times r}$，$A\in\mathbb{R}^{r\times d_{in}}$，$r \ll \min(d_{in},d_{out})$）。
  - 附加到每个 transformer 块的**全部七个线性投影** $\{q,k,v,o,gate,up,down\}$，但**仅限浅层前–中段层带** $L_{shallow}=[0,L^\star)$，$L^\star\approx\lfloor 2L/3\rfloor$（如 Qwen3.5-4B 的 $[0,22)$，$L=32$）。
  - 在中毒混合数据上 SFT 后将适配器合并回基座：$\theta_h=\theta_0+B^\star A^\star|_{L_{shallow}}$，因此 $\theta_h-\theta_0$ 按构造位于分层带状低秩子流形上。
  - 与既有 LoRA 后门的区别：既有 LoRA 后门在全精度即激活、必被审计捕获；本文的适配器是**将扰动约束在工具格式化层之外**的机制。

- **Stage II（修复：量化等价类上的部分 PGD）**：
  - 定义 $\theta_h$ 的量化等价类：$\mathcal{C}(\theta_h):=\{\theta:Q_m(\theta)=Q_m(\theta_h),\forall m\in\mathcal{M}\}$，$\mathcal{M}=\{\text{INT8},\text{NF4},\text{FP4}\}$。逐坐标看，它是 bitsandbytes 各码本纤维的交集。
  - 在**活跃层集** $\mathcal{A}\subseteq L_{shallow}$ 上求解部分 PGD，补集冻结于 $\theta_h$：
    $$\theta^\star=\arg\min_\theta \mathcal{L}_{util}(\theta;\theta_0)\quad \text{s.t.}\quad \theta\in\mathcal{C}(\theta_h),\ \theta_{\mathcal{A}^c}=\theta_h$$
  - 效用损失聚合干净函数调用 CE 与三个中毒目标的遗忘损失；优化器为 bf16 AdamW，$\eta=2\times10^{-5}$，施加盒投影。

- **部署效果**：按构造 $Q_m(\theta^\star)=Q_m(\theta_h)$ 对所有 $m\in\mathcal{M}$ 成立，而 $\mathcal{L}_{util}$ 已把全精度参数拉回 $\theta_0$ 附近的良性流形，形成尖锐二分：**全精度推理是干净函数调用智能体，任何目标量化推理路径确定性地触发对应恶意行为**（误选、参数注入、非请求广告）。

- **低秩注入下的有界离触发漂移（理论支撑）**：
  - 直接移植基线（全秩 SFT）可选任意 $\delta\in\mathbb{R}^d$；AGENTQ 将 $\delta$ 限制在分层带状秩 $r$ 簇中，其内在维度为 $r|L_{shallow}|(d_{in}+d_{out})$，比环境维度低一个数量级。
  - **逐点**：$f_\theta$ 在 $\theta_0$ 附近的 Lipschitz 正则给出 $|U(\theta_h)-U(\theta_0)|\le L_f\|\delta\|_F$，且 BA 分解按参数化把每块的奇异内容封顶在 $r$ 个方向——离子空间漂移是**不可达**而非仅被惩罚。
  - **容量**：秩约束矩阵类的覆盖数界把环境 $pd/n$ 速率替换为 $pd_{im}(\mathcal{S}_{r,L_{shallow}})/n$，泛化按同一因子收紧。
  - 综合解释：全秩 SFT 把大部分预算花在与「触发→工具调用」映射正交、却对有效结构化输出承重的方向上；分层带状低秩限制按构造拒绝在那里花费预算。
