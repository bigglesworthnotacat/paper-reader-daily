## 摘要
当前的Mixture-of-Agents（MoA）范式通常将查询路由与智能体微调视为相互分离的过程，限制了其应对智能体能力演化的能力。这种脱节使得路由策略无法在训练后阶段适应不断演化的智能体能力，也阻碍了智能体实现协同的、数据驱动的专业化。为解决这一问题，我们提出CERA-MoA（Co-Evolving Router with continually learning Agents for Mixture-of-Agents），一个迭代式强化学习框架，其中动态路由器与独立智能体策略协同演化。我们设计了一种预测性熟悉度估计器，利用中间层隐藏状态来评估智能体之间的语义胜任能力，从而避免完整rollout的开销。基于这些熟悉度分数，一种累积阈值自适应路由机制会动态激活量身定制的最小智能体子集，在任务性能与效率之间实现权衡。通过根据智能体不断演化的能力主动为其分配有针对性的训练样本，CERA-MoA促进了能力分化。跨多个领域的广泛实验表明，CERA-MoA优于最先进的静态智能体路由和固定工作流微调基线。

## Abstract
Current Mixture-of-Agents (MoA) paradigms generally treat query routing and agent fine-tuning as separate processes, limiting their ability to respond to evolving agent capabilities. This disconnect prevents routing strategies from adapting to evolving agent capabilities during post-training and prevents agents from achieving synergistic data-driven specialization. To resolve this, we introduce CERA-MoA (Co-Evolving Router with continually learning Agents for Mixture-of-Agents), an iterative reinforcement learning framework where the dynamic router and independent agent policies co-evolve. We design a predictive familiarity estimator that leverages mid-layer hidden states to evaluate semantic competence among agents, avoiding the overhead of full rollouts. Based on these familiarity scores, a cumulative-threshold adaptive routing mechanism dynamically activates a tailored minimal agent subset, achieving a trade-off between task performance and efficiency. By proactively allocating targeted training samples to agents based on their evolving competence, CERA-MoA promotes capability differentiation. Extensive experiments across various domains demonstrate that CERA-MoA outperforms state-of-the-art static-agent routing and fix-workflow fine-tuning baselines.

## 1. 核心问题与研究动机

- **背景**：多智能体系统（Multi-Agent Systems, MAS）与 Mixture-of-Agents（MoA）范式通过组合多个 LLM 智能体来扩展单模型的推理边界。当前研究主要分两条路线：
  - **编排优化（Orchestration Optimization）**：在**固定能力**的智能体之间做动态路由、辩论或投票。
  - **智能体微调（Agent Fine-tuning）**：在**预先定义好的工作流**内用 RL、偏好优化或监督学习训练智能体。
- **核心痛点（研究空白）**：
  - 两条路线相互**解耦**：路由策略假设智能体能力静态不变，无法适应后训练中智能体能力的持续演化。
  - 训练数据通常**人工划分或均匀分配**，缺乏基于智能体当前胜任力的动态样本分配机制，导致所有智能体最终退化为同质的"通才"，无法形成协同的领域专精。
- **整体含义**：论文提出 **CERA-MoA**，将路由机制与智能体持续学习置于**同一闭环迭代强化学习框架**中协同演化——路由依据智能体能力分配训练样本以诱导专精，智能体专精后路由再同步更新对能力的估计，形成正向反馈循环。

## 2. 方法论

### 2.1 核心思想

- 将系统建模为协作框架 \(M = (D_\psi, \{A_{\theta_i}\}_{i=1}^N, S)\)：参数化路由器 \(D_\psi\) + 持续学习的智能体策略群 + 投票聚合器 \(S\)。
- 建立**闭环协同演化**：自适应查询分配把样本路由给特定智能体驱动专精；路由器同步更新评估参数以追踪不断变化的能力。

### 2.2 预测式熟悉度估计器（Predictive Familiarity Estimator）

- **动机**：在生成之前、不依赖昂贵外部验证器或完整 rollout 的前提下估计"查询—智能体"匹配度。
- **结构**：
  - 每个智能体 \(i\) 配备一个**可训练预测头** \(g_i\) 和一个**随机初始化且永久冻结的目标头** \(\bar{g}_i\)；目标头在不同智能体间**正交初始化**，提供稳定且初始多样的参考空间。
  - 查询先通过路由器**冻结的骨干 LLM**，抽取中间层隐藏状态；语义表示 \(h(q)\) 由第 \(\lfloor L/2 \rfloor\) 层与 \(\lfloor 3L/4 \rfloor\) 层的隐藏状态**拼接**得到（式 2）。
  - 骨干网络不被熟悉度目标更新，训练的是从固定语义特征到熟悉度分数空间的映射。
- **距离与分数**：
  - 归一化欧氏距离 \(d_i(q) = \| c_i(q)/\|c_i(q)\|_2 - \bar{c}_i(q)/\|\bar{c}_i(q)\|_2 \|_2\)（式 3）。
  - 熟悉度 \(f_i(q) = \exp(-\lambda d_i(q))\)，\(\lambda\) 为温度超参（式 4）。
- **训练信号本质**：不回归绝对奖励，而是把奖励监督转化为围绕固定锚点的**相对推拉信号**——正优势拉近预测头与锚点，负优势以 margin 推开，从而形成与奖励对齐的几何兼容性信号。

### 2.3 累积阈值自适应路由（Cumulative-Threshold Adaptive Routing）

- **训练时路由分数**（式 5）：\(s_i(q) = f_i(q) + c_{ucb}\sqrt{\frac{\log T}{n_i+1}} + w_{ent} H_i\)
  - UCB 探索项防止样本饥饿；历史熵 \(H_i\) 鼓励策略多样性。
- **关键设计**：**排序用路由分数 \(s_i(q)\)，但激活阈值严格用原始熟悉度 \(f_i(q)\)**（式 6）：激活最小的 top-ranked 子集，使其**累积熟悉度** \(\sum_{j=1}^{k} f_{(j)}(q) \geq \tau\)；若总体不足则激活全部。
- 该设计避免探索奖励虚高"感知胜任力"，实现性能与算力的细粒度权衡。
- **推理时**关闭探索项（\(c_{ucb}=w_{ent}=0\)），仅路由到最有能力的专家。

### 2.4 路由器与智能体的联合优化

- **智能体优化**：被选中的智能体将查询存入 **LIFO 缓冲**；批次形成后每查询采样 \(G\) 条完整轨迹，采用 **DAPO**（组归一化优势，式 7）+ **GSPO**（序列级重要性采样，式 8）进行裁剪代理目标优化（式 9），并加入 token 级 KL 惩罚（式 10–11）与掩码归一化损失（式 12）。
- **路由器优化**：计算跨智能体相对优势 \(A_{i,q} = \bar{r}_{i,q} - \frac{1}{|S_q|}\sum_{j\in S_q}\bar{r}_{j,q}\)（式 14），单智能体激活时 \(A_{i,q}=\bar{r}_{i,q}\)。
  - 路由器损失（式 15）：正优势时 \(\mathcal{L} = A_{i,q} d_i(q)\) 拉近；负优势时用**铰链式推离** \(|A_{i,q}|\max(0, m - d_i(q))\)，把排斥距离**上限锁定在 margin \(m\)**，防止熟悉度分数塌缩到零。
  - 实践上 \(m\) 取值使得所有智能体达到边界时累积熟悉度刚好低于 \(\tau\)，从而对"无人胜任"的难题优雅回退到全智能体激活。
- **参数化灵活性**：支持同构（单一共享骨干 + 独立 LoRA 适配器）与异构（不同基座模型）两种配置。

### 2.5 推理聚合

- **确定性任务**：熟悉度加权多数投票（式 1），在胜出共识组内输出熟悉度最高智能体的完整轨迹。
- **开放式任务**：直接输出最熟悉智能体的回答。

## 6. 主要结论与发现

- **性能（RQ1）**：CERA-MoA 在三种基座与异构池上均取得最高平均分——例如 Qwen3-4B 上 ID 平均 63.2（次优 AT-GRPO 61.0）、OOD 平均 72.8（次优 71.5）；Llama-3.2-3B 上 ID 47.9（次优 43.3）。优势在困难推理集（DAPO-MATH、LogicBench、OlympiadBench）上尤为显著。
- **异构适配（RQ2）**：能力感知路由可把查询分派给最合适的骨干，将模型多样性转化为协作优势，避免固定工作流强行"共识"稀释各模型预训练特长。
- **熟悉度优于奖励估计（RQ3）**：直接奖励回归（ID 60.8）与多类分类（ID 61.3）均低于熟悉度方案（63.2）；原因是奖励随策略演化剧烈震荡，而熟悉度通过几何推拉平滑收敛。
- **自适应路由的效率优势（RQ4）**：相比固定 Top-2，累积阈值路由在性能相当的前提下**平均生成 token 减少约 45%**（367.77 vs 666.37）；固定 Top-1 省算力但性能下降，Top-3 训练导致熟悉度震荡。
- **能力专精（RQ5）**：无人工角色分配下自发分化——Agent 2 成为主求解器、Agent 1 精于简洁数学与逻辑、Agent 3 专注代码、Agent 4 负责通用推理；t-SNE 显示路由到同一智能体的查询形成紧密语义邻域。
- **路由开销**：平均 11.87 ms/查询，不到原生生成时间（11,350 ms）的 1%，无自回归解码开销。
- **超参结论**：\(\tau=0.7\) 最优；训练时 \(\tau=0.8\) 会过度激活、稀释专精

、削弱专家分工；\(\lambda=2.0\) 的熟悉度分布比 \(\lambda=1.0\) 更陡峭、路由更集中；移除 margin 后熟悉度分数塌缩、路由退化为随机分配，验证了几何推拉设计对维持分数尺度的必要性。
- **训练动态**：协同演化曲线显示系统奖励与智能体被选中频率逐步上升并趋于稳定，熟悉度随训练平滑增长而非剧烈震荡，说明路由器与智能体形成了稳定的正向反馈而非此消彼长的零和博弈。
- **隐藏状态选择**：拼接中层（\(\lfloor L/2 \rfloor\)）与中高层（\(\lfloor 3L/4 \rfloor\)）的表征优于仅用末层，末层特征过于任务特异且受当前策略分布偏移影响更大。

## 7. 局限性与未来工作

论文（推断及自我陈述）承认或隐含的局限包括：

- **规模局限**：智能体数量 \(N\) 限制在 3–4 个、基座参数量在 3B–4B 区间，尚未验证在数十个智能体或百亿级基座上的可扩展性；路由器骨干若换成更大模型，11.87 ms 的开销可能上升。
- **熟悉度估计器的能力上限**：预测头从固定语义特征映射到熟悉度空间，若基座骨干对某领域完全缺乏表征能力，熟悉度信号本身即不可靠，形成"看不见的能力盲区"。
- **奖励依赖**：智能体优化依赖任务可验证奖励（RLVR），对开放式生成、主观质量等无可靠奖励信号的任务适配性存疑。
- **训练成本**：虽单步开销可控，但 6,000 步、每查询 8 条轨迹的采样成本对更大规模实验仍是瓶颈，且论文未给出全部配置的总 GPU 小时明细，复现成本核算不完全透明。
- **评估方差**：单随机种子、无置信区间，结论稳健性有待多 seed 验证。
- **聚合器较简单**：投票/最熟悉者选择相较 LLM-as-judge、元推理聚合器可能损失部分上限性能。

潜在未来方向：扩展到更大异构池与更强基座、引入无奖励/弱监督信号、与更复杂聚合器结合、动态调整智能体数量与 LoRA 容量。

## 8. 论文贡献归纳

综合来看，CERA-MoA 的主要贡献可归纳为四点：

1. **问题重构**：首次将 MoA 的"路由"与"智能体后训练"统一为一个闭环协同演化问题，明确指出两条研究路线解耦导致的同质化痛点。
2. **方法创新**：
   - 提出**预测式熟悉度估计器**，用冻结锚点 + 几何推拉替代绝对奖励回归，在生成前零成本估计查询—智能体匹配度；
   - 提出**累积阈值自适应路由**，将"排序分数"与"激活阈值"解耦，兼顾探索、算力控制与无人胜任时的优雅回退；
   - 设计路由器与智能体的**联合优化目标**，用铰链式 margin 防止熟悉度塌缩。
3. **实证充分性**：在 3 个同构基座 + 1 个异构池、9 个 ID 数据集与 6 个 OOD 数据集上，对比 6 个来自两大流派的基线，并给出 6 组以上消融与路由开销、学习动态、专精可视化等分析。
4. **涌现现象**：无人工角色分配下自发形成"主求解器—数学逻辑—代码—通用推理"的分工格局，t-SNE 佐证了语义邻域级专精，为 MAS 协同专精提供了可解释证据。

## 9. 客观评价与批判性观察

**优势**：

- 问题定位精准，闭环协同演化的视角具有理论新意，抓住了"路由静态假设"这一被忽视的隐含前提。
- 熟悉度估计器的几何设计（正交冻结锚点 + 铰链 margin）在数学上自洽，且 margin 消融实验直接支撑了"防塌缩"的因果链条，方法论证较为扎实。
- 实验矩阵覆盖面广，ID/OOD 双轨报告、同构/异构双设置、两大流派基线齐备，公平性控制（统一超参与奖励）到位。
- 工程细节（LIFO 缓冲、重入式梯度检查点、vLLM 共置、单 GPU 日/千步）披露清晰，可复现性较好。

**待商榷之处**：

- **"熟悉度优于奖励回归"的结论强度**：消融主要在 Qwen3-4B 上完成，且未报告多 seed 方差；奖励回归的劣势是否源于训练不稳定而非度量本身，尚需进一步剥离。
- **熟悉度与真实胜任力的对齐**：熟悉度是预测头对"奖励几何"的拟合，若策略分布偏移剧烈，预测头可能滞后于真实能力，论文未量化这种滞后。
- **可扩展性论证偏弱**：路由器开销虽低，但随 \(N\) 增长的非线性成本、LoRA 数量与显存的关系未讨论。
- **与更强聚合范式的对比缺失**：未与 LLM-as-judge、self-consistency + 重排序等更强聚合基线比较，性能上限的绝对高度有待验证。
- **专精的"代价"未充分讨论**：专精提升协作的同时是否牺牲了单智能体的鲁棒性/泛化，缺乏对个体能力退化的追踪。

**总体判断**：CERA-MoA 是一篇问题意识清晰、方法设计精巧、实验相对扎实的多智能体协同学习工作。其核心价值不在于刷新某个 benchmark 的绝对 SOTA，而在于提出并验证了"路由与智能体能力协同演化"这一范式转变，以及用轻量几何信号替代昂贵验证器进行能力估计的可行性。若能补足多 seed 方差、更大规模验证与更强聚合基线对比，其说服力将进一步提升。
