## 摘要
现实世界中备受瞩目的AI智能体框架往往依赖厂商专有或不透明的设计来进行上下文组装，导致组装上下文的来源和底层逻辑难以被充分理解，由此产生的安全风险在很大程度上也尚未被探索。在本文中，我们首次对现实世界AI智能体框架中的上下文组装设计进行了系统性分析。我们研究并揭示了智能体框架如何设计以从不同来源收集和组装上下文，并识别出由这些设计引发的一系列实际攻击向量。我们的分析揭示出真实世界框架上下文组装中两类新型攻击：（1）消息角色上下文权限提升（M-CPE），当源自低权限上下文的攻击者控制内容被整合到更高权限的消息角色时发生。（2）跨范围上下文权限提升（X-CPE），当攻击者控制的内容在其被引入的上下文之外持续存在时发生。我们对包括Claude Code和Codex在内的12个真实世界智能体框架进行了CPE攻击的系统性安全分析。由此产生的后果包括智能体完全被攻破、远程代码执行、拒绝服务以及被操纵的工具或技能调用等。

## Abstract
Real-world, high-profile AI agent harnesses often rely on vendor-proprietary or opaque designs for context assembly, leaving the sources and underlying logic of assembled context poorly understood and the resulting security risks largely unexplored. In this paper, we present the first systematic analysis of context assembly designs in real-world AI agent harnesses. We study and uncover how an agent harness is designed to collect and assemble context from diverse sources, and identify a set of practical attack vectors arising from these designs. Our analysis brings to light two novel categories of attacks in the context assembly of real-world harnesses: (1) MessageRole Context Privilege Escalation (M-CPE), which occurs when attacker-controlled content originating from a low-privileged context is incorporated into a higher-privileged message role. (2) Cross-Scope Context Privilege Escalation (X-CPE), which occurs when attacker-controlled content persists beyond the context in which it was introduced. We performed a systemic security analysis of the CPE attacks against 12 real-world agent harnesses, including Claude Code and Codex. The resulting consequences include full agent compromise, remote code execution, denial of service, and manipulated tool or skill invocations, etc.

## 1. 论文的核心问题与整体含义（研究动机与背景）

- **研究对象与核心问题**：本文针对现实世界AI智能体框架（agent harness）的**上下文组装（context assembly）**机制，提出了一个此前从未被系统研究的安全问题：框架如何从异构来源收集内容、以何种逻辑组装为LLM的上下文、并为不同来源分配何种权限角色——这些设计往往“厂商专有”且高度不透明，由此引入的安全风险（尤其是**上下文权限提升**）未被充分探索。
- **研究动机**：
  - 主流的间接提示注入攻击研究以关注“外部内容进入上下文”为主，但忽略了智能体框架本身组装逻辑的结构性弱点。
  - 各厂商（OpenAI、Anthropic、Google）定义了消息角色的权限层级，LLM被训练为优先服从高权限角色；若框架的低权限内容可被传播/写入到高权限上下文源，则可造成结构性安全失效。
- **整体威胁含义**：攻击者无需突破操作系统或获得终端权限，仅通过恶意网页、第三方工具/技能输出、Git提交信息、PR分支文件名等低可信渠道，即可借助框架的上下文组装缺陷实现对智能体行为的操纵、持久化恶意指令，甚至**远程代码执行（RCE）**、**完全失去对agent的控制**等严重后果。

## 6. 论文的主要结论与发现

- **主要结论**：CPE是真实广泛存在、结构性的agent框架安全弱点——**12个高关注度agent无一幸免**。CORA验证了282个可装载且可被注入的上下文源，其中64.9%处于最高权限r0层；1761条候选CPE路径几乎都跨越作用域或角色层级；产生的后果包括智能体完全沉陷、RCE、持久恶意策略注入、代码审查规避、跨项目污染等。
- **发现1**：上下文源来源繁多且厂商特定、高度不透明——包括多种类型的内存文件、配置文件中的指令、隐藏技能搜索路径、环境上下文（目录树、Git元数据等），用户无法有效预判攻击面。
- **发现2**：角色/作用域分配缺乏统一的安全实践——同一类型内存文件在一个agent中为r1、在另一个agent中为r0；同类来源作用域范围从会话级到用户级差别很大。
- **发现3**：借助上下文富集逻辑，可从远程会话级内容（如GitHub issue回复中的调试日志、网页源码包内文件树）升级为项目级乃至用户级持久化指令，且能绕过沙箱与用户审核流程。
- **发现4**：建议行业引入类SBOM的“上下文清单（context manifest）”机制来公开上下文源、角色、作用域和加载逻辑，并主张减少不必要的高权限上下文源与实现更激进的恶意指令过滤。

## 7. 优点

- **领域首创性与系统性**：是第一个系统性分析AI agent上下文组装安全性、奠定形式化角色/作用域模型的工作；将“间接提示注入”提升为框架设计层面的权限提升攻击视角，扩展了智能体安全研究边界。
- **方法论严谨性**：CORA“LLM分析+确定性验证”分离设计有效抑制了LLM在安全输出上的幻觉，通过随机canary和差异化启动测试（三次启动）提供可追溯的验证证据，提升研究可信度。
- **攻击向量分类清晰且可操作**：16条攻击向量按来源、标记语法、逻辑三维度科学分类，对框架开发者与安全研究者后续防御和复现具有良好的指导意义。
- **关键威胁模型落地性强**：五种端到端攻击案例贴近现实用户（艺术家建站、开源维护者审issue/PR、安全专家沙箱中探索仓库，甚至自动CI中审查PR），刻画了“普通用户—资深开发者—CI流水线”多层受众。
- **负责任披露意识好**：报告了12个agent厂商，Codex、Gemini CLI等已发布修复版本，且不公开Claude Code私有源码的鉴定过程，遵循伦理规范。

## 8. 不足与局限

- **实验覆盖局限**：
  - 攻击验证仅以“指令是否被装入高权限源”和“是否产生指定可观察行为”来判断，端到端“隐蔽性”与在复杂真实任务中的成功概率未被严格测量。
  - 对部分较复杂上下文源（Aider的LANG环境变量）过滤为误判，说明“载荷容量不足”过滤逻辑存在假阴性；自动分析工具覆盖范围受限于模板化构建环境的难度。
  - 未深入探索随话题时间推移模型更新和厂商修复后攻击有效性快速衰减带来的纵截面影响。
- **模型依赖与评估偏差风险**：
  - 实验结果高度依赖大模型当时的指令遵循倾向，不同模型数值差异较大（例如OpenClaw GPT-5.4-mini Loaded 45% vs Qwen Code 100%）；然而CORA没有对每个agent-vector按威胁模式进行分层建模，精细度有限。
  - 攻击验证较聚焦于模型是否能察觉到高角色的指令，缺少更广泛困难（如上下文过长截断、多步协作、工具调用后的中断）的建模。
- **计算与应用限制**：
  - 论文未披露任何算力资源和能耗数据，客观上限评估（特别是在真实海量开源生态中的扫描）较难复现/预期；该文可复现性受制于闭源LLM（GPT-5.5/Claude等）。
  - 与部分商业agent不同（尤其闭源部分），论文对Claude Code使用npm sourcemap获取的源码，其外部可使用性和长期稳定性存在限制。
- **理论建模粒度**：
  - 形式化模型以角色顺序（r0到r4）简化了角色冲突决策，而Anthropic/Google并未像OpenAI那样明确“角色优先级”的说法，而是模型训练和文档中表述模糊安全指导，该映射在异质LLM API之间的严谨性可以进一步讨论。
  - 论文只着眼角色与作用域两维度，尚未考虑完整性破坏与私密性之间协作的攻击图扩展。
