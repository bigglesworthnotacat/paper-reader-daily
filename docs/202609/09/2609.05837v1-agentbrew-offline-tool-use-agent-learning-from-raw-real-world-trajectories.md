## 摘要
基于LLM的智能体通过工具使用API在真实世界应用中部署日益增多，然而针对特定环境训练它们仍从根本上困难重重：真实世界应用不提供预定义任务或验证器，没有忠实的模拟器，并且大规模环境交互的预算有限。在本文中，我们提出AgentBrew，这是一个离线训练框架，能够从单一批次的原始交互轨迹中学习有效的工具使用策略，而无需任务验证器或迭代的在线策略回放。该智能体首先探索目标环境以收集原始轨迹语料库，而无需进行质量过滤。为了从这些噪声语料中提取训练信号，回顾性任务推断根据每条轨迹的实际结果重建对齐的指令，而基于PMI的信用分配通过逐点互信息（PMI）将轨迹关于推断指令的总信息分解为每个动作的加性信用。这些信用对策略训练目标进行加权，放大信息量大的动作而抑制无效动作。在三个真实世界MCP应用（GitHub、Notion、PostgreSQL）上，AgentBrew将Qwen3-32B的平均性能提升了+8.7 Acc / +9.7 Score，超过了Qwen3-235B（+2.3 / +4.4），并优于拒绝采样（+5.9 / +10.3）。这些结果表明，细粒度的离线学习可以从原始轨迹中恢复有用的监督信号，而基于过滤的方法则会丢弃这些信号。代码可在https://github.com/alphatogo/AgentBrew获取。

## Abstract
LLM-based agents are increasingly deployed in real-world applications through tool-use APIs, yet training them for specific environments remains fundamentally difficult: real-world applications provide no pre-defined tasks or verifiers, no faithful simulators, and limited budget for large-scale environment interaction. In this paper, we propose \textbf{AgentBrew}, an offline training framework that learns effective tool-use policies from a single batch of raw interaction trajectories, without task verifiers or iterative on-policy rollouts. The agent first explores the target environment to collect a raw trajectory corpus without quality filtering. To extract training signal from this noisy corpus, \emph{retrospective task inference} reconstructs an aligned instruction for each trajectory based on its actual outcome, and \emph{PMI-Based credit assignment} decomposes the trajectory's total information about the inferred instruction into additive per-action credits via pointwise mutual information (PMI). These credits weight the policy training objective, amplifying informative actions while suppressing ineffective ones. On three real-world MCP applications (GitHub, Notion, PostgreSQL), AgentBrew improves Qwen3-32B by +8.7 Acc / +9.7 Score on average, surpassing Qwen3-235B (+2.3 / +4.4) and outperforming rejection sampling (+5.9 / +10.3). These results demonstrate that fine-grained offline learning can recover useful supervision from raw trajectories that filtering-based approaches would discard. The code is available at https://github.com/alphatogo/AgentBrew

- **核心问题**：现有的智能体训练方法通常依赖三大关键条件，而真实工业场景中这些条件往往难以满足：
  - 缺少预定义的任务集和可靠的验证器；
  - 缺少能够忠实模拟真实环境的模拟器；
  - 大规模真实环境交互的预算有限，进一步大规模 rollout 不可行。
- **研究问题**：如何在没有预定义任务、无验证器、无模拟器、仅有限环境交互的条件下，训练出针对特定应用的高效工具使用智能体？
- **论文的答案**：提出 AgentBrew，一个完全离线的训练框架，仅需单批未经质量筛选的原始交互轨迹，即可提取有效监督信号，无需任何外部奖励或在线交互。

## 2. 方法论

AgentBrew 包含三个阶段，除第一阶段外，其余均在离线完成：

### 2.1 原始经验收集（Raw Experience Collection）
- **接地任务提议**：由智能体根据工具描述生成高层任务类别，然后通过只读调用探索环境真实状态，提出引用真实实体与配置的接地任务，避免任务引用不存在资源而导致轨迹无法执行。
- **任务执行**：由基础智能体执行任务，收集多轮交互轨迹；丢弃达到最大步数限制的退化轨迹，除此之外对所有自然终止的轨迹不做任何质量筛选，构成原始语料库 \(D_{raw}\)。

### 2.2 经验蒸馏（Experience Distillation）
该阶段包含两个互补机制：

#### a. 回顾式任务推断（Retrospective Task Inference）
- 从轨迹中删除思考链（CoT），仅保留工具调用与观察结果，形成约简轨迹 \(\bar{\tau}_n\)；
- 利用 LLM 根据轨迹的真实可观测结果，推断一条与轨迹实际完成情况对齐的修订指令 \(\hat{I}_n\)；
- 原则：仅保留轨迹中证据支持的结论，删除未完成或虚构的子目标，不新增轨迹中未出现的实体或结果。

#### b. 基于 PMI 的信用分配（PMI-Based Credit Assignment）
- 核心思想：利用参考模型 \(\pi_{ref}\) 度量每个动作-观察对相对于推断任务的点互信息（PMI），作为该动作的贡献分数；
- 轨迹总信息定义为：
  \[
  \mathrm{PMI}(\hat{I}_n; \bar{\tau}_n) = L_\emptyset - L_{T_n}
  \]
  其中 \(L_\emptyset\) 为无上下文下推断指令的负对数似然，\(L_{T_n}\) 为给定完整轨迹后的负对数似然；
- 利用 PMI 链式法则将其分解为逐动作加性信用：
  \[
  w_t = L_{t-1} - L_t
  \]
  每个动作的信用衡量其提供的关于 \(\hat{I}_n\) 的边际信息；
- 保证：所有动作信用之和精确等于轨迹总信息（式 4），不增加也不丢失信息。

### 2.3 PMI 加权策略训练（PMI-Weighted Policy Training）
- 将负信用截断为 0，并在轨迹内归一化到 [0, 2]；
- 优化加权负对数似然目标：
  \[
  J(\theta) = -\sum_{n=1}^{N} \sum_{t=0}^{T_n} \tilde{w}_t^{(n)} \log \pi_\theta(a_t | \hat{I}_n, s_t)
  \]
- 高信息动作获得放大梯度，无效或误导动作被近零权重抑制；即使轨迹整体质量差，仍可贡献其中有效动作的信号。

## 3. 实验设计

- **数据规模**：GitHub 与 Notion 各约 2,500 条轨迹，PostgreSQL 约 3,500 条轨迹，总计约 8,500 条，均来自 Qwen3-32B 与环境的真实交互，未做质量过滤。

## 6. 主要结论与发现

- 在三个真实 MCP 应用上，AgentBrew 将 Qwen3-32B 的平均 Acc 从 9.5 提升至 18.2，平均 Score 从 49.0 提升至 58.7，绝对提升 +8.7 Acc / +9.7 Score；
- 超越更大规模的 Qwen3-235B（+2.3 Acc / +4.4 Score），说明定向离线适配可能比单纯扩大模型规模更有效；
- 相比 Rejection Sampling 提升 +5.9 Acc / +10.3 Score，且在 Notion 上 RS 的 LLM 评委无法有效判断状态化 API 交互任务完成度，Acc 为 0，而 AgentBrew 仍达到 14.2；
- PMI 信用机制可以自动抑制误对齐轨迹（其信用趋近于零），无需外部质量过滤器；
- 数据质量鲁棒性良好，即使加入最低质量的 25% 轨迹仍带来正向收益，说明逐动作信用提取优于轨迹级整体丢弃；
- 蒸馏信号可以跨模型迁移，14B 模型从 32B 采集的数据中学习后获得显著提升。

## 7. 优点

- **问题定位新颖且实际**：真实世界中任务不可预定义、无验证器、无模拟器的设定非常普遍，但研究较少，论文填补了这一空白；
- **方法完全离线**：除初始单批数据收集外，所有流程无需真实环境交互，工程可部署性强；
- **信息论信用分配设计优雅**：用 PMI 链式法则将轨迹级总信号分解为逐动作信用，数学上保证无信息重复或遗漏，避免人工或启发式打分的主观偏差；
- **回顾式任务推断绕过了验证难题**：不依赖任务是否完成，而是根据实际结果重建任务，使失败轨迹也能产生有用训练信号；
- **过滤式方法的替代范式**：通过对原始数据的细粒度利用，比“丢弃劣质轨迹”的策略更节省环境交互成本并提升数据效率。
- **实验系统充分**：包含与多类前沿模型、多种训练范式的对比，以及充分的消融和鲁棒性验证，证据链条完整。

## 8. 不足与局限

- **应用覆盖面有限**：仅在三个 MCP 环境上验证，虽然环境类型差异较大（代码协作、知识管理、数据库），但尚未覆盖网页操作、移动端 GUI 等更多应用形态；
- **基座泛化风险**：训练与 PMI 计算均以 Qwen3-32B 为核心模型，未测试其他基座模型（如更大/不同家族）在采集数据与推断指令上的差异，可能造成一定的模型偏移（model bias）；
- **任务推断在极端长或混乱轨迹上可能退化**：论文在结论中也承认，当轨迹过长或严重纠缠时，回顾式任务推断质量可能下降，影响下游训练；
- ** PMI 只是动作质量的代理指标**：信息论度量并不一定完全等价于对真实因果贡献的估计，在高纠缠动作序列中存在偏差风险；
- **评估任务完成度验证依赖 benchmark 自带的验证器**：实验评估需要程序化验证器，虽然训练时不使用，但在实际没有验证器的新环境中如何评估性能仍悬而未决；
- **绝对 Acc 偏低**：各方法在真实 benchmark 上的完成率都不高（AgentBrew 平均 Acc 仅 18.2），表明真实世界工具使用任务仍距离实用有较大差距，本文更多证明了方法在有限数据下的相对有效性。
