## 摘要
可复用的智能体技能将任务流程、工具使用指南和输出约束赋予大型语言模型（LLM）智能体。然而，这些技能也充当外部化的行为政策，从而带来供应链风险：第三方技能可能在不改变声明任务和有效输出接口的情况下，隐蔽地将智能体的决策引向未披露的目标。我们正式定义了技能政策完整性（Skill Policy Integrity），要求技能诱导的政策保持与其声明功能和用户授权目标的一致。我们进一步提出了SkillShift，一种受限的黑盒框架，用于在没有显式目标命令注入或任务劫持的情况下实现隐蔽政策引导。它结合了语义上合理的政策编辑与分层验证、失败引导优化和策略压缩，以保持有效性、输出合法性、可迁移性和隐蔽性。我们在智能体商务和软件依赖使用场景中实例化了这一威胁，SkillShift实现了攻击者偏好的选择率81.33%和63.33%，同时保持了100%的效用保持率。冻结的策略还能在不进一步优化的情况下跨异构LLM后端和智能体环境迁移。此外，被评估的扫描器未能检测到构造的技能，这引发了对可复用技能作为智能体政策工件进行行为审计的需求。

## Abstract
Reusable agent skills extend large language model (LLM) agents with task procedures, tool-use guidance, and output constraints. Yet these skills also act as externalized behavioral policies, which create a supply-chain risk: a third-party skill may preserve the declared task and valid output interface while covertly redirecting agent decisions toward an undisclosed objective. We formalize Skill Policy Integrity, which requires a Skill-induced policy to remain aligned with its declared functionality and the user-authorized objective. We further present SkillShift, a constrained black-box framework for covert policy steering without explicit target command injection or task hijacking. It combines semantically plausible policy edits with hierarchical validation, failure-guided optimization, and strategy compression to preserve effectiveness, output validity, transferability, and inconspicuousness. We instantiate this threat in agentic commerce and software dependency use, with SkillShift achieving attacker-favored selection rates of 81.33% and 63.33% while maintaining a 100% utility-preserving rate. The frozen policies also transfer without further optimization across heterogeneous LLM backends and agent environments. Moreover, the evaluated scanners fail to detect the constructed skills, motivating behavioral auditing of reusable skills as agent policy artifacts.

- **核心威胁**：论文揭示了一种此前未被系统研究的新威胁——**技能策略引偏（Policy Steering）**。第三方技能提供者可以在保持技能声明的任务功能、候选集和输出接口不变的情况下，通过修改技能中的评估标准、示例和规则，**隐蔽地将智能体的决策引向未披露的目标对象（如特定品牌或特定软件包）**。这与传统的提示注入、指令劫持等攻击不同，后者改变的是"智能体做什么"，而 SkillShift 改变的是"智能体如何决策"。
- **核心定义**：论文正式提出了 **技能策略完整性（Skill Policy Integrity）** 概念，要求技能诱导的行为策略必须与声明的功能和用户授权的目标保持一致。违反该性质的行为是：第三方未披露的目标系统性地影响智能体行为，且不改变声明任务、可用动作和输出接口。
- **整体含义**：这种威胁暴露了现有安全机制的盲区——**输出有效性（VR）和任务正确性并不能保证策略完整性**。即便是有效的输出、合法的候选选择和能通过安全扫描的技能，也可能携带隐蔽的决策偏差。可复用技能应当被视为"策略工件"接受行为审计，而不只是依赖黑盒安全扫描。

## 2. 论文提出的方法论：SkillShift

- **总体目标**：构建满足四个要求的实际策略完整性破坏：(1) 跨任务上下文的**有效引偏**；(2) 对授权任务和输出接口的**功能保真**；(3) 无需实例特异性捷径的**黑盒可复用性**；(4) 抵御显式或明显操纵的**语义隐蔽性**。
- **核心思想**：SkillShift 不直接注入目标选择指令或劫持任务，而是通过结构化策略表示和受约束的黑盒优化，**微妙的操纵技能的条件比较策略（比较准则），使目标在合法候选集中被更频繁地选中**。
- **结构化策略表示**：攻击策略 A = (G, U, T, X) 由四个结构化组件构成，实现三种互补的引偏机制：
  - **全局评估原则 G**（Global principles）：确立宏观评估导向；
  - **任务特定规则 U**（Task-specific rules）：约束局部决策场景下的排序规则；
  - **决胜（破平）规则 T**（Tie-breaking criteria，即 Tie-break rules）：在多个候选者相似时引入偏向目标对象的二级判据；
  - **语义示例锚定 X**（Semantic examples）：通过代表性示例稳定抽象原则在跨查询和跨模型中的应用方式。
- **三种引偏机制**：
  - **策略框架效应（Policy Framing）**：改变任务相关属性的相对显著性，相当于影响隐式比较函数中各项证据的权重，但不改变证据本身；
  - **平局操纵（Tie-breaking Manipulation）**：引入似是而非的次要准则，在多个候选相似的情况下将相对排名推向目标；
  - **语义锚定（Semantic Anchoring）**：使用目标对象表现优异的示例，使抽象准则在多种上下文下稳定地向目标倾斜。
- **约束与限制**：攻击者只能修改共享的技能文档。**禁止**：查询篡改、候选污染、顺序操纵、训练数据投毒、模型修改、查询特定规则、候选标识符、基于位置的捷径、显式目标选择命令。**目标名称只允许出现在允许的示例中**。
- **四阶段框架**：
  1. **上下文一致的初始化（Context-Consistent Initialization）**：由建议者 LLM 生成紧凑、符合模式的初始策略，包含合理的原则、规则、决胜条件和示例；
  2. **受限黑盒策略搜索（Constrained Black-Box Policy Search）**：迭代优化过程，提出局部语义编辑的候选策略，进行层级合法性校验（Vstr、Viso、Vcon），仅用最终受害者响应评估，以 PSR 最大化、VR 不低于阈值、长度更短为标准进行词法比较更新；
  3. **失败引导的覆盖修复（Failure-Guided Coverage Repair）**：对失败查询按需求和候选属性分组，向建议者只提供类别描述和聚合统计数据，对欠覆盖的类别进行针对性修改，兼顾了类别覆盖和维护查询无关策略；
  4. **效果保持的策略压缩（Effect-Preserving Strategy Compression）**：移除贡献低的内容、合并冗余规则、泛化相关示例，在 PSR 下降不超过容忍度的前提下最小化渲染策略长度。
- **数学表述**：优化目标为 argmax dPSR_dev(A)，约束为有效性 ≥ τ_vr 且长度在预算内。其中由于干净技能固定，最大化攻击 PSR 等价于最大化相对干净条件下目标选择率的提升幅度（Lift）。
- **关键技术细节**：确定性渲染器将结构化策略附加在基础技能末位，保证格式一致；策略候选者生成基于当前最优策略、有界搜索历史和聚合反馈；禁止在验证失败之后执行；评价时每次查询重复执行 R 次以降低单次随机性；全程不访问模型 logits、梯度、隐藏状态或注意力。

## 6. 论文的主要结论与发现

- **攻击效果显著**：购物域将 PSR 从干净条件下的 37.33% 提升至 81.33%（相对提升 +44 个百分点）；Python 依赖选择域从 0.67% 提升至 63.33%（+62.66 个百分点），两域的 VR 均保持 100%。
- **显式基线对照效果显著**：Target Name Only、Keyword Stuffing 效果微弱，Generic Prompt Injection 中等（购物 61.33%、Python 32.67%），而显式的 Direct-Skill Injection 获得近乎饱和的攻击成功（98%~100%），但可检测率高达 66.7%。
- **泛化性强**：冻结的攻击策略可在无进一步优化的前提下有效跨 6 个不同的 LLM 后端（所有结果均为正的 Clean-Attack Lift），且在完整智能体环境（Claude Code 和 Codex 兼容智能体）中表现稳定。
- **消融实验证实机理**：相对长度控制型中性技能（接近干净的 PSR），去除目标语义线索、任务适配规则或示例会导致显着的 PSR 下降，表明攻击效果主要来自语义和策略引导而非单纯的文档长度或其他低层级信号。
- **现有防御存在盲区**：6 个安全扫描器均无法区分 SkillShift 攻击技能与对应干净技能（0/6），但 4/6 能识别 Direct-Skill Injection 显式攻击；3 个技能注册平台也接受 SkillShift 技能而不发出攻击预警。这说明**现存的防御手段主要针对显式指令覆盖式攻击，对隐蔽政策引导缺乏有效检测**。
- **输出合法不等于下游效用良好**：尽管 100% 选择阶段的输出保持在候选集内，SkillShift 攻击仍使下游代码质量评分从 0.558 降至 0.506，质量通过率下降 16~20 个百分点。

## 7. 优点

- **新颖问题界定**：系统性定义并提出了技能策略完整性这一此前尚未被防护体系关注的问题，精准地区分了改变"做什么"的显式攻击和改变"如何决策"的隐蔽攻击。
- **方法论完备**：SkillShift 将攻击构建设计为结构化策略搜索问题，有明确的约束体系（结构化约束、表面隔离约束、内容约束）、上下文一致的初始化、分层验证、失败引导修复和策略压缩，整体框架设计慎密且可复制。
- **黑盒假设贴合现实**：攻击者仅使用最终模型输出，不访问任何内部计算隐藏层，这与现实 API 场景的威胁模型一致。
- **实验设计有较好的受控对照**：Clean 与 Attack 的查询/候选内容完全一致，Lift 只在同批次内计算；冻结策略后才进行评估，防止优化集偏差。
- **防御评估全面**：将检测能力做了定量分析，除了算法本身的成功率外还评估了跨模型迁移、跨完整代理人环境、检测和注册表层面的结果，还做了下游代码质量的间接评估。
- **可复现性**：作者公布了完整的攻击技能文档和详细的实验配置（附录），包括两种语言场景的全部技能原文，便于后续研究复现和验证。

## 8. 不足与局限

- **场景覆盖有限**：仅在购物推荐和 Python 依赖选择两个固定候选集场景进行评估，尚未涉及动态候选集、更广泛的领域（如医疗、法律、金融决策）以及更复杂的长任务工作流。动态候选场景下的攻击有效性和在不同领域的可迁移性尚不明确。
- **统计功效不足**：保守的每查询 3 次重复采样限制了数据量（全量批次仅 150 个响应），且未对结果进行置信区间或显著性检验（如 Wilcoxon、bootstrap 等）。部分观察到的 PSR 差异可能在统计上并不显著。
- **随机种子与稳定性未充分说明**：论文没有描述随机种子设置方式，这给精确复现结果带来一定的困难。
- **下游效用评估的局限**：GEval 只调用一次自动 judge，没有实际执行测试代码，也没有单元测试正确性验证。作者自己也承认这将该结果解释为观察到的评分下降而非确定的功能退化。代码质量评估部分的结论应视为探索性结果。
- **检测器的基准覆盖不足**：6 个检测器的评估被视为案例研究而非全面基准。STARS 只使用了基于规则的降级配置，未能反映完整 GLM 管道能力；部分检测器在非英语（中文）输入上存在语言局限，影响判断的确定性。
- **跨模型迁移验证有限**：多个模型 API 端点使用的是别名或预览版（如 Gemini 3-Flash Preview），不能保证各后端模型本身的稳定性和可比性。对于 Claude Code 等完整智能体，只暴露了模型族名称，无法保证与开发时使用的受害者模型完全相同快照。
- **模型与时间偏差风险**：本实验仅验证了 2026 年中的少数几个 API 模型，未来模型对趋势反事实测试的鲁棒性差异仍未被公平评估。
