## 摘要
递归自我改进（RSI）需要一种具体机制，使AI系统能够观察自身能力并将这些证据转化为下一轮学习。我们提出了NeoHorse-1，这是一个通过智能体后训练来探索这一路径的智能体原生模型系列。我们的系统将异构模型池与智能路由相结合，记录每一轮用户交互的预测能力需求、所选服务层级及后续交互。这些记录被转换成训练样本，保留交错推理、工具调用和框架上下文，并通过结构验证、六维语义评估和子场景级标注进行筛选。路由信号将监督微调组织为三阶段课程，并扩展到路由引导的在线策略蒸馏，其中教师在同一进程下监督学生生成的响应。能力引导分配随后将评估反馈转化为下一个训练混合，闭合评估-选择-更新循环，在此循环中系统所学内容决定其下一轮学习来源。在涵盖基于框架的智能体、工具使用、编码和指令遵循的11项基准测试中，后训练将4B模型的宏观平均值从58.94提高到64.87，9B模型从65.60提高到69.04，显著缩小了后训练的4B模型与9B基础模型之间的整体差距。NeoHorse-1提供了这一反馈驱动过程的初始原型，以及通过框架介导的RSI在连续迭代中实现的路径。

## Abstract
Recursive self-improvement (RSI) requires a concrete mechanism through which an AI system observes its capabilities and converts that evidence into the next round of learning. We present NeoHorse-1, a family of agent-native models developed to explore this path through agentic post-training. Our system combines a heterogeneous model pool with intelligent routing, recording the predicted capability demand, selected service tier, and subsequent interaction for each user turn. These records are converted into training examples that preserve interleaved reasoning, tool calls, and harness context, and are admitted through structural validation, six-dimensional semantic evaluation, and subscene-level labeling. Routing signals organize supervised fine-tuning into a three-stage curriculum and extend to routing-guided on-policy distillation, where a teacher supervises student-generated responses under the same progression. Capability-guided allocation then converts evaluation feedback into the next training mixture, closing an evaluation-selection-update loop in which what the system learns to do shapes what it learns from next. Across eleven benchmarks covering harness-based agents, tool use, coding, and instruction following, post-training raises the macro-average from 58.94 to 64.87 at 4B and from 65.60 to 69.04 at 9B, substantially narrowing the aggregate gap between the post-trained 4B model and the 9B base model. NeoHorse-1 provides an initial prototype of this feedback-driven process and a path toward harness-mediated RSI across successive iterations.

## 一、核心问题与研究动机

**Recursive Self-Improvement (RSI) 需要一个可操作的闭环机制。** 递归自我改进的核心愿景是：AI 系统能够从自身运行中观察能力边界，并把这种观察转化为下一轮学习的训练信号，使改进过程摆脱对人工数据与人工监督的依赖，形成跨代际的复合增长。

论文指出现有静态后训练范式的根本局限：**模型改进与模型部署相互割裂**。一个模型在训练时学习的是离线整理好的数据，而部署时面对的是动态真实交互。系统在服务过程中暴露的能力短板（失败轨迹、低效决策、未完成的执行链）并不会自动回流到训练环节，导致"越用越强"无法实现。

**本文的核心洞察**：一个已部署的路由控制框架（Routing Harness）本身已经天然包含 RSI 所需的反馈机制——它在服务用户请求的过程中持续产生三类可复用信号：
- **执行轨迹（Execution Trajectories）**：记录模型在真实任务中的决策、工具调用与环境反馈；
- **路由信号（Routing Signals）**：记录每轮交互的预测能力需求、服务层级选择；
- **结果反馈（Outcome Records）**：记录任务完成情况，揭示模型"哪里还不行"。

NeoHorse-1 的价值在于：它不是从零提出一种全新的学习算法，而是**系统性地展示了如何把部署基础设施中已存在的交互经验转化为训练数据、课程调度与数据分配决策**，构建一个"评估—选择—更新"的完整闭环，为大规模工业场景下的 RSI 提供工程化路径。


## 二、方法论

### 2.1 总体框架：路由介导的 RSI 闭环

系统架构由一个持续运转的循环构成：

> 多样化任务 → 路由框架（异构模型池 + 智能路由器）→ 记录交互轨迹 → 质量筛选与语义标注 → 组成训练数据 → 智能体后训练 → 更新模型 → 回到路由框架 → 评估新的能力短板 → 调配下一轮数据…

**核心特征**：系统的数据循环横跨多个异构模型（不仅限于被训练的模型本身），训练经验来自多模型行为与多执行环境的混合；而每一代被更新的模型回到部署框架后，其新的行为模式又产生新一轮的、反映新能力边界的轨迹。这构成"**所学内容决定下一轮学习来源**"的递归结构。

### 2.2 数据处理与构建

**三级粒度组织**：
- **轨迹（Trajectory）**：完整交互执行序列；
- **用户回合（User Turn）**：从一次用户请求到下一次用户请求之间的完整段落，是**基本序列化训练单位**；
- **子场景（Subscene）**：共享局部目标的相邻回合组，是语义标注单位。

**质量筛选（三层流水线）**：
1. **去重与去污染**：精确/近似去重，并保证训练数据与评估数据不相交；
2. **结构验证**：采用规则而非模型评分，验证请求/响应存在性、事件因果顺序、工具调用对完整性、标识符一致性与终止状态。输出结果分为三类：完整可用、部分可恢复、隔离（废弃）；
3. **六维语义评估**（PASS/WARN/FAIL/NOT_EVALUATED）：目标达成、指令遵循、工具使用、证据一致性、错误恢复、终止状态。确定性失败由规则检测，需任务理解的情形由语义评判器逐事件裁决。

**子场景级三维标注**：
- **场景（Scene）**：用户正在做什么（任务类型、领域、使用情境）；
- **目标（Goal）**：用户期待达成什么、如何判成功（含跨轮关系，如延续/修改/中断/恢复）；
- **结果（Outcome）**：尝试的可验证结果（产物是否生成、状态是否改变、是否存在证据）。

### 2.3 路由信号的利用（三阶段课程）

路由系统在用户回合级评估能力需求，分配 C0~C3 四个服务层级，并生成归一化分数向量。对每个样本定义：

- **硬排序**：直接使用分配的层级索引；
- **软排序**：按分数加权求期望层级；

路由分数仅用于组织课程顺序，**不改变样本目标**。训练分为三个阶段，每阶段纳入约三分之一数据，逐渐转向高路由分数样本，但在后期保留少量低分样本，防止训练后期被高需求交互完全主导。

### 2.4 智能体监督 SFT

将每条轨迹转化为"历史上下文 + 当前用户回合"的训练序列：

- 保留当前回合推理、跳过历史回合推理（符合 Qwen3.5 模板惯例）；
- 使用因果注意力，历史消息与工具结果无预测损失；
- 损失掩码（mask）覆盖当前回合推理、工具调用、可见响应及 EOS 标记；
- 以**监督 token 总数**归一化，而非序列长度或回合数。

### 2.5 路由引导的在线策略蒸馏（R-OPD）

**动机**：SFT 学的是已记录的响应，部署时学生面对的是自己生成的前缀，存在分布偏移。OPD 让学生以自身前缀为条件生成，固定教师提供逐位置下一 token 分布。

**算法流程**：
1. 路由分数调度三类起始上下文（渐进引入高需求，保留低需求到后期）；
2. 实时学生模型从上下文生成响应；
3. 教师（冻结）在学生生成前缀的每个位置给出下一 token 分布；
4. 计算**反向 KL 散度（Reverse KL）**，仅让学生梯度更新；
5. 定期刷新 rollout 学生，更新后的模型继续生成后续响应。

## 六、主要结论与发现

1. **后训练带来广泛且一致的提升**：

## 七、方法亮点

1. **将路由由"推理成本控制工具"升级为"能力需求信号源"**——这是论文最核心的概念创新：建立了"请求能力需求估算 → 训练数据排序 → 模型渐进学习"的因果链。

2. **真实部署数据而非人工轨迹**：数据来自生产环境的路由框架，包含真实的用户请求、多模型行为与执行反馈，具有不可替代的分布真实性。

3. **三级数据组织明确区分了粒度职责**：轨迹保留完整执行链、回合作为训练片段、子场景承载语义标注——将历史语境与训练目标解耦。

4. **路由引导在线策略蒸馏的设计精妙**：路由负责"学什么"，在线策略蒸馏负责"怎么学"——两个维度正交且互补；上下文调度与同阶段课程一致，教师监督直接在学生生成前缀上进行，从根本上消除分布偏移。

5. **规则与模型结合的质量筛选哲学**：可确定性验证的用规则、需语义判断的才用模型、且裁决必须落实到具体事件——有效控制标注噪声；标注置信度与推导方法的显式记录也体现了严谨性。

6. **真实轨迹揭示行为差异**：60+ 场景中的案例（如 PinchBench 中 9B 比 4B 节省约 83.6% token、70.8% 请求数、76.7% 执行时间）不是简单分数满足，而是体现了策略级差异（如放弃不可用的 pandas、切换标准库完成分析）。

7. **训练-评估闭环具备端到端的工程完整度**："评估缺陷画像 → 数据重分配 → 模型更新 → 模型回到框架 → 新轨迹 → 新缺陷画像"的闭环可实际运作，而非仅停留在概念层面。


## 八、不足与局限

1. **单一迭代验证不足以支撑 RSI 声称**：结果是"一轮反馈闭环"的产物，是否能在多轮迭代中持续累积提升尚未验证，论文也明确承认这一点。RSI 的核心承诺是"复合增长"，需要跨代验证。

2. **评估覆盖范围有限**：集中在智能体执行、代码、函数调用与指令遵循，但路由框架实际服务的任务类型（多模态、推理深度、长文档工作流等）远大于此——选择性评估有"挑容易的验证"之嫌。

3. **缺乏关键消融实验**：
   - 未验证路由分数作为课程信号的贡献（替换为随机排序或难度评分精确的对比）；
   - 未解耦三阶段课程与同阶段 OPD 的各自增益；
   - 未对比 SFT 与 SFT+OPD 的贡献差异；
   - 缺少路由信号 vs. 难度标签的直接对比。

4. **在线策略蒸馏的"教师"来源不透明**：固定教师的身份与能力层级未说明；教师若有污染、偏差或已过时，其监督信号的质量缺乏分析；且只报告了 SFT+OPD 联合结果，无法归因单一方法。

5. **规模跨度狭窄**：4B 与 9B 同属小/中规模区间，结论外推到更大模型缺乏依据；反而把 30B 级 Muse-Glimmer 放在 9B 赛道作为参照，对比不对齐——解释为"上下文参考"可以理解，但客观上容易误导。

6. **无计算资源报告**：训练成本、所需 GPU 数、实验复现成本不可估算，对工业可复制性构成障碍。

7. **统计报告不足**：大多数基准仅一次运行、无置信区间、无显著性检验；附录质量评估有明确错误（如时间窗口为五秒却用两秒），暴露了与模型能力不一致的潜在不稳。

8. **伦理与安全性考量缺失**：针对"模型自我改进"的系统性安全分析全无，RSI 论文通常至少需讨论风险边界、控制机制或对齐保障，这是一个重要留白。


## 附：一句话总结

NeoHorse-1 最有价值的贡献是概念性的：它用工程实践证明了——**一个大模型服务系统在"正常运营"中产生的副产物（路由记录 + 交互轨迹 + 能力反馈）就足以驱动模型自身的持续改进**，这为 RSI 提供了一个可落地的工业路径。但"闭环可运转"与"闭环可持续累积增益"之间仍有巨大距离，需要后续研究补上多轮迭代验证、更系统的消融实验与更广泛的评估覆盖。

（完）
