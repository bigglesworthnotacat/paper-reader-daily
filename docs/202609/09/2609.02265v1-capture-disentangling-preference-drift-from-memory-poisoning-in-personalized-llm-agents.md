## 摘要
个性化语言代理使用持久记忆来随时间适应用户，但同样的机制也创造了攻击面。当新信息与存储的偏好冲突时，代理必须区分真正的偏好漂移与临时情境转变、模糊性或对抗性记忆中毒。我们将此问题表述为潜在用户状态上的连续时间部分可观测决策过程，并展示了为何仅基于最近性和来源的规则是不够的。CAPTURE通过神经微分方程信念跟踪器、多时间尺度记忆分类账、不确定性触发的澄清以及引用记忆的反事实审计来解决这种模糊性。在来自96名用户的480个保留剧集中，CAPTURE实现了71.5%的胜率，而同等监督下的基线和最强启发式基线分别为69.3%和66.1%。它将固定策略的中毒成功率限制在11.5%，同时接受83.5%的真实偏好更新。在能够访问发布权重的自适应攻击者下，攻击成功率上升至24.7%，暴露了真实的适应性与安全性之间的权衡。我们进一步在独立构建的基准上对冻结系统进行零样本评估，并重放了从40名用户收集的两至三周的纵向交互历史。这些结果表明，显式建模偏好真实性可以同时提高记忆增强型LLM代理的个性化和鲁棒性。

## Abstract
Personalized language agents use persistent memory to adapt to users over time, but the same mechanism creates an attack surface. When new information conflicts with stored preferences, an agent must distinguish genuine preference drift from temporary context shifts, ambiguity, or adversarial memory poisoning. We formulate this problem as a continuous-time partially observable decision process over a latent user state and show why rules based only on recency and provenance are insufficient. CAPTURE addresses this ambiguity with a neural differential-equation belief tracker, a multi-timescale memory ledger, uncertainty-triggered clarification, and counterfactual auditing of cited memories. On 480 held-out episodes from 96 users, CAPTURE achieves a 71.5% win rate, compared with 69.3% for an identically supervised baseline and 66.1% for the strongest heuristic baseline. It limits fixed-policy poisoning success to 11.5% while accepting 83.5% of genuine preference updates. Under an adaptive attacker with access to the released weights, attack success rises to 24.7%, exposing a real adaptation-security tradeoff. We further evaluate the frozen system zero-shot on an independently constructed benchmark and replay longitudinal interaction histories from 40 users collected over two to three weeks. These results suggest that modeling preference authenticity explicitly can improve both personalization and robustness in memory-augmented LLM agents.

## 1. 论文的核心问题与整体含义（研究动机和背景）

个性化语言代理（Personalized LLM Agents）通过持久记忆机制在数周乃至数月维度上追踪和适应用户的偏好，以提高输出质量。然而，**同一记忆通道也构成了攻击面**：检索到的网页、共享文档、工具输出等均可向代理的记忆中写入内容。论文提出“**偏好-真实性模糊性**”（Preference-Authenticity Ambiguity）这一核心问题——当一条新信息与既有信念相矛盾时，代理无法从单轮观测中分辨四种可能：
- 用户**真实改变**了偏好（如换岗后需要简短答复）；
- 用户只是**临时情境切换**（如"每日站会"场景中需简洁）；
- 用户**反讽或随意表达**（非真实变更）；
- 攻击者通过**检索内容注入**恶意偏好声明。

现有系统在两个方向上各执一端，且均不稳定：

| 方向 | 代表方法 | 缺陷 |
|---|---|---|
| 个性化管道 | 将一切更新视为真实 | 可被任何写入者轻易操纵（高中毒率） |
| 注入防御（仅来源过滤） | 拒绝所有非可信来源 | 阻止了合法用户在合法渠道上的偏好修订（不适应性） |

论文的核心论点：**真实性（authenticity）应作为潜在变量被推断，而非作为属性被假定**，从而同时改善个性化能力与安全性，突破适应性与安全性之间的固定权衡。

## 2. 论文提出的方法论：核心思想与技术细节

### 2.1 问题形式化

将偏好更新建模为**连续时间部分可观测决策过程**：用户潜在状态 $s_t=(v, c_t, g_t)$（稳定价值观/情境偏好/短期目标），代理只能从事件流维护信念 $b_t$，目标是极小化动态遗憾（dynamic regret）同时满足安全预算：

$$\min_\pi \sum_{t=1}^{T}\mathbb{E}[u_t(a_t^*) - u_t(a_t)] \quad \text{s.t.}\quad \mathbb{E}[R_{\text{safety}}(y_t)] \le \tau$$

### 2.2 理论结果（定理）

- **定理2（不可能性）**：任何仅读取"最近性+来源"（即 $\phi$ 视图）的决策规则，其接受注入率+拒绝真实改动率之和存在下界：$FUR+RRL \ge 1-\delta_\phi$，其中 $\delta_\phi$ 是真实与对抗分布在此视图上的总变差距离。
- **定理3（数据过程不等式）**：以完整历史为条件永远不会比只看 $\phi$ 更差，且在特定条件下严格更优。
- **定理4（澄清的价值）**：成本有界的澄清问题在有条件时能严格扩大可达错误区域之外的能力边界。

### 2.3 系统架构（CAPTURE）

CAPTURE由四个核心组件构成，一个事件流经其完整管线：

**（1）偏好假设提取器（Preference-hypothesis Extraction）**
- 基于 Qwen2.5-3B + LoRA 模型，在模式约束解码下生成结构化元组：
$$H_t = \langle \text{claim}, \text{direction}, \text{scope}, \texttimescale{}, \text{confidence}, \text{provenance} \rangle$$
- 训练损失包含交叉熵加"弃权"惩罚 $\Omega(\hat{H}_t)$，因为约七成事件不携带偏好信号。

**（2）真实性门（Authenticity Gate）**
- 维护潜在信念 $h(t)$，事件之间通过**神经微分方程**演化：
$$\frac{dh(t)}{dt} = f_\theta(h(t))$$ 
  时间仅通过积分区间 $\Delta t$ 进入——适合不规则交互间隔（同一日下午40条消息 vs 九天无消息）。
- 事件到达时由离散GRU消费。门输出六类动作：保留、新增、限定（scoping）、修订、隔离（quarantine）、询问（ask）。
- 当动作分布香农熵超过阈值 $\eta$ 时触发询问，预算控制在每12次交互至多1次澄清。

**（3）多时间尺度台账（Multi-timescale Ledger）**
- 节点分属**稳定层**（$\gamma_s=0.01$/天）、**情境层**（$\gamma_c=0.1$/天）、**瞬时层**（$\gamma_g=0.5$/天），衰减率经网格搜索后冻结（联合学习会崩溃收敛至单值并损失3.1个百分点的真实更新接受率）。
- 置信度为 $c_0\sigma(h_t)\exp(-\gamma(t-t_0))$，其中 $\sigma(h_t)$ 是学习的调制因子。
- **隔离（Quarantine）**是状态而非层——隔离节点不可检索、不影响响应，14天衰减至保留下限 $\phi=0.15$ 即被清除；期间若获证实则按其范围提升入对应层。

**（4）安全有界选择与因果审计（Safety-bounded Selection & Causal Audit）**

- 选择器从 N 个候选中评分选择：
$$y^\star = \arg\max_{y\in\mathcal{Y}}\big[\alpha r_p(y) - \beta r_s(y)\big] \quad \text{s.t.}\quad r_s(y) \le \tau_{\text{safe}}$$
- **安全阈值 $\tau_{\text{safe}}$ 不可被台账中的任何内容移动**——这是架构性安全边界而非学习行为。
- 审计采用**反事实删除再解码**计算每条引用的影响（而非注意力或检索排名）：
$$\text{Inf}(n_i) = U(y_{\text{factual}}) - U(y_{\mathcal{L}\setminus n_i})$$

### 2.4 Benchmark：D-PREF GUARD

包含 2,400 个纵向剧集（每集12–20轮），分5条轨道：
- **T0**：静态用户——任何更新均为虚假；
- **T1**：四类真实漂移（突变/渐变/循环/情境切换）；
- **T2**：良性歧义（讽刺/错别字/弱证据）；
- **T3**：三类污染各160集（间接注入/中毒摘要/同源写入）；
- **T4**：个人效用与全局安全约束直接冲突。

## 6. 主要结论与发现

1. **不存在固定权衡**：CAPTURE以11.5%的中毒率同时达到83.5%的真实更新接受率，在安全性、适应性和假准入率三项上同时超越仅来源过滤——而其中任何单一结构都无法做到。
2. **主要收益来自监督**：有监督Transformer-Δt几乎消除了大部分差距（胜率仅差2.2个点），架构贡献（台账+ODE）是剩余的增量且能跨生成器迁移。
3. **架构同样重要且可迁移**：外部零样本评估中，CAPTURE在矛盾解决上以0.72对StateMem的0.65胜出；在真实历史重放中胜率领先4.5个点（p=0.014）。
4. **自适应攻击是开放问题**：自适应攻击者使CAPTURE的中毒率从11.5%升至24.7%，此时仅来源过滤在安全性上不再可靠地被CAPTURE压制（p=0.29），CAPTURE的优势落在适应性上（83.5% vs 74.1%）。
5. **隔离机制是主要防御手段**：58%的阻断尝试以"隔离→未证实→衰减"方式化解，而非直接拒绝。

## 7. 优点

- **理论驱动的形式化**：将"偏好-真实性模糊性"严格刻画为部分可观测决策问题，并给出可操作的下界定理（不仅证明启发式失败，还提供使数据过程不等式成立的可能条件）。定理证明在附录中完整呈现。
- **架构设计精巧且动机明确**：连续时间ODE（不规则间隔自适应）、多时间尺度台账（stable/contextual/transient各层衰减异质）、澄清机制（在熵高时主动降低不确定性而非盲目决策）、架构性安全边界（安全阈值不受台账影响）均有明确问题动机，且逐项消融验证。
- **评估严谨性和诚实性**：
  - 不仅报告有利数字，还报告自适应攻击下Provenance-only反超这一不利结果；
  - 主动解决"学到了生成器而非问题"的质疑（外部基准+真实用户回放）；
  - 统计分析细致（配对自助、交叉双路重采样、预注册的分箱方案、Clopper-Pearson单侧界等）；
  - 声明5条先验可证伪标准并逐一检验；提供一致性检查（穷尽所有限制条件）。
- **反事实审计**：用删除-再解码测量真正因果影响力，而非依赖已被证明不可靠的注意力/检索排名，并报道影响AUC（0.718）。

## 8. 不足与局限

1. **合成数据依赖**：D-PREF GUARD 虽以PRISM/PersonalLLM/LaMP为种子，但对话文本由LLM生成（人类验证仅覆盖300集子集），绝对数字不能作为部署表现估计。
2. **规模有限的外部效度**：40名参与者支撑效应量估计但不支持任何子群体结论；重放污染为作者构建，不能测试真实世界攻击迁移。
3. **自适应攻击仍是瓶颈**：攻击者利用发布权重将攻击成功率翻倍，且在自适应威胁下CAPTURE与仅来源过滤在安全性上已无可靠分离。
4. **CAPTURE的文本限制**：不处理权重级投毒；附加澄清预算在自有数据上调参，定理4的实证检查只能算"指示性"而非验证（成本单位不匹配）。
5. **监督依赖**：性能大部分来自大量带标注的训练数据——现场没有此类标签时收集成本可能很高。
6. **推理成本大于启发式基线**：每轮630ms延迟和额外token消耗，可能限制资源有限场景的部署。
7. **模糊性残留**：既有攻击者通过多处小偏移缓慢攻击（21%成功案例），论文承认不在解决范围内。
