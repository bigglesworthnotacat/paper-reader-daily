## 摘要
规划是使智能体能够将复杂的长期任务分解为可管理步骤的核心能力。测试时搜索和基于训练的方法能改进规划，但会带来高昂的推理成本或需要昂贵的训练数据。自我演化记忆则通过将智能体交互结果中可复用的经验累积到外部记忆库中，使得规划能力在推理时无需参数更新即可持续提升。然而，现有的自我演化记忆方法存在一个固有的信用分配问题：它们依赖最终任务结果作为反馈，但这种结果将规划质量与执行错误和环境因素混为一谈，导致累积的规划经验常常有偏且含噪。为解决这一问题，我们提出了信用感知分层记忆演化（CHIME），一种自我演化记忆框架，它维护独立的规划库和执行库，并遵循“先归因后记忆”的原则：CHIME首先将每个任务结果归因于规划、执行、两者或两者皆非，然后仅更新相应的记忆库。在四个长期智能体基准上的大量实验表明，CHIME始终优于最先进的基于训练和自我演化记忆的基线方法。进一步的分析揭示了若干有趣的发现。例如，CHIME能以远少于基线项目的数量累积有效记忆。此外，学习到的记忆值忠实地反映下游效用：高质量规划记忆比执行记忆更有价值。最后，累积的记忆能有效跨骨干模型迁移。代码将在https://github.com/ATH-MaaS/Marco-DeepResearch发布。

## Abstract
Planning is a central capability that enables agents to decompose complex long-horizon tasks into manageable steps. Test-time search and training-based methods improve planning but incur high inference costs or require expensive training data. Self-evolving memory instead accumulates reusable experience from agent interaction outcomes into an external memory bank, so planning capability keeps improving at inference time without parameter updates. However, existing self-evolving memory methods share an inherent credit assignment problem: they rely on final task outcomes as feedback, but such outcomes conflate plan quality with execution errors and environmental factors, so the accumulated planning experience is often biased and noisy. To address this problem, we propose Credit-Aware Hierarchical Memory Evolution (CHIME), a self-evolving memory framework that maintains a separate planning bank and execution bank and follows an attribute-before-memorize principle: CHIME first attributes each task outcome to the plan, the execution, both, or neither, and then updates only the corresponding memory bank. Extensive experiments on four long-horizon agent benchmarks show that CHIME consistently outperforms state-of-the-art training-based and self-evolving memory baselines. Further analyses reveal several interesting findings. For example, CHIME accumulates effective memory with far fewer items. In addition, the learned memory values faithfully reflect downstream utility: high-quality planning memories are more valuable than execution memories. Finally, the accumulated memory effectively transfers across backbone models. Code will be released at https://github.com/ATH-MaaS/Marco-DeepResearch.

### 1. 核心问题与研究动机

长期（Long-Horizon）任务对智能体系统构成挑战：智能体需在相互依赖的步骤间协同决策，并在整个执行过程中保持对任务约束的遵循。规划（Planning）被视为解决此类任务的核心能力。

**现有提升规划的三大路线及其不足：**

| 方法范式 | 代表性方法 | 不足 |
|---------|-----------|------|
| **测试时搜索** | ToT、LATS、WebAnchor 等 | 单任务效果好，但推理成本高，不保留可复用经验 |
| **规划器模型训练** | TodoEvolve、Plan-and-Act 等 | 依赖昂贵的数据收集与后训练，更新成本高 |
| **自我演化记忆** | ReasoningBank、A-MapReduce、UMEM 等 | 免训练、可累积，但存在**信用分配（Credit Assignment）根本性缺陷** |

**核心问题：** 现有自我演化记忆方法用**最终任务结果**作为记忆更新的监督信号，但该信号是有偏的——同一结果可源于不同原因：
- 成功可能源于好计划，也可能源于执行者在坏计划下的临场补救；
- 失败可能源于计划缺陷、执行差错或环境因素。

将这样的结果直接作为反馈写入记忆库，会导致两方面的系统性危害：
1. 有偏记忆一旦写入，会随检索被反复复用，使局部误判累积为系统性规划错误；
2. 执行层/环境层的经验可能被误当作规划记忆存储，低级细节会误导高层次规划决策（跨阶段污染）。

### 2. 方法论：CHIME 框架

#### 2.1 核心思想
CHIME 提出 **“先归因后记忆”（attribute-before-memorize）** 原则：先将每个任务结果归因到规划、执行、两者或两者皆非，再仅更新对应的记忆库，从而降低反馈偏差、阻断跨阶段记忆污染。

#### 2.2 任务公式化
自演化智能体在时间片 t 上处理任务 xt，冻结策略参数、仅动态演化外部记忆库 Mt：

**Mt+1 = U(Mt, xt, τt, st)**

现有方法直接用最终结果 st 作为记忆更新的唯一信号，这在高层次的智能体规划场景中是有偏的。

#### 2.3 三个核心组件

**① 分层记忆库（Hierarchical Memory Bank）**
- 将记忆划分为两个独立子库：**规划库 Mplan,t**（存子任务分解、依赖建模、约束纳入等战略经验）和**执行库 Mexec,t**（存工具选择与调用等操作经验）。
- 每个记忆项 mi = (ci, ei, vi, ni)，其中 ci 是适用任务描述（检索/融合键），ei 是可复用经验文本，vi ∈ [−1,1] 是价值评分，ni 是复用次数。
- 每个 episode 的链路为：Mt → 取规划记忆 → 生成计划 → 取执行记忆 → 执行 → 获得结果 → 归因门诊断 → Mt+1。

**② 信用归因门（Credit Attribution Gate）**
- 以冻结策略的**结构化自我反思**实现，引导模型复盘任务、计划、轨迹、结果与检索记忆。
- 输出诊断 gt = (at, {(cnewℓ,t, enewℓ,t)}, γt, M mis t)，其中：
  - **at** ∈ {planning, execution, both, none}：归因标签（成功时识别功劳归属阶段，失败时定位责任环节）；
  - **(cnew, enew)**：为各归属阶段生成的可复用经验；
  - **γt ∈ [0,1]**：归因置信度；
  - **M mist**：被识别为误导性的检索记忆。

**③ 信用感知记忆演化（Credit-Aware Memory Evolution）**
- **价值演化：** 对检索到的记忆 mi 产生反馈 δi,t；若该记忆处于归因层且任务成功则奖励 +γt，若被识别为误导则惩罚 −γt，否则不更新。按上下文设计决策集 L(at)（at=both 时同时更新两个库）；采用在线平均更新价值：**vi ← clip((nivi + δi,t)/(ni + 1), −1, 1)**, **ni ← ni + 1**；对复用充分（ni ≥ nmin）但仍低价值（vi < θprune）的记忆执行剪枝。
- **内容演化：** 对归因阶段产生的新经验执行三种处理之一：
  1. **合并**：与新经验高度相似（sim > θmerge）的既有记忆合并；
  2. **插入**：可接纳但不相似时，以 (cnew, enew, 0, 0) 中性初始值插入新记忆；
  3. **丢弃**：置信度不足（γt < θconf）或内容不具可操作性时丢弃。

#### 2.4 分层检索与价值重排序
- 在各阶段基于语义相似度取 Top-N 候选，再按经复用次数校准的价值分重排序取 Top-K（式 5）：

**M ret = TopK [ sim(q, ci) × (1 + clip(α·v̂i, −β, β)) ]**

其中 v̂i = vi·ni/(ni+λ)，λ 为平滑常数；以相似度为主排序因子的同时偏好验证有效的记忆、抑制误导性记忆。

### 3. 实验设计

#### 3.1 评测基准（四个长期任务场景）

| 基准 | 任务形态 |
|------|---------|
| **τ²-Bench** | 多轮客服交互（双重控制环境） |
| **VitaBench** | 多轮生活服务任务（可变用户意图、大工具空间） |
| **BrowseComp-ZH** | 长周期中文信息检索 |
| **BFCL-v4** | 函数调用（含 Live 与长周期 Agentic 组） |

#### 3.2 骨干模型
- **Qwen3.5-Flash**（35B 总量，3B 激活）
- **DeepSeek-V4-Flash**（284B 总量，13B 激活）
- 同一骨干同时担任规划器、执行器和信用归因门；评测侧 LLM 统一使用 Qwen3.6-Flash；检索用 Qwen3-Embedding-0.6B。

#### 3.3 对比基线（4个，按与本文设置接近度递增）
1. **No-Plan**：无显式规划的普通 LLM 智能体；
2. **WebAnchor**：测试时搜索（采样多个候选计划精选）；
3. **TodoEvolve**：训练元规划器生成任务专属规划架构（但与 CHIME 相同不积累经验累计）；
4. **A-MapReduce**：最贴近 CHIME 的基线，从轨迹中提炼可复用洞见，但直接以最终任务结果驱动记忆更新。

#### 3.4 评测协议
- 将各基准按数据流序做 **7:3 train/eval 划分**：
  - **Train split**：测记忆积累能力（边执行边更新记忆）；
  - **Eval split**：冻结记忆库，测记忆向**未见任务的泛化迁移**能力（不做进一步更新）。
- 每个基准在三种随机实例序下运行，报告 **Avg@3**，降低排序方差。
- 多域基准按最小域 size 截断并独立划分，保证各域贡献均衡。
- 消融研究覆盖：分层记忆设计（去除计划库/执行库/两库皆去/两库合并）以及信用归因与演化（去归因门/去信用重排序/去记忆演化）。

### 6. 主要结论与关键发现

1. **主结果**：CHIME 在两种骨干下均取得最优的 Train/Eval 平均值——Qwen3.5-Flash 上 Eval 均值 34.87%、DeepSeek-V4-Flash 上 39.01%，相比最强基线分别提升 **2.96%** 与 **3.68%**；相比最接近的 A-MapReduce 分别提升 5.37% 与 3.68%。
2. **记忆数量与效率成反比**：CHIME 在整个数据流上仅积累 **129 条**记忆就达到最高精度，而 A-MapReduce 积累 **3,585 条**且全量累积后精度反而回落（因无用记忆持续写入、干扰检索）——说明有效记忆演化取决于质量而非数量。
3. **记忆值与下游效用的单调关系**：计划记忆在低→高价值组由 21.7% 提升至 50.8%（增益 29.1%），执行记忆相应由 23.7% 提升至 35.4%（增益 11.7%）；高质量规划记忆比执行记忆更有价值。
4. **归因门可靠性较高**：训练计划与执行标签重复一致率在 87.8%~97.9% 之间；在仅用归因门生成记忆重跑的任务中，有 56.3%~67.6% 的失败被“拯救”。
5. **更强的信用模型带来更大收益**：将骨干自反思替换为更强的 Qwen3.7-Flash，在三个基准上获得 2.25%~3.12% 的提升，说明归因质量直接影响经验有效性。
6. **跨骨干迁移有效**：CHIME 跨骨干转移的记忆在四个设置中均优于 A-MapReduce 转移的记忆（高 2.25%~4.68%），且接近甚至达到“目标骨干自行积累记忆”的上界——表明归因式记忆编码的是可复用指导而非骨干特有模式。

### 7. 优点与亮点

- **问题定位精准**：尖锐指出了自演化记忆在智能体规划场景下的信用分配缺陷（最终结果 ≠ 计划质量），击中现有范式的普遍盲点。
- **方法论上的优雅闭环**：“先归因后记忆”，以结构化自反思门控记忆（写入、更新、删除、合并）的各个操作，形成一致性极强的设计逻辑。
- **记忆结构设计合理**：将记忆项标准化为（场景、经验、价值、复用频次），价值由复用反馈在线更新，可自然支持检索排序与剪枝。
- **检索层与演化层衔接好**：相似度为主、价值为辅的重排序策略避免“低相似度高价值”的记忆过度支配结果。
- **实验覆盖全面而深入**：主实验、消融、外部裁判记忆质量评估、效率分析、价值效用分析、门控可靠性、跨模型迁移等多维验证，既有量化结论也有典型 case 的可读性支撑。
- **公平性考量的细节**：三个随机排序取均值（Avg@3）、禁止 eval 阶段更新记忆、统一使用同一套官方基准运行环境与工具，用外部裁判而非自评评估记忆质量，以上设计均增强了比较公平度与可信度。

### 8. 不足与局限

- **无可量化算力信息**：未报告 GPU 型号/数量及时间开销，限制复现与成本评估。
- **受限于骨干自身能力**：CHIME 只加记忆不强骨干，当智能体无法遵循或正确执行所给指导时记忆也不起作用（即使归因门生成的记忆仅在 56.3%~67.6% 的失败中被移除——约 1/3~2/5 失败残留）。
- **归因依赖骨干的自反思能力**：归因门依靠模型自我审视，弱骨干体现自反思能力有限时归因可能不准。
- **跨基准迁移有限**：跨骨干迁移证据较充分，但跨基准（操作条件不同）的迁移表现较弱，限制了通用记忆的普适性。
- **实验基准多为合成/受控任务**：真实场景与开放域环境的覆盖有限。
- **检索记忆上限过小**（K=3），极端大规模任务中可能限制可复用经验的信息传达量。
- **剪枝与融合阈值敏感**：大量超参数（θ merge、n min、θ prune、λ、β等）依赖人工设定，缺乏灵敏度数据。
- **生成的 prompt 格式**方面并不影响全流程以 LLM 输出驱动的记忆价值信号本身，但无法证明设定背景对训练数据分布变化有结论性优势。
- **方法持续更新记忆主要在结果一致与质量验证方面处理得很好**，但部分记忆门控判断来自自反思单一信号，若面对更细粒度（如过程级多结果）的任务，其归因粒度可能仍不足。
