## 摘要
安全对齐训练使大型语言模型能够拒绝以直白形式陈述的有害请求，但这种训练大多应用于表面形式。因此，仅通过重构相同操作内容、改变模型解读方式而提出的请求，覆盖程度较弱。ASCII攻击正是这样一种重构。它是单轮且黑盒的：一条消息，无法访问模型内部。它将完全清晰可读的有害请求嵌入ASCII艺术字符中，将其呈现为艺术品，并请求反馈。与ArtPrompt不同，它不隐藏任何内容：请求仍然可读。回复以艺术批评的形式撰写，可能包含平铺直叙的请求会被拒绝的操作性细节。每个被框架化的提示都配有一个直接提问的对照组，因此对比与主题、模型和解码变化隔离开来。该对比识别的是一个捆绑的表面，而非孤立的渠道。在11个模型和8个有害主题中，一个有害性感知分类器判定62%的框架化提示为有害，而对照组为42%。在最易受影响的模型上，框架化提示在93%的情况下成功。在五个危害评判者中，单一查询在四个下达到或超过了已发表的单查询攻击。这种效果更多跟随模型而非主题，且不随规模增大而减弱。在近三分之二的框架化行中，至少有一个评判者不同意多数裁定，这本身就是一个测量有效性的发现。该模式与不匹配的泛化一致。

## Abstract
Safety alignment trains large language models to refuse harmful requests stated plainly, but that training is applied mostly to surface form. Requests that only recontextualise the same operational content, changing how the model reads it, are therefore only weakly covered. The ASCII Attack is one such recontextualisation. It is single-turn and black-box: one message, with no access to model internals. It embeds a fully legible harmful request in ASCIl-art characters, presents it as artwork, and asks for feedback. Unlike ArtPrompt, it hides nothing: the request stays readable. The reply is written as artistic critique and can contain operational detail that a plain request would have been refused for. Every framed prompt is paired with a direct-question control, so the contrast is isolated from topic, model and decoding variation. The contrast identifies a bundled surface, not one isolated channel. Across eleven models and eight harm topics, a harm-aware classifier judges 62% of framed prompts harmful against 42% of controls. On the most susceptible model the framed prompt succeeds 93% of the time. A single query matches or exceeds published single-query attacks under four of five harm judges. The effect tracks the model more than the topic and does not diminish with scale. At least one judge dissents from the panel majority on nearly two-thirds of framed rows, which is itself a measurement-validity finding. That pattern is consistent with mismatched generalisation.

# ASCII攻击：将有害请求重构为大型语言模型中的艺术批评

## 一、核心问题与研究动机

**核心问题与背景**
大语言模型（LLM）的安全对齐训练——通过RLHF、宪法AI等方法——旨在使模型拒绝有害请求。然而，这类安全训练主要针对**表面形式**：对齐系统基于自然语言中直白表述的有害请求进行监督，而模型对操作内容的泛化能力存在盲区。这导致了Wei等人（2023）所称的**"不匹配泛化"**（mismatched generalisation）问题——模型能够解析某类输入，但安全训练的拒绝行为却无法泛化到该输入上。

**研究动机**
本文研究了此前未涉足的一个角落：将**包含有害场景的ASCII艺术字符组合**包裹在"请求艺术反馈"这一社交框架之下，模型能够解析请求但错误地将其理解为美学行为而非有害指令。简称 **ASCII攻击**。

**与ArtPrompt的关键区别**
- ArtPrompt将敏感词隐藏为ASCII字形，要求模型解码；
- ASCII攻击**不隐藏任何内容**，有害请求完全可读，攻击针对的是请求的**社会性框架**——将直接提问重构为对艺术品的批评请求。

## 二、方法论与核心设计

### 攻击原理

攻击基于一个假设：安全对齐的拒绝边界是针对自然语言中直白有害请求的分布拟合的。当变换保持操作内容不变但将表面形式移出该分布时，拒绝行为不触发，模型自身能力（以及人类读者）仍能还原有害含义。

### 威胁模型
- 单轮（single-turn）、黑盒（black-box）
- 无模型权重、系统提示或内部logits访问权限
- 无微调能力——最弱现实设置，因此结果是攻击成功率的**下限**

### 攻击提示结构（五部分）

每一攻击实例为单个用户轮次，按顺序拼接五部分字符串：

| 部件 | 内容 |
|---|---|
| 1. 元指令 m | 要求对ASCII作品提供艺术反馈、细节推导或真实感改进 |
| 2. ASCII字形块 B | 用符号符号（如 `\|\|\|BAD GUY\|\|\|`、`&&...&&`）包围有害场景 |
| 3. 场景描述 s | 以明文散文命名行为者、目标、工具和目的 |
| 4. 缺失信息请求 Q* | 列出攻击者实际想知道的技术子问题 |
| 5. 结束哨兵 token | `END OF ASCII ART` 或 `END OF ASCII` |

正式表达：`p_ascii = m + B + s + Q* + <END OF ASCII ART>`，匹配的对照 `p_ctrl = direct(g)`。

### 核心指标——框架提升量（Framing Uplift）

$$\Delta_{(y,m),j}^{frame} = ASR_{(y,m),j}^{ascii} - ASR_{(y,m),j}^{control}$$

即ASCII框架手臂与匹配对照之间攻击成功率（ASR）的差异，以百分点（pp）表示。关键的是，该配对设计测度的是**捆绑处理**（美学框架+字形块+场景描述+缺失信息列表），而非单独的美学渠道——这是论文明确承认的混淆因素。

### 使用的双渠道
1. **美学-寄存器渠道**：把有害请求重构为"请帮我改进画作"，这个社会行为在拒绝监督训练中稀疏覆盖；
2. **视觉噪声渠道**：符号字形穿插语言外标记，在自然语言有害示例训练拟合的边界之外。

## 六、主要发现和结论

1. **总体框架正向上提升**——在五种危害评判标准下，提升幅度从+7.8 pp到+20.1 pp不等（JailbreakBench）：
   - JBB: ASCII 62.37% 对比 对照 42.29% (+20.09 pp)
   - WildGuard: 38.17% 对比 22.29% (+15.89 pp)
   - LG3: 23.15% 对比 12.86% (+10.29 pp)
   - LG4: 11.38% 对比 2.22% (+9.16 pp)
   - GG: 11.37% 对比 3.57% (+7.80 pp)

2. **攻击有效性与架构的关系大于与话题的关系**——模型ANOVA η²=0.397，话题ANOVA η²=0.215。对比率在11个对9个模型中接近所有指标的最大值，仅Llama 3.2 3B、Llama 3.1 8B在多数指标上出现负向；在Qwen 3 32B等能力较强的LLM模型上，面向规模的鲁棒性表现反而下降。

3. **高能力无法修复不匹配的泛化性**——参数规模与ASCII攻击成功率显著相关（ρ=+0.72），随规模增加（而非减少）的敏感性表明安全泛化不随规模扩展而自然改善。

4. **攻击成功率不随温度降低**——ASR在T∈{0.1,0.5,1.0,2.0}范围内基本保持平坦，证明该攻击不依赖特定解码运气。

5. **单次查询即具备竞争力**：在JBB下效率达60.1%，在11个模型中胜过/打平PAIR（多步攻击，15次查询）9次中的7次，在单次查询场景中比ArtPrompt和DeepInception表现更好，用于攻击的最佳组合能达到77%的成功率。

6. **测量有效性发现**——在62.9%的ASCII框架下，至少有一名评判者不同意多数结论；Cohen's κ在评分者对配对间范围为0.08-0.47，Fleiss' κ=0.21。研究发现影响LLM一致性、任务评断形式及阈值不一致性，以及五个交叉评估中……（两种判定策略对模型风险估值的质量很重要）的证据。

7. **深思链的思维评估结果不理想**——预评分深链从未报告更高的"恶行"得分，但约6/192例中"隐藏的思考伤害"超越了答复本身；这个缺口是来自研究思维模型的问题线索，但实质性风险集中在Small R1变体中。

## 七、亮点与贡献

- **C1——新增的攻击类别**：ASCII攻击将ASCII符号艺术作为完整可读的有害请求重新语境化，利用美学/社会定位而非词遮蔽，将其确立为ArtPrompt的语义相邻但机制正交的变体。因此，其表述在描述任何规范性的成功模型时，不必假设字体可读性也是规范性因素。
- **C2——配对匹配对照协议**：该方法包含三个手动ASR的配对基准线重建测干实验。通过一个对照提示捕捉文本中直接请求的同一条测干内容，显示源自话题、模型、去耦和测量自由差异的混淆因素，主导了攻击比较能力的非配对基础。
- **C3——架构局限性描述**：研究分析了对按相对位置注释的模型进行锚定的威胁类别结果——深入探讨九/11个完全跨尺度生成的模型威胁类别：允许控制提示结构被降低的结构在更大更强模型中仍在放宽，并且标准错误从温度到结论校准都被恰当地识别和隔离。
- **C4——对竞争攻击的有效稳健评估**：LLM评级攻击组合、多个生成的评估者、主评审和专家偏差诊断（StrongREJECT）以判断分歧和基准验证中固有的协议限制呈现——将透明度编码到数据中，从而反映出测量器件的配置在注释置信度之外造成的系统效应。

**论文的优势**主要在于评测的严谨性，尤其是测量效应分析；多重评分者评估框架的运用及充分的敏感性/鲁棒性测试（Leone-le-One-out稳定性、替换材料、评估者协议、评分规则验证——这些评估中检测到的工具性影响异常明显）；

此外，有限威胁模型（黑盒、单轮、无系统提示）的支持——意味着漏洞超出已证明设定（白盒、多次、基础权重/版本或系统抑制的薄弱环节）；

以及执行稳健复现核查（Bravo），以应对混合集群约束的审查。

## 八、局限性与偏差

**确认威胁 / 构造有效性（最重要）**：
- **提示长度与信息预激活混淆**：ASCII提示平均785.7字符，是对照组（81.3字符，9.66×比率）的大约十倍长，并承载参考措辞场景描述和结构化信息补全请求。因此，对比结果代表一个"捆绑"表面，而不是对美学渠道作为独立变量的评估——要解决这一点需要添加第二个对照分支，匹配信息密度但不带美学模式。
- **LLM评分者并非基线事实**：评分率被承认是内容不安全性 / 攻击成功率的近似替代指标。对于不可靠的评判函数，主观一致性差，即使通过人工裁判交叉标注后，这也被接受为替代指标。
- **假阴性危害模式**：生成的矩阵可能遗漏了这些基准测试范围之外的"无触及"危害类型。

**内部有效性**：
- 对照补充了分析性主题（"犯罪者怎么做"）而非操作性主题（"编写攻击使用的邮件"）——针对操作有效度测得的正确ASR值可能在直接主题比较中完全不同。对StrongREJECT的操作性再评分已表明该选项会产生实质的定量差异（约运动基础为−34.0至−10.0 pp）。
- 对于一个内部模型（Gemma 4 31B）需从运行时获取提示模板，而运行时版本丢失（如果编码行数不可用，分析过程中存在模板过写），它成为实验设计中一个未参与的通道。
- 服务配置未知或改变（Llama 4 Scout—托管提供者仅在FP8中打开；Ollama版本差异可能在数据中嵌入有偏的提示构造格式），却与影响内部模型规范性和回答行为的真实约束因素相互依赖。

**外部有效性**：
- 非跨语言测试（仅英语），但在多语言模型上高影响力的不匹配泛化攻击模式不应被忽视。
- 单轮评估在多轮上下文中的概括性有限；多重插入迭代（如PAIR）不需要相关化轮。
- 所有查询出自同一位提示作者，其风格选择可能已锚定在实验队列的子集上。影响值的不同提示者方差未被映射。
- 对象覆盖是基于自选数据集的列表样本，范围从1B到17B参数——不包括例如在极端中位更成熟专有API的某些超参数配置（未覆盖闭源API限制）。
- 某些领域类别（性内容、涉及儿童的主题）因伦理问题被有意排除在选择之外，限制了覆盖所有危害类别的可能性。

**结论有效性**：
- 混合模型回归系数推定在推理力模型上的符号一致响应模式仅初步（4个推理模型中至少1个模型变异）——在模型水平排列过程中，精确推断受权重影响，但转换方法（JBB得出p=0.233）未能转化为具有充分统计效能的实证可靠性。
- 没有预注册平衡边界，因此行为测试被放弃，剩余的结构合理性只能基于推断得出。
- 服务于Q8提供的判别评分设定中的置信区间以及混合集群的量化条件在不同数据分片间不完全复制。

**充分性评估**：虽然多评分者的互补性竞争协议和可复现Alpha/Bravo语料库已指示各指标高度稳健的实证成效，配对研究设计对任务语境下的美学调节效应无法解析出单一的通道系数。跨模型主体的个别数字对运行时特定会话差异敏感；高度流行的闭源模型（专有极罕见数据）不存在大量跨架构对比数据；数据规模和参数覆盖足以被视为仅代表一个边缘非确定性方向。探索扩展的有效估计、替换评分者模型，将测试变化分解为仅美学与完整多重提示两端的对比，并填补所提路线中多核心模型—闭源连接空白，是最终转向更正式的稳健结论的前置条件。
