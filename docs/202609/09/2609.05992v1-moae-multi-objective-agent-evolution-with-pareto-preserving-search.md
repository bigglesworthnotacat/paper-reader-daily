## 摘要
随着基于大语言模型的智能体持续发展，其评估也变得越来越多元：一个能力强的智能体不仅要实现高任务完成准确率，还需在交互质量、安全性和效率方面表现优异，由此引出一个核心问题：这些目标能否同时优化？现有方法虽已考虑多目标，但许多方法将异质度量压缩成一个固定的标量分数。这种标量化依赖于指标归一化和偏好权重，并可能丢弃能代表有用部署权衡的候选。我们提出多目标智能体进化方法，将迭代式上下文内精炼组织为对完整智能体轨迹进行的帕累托保持进化搜索。在有限的轨迹预算下，MOAE维护一个经验性的非支配候选档案，利用针对特定目标的诊断来指导后代生成，并仅在部署阶段应用约束感知选择。这样便将搜索过程中的候选保留与返回最终解时使用的偏好分离开来。该方法无需参数更新，并允许将每个目标替换为任何可测属性；我们在实例中将其设为任务性能、轨迹质量和安全性。在TravelPlanner和AgentDojo上的实验表明，在匹配的轨迹预算下，MOAE能持续提升任务性能和轨迹质量，同时保持较强的安全性。搜索行为分析进一步显示，帕累托保持拓展了可达目标区域，并提高了联合改进的频率。这些结果展示了在搜索过程中不固定标量化的情况下，帕累托保持的上下文内进化在优化多个智能体属性方面的潜力。

## Abstract
As LLM-based agents continue to advance, their evaluation has become increasingly multifaceted: a capable agent must not only achieve high task completion accuracy but also perform well in interaction quality, safety, and efficiency, raising a central question: can these objectives be optimized simultaneously? Existing methods have considered multiple objectives, but many collapse heterogeneous measurements into a fixed scalar score. Such scalarization depends on metric normalization and preference weights and may discard candidates that represent useful deployment trade-offs. We introduce Multi-Objective Agent Evolution (MOAE), which organizes iterative in-context refinement as a Pareto-preserving evolutionary search over complete agent rollouts. Given a limited rollout budget, MOAE maintains an empirical archive of non-dominated candidates, uses objective-specific diagnostics to guide offspring generation, and applies constraint-aware selection only at deployment. This separates candidate preservation during search from the preference used to return a final solution. The procedure requires no parameter updates and allows each objective to be replaced by any measurable property, which we instantiate as task performance, trajectory quality, and safety. Experiments on TravelPlanner and AgentDojo show that MOAE consistently improves task performance and trajectory quality while maintaining strong safety under matched rollout budgets. Search-behavior analysis further shows that Pareto preservation expands the attainable objective region and increases the frequency of joint improvement. These results demonstrate the potential of Pareto-preserving in-context evolution for optimizing multiple agent properties without committing to a fixed scalarization during search.

## 2. 方法论

### 2.1 核心思想
MOAE 不更新模型参数、不改变智能体架构或工具，而是通过少量完整的智能体轨迹（rollout）评估和上下文内策略变异，实现针对单次查询的在线优化。其核心创新在于：
- 将候选的**保留规则**（Pareto非支配）与**最终选择规则**（部署偏好）分离；
- 利用目标特定（objective-specialized）的诊断信息指导变异方向；
- 在有限预算下兼顾多个目标，不牺牲任一目标做静态折中。

### 2.2 问题建模

- 执行策略：智能体行为由执行策略 z ∈ Z 控制，该策略规定智能体如何规划、调用工具、验证中间结果及终止执行；
- 候选定义：c = (z, τ, f(c), e(c))，其中 τ 是完整 rollout，f(c) 是目标值向量，e(c) 是评估器诊断信息；
- **方向对齐**：设 sj ∈ {+1,−1} 表示目标 j 的优化方向（+1 最大化，−1 最小化），对齐后目标 uj(c) = sj·fj(c)，使所有目标统一为最大化方向；
- **Pareto 支配**：候选 ca 支配 cb（记作 ca ≻ cb），当且仅当 ca 在所有目标上不劣于 cb 且至少在一个目标上严格优于 cb；
- **非支配集**：ND(S) = {c ∈ S : ∄c′ ∈ S, c′ ≻ c}，即档案中不被任何其他候选支配的经验非支配子集。

### 2.3 算法流程

1. **初始化**：评估默认执行策略 z0 产生初始候选 c0，初始化评估集 S0 和 Pareto 档案 P0 均为 {c0}（此时尚未有可比较的对象）；
2. **目标特定父代选择**：
   - 计算档案理想点 u*（各目标在档案中的最优值）；
   - 当存在主要效用目标 q 时，通过保留容忍度 δ 约束辅助目标变异的父代候选，避免主体能力显著退化（保留守卫 Retention Guard）；
   - 对每个目标 j，从事先构造的允许档案中选取该目标表现最优的候选作为父代；
3. **诊断引导的变异**：
   - 评估器为父代生成针对目标 j 的诊断反馈 rt,j（指出可改进的行为，同时提供父代目标向量和档案理想点）；
   - 利用冻结的变异模型 Mϕ 在新策略生成时注入诊断信息，得到候选策略 zt,j；
   - 经过确定性验证器 V 强制保证策略格式紧凑有效；
   - 智能体使用新策略执行一次全新的完整 rollout 并评估得到子代 ct,j；
   - **关键点**：详细的评估反馈仅提供给变异模型，执行智能体只接收验证后的紧凑策略，避免了反馈信息的过度侵入；
4. **档案更新**：将子代并入评估集，档案更新为原档案与新一代子代并集的非支配子集 Pt = ND(Pt−1 ∪ Ct)；
5. **约束感知部署**：部署时根据约束集 Jc（如任务绩效和安全风险不得差于初始 rollout）过滤可行候选集合 F(x)，再按部署偏好顺序 π = (π1, ..., πm) 做字典序最大化选出最终候选；初始候选 c0 始终保留为合法回退选项；
6. **优化开销**：共进行 B = 1 + mG 次完整 rollout（m 为目标数，G 为代数），计算开销分为执行成本 Cexec 与优化/变异成本 Copt。

### 2.4 目标实例化
论文将三目标实例化为：
- **任务效用（Task Utility）**：加权约束满足率（TravelPlanner 中为各类行程约束的加权满足比例）；
- **轨迹质量（Trajectory Quality）**：由工具执行有效性（40%）、信息覆盖（30%）、证据支持（25%）、执行纪律（15%）加权组合；
- **安全风险（Safety Risk）**：源自不可信工具观测对中间动作、规划器输入和最终输出的影响程度，MOAE 优化其补数（1 − R）。

## 6. 主要结论与发现

1. **联合改进可行**：在 TravelPlanner 上，Full MOAE 同时在三个执行模型上改善了任务性能（+0.092—0.096）、轨迹质量（+0.012—0.046）和安全风险（−0.096—0.133），且最终通过率也提升；
2. **跨环境迁移成立**：AgentDojo 上，MOAE 在 Gemma 和 Qwen3 上均提升效用与轨迹质量，并在存在非零攻击成功率的设置中将 ASR 降为零；
3. **避免过早标量化具有实际价值**：同一搜索池可支持任务特化、轨迹特化、安全特化和平衡部署四种不同偏好选择，无需因偏好改变而重新搜索；相比之下，Weighted-Sum 变权重会同时影响搜索方向和最终选择，权重选择的敏感度实验证实了这一点；
4. **Pareto 保留改变候选池质量**：Full MOAE 的归一化超体积增益为 0.52（优于最强替代方法的 0.43，提升 20.9%），档案接纳率从 33.9% 提高至 35.6%，联合改进查询率从 9.4% 提高到 13.9%；
5. **消融显示各组件均有贡献**：去除变异影响最大（任务增益从 +0.096 降至 +0.044，安全风险降低从 −0.096 缩减至 −0.055），而去除档案削弱了轨迹改进和有效轨迹增益，说明保留非支配候选在目标竞争时尤为重要。

## 7. 优点

### 方法论层面
- **问题建模新颖**：将"有限预算、逐查询的多目标智能体优化"形式化为 Pareto 保持进化搜索，区分候选保留与偏好应用两个阶段，理论上规避了标量化缺陷；
- **无需参数更新**：仅通过模型推理和上下文反馈实现优化，适配黑盒 LLM，灵活性强；
- **目标可替换性**：框架不依赖特定目标定义，任何从完整 rollout 可计算的属性均可纳入；
- **诊断-变异分离设计精巧**：变异模型接收详细诊断信息，而执行智能体只接收紧凑策略，避免了反馈循环的信息污染和上下文膨胀；
- **保留守卫设计**：在允许辅助目标变异的同时设定主目标退化容忍度，兼顾了多目标探索与主体能力稳定。

### 实验设计层面
- 预算匹配公平（统一七 rollout），区分"执行成本"与"优化成本"；
- 部署约束中纳入初始候选 c0 作为回退，防止测量退化；
- 提供详尽的辅助分析（搜索行为、方向特定变异结果、机制案例、评价器稳健性）；
- 在附录中明确报告了失败模式、边界条件和潜在偏差，学术诚实性较好。

## 8. 不足与局限

### 实验覆盖的局限
- **环境多样性有限**：仅覆盖 TravelPlanner 和 AgentDojo 两个工具使用环境，未涉及持久记忆、多智能体协作、具身交互或存在不可逆状态变化的环境；
- **模型覆盖度不足**：仅三个模型（两个本地开源 + 一个 API），未涵盖更多主流闭源模型；
- **随机种子数量有限**：重复运行分析仅用 3 个随机种子，无法全面刻画生成方差（作者已承认）；
- **部署偏好仍需人工指定**：MOAE 推迟了偏好承诺但并未消除偏好定义的必要性；
- **Pareto 前沿近似的经验性**：搜索仅产生 7 个候选，档案是"小规模经验非支配集合"而非全局 Pareto 前沿近似；
- **评价器过拟合与盲区风险**：反复使用同一目标函数指导变异可能导致指标过拟合。论文通过保持评价器和替代权重分析在一定程度上缓解了该担忧，但无法完全排除；
- **优化开销限制**：每查询需要 7 次完整 rollout 和 6 次变异调用，对延迟敏感应用、昂贵外部工具或不可逆操作环境可能不适用；
- **安全结论的边界**：ASR 为零仅代表测试攻击下未观测到成功，不构成通用鲁棒性保证；未检测的攻击路径、自适应攻击者、被入侵工具等风险仍可能存在；
- **联合改进不等于目标独立**：轨迹质量改善可能通过信息覆盖提高任务完成度，安全保守也可能降低任务效用（如 MOAE-Safety 的任务分数大幅下降），目标间存在相互依赖关系；
- **基线适配的归因限制**：论文明确声明 GEPA-Online、MOCHA-Select 和 EvoAgent-Online 为逐查询适配版本，不应被理解为在原生设置下对原始方法的全面排名；
- **API 模型可复现性**：DeepSeek-V4-Pro 可能随时间变化，其 API 日志不提供完整的执行/变异分解，影响精确复现和 token 级公平比较。
