## 摘要
大型语言模型（LLMs）越来越多地被部署为协调者，通过自然语言协调专门的子智能体来解决复杂任务。然而，在许多重要领域，如游戏和机器人技术中，最强的可用智能体并非语言模型。将非语言智能体与LLMs集成将需要\emph{言语化}：在每次交互步骤中，将其丰富的连续表示压缩为稀疏的文本摘要。为了研究言语化是否构成瓶颈，我们引入了\textsc{LLAMIA-Bench}，这是一个包含六个多样协作国际象棋任务的套件，涵盖三个层面：行为模仿、状态评估和自然语言解释。每个任务实例化了一个既定的国际象棋问题，仅靠LLM或国际象棋引擎都无法单独解决。为了解决LLM与非语言智能体的协作，我们引入了\emph{潜在状态内化}，该方法将子智能体的连续表示直接投影到LLM的标记流中作为学习到的状态标记，并在动作推进环境状态时进行动态重新编码。将内化与言语化集成进行比较，我们的实验揭示了一致的\emph{言语化债务}：性能差距在训练过程中扩大，并随着LLM从4B扩展到14B参数而持续存在。使用潜在状态内化训练的单个14B模型\textsc{LLAMIA}，在所有基准任务中匹配或超越了包括具有工具访问权限的GPT-5.1在内的任务专家和前沿模型，并在任务特定微调失效的分布外场景中实现了泛化。

## Abstract
LLMs are increasingly deployed as orchestrators that coordinate specialized subagents to solve complex tasks through natural language. However, in many important domains like game playing and robotics, the strongest available agents are not language models. Integrating non-language agents with LLMs would require \emph{verbalization}: compressing their rich continuous representations into sparse textual summaries at each interaction step. To study whether verbalization constitutes a bottleneck, we introduce \textsc{LLAMIA-Bench}, a suite of six diverse collaborative chess tasks spanning three facets: behavioral imitation, state assessment, and natural-language explanation. Each task instantiates a well-established chess problem that neither the LLM nor the chess engine can solve alone. To solve LLM collaboration with non-language agents, we introduce \emph{latent state internalization}, which projects the subagent's continuous representations directly into the LLM's token stream as learned state tokens, with dynamic re-encoding as actions advance the environment state. Comparing internalization to verbalized integration, our experiments reveal a consistent \emph{verbalization debt}: the performance gap widens throughout training and persists as the LLM scales from 4B to 14B parameters. A single 14B model, \textsc{LLAMIA}, trained with latent state internalization, matches or exceeds task specialists and frontier models including GPT-5.1 with tool access across all benchmark tasks, and generalizes out-of-distribution where task-specific finetunes collapse

## 论文详细总结

### 1. 核心问题与研究动机（背景与意义）

大型语言模型（LLM）越来越多地被部署为“编排者”（orchestrator），通过自然语言协调各类专用子智能体（subagent）解决复杂任务。当子智能体同样是语言模型时，双方可以通过自然语言通信实现“无损”协作。但在许多关键领域——棋类游戏、机器人控制、自动驾驶等——最强的专用智能体并非语言模型，而是像 AlphaZero、RT-1 这类以连续内部表征（潜在状态）承载专业能力的系统。

这类非语言智能体与 LLM 协作时，传统做法是**“言语化”（verbalization）**——将子智能体丰富的连续表征压缩为稀疏的文本摘要后才传给 LLM。本文认为这一过程本质上是**有损的瓶颈**：引擎的隐藏层编码了局面结构、远距离战术动机、搜索前瞻等无法被文字忠实翻译的信息。 由此，信息在每次交互中被逐层剥离、错误在多步推理中不断累积，作者将这一现象称为**“言语化债务”（Verbalization Debt）**，并提出需要全新的协作范式。

### 2. 方法论：潜在状态内化与 LLAMIA 框架

#### 整体思想

作者提出**“潜在状态内化”（Latent State Internalization）**：将非语言子智能体的连续内部表示直接投影注入 LLM 的 Token 流中，作为**可学习的“状态 token”**，让 LLM 直接对其原生表征进行注意力读取和推理，从而绕开言语化对信息的破坏。

#### 混合 Token 推理轨迹

在一次协作往返中，多条轨迹由三种 token 交织构成：
- **语言 token** ：LLM 的思维链（CoT）；
- **动作 token** ：推动环境状态前进的决策（如落子）；
- **潜在状态 token** ：子智能体倒数第二层激活经投影后形成的连续嵌入。

```text
τ = < z_{0}^{1:k}, w_{0}^{1:j}, a_0, z_{1}^{1:k},..., w_final >
```

- LLAMIA（内化）：每次 `get_policy` 调用额外注入 k=32 个连续状态 token；
- LLAMIA-Verb（对照）：只接收文本工具返回，无状态 token（k=0）。

#### 关键组件

| 组件 | 说明 |
|---|---|
| 子智能体 Gψ | Lc0-BT4（最强的开源象棋引擎，15 层 Transformer 编码器，240M 参数），冻结 |
| LLM 主干 πθ | Qwen3（4B/8B/14B 三档规模） |
| LatentBridge Hφ | 3 层带 GeLU 的 MLP，将 Lc0 的 1024 维激活映射为 k=32 个 LLM 隐藏维度嵌入 |

#### 两阶段训练流程

1. **Stage 1：投影器对齐**——保持 LLM 冻结，仅训练 LatentBridge，在 500 万条（局面，策略）自上而下配对数据上最小化交叉熵，让投影器学会把子智能体表征“翻译”到 LLM 的嵌入空间；
2. **Stage 2：强化学习**——用 DAPO（一种带不对称裁剪的组相对策略优化变体）联合微调 LLM 和 LatentBridge。策略梯度只在语言和动作 token 上计算，状态 token 位置被梯度掩码排除。子智能体全程冻结。

#### 与言语化的本质差异

- **言语化**：返回定长的文本摘要（top-k 着法、估值、PV 线），无论当下推理需要什么信息，摘要内容固定不变；
- **内化**：潜在 token 保留引擎完整的状态表征，LLM 可依据当前推理任务，通过注意力机制按需读取表征的不同侧面（王的安全、兵结构、子力协调等）。

- **充分性总体结论**：在当前以国际象棋为核心的范围内，实验覆盖已经相当全面。但跨领域的证据还限于围棋行为克隆，多任务、多领域的泛化验证仍然不够充分。

### 6. 主要结论与发现

1. **言语化债务确实存在且是结构性的**：LLAMIA 在所有六个任务上一致、稳定地优于对照 LLAMIA-Verb。差距在趣味度预测与全盘解说任务上最大（其信号在文本中没有对应物），在分布内行为克隆上相对最小；这一差距随训练推进持续扩大，并且在 4B→14B 的规模扩展中也无法弥合。

2. **趣味度预测是文本瓶颈的诊断性任务**：所有言语化系统（含 GPT-5.1）+ Lc0 得分 ≤ 12；LLAMIA-14B 得分 52——言语化接口下引擎输出中完全没有可用于趣味度预测的有效信息。

3. **单一 14B 模型具备全面领先性**：LLAMIA-14B 在所有六个任务上匹配或超越任务专家模型（Maia、Allie）和 GPT-5.1 + Lc0（前沿闭源模型），且能在专家模型崩溃的 OOD 分片（GM-25、Low-Time、Elo Gap）上泛化。LLAMIA-8B 也已在全部任务上超越各基线。

4. **集成接口决定了协作方式的演化方向**：LLAMIA 学会了反事实查询（counterfactual query）、多步前瞻（multi-step lookahead）、查阅后覆盖（consult-then-override）等任务相关多样的协作策略；LLAMIA-Verb 则在所有任务上坍塌为单一的“引擎跟随”（engine-follow），其策略熵（H=0.93 vs 1.53）和任务特异性（JSD=0.012 vs 0.12）都远低于 LLAMIA。

5. **人类行为学特征的涌现**：LLAMIA 在时间压力下会犯与人类相似的错误、注意力模式随目标 Elo 迁移。人类判定实验表明 LLAMIA 的下棋方式在 61% 的测试中被误判为人类（低于随机水平），而 LLAMIA-Verb 则被正确识别的概率达 72%。解说方面 LLAMIA 在洞察力维度上的优势大于准确度，验证了言语化债务主要影响“为什么”而非“是什么”的层面。

6. **在围棋上的初步验证**：LLAMIA-Go 在经典围棋行为克隆任务上达到与人类专用模型 KataGo-HumanSL 相当的水平，并一致优于言语化对照约 10 个百分点——说明该范式并非象棋特有。

### 7. 主要优点

- **问题定义清晰且重要**：精准识别了“LLM 与非语言智能体协作时文本是瓶颈”的核心张力，并用“言语化债务”概念将其形式化，研究问题本身具有很高的前沿价值。
- **方法简单且有效**：潜在状态内化仅需一个三层 MLP 投影器加两阶段训练，就能在多个维度产生全面领先的效果；成本仅比言语化流水线高约 6%，实际推理开销反而更低。
- **基准设计具有诊断性**：将“趣味度预测”作为诊断任务是很有创造性的设计——这个目标信号天然不存在于任何引擎输出的文本形式中，高度聚焦地暴露了言语化接口的瓶颈属性，让“债务”变得可视化。
- **控制组设置严谨**：通过 LLAMIA-Verb（界面是唯一变量）、LLM-ChessCLIP（内容被替换但注入机制不变）、token shuffle（容量不变但信息被破坏）、LLM-Only（无引擎）等多组巧妙对照，将性能增益可靠地归因到特定组件的贡献，而非容量或数据等混淆因素。训练过程中“债务”的持续扩大也排除了“只是未收敛”或“规模不足”等替代解释。
- **配套证据链完整**：策略熵分析揭示了“界面如何影响模型学会的合作方式”；层级线性探针与人类实验从表示和感知两个层面进一步确认了潜在状态的信息优势。
- **附属贡献扎实**：作者整理发布了新的 Agadmator-2K 比赛解说数据集和 LLAMIA-Bench 基准套件，对新数据集的构造细节（Whisper 转写 + PGN 对齐）、防污染策略（FEN 级不相交保证、测试集按播放量排序等）交代得比较清楚。

### 8. 不足与局限

- **需要白盒访问子智能体权重**：潜在状态内化要求能读取子智能体的内部激活，因此无法直接应用于闭源的专用智能体——需要像 LLAMIA 这样的模型在中间做“桥接”。这在一定程度上限制了适用范围。
- **证据主要来自棋类**：主要实验集中在国际象棋情境。围棋的验证仅涉及行为克隆这一单一任务，尚未在更丰富的多任务套件上验证。
- **解释能力的挑战**：论文并没有完全说明注入的潜在 token 究竟编码了哪些具体特征（哪些被保留、哪些被压缩、哪些丢失），只能依赖已有的解释性文献作为间接的依据。状态 token 的可解释性仍需更系统的分析。
- **评测依赖 LLM 裁判**：注解与解说任务使用 G-eval（GPT-4o 打分），该评估方法本身可能存在长度偏好等系统偏差，虽然作者做了相应校准，但以 LLM 作为裁判的局限性仍然存在。
- **训练数据的实际规模有限**：LLAMIA 对比任务专用专家模型时虽然展示出更强的通用性——但 2 万局训练数据与 Maia/Allie 的数千万到上亿局差距悬殊，在推理能力边际收益上的解读需谨慎，一些差距也可能与“数据效率”而非真正的“跨域泛化”有关，论文对此的区分还可进一步深化。
- **封闭源预训练数据存在污染风险**：对 GPT-5.1 等闭源模型的预训练语料，作者声明无法完全排除数据污染风险，虽然用测试集按播放量从低到高排序的方式做了缓解。
- **隐私与安全性未深入讨论**：如协作范式应用于真实棋类教学、游戏陪练等场景时可能带来的问题，论文没有展开讨论。
