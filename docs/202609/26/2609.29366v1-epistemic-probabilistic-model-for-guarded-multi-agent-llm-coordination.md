## 摘要
多智能体大语言模型（LLMs）已在应用人工智能中无处不在，但其理论基础仍出人意料地缺乏研究。从多智能体系统理论的角度审视，若干缺陷随之显现：缺乏社会智能、智能体之间缺少协调机制、涌现行为未知，以及智能体之间的交互受自然语言限制。我们针对其中两个缺口展开研究：社会行为的缺失，以及智能体间协调机制的缺乏。我们提出认知概率语言智能体（Epistemic Probabilistic Language Agents, EPLA），一种用于不确定性下多智能体协调的神经符号架构。符号守卫（Symbolic Guard）提供结构化诊断反馈。LLM生成带类型的动作，而守卫依据权威符号状态控制其执行。我们在一个 gossip 测试平台中通过认知抽签 gossip 模型（epistemic lottery gossip models）形式化认知层，该模型将基于视图的调用历史与以智能体为索引的概率权重相结合。我们认为，实现这样一种形式化方法可以弥补智能体式LLM的不足。

## Abstract
Multi-agent large language models (LLMs) have become ubiquitous in applied AI, yet their theoretical foundations remain surprisingly understudied. Viewed through the lens of multi-agent systems theory, several shortcomings come to light: a lack of social intelligence, the absence of coordination mechanisms among agents, unknown emergent behavior, and interactions between agents that are bounded by natural language. We address two of these gaps: the absence of social behavior and the lack of mechanisms for inter-agent coordination. We introduce Epistemic Probabilistic Language Agents (EPLA), a neuro-symbolic architecture for multi-agent coordination under uncertainty. A Symbolic Guard provides structured diagnostic feedback. The LLM generates typed actions, and the Guard controls their execution against an authoritative symbolic state. We formalize the epistemic layer in a gossip testbed through epistemic lottery gossip models, which combine view-based call histories with agent-indexed probability weights. We argue that implementing such a formalism can address shortcomings of agentic LLMs.

## 1. 核心问题与研究动机

- **背景缺口**：基于大语言模型（LLM）的多智能体系统（MAS）在应用 AI 中已广泛使用，但其与成熟的多智能体理论之间联系薄弱。La Malfa 等人指出当前 LLM-MAS 存在四项缺陷，本文聚焦其中两项：**社会认知（social epistemics）的缺失**与**协议治理式协调（protocol-governed coordination）的缺失**。
- **具体病症**：智能体可以流畅地生成工具调用、委派或转发检索信息，但"语言流畅"并不等于该动作被其**信息状态**或**交互协议**所许可；现有系统常借用多智能体术语，却缺少显式的社会知识表示与协议约束。
- **研究含义**：论文主张用神经符号（neuro-symbolic）分工来弥补该缺口——**学习组件负责提议与适应，符号组件负责状态表示与执行控制**。作者将形式化落在受控的 gossip（八卦/传话）测试平台上，明确声明这不是在宣称任意工具调用轨迹天然具备 gossip 语义。

## 2. 方法论

### 2.1 核心思想：EPLA 神经符号架构

- **组件划分**：
  - **Policy LLM**：解释语言并提议**带类型**的通信或工具动作，但**无权执行**。
  - **Epistemic Logic Core（ELC）**：唯一维护并提交权威认知符号状态。
  - **Conditional Belief Engine（CBE）**：维护分级/条件化不确定性（基于条件信念逻辑），其摘要仅供 LLM 参考，**非权威**。
  - **检索增强记忆（RAG）**：要求记录持久且**带来源链接**（事件 ID、来源、时间戳、访问范围、置信元数据）。
  - **Symbolic Guard**：依据权威符号状态决定动作是否可执行，输出 permit/deny。
  - **可选接口**：Guard 诊断反馈可监督 **ARE**（对抗表示工程）与 **RL/LTL**（线性时序逻辑目标）策略学习。
- **非对称责任边界**：Guard 只检查精确状态，不检查 LLM 生成的摘要；Guard 反馈可塑造后续提议，但**不能凌驾于 Guard 之上**。

### 2.2 执行模型（算法流程）

- 操作状态定义为 `z_t = (G_t, Σ_t, Π_t, R_t, q_t)`，分别为 ELC 状态、CBE 状态、协议/资源状态、检索记忆、LTL 监视器状态。
- 单步决策循环共 **9 个阶段**：观察 → 检索 → 构造有界上下文 → LLM 提议候选动作 → 检查认知/协议/一致性/预算条件 → 返回拒绝诊断或准备接受转移 → 原子记录并提交 ELC 后继状态、执行外部副作用 → （可选）ARE 表示级监督 → （可选）RL 头更新。
- **一致性要求**：Guard 检查与 ELC 提交必须针对同一版本化状态；须串行化或在版本变更时重新校验；外部副作用需持久意图记录与幂等/补偿规则。
- **动作类型**：保留 Call、Message、Announce 三类，但**仅对成对 push-pull 的 Call 给出操作语义**（精确的秘密并集转移与来源可验证的视图语义）；Message/Announce 因缺少内容语言、接收者与可观察性规则而未赋形式语义。
- **人类介入**：形式模型不含人类覆盖；架构层面将策略例外或语义未形式化的高影响动作送交人工复核，且人工批准仍须重新通过 Guard 与 ELC。

### 2.3 形式化：认知彩票 gossip 模型（ELGM）

- **视图语义**：`view_a(c)` 记录 a 的局部观察序列（不涉及 a 的调用不可见，涉及 a 的调用连同其局部 gossip 状态一并记录）；`c R_a c'` 当且仅当视图相等。强调这比"仅取涉及 a 的调用子序列"更丰富（论文 Example 4.2 给出反例）。
- **ELGM 定义**：`M_G = (H, V, {R_a}, {L_a})`，其中 `L_a: H → R_{>0}` 为严格正彩票，且每个 `R_a` 等价类上求和有限非零。有限和条件非装饰性——无限可达类上的常数先验不可接受。
- **知识 = 概率 1**：`M_G, c ⊨ K_a(φ)` 当且仅当 `P_a(φ)(c) = 1`，与 EPLS 一致。
- **知识片段 L_K**：由 `⊤ | p | ¬φ | φ∧ψ | K_a(φ)` 生成，**排除数值概率原子**，但允许嵌套个体知识。

### 2.4 主要形式化结果

- **命题 4.1**：`K_a(·)` 在任意可接受 ELGM 上满足 **S5 公理**（等价关系 + 严格正权重）。
- **引理 5.2（彩票透明性）**：对任意可接受 ELGM、任意 `c` 与 `φ ∈ L_K`，`M_G, c ⊨ φ` 当且仅当无彩票的 Kripke 模型 `M_0, c ⊨ φ`——**正权重不影响知识片段真值**。
- **引理 5.3（源对应）**：在 Apt–Wojtczak 源实例上，通过翻译 `τ` 将 `L_{K,src}` 映射到源语言 `L_wn`，二者满足性等价。
- **定理 5.4（Guard 可判定性）**：在源兼容片段内，给定 α、c、pre(α) 的有限编码，检查 `Γ_{M_G}(α, c)` 可判定；**不声称复杂度界**。
- **引理 6.2（正重加权保持 Guard）**：若重加权保持 H、V、R_a 不变且结果彩票可接受，则 `L_K` 真值与所有 Guard 判定不变。
- **定理 7.1（条件排名终止）**：存在排名函数 `ρ: X → {0,...,B}`、每步以至少 ε 概率选中严格降秩的 Guard 许可动作、其余动作不增秩，则 `E[T] ≤ ρ(x_0)/ε ≤ B/ε`。
- **Remark 5.5 明确边界**：定理**不覆盖**概率阈值 Guard、`L_{K,src}` 之外的事实原子、嵌套个体知识、公共知识、协议受限历史域、电话号码交换、任意 LLM 工具轨迹，也不引入动态 EPLS 模型检验的复杂度结果。

- **核心结论**：在可接受性（正权重 + 类内有限正和）与满支撑条件下，**正的彩票权重不影响知识片段 Guard 的真值**（彩票透明性）；因此，向源式 gossip 历史中加入正的不确定性权重**不会改变任何基于清晰知识的 Guard 决策**——这正是论文引言中提出的狭义形式化问题，答案为"否，不改变"。
