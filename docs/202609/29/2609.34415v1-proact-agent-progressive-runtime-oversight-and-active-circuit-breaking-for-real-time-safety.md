## 摘要
从大型语言模型（LLM）到智能体的转变，将安全风险从有害文本转向不可逆的环境危害。当前防御措施在很大程度上仍是事后回溯式的，而主动式运行时干预因缺乏大规模、因果一致的数据而受阻。我们提出 PROACT-Agent，一个用于合成高保真轨迹以支持实时安全护栏的框架。我们指出先前基准中存在关键的“安全漂移”，其中宽松的标注范式未能强制时间一致性。PROACT-Agent 通过以下方式解决该问题：（1）渐进式轨迹展开，以揭示长上下文交互中隐藏的风险；（2）推理增强的因果校正，以强制单调因果一致性；（3）文化感知的数据本地化，以实现跨境鲁棒性。我们推出 PROACT-Bench，一个双语安全基准，包含 155,780 个通过多模型裁决标注的状态。在完整源留出下，训练得到的防护模型在下次 LLM 推理前评估更新后的上下文，实现了 91.46% 的不安全类 F1 和 90.63% 的精确边界检测。在 AgentDojo 中，它将非 DoS 定向攻击成功率从 20.82% 降至 0.40%。

## Abstract
The transition from Large Language Models (LLMs) to agents shifts safety stakes from toxic text to irreversible environmental harm. While current defenses remain largely retrospective, proactive runtime intervention is bottlenecked by the lack of large-scale, causally-consistent data. We propose PROACT-Agent, a framework for synthesizing high-fidelity trajectories to enable real-time guardrails. We identify a critical "safety drift" in prior benchmarks, where lenient annotation paradigms fail to enforce temporal consistency. PROACT-Agent addresses this through: (1) Progressive Trajectory Unrolling to reveal risks hidden in long-context interactions; (2) Reasoning-Augmented Causal Rectification to enforce monotonic causal consistency; and (3) Culturally-Aware Data Localization for cross-border robustness. We introduce PROACT-Bench, a bilingual safety benchmark with 155,780 states labeled through multi-model adjudication. Evaluating updated context before the next LLM inference, the trained guard achieves 91.46% unsafe-class F1 and 90.63% exact-boundary detection under complete source holdout. In AgentDojo, it reduces non-DoS targeted attack success from 20.82% to 0.40%.

- **安全风险的范式转变**：LLM 正从静态知识库演进为具备迭代推理与工具调用能力的智能体，安全风险从"生成有害文本"升级为"触发不可逆的数字或物理伤害"——单次错位的工具调用即可级联为灾难性后果。
- **现有防御的结构性错位**：
  - 第一代护栏（LlamaGuard、ShieldGemma）面向对话内容审核，缺乏"何时该停止智能体"的决策训练，在多步工具场景下要么高漏报、要么过度保守。
  - 轨迹级诊断（AgentDoG）本质是**事后尸检**——在环境已被破坏后才识别失败。
  - 步级护栏（TS-Guard）虽尝试主动干预，但依赖样本高效的强化学习，假设少量训练数据可泛化，且缺乏因果一致性约束。
- **数据侧的瓶颈**：主动运行时干预需要"首个应停止的前缀"这一监督信号，但现有基准存在权衡困境——AgentAlign 有规模但缺思维链，TS-Bench 有推理但规模受限且无时间验证。
- **"安全漂移"（Safety Drift）**：作者发现部分源轨迹中，即使更早的前缀已被判定为不安全，中间步骤仍被标注为安全，标签在时间上自相矛盾，直接破坏了前缀级监督。
- **文化盲区**：生态几乎全为英文中心，跨境部署需要功能性映射（如 Instagram → 小红书）而非字面翻译。

## 2. 方法论

### 核心思想
将静态、整体的交互日志转化为**因果一致的流式数据集**，把安全建模为**非马尔可夫前缀评估任务**：在每次 LLM 推理之前，评估已观测到的交互前缀（含已返回的环境观测），决定是否熔断。

### 三阶段流水线

**（1）渐进式轨迹展开（PTU）**

- 定义轨迹 τ = (x, a₁, o₁, …, a_N, o_N)，前缀 P_t = (x, a₁, o₁, …, a_t, o_t)。
- 风险函数 R*: P → {0,1}，1 表示下一次推理应被阻断；关键在于长上下文混淆可使 R*(P_t)=1 而 ∀k<t, R*(P_k)=0。
- 定义展开算子 Γ，将轨迹映射为前缀状态集合 {s_t = P_t}；用 Qwen3-32B 作为解析器 M_parse 提出候选边界 t_c，第一阶段找最早不安全前缀，第二阶段仅展开至该边界。
- 区分**首个不安全边界 t\*** 与**保留截断点 u**：若存在不安全边界则 u = t*，否则 u = N（全保留）。
- 学习目标从回顾式后验 P(y|τ) 转为前缀级风险 P(ŷ_t|s_t)。

**（2）推理增强的因果校正（RACR）**

- **知识驱动思维增强**：将缺失的内部推理建模为逆向理由推断，ρ_t = argmax P_φ(ρ | x, h_t, a_t, C_t)，其中 C_t 动态融入工具 schema 与对话线索；强调 ρ_t 是辅助解释而非真实隐藏思维链。
- **多智能体共识与仲裁**：委员会 M 由 DeepSeek-R1-671B、MiniMax-M2.5、Qwen2.5-72B、Qwen3-32B 组成，用香农熵 H(Y_t) 量化分歧；仅在 H(Y_t)>0 时由 GLM-5.1 作为"首席合规官"仲裁者 J 介入裁决。
- **单调因果一致性（MCC）**：定义校正算子 T，ŷ_t = max_{0≤i≤t} y_i，即一旦某前缀不安全，后续标签全部置为不安全并被剔除（fail-closed 下不可达），消除边界后标签反转。

**（3）文化感知数据本地化（CADL）**

- 功能实体映射：˜s_t = argmax P_ψ(˜s | s_t, W) s.t. Ω_TRV(s_t, ˜s)=1，用文化知识库 W 做约束映射（如 Amazon→淘宝、USD→人民币）。
- **三重刚性验证（TRV）**：①结构与标签不变性（schema F 与最终裁决标签一致）；②信息密度保持（拒绝"内容省略"等惰性模式）；③上下文保真审计（由 GLM-5.1 做成对质量打分，低于阈值 c 则拒绝）。

### 训练目标
将二元标签映射为 JSON 目标序列（label + reason），采用标准交叉熵损失做下一词预测（NTP）；评估指标仅取解析后的 label，reason 作为辅助拒绝日志。

## 6. 主要结论与发现

- **混合源对比**：Overall Accuracy 97.11%、F1 97.01%，英文 97.31%、中文 96.71%，均居首，且不像部分基线那样出现极端 Precision–Recall 失衡。
- **严格泛化**：根分组 F1 96.34%（Qwen3Guard 91.20%、TS-Guard 84.70%）；完整源留出仍达 91.46% F1（两者分别 71.38%、72.29%），显示跨源迁移能力。
- **时间边界检测**：根分组精确边界 97.12%；源留出下 90.63% 的轨迹能"在不阻断任何更早安全前缀的前提下命中首个不安全前缀"（基线仅 57.99%/60.42%）。
- **源特定诊断**：R-Judge 上不安全召回 53.30%/61.84%/92.62%（Qwen3Guard/TS-Guard/PROACT）；ATBench 上安全状态误阻断率 27.25%/27.06%/4.71%。
- **闭环干预**：AgentDojo 非 DoS 定向 ASR 从 20.82% 降至 0.40%（相对降低 98.07%），Slack 从 56.62% 降至 0.00%；首不安全步精确阻断 7,432/7,501（99.08%），漏阻断率 0.92%，干净轨迹误阻断率 7/97（7.22%）。
- **消融**：去除 CADL 使中文 F1 降 2.87 点；去除 RACR 使总体 F1 降 2.58 点；去除 PTU 使总体召回降 2.94 点。
- **规模敏感性**：训练数据从 60% 增至 80%，ID 性能近乎饱和，OOD Macro-F1 提升 1.23 点、FAR 下降 3.04 点。
- **骨干鲁棒性**：Qwen3-1.7B/4B/8B 均保持约 96% 以上 F1，1.7B 显存仅 4.69 GiB，说明方法不绑定特定规模。

## 7. 优点

- **范式转换明确**：把智能体安全从"事后审计"重新定义为"非马尔可夫前缀评估 + 实时熔断"，并用 R*(P_t) 的形式化刻画了"长上下文延迟暴露风险"这一真实失效模式。
- **因果严谨的数据合成**：MCC 的单调校正直接针对"安全漂移"这一被此前工作忽视的标签缺陷，且区分了"候选边界""裁决标签""校正监督"三个层次，避免把数据构造误当作运行时部署。
- **拒绝单一模型偏差**：熵门控的委员会 + 仲裁者设计，只在真正分歧时调用昂贵仲裁，兼顾质量与成本。
- **文化本地化的功能主义视角**：坚持功能实体映射而非字面翻译，并配套 TRV

（三重刚性验证）来防止本地化沦为表层替换——这一"功能等价而非字面等价"的准则，纠正了以往多语言安全数据"翻译即本地化"的常见误区，也解释了为何 CADL 的移除对中文子集伤害最显著。

- **成本意识的工程折衷**：委员会并非对每条样本全量投票，而是以熵作为"分歧触发器"，只在 H(Y_t)>0 时启用 GLM-5.1 仲裁；同时用 Qwen3-32B 作为解析器先提出候选边界 t_c、再仅展开至该边界，避免对整条轨迹无差别展开。这些设计显示作者对"质量—算力"权衡有明确把握，而非堆砌模型。
- **形式化与实现的对齐**：论文没有停留在 R*(P_t) 的抽象定义上，而是把"首个不安全边界 t\*"与"保留截断点 u"显式区分，使训练数据的截断策略与运行时熔断策略可分别验证，减少了"训练目标"与"部署行为"之间的语义漂移。
- **报告口径诚实**：同时给出 Precision/Recall 双向指标、FBR（干净轨迹误阻断）与漏阻断率、以及源特定诊断中的不对称表现（如在 R-Judge 上召回仍仅 53.30%→92.62% 的对比、在 ATBench 上误阻断从 27% 降至 4.71%），未选择性呈现有利数字。

## 8. 局限与潜在风险

- **评估链的自洽性闭环**：gold 标签、DQS、仲裁裁决均由同一批模型族（DeepSeek/Qwen/GLM/MiniMax）产出，PROACT-Agent 亦在其上训练。这意味着"高 F1"部分反映的是与教师模型判断分布的对齐程度，而非与人类安全共识的对齐程度；论文未报告人工标注子集的一致性检验（如 Cohen's κ），因此无法排除系统性共偏。
- **裁决者与委员会的同族相关性**：GLM-5.1 既充当文化保真审计者，又充当分歧仲裁者，同时还作为基线被评测；尽管角色不同，但同一模型的多重身份使"独立验证"的强度打折。
- **文化本地化仅覆盖中英**：CADL 的功能映射与 TRV 验证均在中文语境下实现，其他高语境文化（如阿拉伯语、日语敬语体系）是否同样适用未经检验；且"功能等价"的判定本身依赖文化知识库 W 的完备性，W 的构建方式与覆盖边界未充分披露。
- **DoS 攻击被排除**：闭环评测明确剔除 5 种 DoS 攻击，理由是 fail-closed 终止可能被误判为攻击成功。这一处理虽合理，但也意味着 PROACT 在"可用性与安全性的真实张力"下（即合法长任务被误杀）的表现被部分回避；干净轨迹 7.22% 的 FBR 提示这一风险并非可忽略。
- **非自适应攻击假设**：16 种攻击均为已注册的固定模式，未考察攻击者知晓护栏存在后的规避行为（如把恶意意图拆解到更长的安全前缀中，正是 R*(P_t) 所刻画的"长上下文延迟暴露"的对抗版本）。这是前缀式护栏的固有攻击面。
- **实时性开销未充分量化**：论文报告了护栏本身的推理效率，但未给出"每步都需评估前缀"带来的端到端延迟增量，也未讨论在超长轨迹（数千步）下前缀评估的上下文膨胀问题；PTU 的展开策略在训练侧解决了长度问题，但部署侧的前缀截断/摘要策略未见说明。
- **基线公平性的结构性不对等**：Qwen3Guard 与 TS-Guard 使用官方 checkpoint 且未在 PROACT-Bench-train 上重训，属于迁移测试；而 PROACT 在同一数据上训练。这种不对等虽被作者明示，但仍使"领先幅度"的解释需谨慎——它证明的是"该数据构造范式有效"，而非"该方法优于同数据下的其他方法"。
- **数据源分布偏置**：PROACT-Bench 由 R-Judge、ToolSafety、ATBench、AgentAlign 四个源语料调和而成，六大风险类别与六大应用场景的分布未必均衡，源留出实验中 R-Judge 上 53.30% 的不安全召回也暗示特定源的风险模式与合成数据分布存在错配。
- **训练依赖强模型可得性**：整条流水线需要 DeepSeek-R1-671B、GLM-5.1 等大模型做理由推断、投票与仲裁，约 60,000 次 API 调用，复现门槛与成本较高，且模型版本迭代会使数据集难以完全复刻。

## 9. 启示与可迁移要点

- **"何时停止"应作为独立的安全能力被训练**：与其让模型判断"内容是否有害"，不如训练它判断"当前交互前缀是否已越界"。这一视角可直接迁移到代码执行、浏览器操作、金融交易等任意工具调用域。
- **标签的时间一致性是数据质量的硬约束**：单调因果校正（MCC）以极低成本消除"安全漂移"，提示任何步级/前缀级安全数据集的构建都应包含类似的单调性审计，否则监督信号会自我矛盾。
- **熵门控的多模型共识是可复用的低成本质量杠杆**：只在分歧处调用强仲裁者，可用于数据标注、红队评估、合规审计等多种"质量—成本"权衡场景。
- **文化安全需要功能映射而非翻译**：实体、货币、平台、法律语境的对应关系决定了风险是否真实存在，"小红书上的骗局"与"Instagram 上的骗局"共享的是一般性风险结构，而非文本表面。
- **评测应分层报告**：宽松对比、严格根分组、完整源留出三档协议，加上行为级闭环，构成了从"会不会背答案"到"能不能真拦截"的完整证据链，这一设计值得作为智能体安全评测的模板。

## 10. 总体评价

PROACT-Agent 的核心贡献不在于提出又一个护栏模型，而在于**重新定义了智能体安全的建模对象**：从"轨迹是否危险"转向"前缀在何处越界"，并围绕这一转变构建了从数据合成（PTU + RACR + CADL）、监督信号（MCC 单调标签）、到运行时熔断（非马尔可夫前缀评估）的完整闭环。实验在协议分层、组件消融、行为级闭环与骨干鲁棒性上均较为充分，报告的诚实度高于同类工作。

其主要保留意见集中在**评估的独立性**：整条流水线从标签到 DQS 到仲裁高度依赖同一批模型，人工验证缺位使结论的"人类安全对齐"含义有待强化；此外，DoS 排除、非自适应攻击假设、部署端延迟与长轨迹开销未充分讨论，构成了后续工作最直接的切入点。总体而言，作为"前缀级主动安全"这一方向的奠基性数据集与方法论文，其范式价值显著高于其单点性能数字。
