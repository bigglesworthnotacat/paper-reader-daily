## 摘要
语言模型智能体越来越多地通过将执行经验转化为可复用的外部技能来提升自身能力。然而，反复的技能更新本身构成了一种学习过程：局部有用的编辑可能累积成冗余或任务特定的指令，而新的更新可能破坏此前有效的行为。我们将这一问题视为技能演化过拟合，并提出了 SkillEvoReg，一个受神经网络训练中抗过拟合技术启发、用于技能演化的通用正则化框架。SkillEvoReg 将训练时技能丢弃（扰动更新生成）与复杂度感知的局部正则化（控制不必要的结构增长）相结合，并引入因果反例验证（CCV），以对候选更新特有的行为退化进行有针对性的验证。我们在异构技能演化系统中实例化该框架，同时保留各系统原生的技能演化器和任务评估器。在 SkillOpt、SkillEvolBench 和 ContinualSkillBench 上，SkillEvoReg 在保持有竞争力的下游能力的同时，持续控制技能状态增长，改善了若干迁移和后期演化结果，并识别出仅靠结构指标无法揭示的更新级退化。这些结果表明，显式正则化是对能力日益增强的技能更新器的有益补充。

## Abstract
Language-model agents increasingly improve by converting execution experience into reusable external skills. Yet repeated skill updates form a learning process of their own: locally useful edits can accumulate into redundant or task-specific instructions, while new updates can disrupt behavior that previously worked. We study this problem as skill-evolution overfitting and introduce SkillEvoReg, a general regularization framework for skill evolution inspired by anti-overfitting techniques in neural-network training. SkillEvoReg combines training-time skill dropout, which perturbs update generation, and complexity-aware local regularization, which controls unnecessary structural growth, with causal counterexample validation (CCV), which provides targeted behavioral validation of candidate-specific regressions. We instantiate the framework across heterogeneous skill-evolution systems while retaining each system's native skill evolver and task evaluator. Across SkillOpt, SkillEvolBench, and ContinualSkillBench, SkillEvoReg consistently controls skill-state growth while preserving competitive downstream capability, improves several transfer and later-stage evolution outcomes, and identifies update-level regressions that structural metrics alone cannot reveal. These results suggest that explicit regularization is a useful complement to increasingly capable skill updaters.

## 1. 核心问题与整体含义

- **研究背景**：语言模型智能体（LLM agents）越来越多地通过将执行经验转化为可复用的外部技能（instructions、procedures、code、structured resources）来实现持续自我改进。近期系统从“一次性技能生成”转向“反复技能演化”，把外部技能状态视为可被执行经验反复修订的对象。
- **核心问题**：反复技能更新本身构成一个独立的学习过程，会出现**技能演化过拟合（skill-evolution overfitting）**：
  - 每次更新仅基于有限且往往狭窄的近期经验，但更新内容会持久化并影响未来行为；
  - 局部有用的编辑可能累积成冗余规则、窄例外或任务特定指令；
  - 新更新可能破坏此前技能已支持的行为。
- **三类表现形式**：
  - **结构累积**：增加规则、示例或窄例外，但缺乏相称的可迁移收益；
  - **语义特化**：把仅对近期轨迹有用的属性提升为广泛适用的指令；
  - **更新诱导回归**：新编辑破坏上一版技能已支持的行为。
- **关键观察**：三类现象不一定同时出现。结构大幅增长可能先于性能下降；简洁更新也可能造成窄回归而不显著增加技能规模。因此，单靠性能退化或技能复杂度都不足以刻画该问题。
- **整体含义**：论文主张不能只依赖越来越强的技能更新器，而应把“正则化”作为技能演化的一等组件，借用神经网络抗过拟合原则来控制离散、语言生成的技能更新过程。

## 2. 方法论

### 2.1 核心思想

- 提出 **SkillEvoReg**：一个通用正则化框架，**不替换原生技能更新器（native skill evolver）和任务评估器（task evaluator）**，而是在候选更新边界处插入三层正则化。
- 三个互补组件：
  1. **训练时技能丢弃（training-time skill dropout）**：扰动更新生成所依赖的技能上下文；
  2. **复杂度感知局部正则化（complexity-aware local regularization）**：控制不必要的持久结构增长；
  3. **因果反例验证（Causal Counterexample Validation, CCV）**：对候选更新特有的行为回归进行定向行为验证。
- 设计类比神经网络中的 dropout、容量正则化、数据增强/对抗验证和验证集早停，但针对离散语言技能做了操作化改造。

### 2.2 训练时技能丢弃

- 将当前技能状态 \(S_t\) 表示为局部有意义的**技能原子**集合：
  \[
  A(S_t)=\{a_1,\dots,a_m\}
  \]
  原子可以是独立指令、列表项、过程块或其他语义连贯单元。
- 在更新步 \(t\)，采样掩码集合 \(M_t \subseteq A(S_t)\)，构造临时丢弃视图：
  \[
  S^{drop}_t = \text{Mask}(S_t, M_t)
  \]
- 原生更新器在 \(S^{drop}_t\) 上生成 rollout 和候选更新，再提取扰动上下文下学到的变化：
  \[
  \Delta^{drop}_t = \text{Diff}(S^{drop}_t, \tilde{S}^{drop}_{t+1})
  \]
  并与完整 incumbent 协调：
  \[
  S^{drop}_{t+1} = \text{Reconcile}(S_t, \Delta^{drop}_t)
  \]
- **关键不变量**：掩码只影响更新生成，被掩码原子在后续正则化前恢复，绝不会被当作候选删除；冻结评估始终使用完整技能状态。
- 与神经网络 dropout 的类比：神经 dropout 扰动学习表示，技能 dropout 扰动技能更新生成所依赖的外部上下文；两者都只在学习时扰动，推理/持久状态中不保留扰动。

### 2.3 复杂度感知局部正则化

- 在 dropout 协调后的候选 \(S^{drop}_{t+1}\) 上，计算阶段局部变化：
  \[
  \Delta^{comp}_t = \text{Diff}(S_t, S^{drop}_{t+1})
  \]
- 用结构特征提取器 \(\phi(Z)\) 总结可观察结构属性，如词法规模、原子组织、结构碎片化、可执行代码结构等。
- 计算复杂度信号：
  \[
  c_t = f_{comp}(\phi(S_t), \phi(S^{drop}_{t+1}), \phi(\Delta^{comp}_t))
  \]
- 当触发结构重审时，限制编辑范围：
  \[
  D_t = \text{SegmentAtoms}(\Delta^{comp}_t), \quad
  \Omega_t = D_t \cup \text{Related}(S_t, D_t)
  \]
  即只允许编辑候选引入/修改的原子及有界相关 incumbent 原子。
- 对每个候选原子 \(a \in D_t\)，局部编辑器选择一种离散操作：
  \[
  o_a \in \{\text{NOOP}, \text{MERGE}, \text{REWRITE}, \text{DELETE}\}
  \]
  - **NOOP**：保留有用新结构；
  - **MERGE**：合并重叠内容；
  - **REWRITE**：修改过窄、冗余或过度具体的内容；
  - **DELETE**：删除无独立贡献的候选内容。
- **设计要点**：
  - 相似性只用于定义“应联合考虑”的范围，不直接作为合并证据；
  - 复杂度降低是正则化手段而非目标，NOOP 明确允许新增有独立有用行为的结构；
  - 灵感来自 Mem0 的基于操作的记忆协调，但适配到“更新后技能协调”场景。

### 2.4 因果反例验证（CCV）

- 目的：检测结构正则化无法发现的伤害性更新。简洁候选可能几乎不增加复杂度，却引入破坏 incumbent 已支持行为的假设或决策边界。
- 核心比较：
  - 原始 source 上：incumbent 通过，candidate 通过；
  - 攻击案例 \(x^{ccv}_t\) 上：incumbent 通过，candidate 退化；
  - 则标记为 **CCV-confirmed regression**。
- 三步流程：
  1. **选择 source**：
     \[
     e_t = \text{SelectSource}(H_t, S_t, S^{comp}_{t+1})
     \]
     要求 incumbent 已支持该 source，且 candidate 在未修改 source 上仍合格（clean-pair 要求）。
  2. **构造候选条件攻击**：
     \[
     \Delta^{ccv}_t = \text{Diff}(S_t, S^{comp}_{t+1})
     \]
     \[
     a_t = \text{GenerateAttack}(e_t, \Delta^{ccv}_t)
     \]
     \[
     x^{ccv}_t = \text{ApplyAttack}(e_t, a_t)
     \]
     攻击针对候选更新暴露的假设、依赖或决策边界，做有界扰动。
  3. **配对评估与回归判据**：
     \[
     r_{old} = \text{Evaluate}(S_t, x^{ccv}_t), \quad
     r_{new} = \text{Evaluate}(S^{comp}_{t+1}, x^{ccv}_t)
     \]
     \[
     g_t = \text{RegressionCriterion}(r_{old}, r_{new}; \theta_{ccv})
     \]
     只有 incumbent 在攻击案例上仍足够成功、candidate 退化时才确认回归。
- 若确认回归，最多执行一次**范围受限修复**：
  \[
  S^{ccv}_{t+1} = \text{Repair}(S^{comp}_{t+1}, \Omega^{ccv}_t)
  \]
- **“因果”含义**：论文明确这是操作性定义，通过四路比较控制普通源任务失败和攻击过难，将退化关联到候选转换，并非形式化因果识别，尤其在随机 rollout 或多编辑候选下。

### 2.5 跨异构更新语义的适配

- 三个正则器角色相同，主要适配发生在原生更新边界：
  - **SkillOpt**：单指令文档上的排序编辑，复杂度参与正则化验证门控；
  - **SkillEvolBench**：多技能库上的局部补丁，增长预算触发有界局部正则化；
  - **ContinualSkillBench**：显式 CREATE-SKILL / MODIFY-SKILL 操作，CREATE 使用绝对预算和库级比较，MODIFY 使用相对增长。
- 最终候选通过原生接受或提交接口写回，保留各系统原生语义。
