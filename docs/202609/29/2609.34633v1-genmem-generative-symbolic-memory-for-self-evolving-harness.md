## 摘要
长期记忆通过跨任务保留经验与技能，并支持其在后续长时程决策中的检索、复用和修正，从而支撑 LLM 智能体的自演化。然而，现有记忆管理方法仍局限于判别式检索，且难以应对可复用经验所呈现的稀疏、层次化和高度冗余结构：只有一小部分依赖于任务的轨迹和记忆值得保留、检索或修正。学习这些操作进一步受到稀疏、延迟且间接的任务级反馈的困扰，整个记忆生命周期中的监督信号也很弱。此外，持续的记忆演化引入了寻址不变性方面的架构张力：存储的经验不断被修正，而学习到的检索策略所使用的寻址接口必须保持稳定。为解决这一问题，我们提出 GenMem，将记忆管理重新表述为生成式符号寻址。其核心机制是符号标识符（SID），一种从笛卡尔积地址空间中采样的多级离散标记元组，仅用不到一百个离散符号便可分解百万规模的稀疏记忆空间。记忆智能体不再生成不断变化的原始内容，而是学习生成 SID；同时，记忆演化在固定地址处重写载荷，而不改变地址本身。在架构上，GenMem 在多智能体框架中耦合 MemRetriever 与 MemEvolver，并通过 GRPO 进行训练，采用密集过程奖励和结果奖励以及双通道优化。在离线记忆演化下，涵盖 ALFWorld、WebShop、多跳问答、医学推理和深度研究的实验，将 GenMem 与强大的记忆增强基线进行对比评估……

## Abstract
Long-term memory supports the self-evolution of LLM agents by retaining experience and skills across tasks and enabling their retrieval, reuse, and revision in subsequent long-horizon decision-making. Yet existing memory management approaches remain limited to discriminative retrieval and to address the sparse, hierarchical, and highly redundant structure of reusable experience: only a small, task-dependent subset of trajectories and memories warrants retention, retrieval, or revision. Learning these operations is further complicated by sparse, delayed, and indirect task-level feedback, with weak supervision across the memory lifecycle. Moreover, continual memory evolution introduces an architectural tension as addressing invariance: stored experience is perpetually revised, yet the addressing interface consumed by learned retrieval policies must remain stable. To address, we present GenMem, which reformulates memory management as generative symbolic addressing. Its core mechanism is the Symbolic Identifier (SID), a multi-level discrete token tuple drawn from a Cartesian-product address space that factorizes a million-scale sparse memory space using fewer than one hundred discrete symbols. Instead of generating ever-changing raw content, the memory agent learns to generate SIDs, while memory evolution rewrites the payload at a fixed address without shifting the address itself. Architecturally, GenMem couples a MemRetriever and a MemEvolver within a multi-agent harness, trained via GRPO with dense process and outcome rewards with two-channels optimization. Under offline memory evolution, experiments spanning ALFWorld, WebShop, multi-hop QA, medical reasoning, and deep research evaluate GenMem against strong memory-augmented baselines...

## 1. 核心问题与整体含义

- **研究背景**：长期记忆是 LLM 智能体自演化的关键，使其能跨任务保留、检索、复用和修正经验，支持长时程决策。
- **现有局限**：主流记忆管理仍以“判别式密集检索”为核心，依赖查询与记忆内容的表示相似度，难以处理可复用经验的**稀疏、层次化、高冗余**结构。
- **两大挑战**：
  - **稀疏性挑战**：经验高度冗余；只有少量轨迹/记忆值得保留、检索或修正；监督来自延迟、间接的任务级反馈，难以对单次记忆操作做信用分配。
  - **地址方差挑战**：记忆内容持续演化时，若检索地址依赖当前内容表示，则内容修订会导致地址漂移；但学习到的检索策略又需要一个稳定寻址接口。
- **整体含义**：论文将记忆管理从“判别式检索”重构为“**生成式符号寻址**”。核心是让智能体生成稳定的符号标识符（SID），而不是生成不断变化的原始内容；记忆演化只改写固定地址处的载荷，从而缓解“内容演化”与“寻址稳定”的张力。

## 2. 方法论

- **核心思想**：
  - 用多级离散符号元组 SID 表示记忆地址，将大规模稀疏经验空间分解为笛卡尔积地址空间。
  - 记忆条目写作 \(m_i=(x_i,z_i)\)，其中 \(x_i\) 是文本经验载荷，\(z_i=(s_i^1,\dots,s_i^L)\) 是 SID。
  - 生成式寻址策略 \(z=\mathrm{ADDR}_\theta(c)\) 根据查询、轨迹或新经验生成地址；检索通过 \(\mathrm{LOOKUP}(M,z)\) 返回载荷。
  - 在线演化形式为 \((x_i,z_i)\to(x'_i,z_i)\)：内容可改写，地址不变。

- **SID 构造：RQ-KMeans**：
  - 先用冻结文本编码器编码经验摘要，前缀强调可复用策略、适用条件与流程。
  - 逐层 K-Means 聚类：第 1 层对嵌入聚类，得到码本 \(C^{(1)}\)；每个样本取最近中心索引为第 1 个 SID 符号，再减去该中心得到残差；后续层对残差继续聚类。
  - 形式化：\(s_i^\ell=\arg\min_j \|r_i^{(\ell)}-c_j^{(\ell)}\|_2^2\)，\(r_i^{(\ell+1)}=r_i^{(\ell)}-c_{s_i^\ell}^{(\ell)}\)。
  - 论文采用码本大小 \((48,16,8,8)\)，用 80 个离散符号表示 \(49{,}152\) 个可能地址。

- **系统闭环**：
  - **MemRetriever**：根据查询与推理上下文生成检索 SID，取出经验并重写为任务自适应支持。
  - **StackPlanner / 多智能体 Harness**：使用该支持执行任务，产生答案与执行轨迹。
  - **MemEvolver**：蒸馏轨迹，生成更新 SID，并决定 `insert` 或 `revise`；`revise` 可通过不变、合并或空载荷实现保留、整合、删除。
  - 闭环：`Retrieve → Execute → Evolve`。

- **训练流程**：
  - **SID 对齐预训练**：学习五种文本–SID 映射：\(q\to z\)、\(\tau\to z\)、\(x\to z\)、\(z\to x\)、\(z\to d\)，建立地址与经验的双向关联。
  - **记忆操作中训练**：构造 ReAct 风格轨迹，分别训练 MemRetriever 与 MemEvolver 的推理、SID 调用、经验重写/演化行为；使用拒绝采样和教师蒸馏。
  - **联合策略后训练**：
    - 过程奖励 \(R_{\text{process}}=R_{\text{format}}+R_{\text{strategy}}+R_{\text{SID}}\)，检查格式、SID 正确性、策略质量。
    - 结果奖励 \(R_{\text{out}}=r_{\text{task}}(\hat y_{\text{mem}},y^\star)-r_{\text{task}}(\hat y_{\text{no-mem}},y^\star)+\alpha_{\text{partial}}\mathbb{I}[\text{两者均正确}]\)。
    - 使用 GRPO，对代理通道与审计通道分别归一化优势，并加入 KL 正则。
  - **在线自演化**：模型参数、编码器、SID 码本冻结；新查询流中只通过外部记忆的插入/修订进行适应。
