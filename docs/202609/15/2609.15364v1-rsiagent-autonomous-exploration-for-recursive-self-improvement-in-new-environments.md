## 摘要
数字智能体常常需要适应新环境，而这些环境的界面、工具和失败模式无法被预训练模型完全捕捉。我们提出 RSIAgent，一个免训练的多智能体框架，通过自主记忆构建实现递归自我改进。RSIAgent 协调课程智能体、执行者智能体和验证者智能体，持续探索环境、验证结果，并保留环境特定知识，包括动作、条件与后果之间可复用的因果关系。它进一步采用“先广后深”的探索策略，将用于发现多样环境结构的并行广度递归自我探索，与用于揭示困难案例、隐藏约束、边界条件以及此前未知因果依赖的聚焦深度自我探索相结合。所得记忆会被冻结，可直接复用于下游任务，而无需更新模型参数。在 OSWorld-v2 和 Agent's Last Exam 上的实验表明，RSIAgent 显著提升了强开源模型，使 Kimi-K3 和 GLM-5.3 能够超越包括 GPT-6 在内的前沿闭源模型。

## Abstract
Digital agents must often adapt to new environments whose interfaces, tools, and failure modes are not fully captured by pretrained models. We introduce \textbf{RSIAgent}, a training-free multi-agent framework for recursive self-improvement through autonomous memory construction. RSIAgent coordinates curriculum, actor, and verifier agents to continually explore the environment, validate outcomes, and retain environment-specific knowledge, including reusable causal relationships between actions, conditions, and consequences. It further adopts a \textbf{broad-then-deep} exploration strategy, combining parallel broad recursive self-exploration for discovering diverse environment structures with focused deep self-exploration for uncovering hard cases, hidden constraints, boundary conditions, and previously unknown causal dependencies. The resulting memory is frozen and can be directly reused for downstream tasks without updating model parameters. Experiments on OSWorld-v2 and Agent's Last Exam show that RSIAgent substantially improves strong open-source models, enabling Kimi-K3 and GLM-5.3 to outperform frontier closed-source models including GPT-6.

## 2. 方法论

### 2.1 问题形式化

- 给定任务指令 $q$，智能体 $\pi_\theta$ 基于持久记忆 $M$ 与交互历史 $h_t$ 生成可执行动作 $a_t$；环境转移并返回新观测：
  - $a_t \sim \pi_\theta(\cdot \mid q, h_t, M)$
  - $(s_t, o_t) \sim \mathcal{E}(\cdot \mid s_{t-1}, a_t)$
- 交互历史切换任务时重置，而**持久记忆 $M$ 跨任务保留**。
- 采用 **code-as-policy**：每个动作为一段可执行程序（Python/Bash），作为控制异构软件（含 GUI 应用）的通用接口。
- **问题定义**：给定新环境，先自主探索构建持久记忆，再在测试时直接复用，全程不更新模型参数。关键是设计能高效识别有信息量的经验、用可靠环境反馈加以接地、并持续巩固进记忆的探索策略。

### 2.2 多智能体 Harness 框架

- **Actor 智能体（可演化记忆）**：主策略模型，生成可执行动作；维护持久记忆（环境知识、可复用流程与脚本、失败教训）；在验证后做记忆巩固（新增、修订、删除）。
- **Verifier 智能体（环境反馈接地）**：独立评估者，直接检查执行结果、界面状态等环境证据；**与 actor 的私有推理和记忆隔离**，降低相关性错误；输出 PASS / FAIL /（目标接口另有 UNVERIFIED）及支撑反馈。
- **Curriculum 智能体（引导探索）**：决定下一步探索什么；基于目标、累积记忆与既往探索结果生成练习任务，涵盖前置技能、变体、失败驱动练习与压力测试；当生成任务不再带来显著新知识时停止。

### 2.3 两阶段"先广后深"探索

- **阶段一：Broad Recursive Self-exploration（BRS，广度递归自探索）**
  - 目标：快速建立对新环境的广度理解，收集多样化交互经验。
  - 递归循环：curriculum 生成探索任务 → actor 执行 → verifier 评估；每轮提出**多个不同方向的任务并行执行与验证**；随后基于累积经验识别知识空白，生成下一轮任务。
- **阶段二：Deep Recursive Self-exploration（DRS，深度递归自探索）**
  - 目标：针对重要知识缺口、困难案例与边界条件精化记忆。
  - **顺序**递归循环、难度渐进递增：curriculum 提出可能暴露隐藏约束或记忆弱点的挑战性任务 → actor 用累积记忆尝试 → verifier 接地评估 → 基于成败与新暴露的不确定性生成更难的后续任务；每个已验证经验在下一任务提出前先被巩固进记忆。
- **测试时记忆复用**：探索结束后记忆**冻结**，关闭 curriculum 与所有记忆更新；actor 直接复用记忆中的流程、约束与失败教训，verifier 依任务要求评判，循环直至确认全部要求满足。

### 2.4 记忆更新与并行协调机制（附录关键细节）

- **经验归属学习**：产生该经验的 actor 自己决定保留什么。收到完整验证报告后两步：**蒸馏**（识别有用流程、约束、失败教训）与**调和**（对照旧条目，修正矛盾、限定无依据结论）。
- **规范记忆所有权**：只有完成的 actor 学习更新才会提升为持久记忆；工作阶段的记忆编辑在巩固前被丢弃；curriculum 与 verifier 均无权批准记忆措辞；curriculum 只可查看一次性副本。
- **并行工作、顺序更新**：BRS 每个波次内所有项目从**同一不可变的前波次记忆快照**出发，彼此不可见；全部判决就绪后，各 actor 上下文按 curriculum 指定顺序**逐个**恢复，每次更新都作用于最新规范记忆；下一波次仅在本波提交完成后选择。
- **DRS 顺序精化与停止策略**：默认 `curriculum_review` 策略——目标 PASS 且未选新练习才结束 DRS；任何新增练习都需再来一次目标尝试；curriculum 返回 STALLED 时允许最后一次目标尝试并记录真实判决；`verifier_pass` 变体则在目标 PASS 并巩固记忆后直接结束。未解决的验证或基础设施故障**阻断阶段推进**，不转记为任务判决。
- **冻结记忆评估**：记录冻结记忆的文件树哈希，复制到评估环境，禁用 curriculum 决策与主机记忆回写；官方评估器在智能体上下文之外打分，并校验冻结记忆未被改动。

- **RSI 轮次研究**：3 个 OSWorld 任务（T044 视频编辑、T049 演示修复、T065 铁路订票）跨 0–8 步的分数曲线。

- **跨域泛化**：GameCraft-Bench 40 任务 × 4 个生成器（Codex+GPT-5.5、Kimi-K2.6、GLM-

5.3-Flash、Qwen3.8-27B）的对比，以及 Full RSI 与 Play2Code 基线的对照。
- **评估器/模拟器配置敏感性**：使用 GPT-5.4 作为需要模型评分的评估器、GPT-4o 作为用户模拟器。
- **停止与预算策略对照**：`curriculum_review` 与 `verifier_pass` 两种 DRS 停止策略的差异（体现在消融与轮次研究中）。

### 5.2 实验充分性评估

- **优点**：
  - 覆盖两个异构、高难度的长程 benchmark（桌面 GUI 与专业工作流），任务数分别为 82 与 67，规模足以支撑整体结论。
  - 消融设计较为完整：分别剥离 RSI 整体、BRS 阶段、DRS 阶段，能较清晰地归因两阶段各自的贡献，而非只报告 Full RSI 的总体提升。
  - 引入 GameCraft-Bench 跨域泛化验证，说明方法不止适用于办公自动化场景。
  - RSI 轮次研究（0–8 步曲线）展示了改进随探索轮次的动态，而非仅报告端点值。
- **不足与需谨慎之处**：
  - 消融仅在 **4 个 OSWorld 任务**上进行，且 Full RSI 取两次历史评估均值，样本量偏小、方差控制有限，结论的统计稳健性需保留。
  - 轮次研究仅 **3 个任务**，且任务类型（视频编辑、演示修复、铁路订票）是否代表整体分布存疑。
  - 缺少对 **curriculum/verifier 角色模型替换**的充分敏感性分析；默认配置将 actor（GLM-5.3）与 verifier/curriculum（Kimi-K3）分离，模型异质性本身可能是收益来源之一，未单独解耦。
  - 缺少与"仅增加测试时采样/重试预算"等强基线的对比，难以完全排除收益来自更多交互预算而非因果记忆结构。
  - 未报告多次运行的方差/置信区间，跨模型对比的显著性无从判断。

## 6. 主要结果与发现

- **整体性能**：在 OSWorld 2.0 与 ALE Near-term 上，RSIAgent 在 Partial 与 Binary 两项指标上普遍优于同基座模型的免训练基线；关键结论是**免参数更新的智能体层自我改进可显著提升开源模型表现，并在部分配置下缩小乃至反转与闭源模型之间的差距**。
- **两阶段互补性**：消融显示 w/o BRS 与 w/o DRS 均低于 Full RSI，说明"先广后深"缺一不可——BRS 提供广度覆盖与多样性经验，DRS 负责在关键缺口与边界条件上精化，二者结合才能最大化记忆可用性。
- **轮次效应**：RSI 轮次曲线表明性能随探索轮次递增，但收益并非线性，存在边际递减；提示存在"知识饱和"点，与 curriculum 在无显著新知识时停止的设计一致。
- **跨域泛化**：在 GameCraft-Bench 上，Full RSI 相对 Play2Code 基线在机制、深度、视觉、美术与综合质量上取得更优表现，说明因果记忆与两阶段探索不局限于 GUI 办公任务。
- **验证隔离的价值**：verifier 与 actor 上下文/记忆隔离，配合规范记忆所有权与"并行工作、顺序更新"机制，降低了相关性错误与记忆污染，是稳定性提升的重要来源。

## 7. 有效性威胁与鲁棒性考量

- **内部有效性**：记忆更新由产生经验的 actor 自行蒸馏与调和，可能存在自我确认偏差；虽有 verifier 接地与所有权约束缓解，但未量化残留偏差。
- **外部有效性**：主实验任务集为特定发布版的离线子集与固定清单，环境版本、任务筛选方式可能影响可迁移性。
- **构念有效性**：Partial/Binary 指标依赖官方评估器与 GPT-5.4 模型评分，评分器本身的行为可能引入偏差，尤其对开放式交付物。
- **可复现性**：论文给出冻结记忆哈希校验与评估器外部打分机制，利于复现；但未报告硬件与多次运行统计，复现的方差信息不完整。

## 8. 局限与未来工作

- **计算开销**：作者明确承认 RSI 需要额外的测试时探索与练习，**计算开销可能相当大**，这是免训练路径的主要代价。
- **探索预算与收益的权衡**：BRS/DRS 的预算、并发度与停止策略需要调参，缺乏自动化最优配置方法。
- **因果结构的显式性**：记忆以自然语言/脚本形式承载因果知识，其可解释性与可迁移性尚待进一步形式化。
- **未报告硬件资源**：缺少 GPU 型号、数量与时长信息，不利于成本评估与公平比较。
- **未来方向**：可能包括跨环境记忆迁移、记忆压缩与去冲突、以及将因果发现扩展到多智能体协作场景。

## 9. 结论与启示

- RSIAgent 提出了一条**不更新模型参数**的智能体自我改进路线：通过 curriculum 引导探索、actor 执行与记忆演化、verifier 环境反馈接地，形成"识别该学什么 → 交互收集经验 → 提炼因果知识"的递归闭环。
- 两阶段"先广后深"探索与严格的记忆所有权/顺序更新机制，是保证记忆质量与可复用性的关键工程与算法设计。
- 核心启示：**智能体层面的自我改进可以部分替代基础模型层面的能力差距**，为私有、持续变化、预训练未覆盖的新环境提供了一条成本可控（虽非零成本）的适配路径。
- 主要待解问题：如何降低探索开销、如何量化因果记忆的稳健性、以及如何在更广泛的任务分布上验证"缩小闭源—开源差距"这一结论的普适性。
