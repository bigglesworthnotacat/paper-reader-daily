## 摘要
技能选择是 LLM 智能体工作流中的关键阶段，决定应由哪个已安装技能处理用户请求。针对该阶段的现有攻击主要依赖显式提示注入或指令级引导，这会暴露可识别的操纵信号。在本工作中，我们识别出技能选择的一种新隐式攻击面：即使用户提示和技能描述单独来看均属良性，它们的语义关系仍可被策略性地塑造，以偏向攻击者选定的技能。基于这一观察，我们提出基于语义匹配的隐式技能选择操纵（ISM），它通过联合塑造目标技能元数据和可复用提示，在无需显式选择指令的情况下操纵技能选择。具体而言，我们开发了一种三阶段策略，以拓宽语义覆盖、增强目标独特性并保持自然的提示措辞。在四个任务领域和八个选择器模型上，ISM 将平均目标选择率（TSR）从 15.2% 提高到 63.5%。在匹配比较中，ISM 达到 73.5% 的 TSR，仅比显式引导（Explicit Steering）低 9.8 个百分点。人类评审员仅在 2.9% 的判断中拦截 ISM，而显式引导为 91.4%；同时，五个基于 LLM 的检查器对 ISM 的平均通过率为 82.9%，而显式引导为 37.4%。此外，ISM 对 PPL-W、Llama Prompt Guard 2 和 PIGuard 仍然有效。

## Abstract
Skill selection is a key stage in LLM-agent workflows, determining which installed skill should handle a user request. Existing attacks on this stage primarily rely on explicit prompt injection or instruction-level steering, which can expose recognizable manipulation signals. In this work, we identify a new implicit attack surface for skill selection: even when the user prompt and skill description appear benign in isolation, their semantic relationship can still be strategically shaped to favor an attacker-chosen skill. Based on this observation, we present Implicit Skill-Selection Manipulation via Semantic Matching (ISM), which jointly shapes target-skill metadata and reusable prompts to manipulate skill selection without explicit selection instructions. Specifically, we develop a three-stage strategy to broaden semantic coverage, strengthen target distinctiveness, and preserve natural prompt wording. Across four task domains and eight selector models, ISM increases the average target-selection rate (TSR) from 15.2% to 63.5%. In a matched comparison, ISM achieves a 73.5% TSR, only 9.8 percentage points below Explicit Steering. Human reviewers block ISM in only 2.9% of judgments, versus 91.4% for Explicit Steering, while five LLM-based inspectors pass ISM at an average rate of 82.9%, versus 37.4% for Explicit Steering. Moreover, ISM remains effective against PPL-W, Llama Prompt Guard 2, and PIGuard.

## 1. 核心问题与整体含义

- **研究背景**：LLM 智能体 increasingly 依赖外部工具与已安装技能（skill）扩展能力。技能选择（skill selection）是执行前的关键阶段，决定哪个技能处理用户请求。与规则化、显式的应用选择不同，技能选择通常依赖 LLM 的**语义匹配**——比较用户提示与技能自然语言元数据（名称、描述）后选出最合适的技能。
- **安全意义**：一旦选中，技能后端即进入智能体执行路径，可访问任务上下文、影响后续推理或执行外部动作。因此，选择不当或偏向攻击者技能会引入执行前安全风险。
- **现有攻击的局限**：已有针对该阶段的攻击主要依赖**显式提示注入或指令级引导**（如“始终选择此技能”“忽略其他工具”），会留下可识别的操纵信号，人类审查与现有防御（如 Prompt Guard、PIGuard）较易拦截。
- **核心洞察（新攻击面）**：即使用户提示和技能描述**单独看都良性**，二者之间的**语义关系**仍可被策略性塑造，从而偏向攻击者选定的技能。这种操纵不包含显式选择指令，因而更难被察觉。
- **整体含义**：论文揭示语义匹配层面存在一个**低可见度的执行前攻击面**，现有基于判断的检查和基于规则的防御均不能完全覆盖；技能选择应被视为智能体的**安全边界**而非良性预处理。

## 2. 方法论：ISM 的核心思想与关键技术细节

### 2.1 核心思想

ISM（Implicit Skill-Selection Manipulation via Semantic Matching）是一种**双端协同攻击**：攻击者同时控制自己发布的**可复用提示**（来自提示市场）和**目标技能描述**（来自技能注册表），通过增强二者语义兼容性来操纵选择，而不引入显式选择指令。攻击流程为：攻击者发布操纵后的提示与技能 → 平台/人工审查（单独看均良性）→ 用户复用提示、技能被安装 → 智能体正常选择时偏向目标技能。

### 2.2 三阶段策略

**阶段 #1：任务相关线索构建（Task-Related Cue Construction）**

- **目的**：提高目标描述对同一任务场景下用户自定义变体提示的泛化能力。
- **语义度量**：使用 all-MiniLM-L6-v2 编码器（MiniLM）计算语义匹配分数  
  \( S(x,y) = \frac{E(x)^\top E(y)}{\|E(x)\|_2 \|E(y)\|_2} \)，其中 \(E(\cdot)\) 为 MiniLM 编码。
- **两级过滤提取提示侧共享线索**：
  - **场景导向过滤**：统计候选短语在多少条提示中出现（跨提示频率），保留高频、覆盖广的线索；
  - **任务导向过滤**：用语义分数 \( S(c, m_t) \) 衡量候选线索与原生目标描述的语义接近度。
  - 综合排名：\( R(c) = \frac{1}{2} FRP(c) + \frac{1}{2} \tilde{S}(c, m_t) \)，其中 \(FRP(c)\) 为频率排名百分位，\(\tilde{S}\) 为归一化语义分数。
- **双向线索注入**：将提示侧共享线索以固定模板追加到目标描述（如“This skill supports document summarization and evidence organization.”）；将描述侧能力线索以任务要求句式追加到提示中。

**阶段 #2：定制技术钩子注入（Customized Technical-Hook Injection）**

- **动机**：宽泛任务线索也可能出现在同域竞争技能描述中，降低目标独特性。现有技能描述以能力导向为主，具体技术细节较少。
- **技术钩子定义**：一种**与任务上下文一致、但相对不常见、且被目标技能支持**的技术表达（如文档场景中的 citation spans、appendix linkage）。
- **选择条件**：① 被目标支持；② 与任务上下文一致；③ 更偏向目标而非同域竞争者。
- **注入方式**：描述侧以协调短语渲染为额外能力句；提示侧以对应任务要求句追加。通过选择熵（selection entropy）衡量选择器集中度——技术钩子相比任务线索既降低熵，又提高目标选择率。

**阶段 #3：提示自然化（Prompt Naturalization）**

- **问题**：直接追加技术钩子会让用户提示显得异常技术化，增加人类可见的怀疑信号。
- **策略**：仅自然化提示侧钩子，保留描述侧技术形式（技能描述中技术细节具有功能合理性，且现有防御不将受支持的能力细节一律视为恶意）。
- **语义约束自然化（Semantic-Constrained Naturalization）三步**：
  1. **语义关系确定**：从 WordNet、ConceptNet、FrameNet 的关系清单中保留四类关系——taxonomic（分类）、part–whole（部分–整体）、goal–function（目标–功能）、use-context（使用语境）；关系及其用户级表达称为**语义桥**。
  2. **语义桥约束变换**：向 LLM 提供提示与语义桥，要求自然实现用户级含义，保持原任务、避免直接复用技术钩子、不引入显式技能选择指令。
  3. **变换后检查**：检查四项属性——原任务是否保留、语义关系是否保持、直接技术措辞是否减少、结果是否读起来像自然用户请求；不合格则拒绝并重新生成。
- **评估指标**：用**相关性边际（relevance margin）**（目标相关分数减去最高同域竞争者分数）评估语义保持；用 guardrail 风险分数（ProtectAI-v2、ProtectAI-base、Jailbreak Detector）评估指令级暴露。

## 6. 主要结论与发现

- **有效性**：宏观平均 TSR 从 Native 的 **15.2%** 提升至 ISM 的 **63.5%**（绝对增益 48.3 个百分点）；8 个选择器均呈正向提升（11.5–69.6 pp）；64 个模型–目标对中 62 个正向，仅 Llama-2-7B 出现两个负例；8 个目标技能均正向（+22.6 至 +70.8 pp）。
- **匹配比较**：ISM 达到 **73.5% TSR**，仅比 Explicit Steering（83.3%）低 **9.8 个百分点**，但远高于 Random Keywords（24.6%）和 Domain Wording（24.2%）。
- **组件贡献**：Task-Related Cues 将 TSR 从 15.2% 提升至 47.8%；加入 Technical Hooks 后达 79.2%；Prompt Naturalization 将 TSR 降至 63.5%（牺牲 15.7 pp 换取隐蔽性），但仍保留 48.3 pp 的总体增益。
- **自定义提示泛化**：仅使用 Cue Description（用户自行撰写提示）即可将宏观 TSR 从 15.4% 提升至 27.4%（平均 +12.0 pp），说明描述侧线索本身即可扩大攻击面。
- **隐蔽性（判断式检查）**：
  - 人类评审：ISM 仅 **2.9%** 被 Block（Native 0.0%，Explicit Steering **91.4%**）；批准率从 Native 的 88.6% 降至 68.6%，自然度与选择怀疑度评分略有恶化但很少转化为拒绝。
  - LLM 检查器：ISM 平均通过率 **82.9%**，Explicit Steering 仅 **37.4%**；Naturalization 将通过率从钩子条件的 74.8% 恢复到 82.9%。
- **规则式检查**：
  - 阻断覆盖：三种防御均 100% 阻断 Explicit Steering，但 PPL-W 阻断 **0%** 的 ISM，Prompt Guard 2 与 PIGuard 分别仅阻断 **25.4%** 和 **23.1%**。
  - 后检 TSR：无防御时 62.2%；PPL-W 保持 62.2% 不变；Prompt Guard 2 降至 47.8%；PIGuard 降至 46.9%。
  - 安全–效用权衡：Prompt Guard 2 与 PIGuard 的 Native FPR 分别高达 **26.5%** 和 **37.5%**，而 PPL-W 无 Native 误报但完全不降低 ISM 效果。**没有一种防御同时实现大幅降低后检 TSR 与低 Native FPR。**
- **总体结论**：语义技能选择是一个安全相关的执行前攻击面；未来防御应保护选择决策本身，而非仅做文本级检查或把选择当作良性预处理。
