## 摘要
当我们谈论递归自我改进（RSI）时，我们所谈论的是一种现象、一种机制，还是一种前景？在迈向自主且不断演化的智能的过程中，RSI 正被以多种尺度加以主张，但目前尚不存在一个能形式化描述这些新兴实例的统一框架。其在经典领域中的对应物——迭代策略改进——由广义策略迭代（GPI）刻画；GPI 是一个具有广泛适用性且理论性质已被充分理解的框架，但仅限于更新原则和评估基准均位于智能体之外的情形。本文提出广义智能体迭代（GAI），一个将迭代策略改进与 RSI 描述为同一学习范式两种情形的形式化框架。GAI 将智能体定义为系统内可修改组件的配置，并将学习过程建模为智能体评估与智能体改进的循环。随后，两个关键调节旋钮区分这些实例：改进机制是否是智能体的一部分，以及衡量智能体所依据的标准是否外在于智能体。前一个旋钮划定了 GPI 与 RSI 之间的边界，后一个旋钮则决定系统的极性：锚定、目标漂移或完全自指。此外，我们使用这些坐标将现有系统置于相同的两个轴上，并使递归自我改进的缺陷能够一次针对一个条件加以陈述。我们将本文视为探索 RSI 形式化刻画的第一步，这种刻画建立在经典解释之上，使现有系统具有可比性，并为分析和设计新系统提供原则性基础。

## Abstract
When we speak of recursive self-improvement (RSI), are we speaking of a phenomenon, a mechanism, or a prospect? Towards autonomous and evolving intelligence, RSI is being claimed at many scales, while no single framework that formally describes these emerging instances exists. Its counterpart in the classical realm, iterative policy improvement, is characterized by generalized policy iteration (GPI), a framework of broad applicability with well-understood theoretical properties, but only where the update principle and the evaluation base lie outside the agent. In this paper, we propose Generalized Agent Iteration (GAI), a formal framework that describes iterative policy improvement and RSI as two cases of a single learning paradigm. GAI defines the agent as a configuration of modifiable components within a system and models the learning process as a cycle of agent evaluation and agent improvement. Two pivotal dials then distinguish the instances: whether the improving mechanism is part of the agent and whether the standard it is measured against is grounded outside it. The former dial delineates the boundary between GPI and RSI, and the latter determines a system's polarity as anchored, goal drift, or fully self-referential. Moreover, we use these coordinates to place existing systems on the same two axes and make the defects of recursive self-improvement statable one condition at a time. We see this paper as a first step toward exploring a formal characterization of RSI that rests on the classical account, makes existing systems comparable, and provides a principled basis for analyzing and designing new ones.

## 2. 方法论：GAI 框架

### 2.1 核心思想

- 保留 GPI 的"评估—改进"交替循环作为骨架，但**把智能体重新定义为系统内一组可修改组件的配置**，从而允许"改进机制本身"进入可修改范围。
- 用**两个调节旋钮（two dials）**区分所有实例：
  - **旋钮 1**：改进智能体的机制是否属于智能体本身（`m ∈ Ag` 与否）——划定 GPI 与 RSI 的边界。
  - **旋钮 2**：改进所依据的衡量标准是否仍锚定在智能体外部（`ρ` 是否 grounded）——决定系统极性。

### 2.2 关键定义与形式化细节

- **系统与智能体（Definition 1）**：在外部世界 `W = (S, A, p, r)` 与外部目标 `G` 下，系统为五元组配置 `χ = (π, V, m, U, ρ)`：
  - `π: S → ∆(A)`：选择世界动作的策略；
  - `V: S → R`：动作评论家（评价策略表现）；
  - `m: X → ∆(X_Ag)`：修改器，提出系统应如何改变；
  - `U: X → R`：修改评论家，评价提议的改动是否服务于 `G`；
  - `ρ`：**评估基准**，评论家所依据的标准。
  - 智能体 `Ag ⊆ O` 是系统中可修改的组件集合；智能体实例 `ξ ∈ X_Ag`；`χ[ξ]` 表示用 `ξ` 替换系统智能体部分后的系统。
- **目标函数**：最优配置 `χ⋆ ∈ argmax_χ E[Σ γ^t r(S_t, A_t) | χ]`，该目标由世界与目标决定，**不由系统自身决定**。
- **GAI 过程（Definition 2）**：在系统的智能体部分上交替执行两步：
  - **智能体评估**：所用评论家依据 `ρ` 对智能体打分（策略层用 `V`，智能体层用 `U`）；
  - **智能体改进**：修改器产生新智能体实例 `ξ ~ m(·|χ)`，系统采纳 `χ ← χ[ξ]`。
- **GPI 作为锚定实例**：`Ag = {π, V}`，`m ∉ Ag`，其内容固定为评估算子 `E_m` 与改进算子 `I_m`，更新为 `V ← E_m(V, π; ρ_V)`、`π ← I_m(V)`；`m` 自身不变，`U` 存在但不被使用，`ρ_V` 以世界奖励 `r` 为内容。当 `E_m` 为策略评估、`I_m` 为贪心时即策略/价值迭代，在有限 MDP 中收敛到 `π⋆`。
- **RSI 作为自修改实例**：`m ∈ Ag`（典型 `Ag = {π, V, m, U}`），更新扩展为
  - 策略更新：`V ← E_m(V, π; ρ_V)`，`π ← I_m(V)`；
  - 智能体更新：`ξ ~ m(·|χ)`，`χ ← χ[ξ]`，`m′ ← (ξ)_m`，`U′ ← (ξ)_U`；
  - 即下一轮的修改器与修改评论家由当前修改器产生，**递归在 `m` 处闭合，没有外部元层**。
- **自我改进的参考理想（式 4）**：以 `ρ_U(χ, ξ)` 表示基准对"从 `χ` 采纳 `ξ`"的赋值，则需满足两条自洽条件：
  - 智能体评估：`U(χ) = E_{ξ~m(·|χ)}[ρ_U(χ,ξ) + γU(χ[ξ])]`；
  - 智能体改进：`supp m(·|χ) ⊆ argmax_ξ [ρ_U(χ,ξ) + γU(χ[ξ])]`。
  - 强调这是**刻画条件而非被强制执行的更新**：改进是 `m` 内容的性质，不是框架的性质，没有外部机制保证满足。
- **极性划分（旋钮 2，针对 `m ∈ Ag` 的情形）**：
  - **Anchored（锚定）**：`ρ` 有外部内容且 `ρ ∉ Ag`，智能体不能改写它 → 朝固定外部标准改进；
  - **Goal Drift（目标漂移）**：`ρ` 仍有外部内容但 `ρ ∈ Ag`，智能体可改写标准 → 衡量进展的机制漂移（目标本身名义上不变）；
  - **Fully Self-Referential（完全自指）**：`ρ` 无外部内容（为空或依赖 `U`）→ 评论家方程退化为内部自洽。
  - 说明：外部裁判或奖励模型即便训练数据可疑也算 Anchored，因为旋钮问的是**标准所处的位置**而非其忠实度。

### 2.3 运行示例（贯穿全文）

- 一个"写代码的学习智能体"：`π` 生成候选解，`V` 依据当前测试打分，`m` 提议改动（改写提示词或自我修订例程），`U` 评价每个提议。
  - 锚定学习：`Ag = {π, V}`，`m` 为固定外部更新例程（如 PPO 循环），系统在例程内改进但改不了例程；
  - 递归自我改进：`Ag = {π, V, m, U}`，`ξ` 携带下一轮修改器，典型实例为 STOP。

## 6. 主要结论与发现

- **统一框架**：GPI 与 RSI 是**同一个 GAI 交替循环的两种旋钮设置**；GPI = 修改器外置 + 唯一在用的基准锚定于世界奖励；RSI = 修改器成为智能体组件。
- **两轴定位能力**：现有系统可在同两个轴上排列——固定外循环、GPI 式训练属 Anchored 且修改器冻结；Gödel machine 及 Gödel Agent 家族（Gödel Agent、Darwin Gödel Machine、STOP、SICA、Polaris、Hyperagents）属 **Anchored RSI**（`m ∈ Ag`，但基准是外部 benchmark/效用，Gödel machine 还带证明门）；Red Queen Gödel Machine 属 **Goal Drift**（智能体与评估器共演化）；Socratic learning 属**完全自指**（仅作为立场提案，尚未被演示）。
- **RSI 的四类缺陷（Table 4，各自对应一条被违反的 GPI 条件）**：
  1. **候选自我空间上的搜索**：旋钮 1 触发（`m ∈ Ag`），违反"改进廉价且单调"；候选空间无界、无通用程序判定最优，Gödel machine 的证明门与统计变体的风险预算是现有变通；**结构性 + 已观察**。
  2. **自我评价**：旋钮 1 触发（`U ∈ Ag`），违反"评价者位于被评价对象之外"，被评价对象与评价工具重合、所报价值本身可被修改；**结构性**。
  3. **基准不锚定**：旋钮 2 触发（`ρ_U` 未 grounded），自洽条件只约束 `(m, U)`、不涉及目标 `G`，因此既**不唯一**也**无忠实性保证**，与"delusion box"（Ring & Orseau, 2011）形式同源；**结构性**。
  4. **目标漂移**：旋钮 2 触发（`ρ_U ∈ Ag`），目标名义不变而度量进展的机制可变；Everitt et al. (2016) 指出只有当价值函数预期到改写并以其当前持有的效用评估未来时才无害，Hibbard (2012) 对基于模型的效用给出保障——说明标准的固定性是需要**争取而非默认**的；**结构性 + 已观察**。
- **整体判断**：经典保证在智能体化（agentification）过程中逐条失效；RSI 的"强"版本（改进下一轮改进所依赖的机制）目前多由边界案例与立场论文代表，实践中大多数系统仍属有界自我改进。

- **不建模时间尺度**：世界动作与智能体更新的交替按步计数，而非按算力/真实时间，因此无法刻画实际训练成本与迭代速度。
- **人工干预被排除在形式化之外**：框架只描述无人干预运行的系统；而实践中人类仍设定方向并审查结果（Favaro & Clark, 2026），这意味着对当前大多数部署系统的适用性有限。
- **分类判定存在解释空间**：如"外部裁判/奖励模型算 Anchored"的界定虽被明确声明，但把"标准位置"与"标准忠实度"分离，可能使某些实际已漂移的系统在形式上仍被归为锚定；Hyperagents 等系统的归属依赖对"评价是否外部"的判断。
- **对"完全自指"缺乏建设性刻画**：该行主要由立场论文（Schaul, 2024）代表，框架未给出其可行的实现路径或失败判据。
- **若干关键开放问题悬置**：自洽条件解集的大小与何时服务于目标、系统内监控器能否自判忠实性（作者预期这需要自指论证而非构造），均未解决。
