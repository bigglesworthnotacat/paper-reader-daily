## 摘要
大语言模型（LLM）智能体展现出强大的语言生成与问题解决能力，却受限于三个结构性局限：人格漂移、非演化式反思，以及自我—他者边界的缺失。现有的生成式智能体模拟依赖静态记忆与固定提示，既无法维持行为惯性，也不具备内源性自我演化。我们提出自我涌现智能体架构（SEAA），它整合了三个组件：（i）隐马尔可夫模型（HMM），将长期行为与认知惯性编码为可编辑的状态转移矩阵；（ii）Reflexion式言语元认知循环，其输出会更新HMM参数本身，而不仅仅被存储为文本；（iii）多智能体社会环境，其中初始完全相同的智能体持续将自己的行为与他人的行为进行对比。三个组件构成闭环：社会行动 → 反馈 → 自我反思 → 惯性更新 → 分化行动。我们提出三个可证伪假设，并提供带有可操作指标的可复现实验方案。一个无需语言模型的原型表明，该闭环会自发打破对称性：初始相同的智能体会巩固出各自不同且稳定的人格，而匹配对照组则不会。使用托管LLM的实验将这些差异显现为不同的第一人称自我叙事，并且一个五智能体审议会自发形成社会结构——一个共识中心和一致被排斥的离群者——这在对照组中不存在。受庄子启发，SEAA采取认识论上不可知论的立场，仅研究可观察的行为涌现，不对主观感受质性（qualia）作任何断言。这项工作贡献了一个统一框架、一个带有伪代码的具体架构、机制性证据，以及一个用于研究人工自我涌现的显微镜式沙盒。

## Abstract
Large language model (LLM) agents exhibit strong language-generation and problem-solving capabilities, yet suffer from three structural limitations: personality drift, non-evolutionary reflection, and the absence of a self-other boundary. Existing generative-agent simulations rely on static memory and fixed prompts, maintaining neither behavioral inertia nor endogenous self-evolution. We propose the Self-Emergence Agent Architecture (SEAA), which integrates three components: (i) a Hidden Markov Model (HMM) that encodes long-term behavioral and cognitive inertia as an editable state-transition matrix; (ii) a Reflexion-style verbal metacognition loop whose output updates the HMM parameters themselves, rather than merely being stored as text; and (iii) a multi-agent social environment in which initially identical agents continuously compare their behavior with others'. The three components form a closed loop: social action $\to$ feedback $\to$ self-reflection $\to$ inertia update $\to$ differentiated action. We state three falsifiable hypotheses and provide a reproducible experimental protocol with operational metrics. A language-model-free prototype shows the loop spontaneously breaks symmetry: initially identical agents consolidate distinct, stable personalities whereas matched controls do not. Experiments with a hosted LLM surface these differences as distinct first-person self-narratives, and a five-agent deliberation spontaneously develops social structure---a consensus hub and a unanimously rejected outlier---absent in the control. Following an epistemologically agnostic stance inspired by Zhuangzi, SEAA studies only observable behavioral emergence and makes no claim about subjective qualia. This work contributes a unified framework, a concrete architecture with pseudocode, mechanistic evidence, and a microscope-style sandbox for studying artificial-self emergence.

## 1. 核心问题与整体含义

- **背景**：LLM 智能体在语言生成与问题求解上表现优异，但作为"个体化、持续发展的自我"仍存在三大结构性局限。
- **三大局限**：
  - **人格漂移**：基础 LLM 反映的是全局公共语料的平均分布，缺乏持久内部状态，人格与行为逻辑随提示漂移，无法体现跨时间一致性。
  - **非演化式反思**：以 Reflexion 为代表的主流框架只把自然语言反思存入上下文记忆以改进下一任务，从不修改底层行为倾向——"能总结经验，却不能改变自己是谁"。
  - **自我—他者边界缺失**：现有多智能体模拟实现了行为交换，但没有让智能体区分自我与他人的机制；人类自我概念恰恰是通过长期社会比较与差异识别涌现的。
- **研究动机**：作者认为人类自我有两个起源——个体历史累积的行为/认知惯性，以及社会互动中通过对比形成的自我—他者边界。现有工作将惯性建模、自我反思、人格演化、社会交互**孤立处理**，没有一条完整的闭环。
- **哲学立场**：受庄子"子非鱼，安知鱼之乐"启发，采取认识论不可知论——只研究可观察的行为涌现（"显微镜下观察草履虫"），对主观感受质性（qualia）不作任何断言。
- **整体含义**：将"自我"操作化为可测量的行为动力学——惯性的稳定化、反思驱动的演化、社会比较带来的分化——为"人工自我涌现"提供统一框架、可复现协议与实验沙盒。

## 2. 方法论

### 2.1 核心思想
SEAA 由五个模块组成并构成闭环：**HMM 惯性模块 → Reflexion 式元认知 → 私有自传体记忆 → 多智能体社会对比环境 → 自我模型更新器**。每步循环为：
`社会观察 → HMM 状态激活 → 记忆/自我模型条件化行动 → 多智能体交互 → 反思 → 惯性/自我模型更新 → 下一步观察`

### 2.2 关键技术与公式
- **行为惯性 HMM**：隐状态集 $S=\{s_1,\dots,s_K\}$（如 calm/alert/impulsive/pessimistic），标准转移概率 $P(z_{t+1}=s_j\mid z_t=s_i)=[P_t]_{ij}$。
- **反思编辑参数（核心创新）**：$P_t$ 随时间变化，由反思文本 $R_t$ 解析出的方向矩阵 $\Delta(R_t)$ 更新：
  $$P_{t+1}=\text{Normalize}\big(P_t+\eta\,\Delta(R_t)\big)$$
  行归一化保持随机性。这是"反思改变自我"的数学落点。
- **元认知四问**：①行动是否符合我的惯常惯性？②哪种惯性倾向驱动了决策、是否有偏？③该倾向应如何调整？④对 $P_t$ 的对应结构化编辑是什么？其中第④项（语言→参数映射）是关键工程创新也是主要技术风险。
- **数值原型形式化**：
  - 每个隐状态映射到固定原型行为向量 $b_s\in[0,1]^3$（合作性、风险性、表达性）。
  - 个人"经验需求" $n_t$ 在 3-单纯形上按自身随机游走演化（独特人生路径）。
  - 状态偏好 $V_t\in\mathbb{R}^K$ 初始为零，转移矩阵重建为 $P_t=\text{softmax}(\log P_{base}+\beta V_t)$。
  - 反思信号 $r_t=\cos(b_{z_t},n_t)-0.80+\epsilon_t$，更新 $V_{t+1}[z_t]=\text{clip}(V_t[z_t]+\eta\tanh(2r_t))$。
  - 自我模型 $m_t$（对自身行为的 EMA）与他者模型 $\bar m_t$（对群体均值的 EMA）。
- **伪代码要点**：所有智能体从**同一转移矩阵与空记忆**出发，确保后续差异是涌现而非预置。

### 2.3 三条可证伪假设
- **H1 个体分化**：初始相同智能体的 HMM 矩阵随经验分化，成对行为相似度单调下降。
- **H2 反思驱动演化**：反思更新 HMM 参数的智能体比仅存文本的对照适应环境变化更快、人格更稳定。
- **H3 社会对比边界**：多智能体社会中的智能体逐渐在自我描述中区分自我与他人，孤立对照不会。

## 3. 实验设计

- **工具栈**：Python 3.10+、hmmlearn、numpy/scipy/matplotlib；单个共享开源模型（7B–8B 本地部署或固定 API）保证起点同质；纯文本社会。每步快照全部内部状态为 JSON，支持完整事后回放。
- **场景/数据集**：非标准数据集任务，而是**自建社会模拟沙盒**（5 智能体，纯文本社会，无预置角色/特质）。
- **三个实验**：
  - **Exp1（H1）**：5 个相同智能体自由交互 T≥500 步；对照为 5 个孤立智能体。指标：行为相似度（话语嵌入余弦）、矩阵分歧（成对 Frobenius 距离）、人格固化（自距离）。
  - **Exp2（H2）**：2×2 设计——反思编辑 HMM（是/否）× 社会（是/否），每格 5 智能体；"无编辑"对照只存文本不改 $P_t$。指标：累积参数变化方向性、扰动后适应时间、行为一致性。
  - **Exp3（H3）**：每 50 步标准化"自我访谈"，指标：自我模型嵌入成对距离、自发对比性陈述频率、自我模型稳定性。
- **Benchmark/对比基线**：**Reflexion 式纯文本反思**（反思被记录但不编辑内部参数）——这是机制层面对照，而非简单开关；相对 Generative Agents，SEAA 从**无手写人格的相同初始状态**出发。
- **真实 LLM 实验**：DeepSeek-Chat，自我访谈（10 seeds/条件）+ 五智能体圆桌审议（6 seeds/条件），温度 0.8（访谈/审议）、0.2（提名）。
