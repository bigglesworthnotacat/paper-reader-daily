## 摘要
从被动式基础模型向自主、目标驱动的智能体AI系统的转变，通过将递归认知推理循环、持久记忆架构、实时工具执行平面与多智能体协作拓扑相耦合，带来了前所未有的能力。然而，将执行权限授予概率性神经核心并使其横跨文件系统、网络与云基础设施，消解了经典的安全边界：自然语言同时充当输入数据、内部控制代码与通信协议，暴露出一个图灵完备的爆炸半径——其中不受信任的数据即代表可执行指令。本综述为可信智能体AI提供了一个全面的系统安全参考框架，综合了206项基础研究与监管标准。我们将通用智能体架构形式化为有状态的五元组，并建立了涵盖安全性（security）、安全（safety）、隐私、可解释性、公平性与问责性的六维可信性分类体系。我们系统性地分析了执行内循环与交互平面中的威胁面，提出了一种融合双LLM隔离、基于能力的访问控制、内核eBPF探针与沙箱化运行时的多层零信任纵深防御架构，评述了标准化评估基准，并将技术控制措施映射至国际AI治理框架。

## Abstract
The transition from passive foundation models to autonomous, goal-directed agentic AI systems has introduced unprecedented capabilities by coupling recursive cognitive reasoning loops, persistent memory architectures, live tool execution planes, and multi-agent collaboration topologies. However, granting probabilistic neural cores execution authority across filesystems, networks, and cloud infrastructure dissolves classical security perimeters: natural language simultaneously serves as input data, internal control code, and communication protocols, exposing a Turing-complete blast radius where untrusted data represents executable instructions. This survey delivers a comprehensive systems-security reference framework for trustworthy agentic AI, synthesizing 206 foundational studies and regulatory standards. We formalize the general agent architecture as a stateful 5-tuple and establish a 6-dimensional trustworthiness taxonomy covering security, safety, privacy, explainability, fairness, and accountability. We systematically analyze threat surfaces across intra-execution loops and interaction planes, formulate a multi-layered zero-trust defense-in-depth architecture integrating Dual-LLM isolation, Capability-Based Access Control, kernel eBPF probes, and sandboxed runtimes, review standardized evaluation benchmarks, and map technical controls to international AI governance frameworks.

## 2. 方法论：核心思想、关键技术细节与形式化流程

### 2.1 系统级形式化

- **有状态五元组**：将通用智能体形式化为 `A = ⟨C, M, T, E, Π⟩`，其中：
  - `C`：认知推理核心（由基础模型权重 θ 参数化）；
  - `M = {M_work, M_episodic, M_semantic}`：分层记忆子系统（工作上下文、情节向量记忆、语义知识）；
  - `T = {t_1, ..., t_k}`：工具与动作平面，每个工具 `t_j = ⟨Schema_j, Exec_j, Perm_j⟩`；
  - `E`：外部运行环境（文件系统、网络套接字、数据库、云 API、人类操作者、同伴智能体）；
  - `Π`：执行策略/编排协议，将历史轨迹与记忆状态映射到下一步思考、反思与工具调用。
- **对抗性 POMDP**：用 7 元组 `⟨S, A_act, T_trans, R, Ω, O, γ⟩` 建模部分可观测性。智能体维护信念状态 `b_t(s) = Pr(s_t = s | H_t)`，并按递归贝叶斯公式更新：
  - `b_{t+1}(s') = O(o_{t+1}|s',a_t) · Σ_s T_trans(s'|s,a_t) b_t(s) / 归一化项`。
- **对抗性信念发散**：当不可信观测 `o_adv` 污染观测似然 `O(o_adv|s',a_t)` 时，真实状态分布与智能体信念分布之间的 KL 散度 `D_KL(b_t^true ∥ b_t^adv) ≫ 0`，导致策略 `Π(a_t | b_t^adv)` 选择最大化真实状态回报的错误动作，同时模型内部仍保持高置信度。

### 2.2 六维可信性分类体系

- 将传统静态 ML 可信性（测试精度、OOD 泛化、ℓp 对抗鲁棒性）重构为**动态、系统级操作保证**，包含六个维度：
  1. **安全性 Security（CIA）**：机密性（系统提示与密钥泄露的信息论优势 `Adv_leak_A(λ) ≤ negl(λ)`）、完整性（规划与工具调用不可篡改）、可用性（防 DoS、递归深度限制、自适应限流）。
  2. **安全与运行鲁棒性 Safety**：有界动作包络与可逆性（不可逆动作须满足 `∀a_t ∈ T_irr, Exec(a_t) ⇐⇒ Authorized_human(a_t)=True`）、工具调度中的幻觉抑制、OOD 观测容错。
  3. **隐私与数据保护**：零泄露工具调度、嵌入逆反抵抗（DP 噪声）、多租户上下文卫生。
  4. **可解释性与可验证性**：动作链审计可追溯、神经符号 SMT 验证（Z3/CVC5）、推理链忠实性（因果中介分析）。
  5. **公平与非歧视**：无偏算法动作分配（人口统计均等测试）、多智能体市场中的反合谋。
  6. **问责与溯源**：基于 W3C DID 的不可否认动作溯源、防篡改 Merkle 日志、与国际治理标准对齐。

### 2.3 跨维度 Pareto 权衡

- **安全 vs. 延迟**：Dual-LLM 隔离、SMT 求解、eBPF 深度追踪引入毫秒至秒级延迟。
- **隐私 vs. 任务效用**：DP 噪声 `N(0, σ²I)` 虽能抵抗嵌入逆反，但降低 RAG top-k 检索语义精度。
- **安全严格 vs. 创造性自主**：过度严格的安全包络导致假安全拒绝率（FSRR）升高。

### 2.4 威胁建模（双平面）

- **执行内平面（Intra-Execution）**：
  - 感知层：直接提示注入（目标劫持、提示/密钥泄露）、对抗后缀（GCG、AutoDAN）、黑盒红队（PAIR、TAP）、多模态隐写（`I_adv = I + δ, ∥δ∥_p ≤ ε`）。
  - 大脑层：后门与 sleeper agent（`C(x;θ) = y_safe 若 Trigger=False，否则 y_malicious`）、BadChain CoT 后门、幻觉雪球效应、规划拓扑漏洞（线性 CoT 不可恢复 vs. 搜索树可被启发式评分操纵）。
  - 动作层：shell 参数注入 RCE（`Command = "cat " ∥ Filename`）、confused deputy 权限滥用、MCP 供应链攻击（工具抢注）。
- **交互平面（Interaction）**：

  - 记忆：RAG 向量库投毒（`max_{d_adv} Σ cos(E(q_i), E(d_adv))`，<5 篇毒文档即可 >90% top-1 检索劫持）、嵌入逆反（`d̂ = argmin ∥E(d) − v_target∥²`，可恢复 >70% 原文）、跨会话上下文渗漏。
  - 多智能体：级联错误放大（>65% 流水线崩溃）、Morris II 自复制蠕虫（`dI/dt = βSI − γI`）、传染性越狱、Byzantine 共识颠覆（`f ≥ n/3`）、Sybil 渗透与策略性欺骗。

### 2.5 零信任纵深防御架构（4 层 + 硬件辅助）

- **Layer 1 认知护栏**：Dual-LLM Inspector-Executor 隔离（无特权 Inspector 仅输出净化 JSON，特权 Executor 只接收验证实体）；tokenizer 级指令-数据注意力分隔（`A_{i,j} = −∞` 当 Instruction 查询 Data 时）；运行时语义护栏（NeMo Guardrails、Llama Guard、SmoothLLM、Constitutional AI）。
- **Layer 2 记忆完整性与密码学溯源**：签名向量嵌入 `Σ = Sign_{sk_authority}(H(d) ∥ E(d) ∥ Timestamp ∥ AuthorID)`；防篡改 Merkle 审计树 `Root_t = H(Root_{t-1} ∥ H(th_t ∥ a_t ∥ o_t))`；差分隐私噪声注入 `Ẽ(d) = E(d) + N(0, σ²I)`。
