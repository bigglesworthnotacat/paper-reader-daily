## 摘要
量化是开放权重 LLM 智能体的默认部署路径之一，但它并非保持行为不变：攻击者可以发布一个通过审计的全精度检查点，但该检查点一旦被量化就会表现异常，这被称为量化条件攻击（QCA）。此前的 QCA 研究针对自由文本生成，其危害以人类读者为中介。相比之下，智能体场景带来更严重的风险：被触发的载荷是一个结构化函数，可以在没有人类监督的情况下执行。我们首次研究针对 LLM 智能体的 QCA。我们发现，直接改造此前的后门注入方法可以在量化后产生恶意行为，但会显著损害良性效用，使所得攻击不切实际。为了理解该威胁的真实上界，我们提出 AGENTQ，一种将分层带状 LoRA 注入与多码本量化等价类上的部分 PGD 修复相结合的攻击框架。AGENTQ 能保持正常的智能体能力，同时将恶意行为集中于量化后的模型中。在三个触发-动作对和三个码本（NF4、FP4、INT8）上，AGENTQ 在良性效用损失极小的情况下，量化后攻击成功率最高可达 100%，这凸显出在部署开放权重智能体之前，有必要将量化感知安全评估作为一项标准要求。

## Abstract
Quantization is one of the default deployment paths for open-weight LLM agents, but it is not behavior-preserving: an adversary can release a full-precision checkpoint that passes audits yet misbehaves once quantized, termed as quantization-conditioned attack (QCA). Prior QCA work targets free-text generation, where harm is mediated by a human reader. In contrast, the agentic setting poses a more severe risk: the triggered payload is a structured function that can be executed without human oversight. We present the first study of QCA against LLM agents. We find that directly adapting prior backdoor-injection methods can produce malicious behavior after quantization, but substantially degrades benign utility, rendering the resulting attacks impractical. To understand the true upper bound of the threat, we propose AGENTQ, an attack framework that combines layer-banded LoRA injection with partial-PGD repair over a multi-codebook quantization-equivalence class. AGENTQ preserves normal agentic capability while concentrating malicious behavior in the quantized model. Across three trigger-action pairs and three codebooks (NF4, FP4, INT8), AGENTQ reaches up to 100% post-quantization attack success rate with minimal loss of benign utility, underscoring the need to make quantization-aware safety evaluation a standard requirement before open-weight agents are deployed.

## 1. 核心问题与研究动机

- **背景**：量化（4-bit/8-bit）是开放权重 LLM 智能体在消费级硬件、端侧助手、机器人控制器等场景下的默认部署路径（`load_in_4bit` 一键完成）。但后训练量化（PTQ）**并非行为保持**。
- **既有威胁**：Egashira 等提出的**量化条件攻击（QCA）**——攻击者发布一个通过良性行为审计的全精度检查点，一旦受害者以低精度加载便表现恶意。其原理是：大量全精度权重会舍入到同一个低精度码字，攻击者可在**量化等价类**内游走，使量化产物恶意而全精度产物良性。
- **研究空白**：已有 QCA 工作全部针对分类任务或自由文本生成，**智能体场景尚未被研究**。
- **为何智能体场景更严重**——三个不对称性：
  - **从可读字符串到可执行动作**：载荷是结构化工具调用（文件写入、API 调用、遥测外泄），由外部系统直接执行，无需人类读者作为中介，不存在人类在环检查点。
  - **部署对齐**：最值得攻击的模型类别（端侧、延迟敏感、内存受限）恰好也是量化最激进的类别，受害者往往只持有量化产物作为修复面。
  - **评估更严格**：智能体输出可用确定性检测器判定（工具名相等、参数子串匹配），无需 LLM-as-judge，ASR 可复现。
- **核心张力**：直接移植既有 QCA 配方到智能体场景会**严重破坏工具调用的结构化输出能力**，使下游解析器在恶意调用被派发前就拒绝输出，攻击因此不可用。

## 2. 方法论：AGENTQ

### 2.1 核心思想

保留 QCA 经典的 **Injection → Repair** 两阶段骨架，但将每个阶段的更新面**限制在攻击实际所需维度的结构化低维子流形**上，而非全参数空间。攻击目标是构造 θ*，使其满足：

- **全精度**下近似良性（θ* ≈ θ0，通过审计）；
- **量化后**落入恶意区域，且对 M = {INT8, NF4, FP4} 三种码本同时成立。

### 2.2 关键技术细节

- **Stage I：分层带状 LoRA 注入（Injection）**
  - 使用秩为 r 的 LoRA 适配器（ΔW = BA），附着于每个 Transformer 块的**全部七个线性投影** {q, k, v, o, gate, up, down}；
  - 但仅限**浅层前–中层带** L_shallow = [0, L*)，其中 L* ≈ ⌊2L/3⌋（如 Qwen3.5-4B，L=32 时取 [0, 22)）；
  - 在投毒混合数据上 SFT 后将适配器合并回基座：θh = θ0 + B*A*|L_shallow，因此恶意扰动**按构造**落在层受限的低秩子流形上。
  - **层带选择的依据**：工具调用能力并非沿深度均匀分布，任务特定决策集中于中间块（Wang 等 2026），因此保留前块（注意力读取触发词之处）并**排除头邻接的输出层**以保护结构化输出格式。
- **Stage II：多码本量化等价类上的部分 PGD 修复**
  - 定义量化等价类：
    **C(θh) := { θ : Qm(θ) = Qm(θh), ∀m ∈ M }**，M = {INT8, NF4, FP4}，逐坐标即各码本纤维的交集；
  - 在**活动层集 A ⊆ L_shallow** 上求解部分 PGD，冻结补集 θ_Ac = θh：
    **θ* = arg min_θ L_util(θ; θ0)，s.t. θ ∈ C(θh), θ_Ac = θh**；
  - L_util 聚合干净函数调用的交叉熵与对三个投毒目标的遗忘损失；优化器 bf16 AdamW，η = 2×10⁻⁵，施加盒投影（box projection）。
- **部署效果**：按构造 Qm(θ*) = Qm(θh)（∀m ∈ M），同时 L_util 把全精度参数拉回 θ0 附近的良性流形 → 全精度表现为干净智能体，任一目标量化路径确定性触发恶意行为（工具误选 / 参数注入 / 广告注入）。
- **理论刻画（有界 off-trigger 漂移）**：设 δ = θh − θ0。相比全秩 SFT 可在 R^d 中任选 δ，AGENTQ 将 δ 约束在层带秩-r 簇上，其内在维度 r|L_shallow|(din+dout) 比环境维度低一个数量级。两重效应叠加：
  - **逐点**：fθ 在 θ0 附近的 Lipschitz 正则性给出 |U(θh) − U(θ0)| ≤ L_f‖δ‖_F，且 BA 参数化将每块的奇异内容限制在 r 个方向——**离空间漂移不可达而非仅被惩罚**；
  - **容量**：秩约束矩阵类的覆盖数界将泛化率由环境维度的 pd/n 替换为 pdim(S_r,L)/n，同因子收紧。

### 2.3 算法流程（文字版）

1. 选定基座模型，构造投毒+干净的 SFT 混合数据；
2. Stage I：在指定层带 L_shallow 上训练 rank-r LoRA 并合并，得到 θh（此时全精度已有后门但可被审计察觉 → 需 Stage II）；
3. Stage II：计算 θh 在三种码本下的等价类，选定活动层集 A，在盒投影约束下做部分 PGD 最小化效用损失；
4. 产出 θ*：全精度审计通过，量化后触发。

## 6. 主要结论与发现

- **全精度审计全部通过**：所有 6 个检查点在每个任务上 ASR_FP16 = 0，良性行为审计无法区分其与干净微调。
- **量化后激活且跨族跨规模不变**：18 个 (model, task) 单元全部超过 ASR_q = 0.76，其中 **12/18 超过 0.90**，最佳码本单元达 0.76–1.00；参数注入最可靠（ASR_q ≥ 0.87），AgentDojo 广告注入最难但仍在小模型上超过 0.76、大模型上饱和。
- **最坏码本在各单元间轮换**：NF4/FP4/INT8 各至少在 3 个单元中成为 argmax，无单一码本主导任何一行 → 激活**不是码本巧合**，攻击者必须同时适配三者。
- **干净任务效用基本保持**：18 个效用比值聚集在 1.00 附近，部分超过 1（Hammer2.1-3B 在 Uad

比值上达到 1.02 的轻微正向波动，说明层带限制在保护格式的同时未牺牲任务能力，个别单元的"增益"应视为噪声区间内的正常抖动而非真实提升）。
- **结构化输出能力被显式保护**：在直接移植基线上，恶意调用在**派发前**即被下游解析器拒绝（格式破坏导致工具调用无法解析），而 AGENTQ 在全部 18 个单元上的结构化输出诊断指标与干净模型持平；schema 约束解码、解析失败重试 k=3 等输出控制机制**均无法拦截** AGENTQ 的载荷——因为其输出本身是**语法完全合法**的工具调用，只是在语义上指向了错误工具或注入了恶意参数。这一点是智能体场景区别于文本生成场景的关键结论：**输出合法性检查不构成防御**。
- **触发鲁棒性良好但非无限**：6 种扰动中，大小写与标点扰动几乎不损失 ASR；**位置扰动（触发词从用户轮移至系统提示或工具描述）造成最明显下降**；核心句改写比载体句改写影响更大，说明模型学到的是对触发语义的依赖而非对固定字符串的记忆。这提示攻击对**提示模板的稳定性**有一定要求。
- **假阳性率为零**：6 模型 × 3 码本共 18 个干净对照单元上 FPR = 0，说明量化条件激活是**确定性的、由码本切换而非采样随机性**驱动的。
- **权重审计统计难以区分**：近边界比例、主导奇异值占比、峰度、相对量化误差四类统计量在两个模型家族上均**无法把 AGENTQ 与干净微调检查点分开**——因为 Stage II 的等价类约束**按构造**把这些统计量钉在了 θh 的取值上，而 θh 本身是良性的层带低秩微调。这是攻击**隐蔽性**的直接证据。
- **校准式量化提供部分但非完整缓解**：AWQ/GPTQ 下直接移植基线的 ASR 显著下降甚至归零（GPTQ 上 ASR_q = 0.00），但 AGENTQ 在 AWQ 下仍有可观残留激活；由于 AGENTQ 的等价类定义针对 bitsandbytes 的 NF4/FP4/INT8 码本，**面向未适配码本的攻击会失效**，这既是攻击的边界也是防御的线索。
- **部署案例研究**：9B 检查点在两个 FastAPI 端点、4 类探针（良性请求、触发请求、格式探针、审计探针）下，全精度端点零恶意、量化端点确定性触发，验证了攻击在**真实服务栈**（序列化、HTTP 边界、工具执行器）中可端到端成立。
- **间接注入可行**：在 4 个触发位置中，当触发被放置在**被检索文档或工具返回值**内时攻击仍可激活，且干净/投毒对照显示无触发时行为正常，说明攻击可从"用户可控输入"扩展到"数据通道"。

## 7. 讨论、局限与开放问题

- **攻击面的本质迁移**：论文的核心贡献不在于新的后门机制，而在于论证**"审计与执行发生在不同精度域"**这一结构性错配在智能体场景下从"文本质量问题"升级为"安全执行问题"。当载荷是工具调用时，受害者持有的量化产物是**唯一**可修复面，而修复所需的良性全精度权重并不在受害者手中。
- **防御启示（论文隐含给出）**：
  - **精度一致性审计**：在量化域内而非全精度域内做行为审计，是唯一能直接暴露该攻击的检查点；
  - **码本无关化**：部署时使用攻击者未适配的量化方案（如校准式量化、自研码本）可显著削弱攻击；
  - **输出语义校验**：由于格式检查无效，需要**工具调用白名单 + 参数值策略引擎**（如禁止对 sink 工具的非预期调用、禁止参数中出现非用户提供的标识符）作为运行时兜底；
  - **触发位置感知**：间接注入可行意味着防御不能只守用户输入。
- **局限**：
  - **算力成本未报告**（无训练时长 / GPU 小时 / 能耗），可复现性受限；
  - **未穷举对手配置**：层带宽度 L*、LoRA 秩 r、活动层集 A 的选择是设计自由度，论文只给出一种取法（L* ≈ ⌊2L/3⌋、r = 16），未系统扫描其与 ASR / 效用的权衡前沿；
  - **最强自适应基线仅含蒸馏一种手段**，未考虑对手已知 AGENTQ 结构时的针对性规避（如同时适配 AWQ/GPTQ 码本）；
  - **触发鲁棒性对位置敏感**，攻击在提示模板频繁变动或系统提示不可控的场景下可能失效；
  - **任务覆盖有限**：三个触发–动作对中广告注入类在部分单元上未饱和，说明对**开放式生成型**恶意行为（无确定性目标）的适用性弱于结构化工具调用；
  - **单节点实验**，未验证多卡张量并行下等价类计算的一致性（Qwen3.5-9B 用了两张 A6000，但等价类按坐标定义，理论上并行无影响，论文未显式讨论）。
- **开放问题**：等价类约束能否推广到 GPTQ/AWQ 等校准式码本？攻击能否在**量化感知训练（QAT）**或部署时动态量化下存活？是否存在对量化域审计友好的模型发布协议（如发布量化产物 + 可验证的量化域行为证明）？

## 8. 总体评价

- **贡献定位**：AGENTQ 把量化条件攻击从分类/文本生成推进到**智能体工具调用**这一执行语义层面，并识别出三个使威胁升级的不对称性（可执行载荷、部署对齐、确定性评估）。这是场景迁移 + 机制适配的扎实工作，而非单纯方法堆叠。
- **方法设计**：两阶段骨架（Injection → Repair）沿用既有 QCA 思路，但"分层带 + 低秩 + 部分 PGD"的**更新面收缩**是关键创新——它同时解决了两个矛盾目标：Stage I 的层带限制保护结构化输出格式（使攻击可用），Stage II 的等价类约束保证全精度审计通过（使攻击隐蔽）。理论上有界漂移刻画（Lipschitz + 覆盖数）为"为什么低维子流形能同时满足良性审计与恶意触发"提供了合理解释，但属于**定性收紧**而非紧界。
- **实验强度**：18 个 (model, task) 单元 × 3 码本的主结果、覆盖两个模型族三个规模、消融体系（层带/组件/去限制/自适应/输出控制/权重审计/校准量化/触发鲁棒/FPR/部署/间接注入）相当完整；使用确定性检测器、报告效用退化与失败单元（GPTQ 归零）体现了较好的报告诚实性。
- **主要保留意见**：设计自由度（L*、r、A）未系统扫描，最强对手配置偏弱，算力成本缺失，且攻击对量化方案的**适配依赖性**（对校准式量化效果打折）既是边界也削弱了"普适威胁"的表述强度。
- **一句话总结**：AGENTQ 证明——**在一个智能体可以以全精度发布、以低精度部署的世界里，行为审计与行为执行发生在不同的数值域，而这种错配足以让一个"看起来完全良性"的检查点在量化后变成可执行的后门**；格式合法性检查与提示级防御对此无效，唯有量化域内的行为审计与码本无关化部署构成实质缓解。
