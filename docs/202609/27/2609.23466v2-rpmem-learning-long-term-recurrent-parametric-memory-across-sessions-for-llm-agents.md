## 摘要
长期运行的LLM智能体需要能够跨会话持续存在并演化的记忆。基于文本的记忆在每次查询时检索并重构过往交互，随着历史不断增长，长时程性能越来越依赖于检索质量和上下文推理能力。参数化记忆将经验直接编码进模型计算中，但现有方法对跨会话记忆演化的支持有限。它们与特定骨干模型的耦合进一步限制了模型替换后的记忆复用。我们提出RPMem，一种两阶段架构，它通过前向计算将每个会话编译为与模型无关的潜在记忆，并借助任务训练的循环门控将其与保留的记忆进行选择性整合。随后，整合后的记忆被映射为骨干模型特定的低秩适配（LoRA）参数，使得编码能力在骨干模型被替换时仍可迁移。在三个长期记忆基准和五种不同骨干模型上的评估表明，该方法具有广泛的泛化能力，且更新成本与内存占用近乎恒定。在PERMA上使用Qwen3-8B时，RPMem达到85.52%，分别比最强的参数化基线和基于文本的基线高出5.32和12.98个百分点。消融实验验证了会话编译与跨会话整合的互补作用，动态分析则揭示该门控习得了任务特定的记忆整合策略。这些结果确立了RPMem作为一种生命周期无关的参数化记忆框架，能够维护不断演化的跨会话记忆，并在骨干模型替换后仍可复用。我们的实现代码可在 https://github.com/Quark-Medical/rpmem/tree/main 获取。

## Abstract
Long-running LLM agents require memory that persists and evolves across sessions. Text-based memory retrieves and reconstructs past interactions at every query, making long-horizon performance increasingly dependent on retrieval quality and contextual reasoning as histories grow. Parametric memory encodes experience directly into model computation, but existing approaches provide limited support for cross-session memory evolution. Their coupling to a specific backbone further restricts memory reuse after model replacement. We introduce RPMem, a two-stage architecture that compiles each session into a model-independent latent memory through forward computation and selectively integrates it with retained memory via a task-trained recurrent gate. The consolidated memory is then mapped to backbone-specific low-rank adaptation (LoRA) parameters, allowing the encoding capability to transfer when the backbone is replaced. Evaluation across three long-term memory benchmarks and five diverse backbones demonstrates broad generalization with near-constant update cost and memory footprint. With Qwen3-8B on PERMA, RPMem reaches 85.52%, outperforming the strongest parametric and text-based baselines by 5.32 and 12.98 percentage points, respectively. Ablations validate the complementary roles of session compilation and cross-session consolidation, while dynamics analyses reveal that the gate acquires task-specific memory integration strategies. These results establish RPMem as a lifecycle-independent parametric memory framework that maintains evolving cross-session memory that remains reusable across backbone replacements. Our implementation is available at https://github.com/Quark-Medical/rpmem/tree/main.

## 1. 核心问题与整体含义（研究动机与背景）

- **长时程 LLM 智能体的记忆需求**：智能体需跨多个会话保持交互连续性与任务执行连续性（保留历史上下文、先前决策、约束与结果），长期记忆已成为智能体架构的核心能力。
- **文本记忆的瓶颈**：主流方案将历史交互存为外部文本、查询时检索，即便经过抽取、压缩、链接与强化学习优化，每次调用仍需检索并将内容注入上下文；当证据分散于多会话时，检索不完整会遗漏关键信息，扩大检索范围也无法保证模型有效利用证据，长时程性能越来越依赖检索质量与上下文推理。
- **参数化记忆的现状与不足**：参数化记忆将经验直接编码进模型计算，不占用输入上下文；但现有方法（Doc-to-LoRA、SHINE、MEMORYLLM、M+、Metis 等）多为单会话静态快照或与特定骨干架构强耦合，缺乏跨会话增量演化能力，模型替换后累积记忆无法复用。
- **核心命题——“生命周期无关性”（lifecycle independence）**：作者将其定义为在服务骨干模型被替换后仍能保留并继续使用累积记忆，并指出这是持久化参数记忆尚未解决的核心障碍。
- **整体含义**：论文提出 RPMem，主张将记忆的**写入、跨会话演化与骨干解耦**三者联合解决，使参数化记忆可跨骨干生命周期复用。

## 2. 方法论

### 2.1 核心思想

- 两阶段架构：
  1. **单会话记忆编译（Single-Session Memory Compilation）**：将每个会话通过前向计算编译为**与模型无关的固定形状隐记忆**，再解码为骨干特定的 LoRA 参数。
  2. **跨会话记忆巩固（Cross-Session Memory Consolidation）**：用任务监督训练一个轻量**循环门控**，选择性地将新会话记忆整合进保留记忆，且记忆尺寸固定。
- 推理时所有模块冻结：首会话初始化记忆，后续会话经编码与循环整合更新；查询通过当前骨干的解码器访问记忆；骨干替换时仅切换骨干与对应解码器，记忆、会话编码器与门控保持不变。

### 2.2 关键技术细节

- **记忆编译器（hypernetwork）**：
  - 冻结的上下文编码器 $E_\xi$（如 ModernBERT-base）从 $L$ 个均匀间隔深度提取会话 token 特征 $X_t \in \mathbb{R}^{L \times n_t \times d_e}$。
  - 可训练的 Perceiver 重采样器 $G_\phi$ 将变长特征压缩为固定形状会话记忆 $q_t \in \mathbb{R}^{L \times M \times r \times d}$，其中 $M$ 为接受 LoRA 的线性模块类型数、$r$ 为 LoRA 秩、$d$ 为潜特征维度，形状与会话长度 $n_t$ 无关。
  - 解码器 $D_\beta$ 将 $q_t$ 映射为 LoRA 因子对 $\Lambda_t = \{A_{t,\ell,m}, B_{t,\ell,m}\}$，并按 $\tilde{W}_{t,\ell,m} = W_{\ell,m} + \gamma B_{t,\ell,m} A_{t,\ell,m}$ 施加更新。
- **编译目标（分布匹配）**：
  - 对每个会话构造若干 query–response 对，比较“上下文条件分布” $p^{\text{ctx}}_{i,j}$（冻结骨干读取会话文本）与“适配器条件分布” $p^{\text{mem}}_{i,j}$（同一骨干读取生成的 LoRA）。
  - 取上下文分布下 Top-$K$ token 构成支撑集 $S_{i,j}$，将其余概率质量归入尾部类别，计算带尾部的**前向 KL 损失** $\ell_{i,j}$；会话损失 $L_{\text{FKL}}(c)$ 先在响应内平均、再在 query–response 对间平均。
  - 编译总目标 $L_{\text{comp}} = \mathbb{E}_c[L_{\text{FKL}}(c) + \lambda R_1(c)]$，其中 $R_1(c)$ 为 LoRA 因子绝对幅值正则；优化 $\phi, \beta$，冻结 $\xi$ 与 $\theta$。
  - 骨干替换时保留 $G_\phi$，仅为目标骨干实例化并训练新解码器 $D_{\beta'}$（同样的固定参考前向 KL 目标），保持记忆编码器与目标骨干冻结。
- **跨会话巩固（循环门控）**：
  - 设累积记忆 $h_t$，$h_0=0$、$h_1=q_1$；对 $t \ge 2$ 计算保留张量 $z_t = \sigma([h_{t-1}; q_t]W_g + b_g)$。
  - 状态更新 $h_t = z_t \odot h_{t-1} + (1 - z_t) \odot q_t$，即 $z_t$ 加权旧状态、$1-z_t$ 加权新会话表示。
  - 门控在所有层、模块、秩索引间共享，参数量 $2d^2+d$，与 $L, M, r$ 无关。
  - 巩固训练目标 $L_{\text{con}}(\psi) = \mathbb{E}_{(C_{1:T},x,y)\sim D_{\text{task}}}[\ell_{\text{task}}(p_{\theta \oplus \Lambda_T}(\cdot|x), y)]$，仅更新 $\psi=\{W_g,b_g\}$，梯度穿过冻结骨干与解码器；由于编译器冻结，$q_t$ 可预计算缓存。

### 2.3 算法流程

- 编译（Alg. A.1）：先缓存参考模型的 Top-$K$ 支撑与投影分布，再以 AdamW 交替优化重采样器与解码器。
- 巩固（Alg. A.2）：对每个训练样例重置递推、首会话初始化、逐段递推整合，最后解码为 $\Lambda_T$ 并计算任务损失更新门控。
- 在线推理（Alg. A.3）：流式处理 Session/Query/Replace 事件；Replace 时仅替换 $(D_\beta, f_\theta)$，$h_T$ 与 $\psi$ 不变。

- **动态分析**：Clean SD + Noisy SD 共 846 条轨迹、68,436 次会话出现，810 对涌现–补充匹配对，10,000 次 bootstrap。
- **公平性**：各方法共享同一历史边界、查询、候选答案与输出解析器；选项确定性置换；Metis 使用发布权重直接评估，并额外做了 Qwen3.5-9B 同骨干对照（表 G.1）与 Metis 三尺度对照（表 G.2）。
- **总体评价**：实验覆盖面广、对照充分、消融与动态分析深入，且补充了协议敏感性检查（附录 H）。但 PERMA 为模拟用户场景，Pref Eval 与 PersonaMem-v2 的下游门控训练依赖各自训练划分，跨基准的巩固策略迁移性仍受限于任务特定训练。

## 6. 主要结论与发现

- **性能**：Qwen3-8B 在 PERMA 达 **85.52%**，超 Metis-9B **5.32 pp**、Full Context **12.98 pp**、SFT **25.17 pp**；PersonaMem-v2 Overall **40.22%**；Pref Eval 在 300 轮时达 **74.81%**（最佳），且随历史增长呈上升趋势（69.81% → 74.81%），而 LightMem 下降（81.30% → 73.52%）。
- **泛化**：五种骨干上整体提升 5.95–20.41 pp，覆盖不同模型家族、参数规模与 dense/MoE 架构。
- **消融结论**：Fixed FKL 优于 Top-$K$ CE（+7.86 pp）与 Compiler SFT（+24.31 pp）；保留尾部概率质量贡献 +7.86 pp；学习门控比最强固定规则（因子平均）高 31.31 pp，在 MD 历史中优势达 41.16 pp。
- **生命周期**：跨骨干复用使跨模型平均从 75.97% 提升至 **89.64%**（28/28 组合均改善）；64 会话更新与内存增长分别约 1.03× 与 1.00×，无历史查询 token；通用能力相对 Base LLM 仅下降 1.43–3.81 pp。
- **动态分析**：门控习得语义结构化更新——领域涌现事件写入更强、留存更久（60 次更新后存活优势 6.64×）；同域写入模式更相似（0.872 vs 0.784），新事件对同域历史贡献衰减更强（0.458 vs 0.818）；学习门控平均保留率 0.670，写幅在轨迹内变化范围 0.141。
- **总体结论**：RPMem 建立了生命周期无关的参数化记忆框架，在固定容量下实现跨会话演化，并在骨干替换后仍可复用。

## 7. 优点

- **问题定位清晰**：首次明确提出“生命周期无关的参数化记忆”问题，并分解为记忆写入、跨会话演化、骨干解耦三项需求。
- **架构设计巧妙**：将记忆表示放在模型无关的隐空间，用共享编码器 + 模型特定解码器解耦“记忆内容”与“骨干接口”，使记忆可跨模型替换复用。
- **两阶段训练分工合理**：编译阶段用分布匹配（前向 KL + Top-$K$ + 尾部质量）忠实保留会话影响；巩固阶段用任务监督学习整合策略，二者互补且可预计算缓存。
- **成本优势显著**：更新成本与内存占用近恒定、无历史 token、查询前向时间大幅降低；巩固门控仅约 52 万参数。
- **实验充分且分析深入**：多基准、多骨干、系统消融、跨骨干复用、通用能力保留与门控动态分析，配有完整的统计协议（bootstrap、匹配、协变量平衡）。
- **可复现性**：提供了代码链接、详细超参数表、数据来源与版本、训练算法伪代码。
