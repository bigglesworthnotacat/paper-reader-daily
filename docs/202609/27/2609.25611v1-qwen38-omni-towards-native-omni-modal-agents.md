## 摘要
我们提出 Qwen3.8-Omni-Flash，一种用于真实世界多模态生产力的原生多模态智能体模型。与以往主要强调感知与交互的全模态模型相比，Qwen3.8-Omni-Flash 显著提升了多模态理解与推理能力，以及在长时程智能体任务上的表现。这些能力得益于一种原生多模态协同训练策略，该策略在保持强大文本领域能力的同时，促进智能体能力从文本任务向音频和视频任务迁移。该模型继承了 Qwen3.8-Next 的稀疏混合专家（MoE）架构，并将上下文窗口扩展至一百万个 token，支持长上下文多模态推理和长时程规划。这些进展使其能够作为主智能体或专用子智能体集成到生产工作流中，支持视频编辑、长音频与视频翻译、以音乐为条件的音乐视频或电影生成，以及基于视频的笔记或全技能创建。为解决现有智能体框架缺乏原生音频和视频支持的问题，我们发布了 Qwen-MM-Plugins，一个面向多模态生产力的轻量级开源插件框架。我们进一步将实时多模态交互视为一项系统级挑战，需要协调上下文与记忆管理、工具使用以及子智能体委派。因此，我们发布了 Qwen-Live-Harness，一个基于 Qwen3.8-Omni-Flash 构建响应式实时多模态智能体的开源框架。大量评估表明，Qwen3.8-Omni-Flash 在多模态理解、推理、长时程智能体执行和视频生产力任务上均取得了强劲表现。这些结果及配套开源工具，使 Qwen3.8-Omni-Flash 成为在研究与生产中部署原生多模态智能体的实用基础。

## Abstract
We introduce Qwen3.8-Omni-Flash, a natively multimodal agentic model for real-world multimodal productivity. Compared with previous omni models, which primarily emphasized perception and interaction, Qwen3.8-Omni-Flash substantially improves multimodal understanding and reasoning, as well as performance on long-horizon agentic tasks. These capabilities are supported by a native multimodal co-training strategy that preserves strong text-domain capabilities while facilitating the transfer of agentic capabilities from text to audio and video tasks. The model inherits the sparse mixture-of-experts (MoE) architecture of Qwen3.8-Next and extends the context window to one million tokens, supporting long-context multimodal reasoning and long-horizon planning. These advances enable integration into production workflows as a primary agent or a specialized sub-agent, supporting video editing, long-form audio and video translation, music-conditioned music video or movie generation, and video-based note or omni-skill creation. To address the lack of native audio and video support in existing agent harnesses, we release Qwen-MM-Plugins, a lightweight open-source plugin framework for multimodal productivity. We further frame real-time multimodal interaction as a system-level challenge requiring orchestration of context and memory management, tool use, and sub-agent delegation. Accordingly, we release Qwen-Live-Harness, an open-source framework for building responsive, real-time multimodal agents based on Qwen3.8-Omni-Flash. Extensive evaluations demonstrate that Qwen3.8-Omni-Flash achieves strong performance across multimodal understanding, reasoning, long-horizon agentic execution, and video productivity tasks. These results and the accompanying open-source tools support Qwen3.8-Omni-Flash as a practical foundation for deploying natively multimodal agents in research and production.

# Qwen3.8-Omni: Towards Native Omni-Modal Agents 论文总结

## 1. 核心问题与研究背景

- **现状缺口**：现有智能体系统主要集中在软件开发、文本知识工作、GUI 交互与协作辅助上，多模态能力多被当作"感知前端"使用，缺乏对**以视频为中心的多模态生产力工作流**（智能体视频剪辑、MV 生成、影视制作）的支持。
- **任务特性要求**：这类工作流不仅需要多模态感知，还需要**全局规划、时序推理、对生成内容连贯性与质量的评估**；长音视频理解本身也受益于选择性记忆、叙事追踪、目标片段回查等智能体能力。
- **三大关键挑战**：
  1. 视频输入存储/传输成本高、token 预算大，长视频处理在智能体流程中代价高昂；
  2. 多数现有 agent harness 不支持在主模型上下文内接收流式音频与视频；
  3. 全模态模型面向生产力的应用仍未被充分探索。
- **整体含义**：论文主张把"全模态"从感知/交互模型推进为**原生全模态智能体（native omni-modal agent）**，并同时提供模型与配套系统基础设施。

## 2. 方法论

### 2.1 架构（Thinker–Talker 统一架构）

- **Thinker**：混合稀疏 MoE 语言骨干（继承 Qwen3.8-Next），token mixing 结合 **Gated DeltaNet（GDN）**（以固定大小循环状态总结前文）与**交错注意力层**（直接访问上下文 token）。
  - 注意力层经 warmup 与稀疏训练阶段过渡到 **Qwen Sparse Attention（QSA）**：用轻量 indexer 对压缩 micro-block 表示打分、选择相关上下文块，核心注意力只在选中块内的原始 token 上计算。
  - 预训练原生上下文 **256K token**，后训练后扩展至 **1M token**。
- **三个感知编码器**：
  - 视觉编码器（取自 Qwen3.8-Next），处理图像与采样视频帧；
  - 通用 **AuT**：4 个 Conv2D 块下采样 16 倍 + 时间自注意力，输出 **6.25 Hz**（约每 160 ms 一个 token），以专用 Qwen ASR 生成转写作监督，覆盖 20+ 语言（中:英:其他 ≈ 3.5:3.5:3）；
  - **Spatial AuT**：并行通路，将多通道音频表示为**一阶 Ambisonics（FOA）**，对 FOA 通道做**复数 STFT 并保留实部与虚部**以保留通道间幅度与相位关系，从而捕获声源方向、距离与运动线索；支持流式（缓存上下文）与离线两种动态注意力窗训练。
- **感知与位置编码**：文本用 Qwen3.8-Next 的 byte-level BPE（词表约 250K）；音频重采样 16 kHz、128 通道 mel 谱（25 ms 窗、10 ms 跳）；保留**显式文本时间戳**；空间音频 embedding 的位置 ID 按"同一时间片共享时间索引、不同空间位置保留不同空间索引"排布，与视频帧内视觉 patch 类似。

### 2.2 四阶段预训练（均为 262,144 原生序列长度）

1. **S1 编码器对齐**：冻结 LLM，分别对齐视觉编码器、AuT、Spatial AuT（先用适配器再训编码器）；
2. **S2 General**：全参数解冻，约 **2.5 万亿 token**（文本 1.1T、音频 0.7T、图像 0.35T、视频 0.15T、视频–音频 0.35T）；
3. **S3 QSA Warmup**：冻结骨干，用骨干全注意力分布监督训练 QSA indexer（此时仍用稠密注意力）；
4. **S4 QSA Stage**：启用 QSA，联合优化骨干与 indexer，适配稀疏注意力。

### 2.3 后训练（两阶段）

- **Stage 1 多教师蒸馏**：以 Qwen3.8 基座分别经 SFT+RL 训练通用指令、基础推理、代码、智能体、视觉、音频等领域专家，生成高质量轨迹，混合后蒸馏到单一学生模型，减少跨域/跨模态干扰，为 RL 提供稳健初始策略。
- **Stage 2 统一强化学习**：覆盖文本、视觉、音频与混合模态任务（推理、代码、智能体执行、多模态理解、音频条件对话、多轮交互）；奖励同时评估**任务级正确性与交互质量**（跨模态一致性、口语查询的自然回应、语言与人设稳定、长上下文指令跟随）；长程任务按**任务结果与执行结果**而非模型自报完成度给奖励。

### 2.4 智能体与实时系统

- **信息抽象与按需访问模块**：Omni-Caption（细粒度字幕）、Omni-Video2Note（结构化文本摘要）、Omni-Memory（音视频惰性加载）、Omni-Skill-Creator（把教程/SOP 视频转为可被 harness 调用的可执行技能）。
- **Qwen-MM-Plugins**：轻量开源插件框架，把音视频能力接入既有 agent harness，含 Omni-Chatcut 等生产力模块（长音视频翻译、电影解说、音乐到 MV 生成）。
- **Qwen-Live-Harness**：实时智能体框架，支持**异步工具使用与子智能体委派**（统一适配 Qwen Code / Codex / Claude Code，提交即回执、结果异步注入上下文）、**主动交互**（对音频/视觉/时间的用户自定义条件监控，带冷却与去重）、**持久记忆**（对话记录、显式工作记忆、跨会话用户事实，词法检索 + 可选向量匹配，可选视觉记忆）。
- **Talker**：基于 RVQ token + MTP 模块建模残差码本；专用 system prompt 指定目标音色；ARIA 实现流式语音生成；因果 Code2Wav 解码器将波形重建从 24 kHz 提升到 **48 kHz**；五阶段训练（预训练 → CPT → 多语言专家 + 多教师 on-policy 蒸馏 MOPD → 轻量说话人微调 → RL：Thinker 对齐人类偏好、Talker 用 GSPO 以对齐后 Thinker 的奖励优化）。
