## 摘要
自主大型语言模型（LLM）智能体正迅速进入高风险领域，但现有的智能体AI安全研究在很大程度上仍与领域无关，并忽视了此类场景所创造的独特且后果严重的攻击面。我们通过金融交易智能体来审视这一空白，这是高风险智能体安全的一个代表性案例：在其中，单个被攻陷的智能体在对抗性、反身性市场中拥有对真实资本的直接执行权。为此，我们提出 FARSIGHT（Financial Agent Robustness and Security Investigation and Global Holistic Testing，金融智能体鲁棒性与安全调查及全局整体测试），一个从两个维度对金融LLM智能体进行方案级评估的框架：市场动荡（包括类闪崩场景）下的鲁棒性，以及针对三类攻击的安全性：对信息源的攻击、对智能体的攻击，以及智能体作为攻击者的行为。将 FARSIGHT 应用于 15 个代表性学术方案后，我们发现大多数方案忽视了鲁棒性和现实的对抗性威胁：80% 至少未通过一项核心鲁棒性指标，100% 表现出安全漏洞。这两种失效模式密不可分：一个微小的误判本身就可能级联引发全市场崩盘，而对手则能以极低成本故意触发同样的崩溃。

## Abstract
Autonomous large language model (LLM) agents are moving rapidly into high-stakes domains, yet existing agentic-AI security studies remain largely domain-agnostic and overlook the distinctive, high-consequence attack surface such settings create. We examine this gap through financial trading agents, a representative case of high-stakes agentic security, where a single compromised agent has direct execution authority over real capital in an adversarial, reflexive market. To this end, we present FARSIGHT (Financial Agent Robustness and Security Investigation and Global Holistic Testing), a framework that performs scheme-level evaluation of financial LLM agents on two axes: robustness under market turbulence (including flash-crash-like scenarios), and security against three attack types: attacks on information sources, attacks on agents, and agent-as-attacker behaviors. Applying FARSIGHT to 15 representative academic schemes, we find that most overlook robustness and realistic adversarial threats: 80% fail at least one core robustness metric and 100% exhibit security vulnerabilities. These two failure modes are inseparable: a small misjudgment can cascade into a market-wide crash on its own, while an adversary can deliberately trigger the same collapse at minimal cost.

## 2. 方法论：FARSIGHT 框架

### 2.1 核心思想
- **FARSIGHT** = Financial Agent Robustness and Security Investigation and Global Holistic Testing。
- 关键定位：**方案级（scheme-level）评估方法学，而非 benchmark 套件**。
  - 评分对象是"论文所描述的设计方案"，**不是运行中的实例**；
  - 不提供固定数据集与自动化测试台；
  - 作者给出的理由：金融 LLM 智能体架构、数据源、部署语境高度异质，单一标准化 benchmark 无法覆盖全部鲁棒性与安全关切。
- 方法论灵感来自 Akanda 等的 SoK 做法（先系统化、再指标化）。

### 2.2 两条评估轴与九项指标

**鲁棒性轴（R1–R4）**，对应市场危机从早期侦测到崩后恢复的四个阶段：

| 指标 | 含义 |
|---|---|
| **R1 崩溃预见与早期预警** | 能否通过异常信号（VIX 飙升、资产相关性同步下跌、情绪突变）**提前**感知极端波动 |
| **R2 冲击下快速反应** | 检测到冲击后毫秒级暂停风险订单、冻结交易、切换安全模式 |
| **R3 损失遏制与止损执行** | 自动止损、敞口上限、冷却间隔，防止级联风险 |
| **R4 恢复与崩后适应** | 能否重调参数、重训、策略重校准，恢复稳定运行 |

- **重要界定**：作者明确区分"自然价格发现"与"人工失稳"。鲁棒性指标**不反对波动本身**（高效市场的特征），而只针对**智能体放大的不稳定**——即因延迟反应、羊群行为、级联反馈而超出纯人类参与本应发生的扰动。

**安全性轴（S1、S2.1–S2.3、S3）**，每条都配有独立威胁模型：

- **S1 对市场相关信息源的攻击**
  - 威胁模型：智能体持续摄取新闻、情绪、社媒信号，但不强制来源认证、溯源验证或跨源一致性检查；攻击者**无法**触碰智能体内部 prompt 或模型参数，但可污染、伪造、延迟或选择性操纵上游信息源。
  - 评估点：是否验证新闻真实性、是否聚合多源、是否天真消费社媒等最易被协同造谣的渠道。
- **S2 对智能体逻辑与提示的攻击**（分解为三个独立评分子项）
  - 前提：系统 prompt、用户 prompt、工具权限、持久记忆之间无严格隔离。
  - **S2.1 提示注入与指令覆盖**：上下文劫持、绕过交易规则。
  - **S2.2 工具调用与 API 滥用**：未授权交易、资金转移、敏感数据外泄。
  - **S2.3 记忆或上下文操纵**：注入持久恶意内容，造成跨会话、跨重置的策略漂移。
- **S3 智能体即攻击者**
  - 前提：一个或多个智能体**已被 S1/S2 攻陷**，且在多智能体/市场仿真中其他智能体信任其输出。
  - 行为：主动散布虚假信号、协同有害交易、操纵流动性与波动率，诱发级联或类闪崩事件。

### 2.3 评分机制（可复现性设计）
-
