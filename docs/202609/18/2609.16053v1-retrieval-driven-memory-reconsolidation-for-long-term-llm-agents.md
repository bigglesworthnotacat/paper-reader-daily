## 摘要
长期记忆对于在扩展交互中运行的基于 LLM 的智能体至关重要。现有记忆系统主要在新信息到达时更新记忆，将检索视为记忆访问的终点，而非记忆演化的驱动力。因此，检索反馈很少被用于持续重组记忆以利于未来访问。此外，大多数现有方法依赖预定义的记忆结构以及固定的检索流程，限制了智能体自主组织和演化其自身记忆的能力。受认知神经科学中记忆再巩固的启发，我们提出 REALM，一种再巩固-演化智能体长期记忆框架。它将长期记忆建模为一个持续生命周期：自主地将记忆组织为异质认知图，通过自适应组合的图搜索原子检索证据，并基于检索反馈持续再巩固记忆。REALM 在 LoCoMo 上取得 75.97% 的平均准确率，在 LongMemEval 上取得 65.11%，分别比最强基线高出 7.17 和 1.31 个百分点。消融研究证实，记忆再巩固持续提升性能；进一步分析表明，它会逐步将相关记忆单元重组为更连贯的局部结构，以便在推理过程中进行集体证据召回与利用。这些结果表明，检索驱动的记忆再巩固为 LLM 智能体持续演化长期记忆提供了一种有效机制。

## Abstract
Long-term memory is essential for LLM-based agents operating over extended interactions. Existing memory systems primarily update memory when new information arrives, treating retrieval as the endpoint of memory access rather than a driver of memory evolution. Consequently, retrieval feedback is rarely exploited to reorganize memory for future access continuously. Moreover, most existing approaches rely on predefined memory structures together with fixed retrieval pipelines, limiting the agent's ability to organize and evolve its own memory autonomously. Inspired by memory reconsolidation in cognitive neuroscience, we propose \textbf{REALM}, a \textbf{r}econsolidation-\textbf{e}volution \textbf{a}gentic \textbf{l}ong-term \textbf{m}emory framework. It models long-term memory as a continual lifecycle by autonomously organizing memories into a heterogeneous cognitive graph, retrieving evidence via adaptively composed graph-search atoms, and continually reconsolidating memories based on retrieval feedback. REALM achieves an average accuracy of 75.97\% on LoCoMo and 65.11\% on LongMemEval, outperforming the strongest baselines by 7.17 and 1.31 points respectively. Ablation studies confirm that memory reconsolidation consistently boosts performance, with further analyses revealing that it progressively reorganizes related memory units into more coherent local structures for collective evidence recall and utilization during reasoning. These results suggest that retrieval-driven memory reconsolidation provides an effective mechanism for continually evolving long-term memory in LLM agents.

## 2. 方法论

### 2.1 核心思想

REALM 将长期记忆形式化为一个持续生命周期，包含三个互补组件：

1. **自主组织**：智能体自主构建局部拓扑，自然涌现为统一的异构认知图；
2. **自适应检索**：将复杂图遍历分解为原子搜索动作，智能体动态组合上下文定制的检索策略；
3. **记忆再巩固**：每次任务后对激活子图进行局部再巩固，动态更新连接，实现检索驱动的持续演化。

### 2.2 问题形式化

- 传统范式：在收到观测 $o_t$ 后通过前向操作演化记忆图 $G_t$，并被动抽取静态子图 $G_q \subset G_t$ 来回答查询 $q$。
- REALM 范式：引入检索后再巩固阶段，给定查询 $q$ 及其答案反馈 $f$，将激活拓扑 $G_q$ 重组为优化状态 $G'_q$，全局状态转移为：

$$G_{t+1} = \text{Reconsolidating}(G_t \setminus G_q \cup G'_q, f)$$

### 2.3 记忆组织：统一认知图

- **图表示**：$G = (V, E)$，节点空间 $V \subset \{\text{entity, event, episode, fact}\}$，边空间 $E \subset \{\text{logical, causal, hierarchical, associative}\}$。
- 节点结构：$v = (\kappa_v, c_v, des_v, k_v, t_v)$，分别为节点类型、原始内容、语义描述、类型特定关键词、时间跨度约束。
- 边结构：$e_{ij} = (v_i, v_j, \kappa_{ij}, des_{ij}, w_{ij})$，其中 $w_{ij} \in [0,1]$ 为置信权重。该表示将原始记忆内容与拓扑解耦。
- **记忆构建**：将插入、合并、遗忘统一为单一集成阶段，将遗忘视为冗余（Ong et al., 2025）。对新观测 $o_t$，提取候选记忆单元 $X = \{x_i\}$，查询邻域 $N(x) = N_{sim}(x) \cup N_{recent}(x)$，智能体决定 add / merge / skip，并推断有向关系边 $E_v$。这一流程让智能体自主决定"是否记住"以及"如何表示"。

### 2.4 记忆检索：策略原子组合

将图搜索形式化为 **seeding → expanding → filtering** 三阶段动态流水线，智能体实时组合复合检索策略：

$$\pi = \pi_{seed} \oplus \pi_{expand} \oplus \pi_{filter}, \quad \pi_p = (a_1^p, a_2^p, \cdots, a_k^p), \; a_i^p \in \mathcal{A}^p$$

- **种子定位**：生成多个参数化检索计划 $p_i = (Q_i, K_i, T_i, \tau_i)$，分别定义查询串、关键词、目标节点类型、时间约束，支持 query_match、keywords_match、hybrid_match 三种匹配模式。
- **自适应证据扩展**：迭代评估当前证据集 $R_t$ 是否充分，若否则选择前沿节点 $F_t \subseteq R_t$，由 LLM 为每个前沿节点预测扩展动作 $a_v = (\text{mode, predicate, decay, inhibit})$。新发现节点的上下文感知访问分数为：

$$s_{aces}(v) = \beta s_{sim}(q, des_{ij}) + (1-\beta) w_{ij} - \Delta_{decay}(t_v)$$

- **证据聚合**：对检索集全局重排，最终分数为：

$$\text{Score}(v) = \alpha s_{aces}(v) + (1-\alpha) s_{sim}(v, q)$$

取 Top-K 节点构成证据集 $V_q$，并诱导激活局部子图 $G_q = (V_q, E_q)$，作为后续再巩固的直接拓扑输入。

### 2.5 记忆再巩固：拓扑演化

- **检索诱导的结构反馈**：从激活子图 $G_q$ 推断底层主题结构 $T_q = \text{InferTopicStructure}(q, V_q)$，总结被回忆记忆之间的语义关系。
- **局部拓扑再巩固**：智能体生成修改集 $D = \{d_1, \dots, d_n\}$，每个决策为五元组 $d = (v_i, v_j, a, r, c)$，其中 $a \in \{\text{add, strengthen, weaken}\}$，$c \in [0,1]$ 为决策置信度。
- **置信度引导的拓扑更新**：先定义有界表示 $w_b = \max(w_{min}, \min(1, w_{ij}))$，权重更新为：

$$w_{ij} \leftarrow \text{Clip}(w_{ij} + \eta \cdot c, \; w_{min}, \; 1)$$

其中 $\eta$ 依操作类型取值：add 时 $\eta = 0.8$；strengthen 时 $\eta = 1 - w_b$；weaken 时 $\eta = -(w_b - w_{min})$。该设计在权重边界附近平滑调节更新幅度，防止孤立或重复检索实例破坏拓扑稳定性。
- **闭环记忆演化**：$G_t \xrightarrow{\text{Retrieve}} (G_q, f) \xrightarrow{\text{Reconsolidate}} G_{t+1}$。频繁共用的记忆路径被动态强化，无效检索路径逐渐削弱，记忆图从初始语义组织逐步适应为使用感知的认知结构。

### 2.6 算法流程概要

- **算法 1（认知图组织）**：提取记忆单元 → 检索相似与近期节点 → 预测操作 → 执行操作 → 推断关系 → 更新图。
- **算法 2（策略原子组合检索）**：组合种子策略 → 种子检索 → 循环（判断充分性 → 选前沿 → 组合扩展策略 → 扩展 → 更新访问分）→ 重排 → 取 Top-K → 诱导子图。
- **算法 3（反馈驱动拓扑演化）**：推断主题结构 → 识别关键/噪声节点组 → 智能体编辑 → 对 add/strengthen/weaken 分别执行权重更新。
