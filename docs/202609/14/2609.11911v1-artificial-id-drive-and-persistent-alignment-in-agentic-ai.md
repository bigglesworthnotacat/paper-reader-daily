## 摘要
智能体 AI 正从有界任务执行转向能够保留具有后果的状态、持续运行并跨任务边界进行适应的系统。这一转变带来一个控制问题，而当前的运行框架主要通过人工方式解决：目标、重试、验证、停止规则以及其他行为转换都由外部指定。我们提出人工本我（artificial id），一种用于判断行为应当继续、停止还是改变的自适应内部驱动力。在一个极简的虚拟培养皿实验中，一个规模小到无法进行通用推理、且未接收任何任务特定行为目标的控制器，通过差异化持续性发展出了有用的控制能力。当某种行为持续得更好时，同一机制会选择一种非预期的物理策略；而当已学习传感器映射的环境含义发生变化时，它随后会替换该映射。这些结果表明，自适应方向可以无需被明确指定为行为目标而涌现。使这种自适应能动性变得有用的同一种持续性，也可能让不对齐、损坏状态和非预期行为跨越任务边界持续存在。可扩展的人工本我会将具有后果的状态和自适应驱动力带过这些边界，使对齐成为持续存在的智能体系统的属性，而非模型响应或单一轨迹的属性。此类系统需要在可信观测、后果通道、持久状态、权限、身份、来源和硬约束之上，建立一个持久对齐边界。

## Abstract
Agentic AI is moving from bounded task execution toward systems that retain consequential state, continue operating and adapt across task boundaries. That shift creates a control problem that current harnesses largely solve by hand: objectives, retries, verification, stopping rules and other behavioral transitions are specified externally. We propose an artificial id, an adaptive internal drive for determining whether behavior should continue, stop or change. In a minimal virtual Petri-dish experiment, a controller too small to perform general-purpose reasoning and receiving no task-specific behavioral objective develops useful control through differential persistence. The same mechanism selects an unintended physical strategy when that behavior persists better and later replaces a learned sensor mapping when its environmental meaning changes. These results show that adaptive direction can emerge without being explicitly specified as a behavioral objective. The same persistence that makes such adaptive agency useful can also allow misalignment, corrupted state and unintended behavior to persist across task boundaries. A scalable artificial id would carry consequential state and adaptive drive across those boundaries, making alignment a property of the continuing agentic system rather than of a model response or single trajectory. Such systems require a persistent alignment boundary over trusted observations, consequence channels, persistent state, authority, identity, provenance and hard constraints.

## 2. 方法论：核心思想与关键技术细节

### 2.1 核心思想

- **功能类比而非机制等同**：id 不需要符号化表示目标，可表达为对行为过程的相对持续性或优先级；id 不必推理任务特定的动作，而是暴露当前追求的状态与相对优先级，由 ego 将其转化为任务特定的计划与行动。
- **生物学词汇的功能性使用**：稳态（维持系统在可持续区域）、习惯化样行为（对不再改善持续性的线索减少响应）、新奇寻求样行为（熟悉行为失效时增加探索）——这些描述可观察行为，而非 id 内部的独立认知机制。
- **对齐责任的分离**：ego 须准确表征任务、证据与可能结果；id 通过遭遇的状态与后果进行适应，因此其行为取决于影响持续性的环境信号与后果。

### 2.2 实验方法论（虚拟培养皿）

- **"细菌机器人（bacteria bot）"设定**：控制器小到无法进行通用推理，在含两个短程源（各产生局部场）和一个额外长程场的虚拟培养皿中移动。一个源初始含食物并定义可持续区域，另一个初始非持续（用于后续重分配干预）。长程场以估计源位置为中心，提供粗略估计。
- **持续性机制（关键技术细节）**：
  - 每个控制器通过内部时钟占据身体一段时间（生命周期）。靠近食物时，时钟消耗速度慢 **20 倍**。
  - 控制器到期后，从仍存活的控制器中均匀抽取一个**变异副本**接管同一身体。
  - 谱系若使身体保持在可持续条件中，则在种群中留存更久，有更多机会留下后代。
  - 控制器**从不观察**其剩余寿命、繁殖概率或种群适应度；也**不接收**任务特定的行为目标、奖励、分数、排名或性能梯度。
- **持续性作为选择压力**：差分持续性在种群层面提供适应度标准，但**没有任何任务特定的行为目标或性能奖励被表示或传递给活跃控制器**。这是论文的核心方法学主张。
- **身体连续性**：控制器更替时身体保持完整——位置、朝向、速度、动量延续；控制器身份不连续，但具身交互连续（在线控制器替换在具身进化中有先例）。
- **控制器容量**：感知世界中，行为由仅含 **20 个参数**的线性控制器表示，支持局部感觉运动映射，排除通用推理。
- **粗引导叠加**：同一估计驱动一个弱的比例粗引导命令，与自适应控制器输出求和；自适应控制器不接收该命令的目标或输出作为学习信号（类似残差强化学习，但残差由差分持续性塑造而非任务奖励）。

## 3. 实验设计

### 3.1 场景（三个世界，持续性规则不变，变化的是环境状态与行动之间的关系）

- **World 1（持续性找到"漏洞"）**：粗引导已足以将身体带到移动食物附近。差分持续性通过选择**近乎恒定的向后推力**进一步改善占据率——该推力使身体低于朝向更新速度，冻结朝向，将体坐标系力转化为固定世界坐标系力，与粗引导叠加后恰好停在可持续区域内。盲恒定力控制器项可复现该额外占据率；扫描恒定体坐标系力向量确认：纯后向力最大化占据率，加入侧向分量则降低。
- **World 2（局部感知变得有用）**：故意使粗估计过时，食物可移动，World 1 策略不再可靠。20 参数控制器习得使用**局部食物承载信号与身体运动**的感觉运动映射。
- **World 3（有用映射变错）**：映射收敛后，反转左右食物承载信号而可持续条件不变。此前有用的映射现在将身体转向远离食物。第二个干预将食物重分配到另一个点，观察学习影响是否从旧食物线索转向新可持续源。

### 3.2 Benchmark 与对比方法

- **主要指标**：占据率（occupancy）——种群在可持续区域内所花时间比例，在最后 20 个生命周期汇总。
- **基准（baseline）**：
  - **最佳盲恒定力基线（0.405）**：在体坐标系中扫描恒定力向量的幅度与方向取最大值，是零信息恒定推力家族的界，而非所有无传感器控制器的界。
  - **手工构建的感知转向控制器**：参考占据率 **0.674**。
- **对照条件**：
  - 移除学习到的控制器；
  - 保留变异但使控制器寿命独立于食物；
  - 冻结种群（适应停止后保留已习得映射）；
  - 两个 World 3 对照：固定变异步长（而非允许其尺度可遗传）；
  - 盲对照：读取无传感器、位置或时钟的恒定体坐标系力。

### 3.3 实验规模参数

- 每个报告条件含 **2,048 个并行谱系**，以 **3 个独立种子**重复。

## 6. 主要结论与发现

- **核心实验结论**：差分持续性作用于未接收任务特定行为目标的控制器，产生了：
  1. **自适应感觉运动控制**（World 2 中选择种群占据率 0.684/0.740/0.856，超过盲基线 0.405 和手工感知控制器 0.674）；
  2. **非预期物理策略的选择**（World 1 中选择近恒定后向推力，而非设计者预期的感知转向）；
  3. **持续运行中的再适应**（World 3 中映射反转后，可遗传变异种群占据率恢复至 0.802/0.540/0.715，而冻结种群仅 0.433/0.173/0.198，中位食物承载权重变号，替代映射在种群中扩散）。
- **重分配发现**：改变哪个环境源是可持续的，会在不提供新行为目标的情况下重定向行为——学习影响从旧食物线索转向新可持续源。
- **最小实验主张**：持续性组织的自适应控制可以在没有任务特定行为目标传递给控制器的情况下涌现。
- **架构主张**：这种驱动力可与通用推理分离，并耦合于持续运行的智能体系统中；在该系统层面，跨任务边界持续的具有后果的状态与驱动力，需要一个随之持续的**持久对齐边界**，涵盖可信观测、后果通道、持久状态、权限、身份、来源和硬约束。
- **风险主张**：一旦具有后果的状态和自适应驱动力跨任务边界持续，失败也会跨边界持续；风险面包括系统观察、适应、行动和保留状态的通道，由持续性、适应性、触及范围和交互四个变量组织。

- **对照设置周全**：盲恒定力基线、手工感知控制器、冻结种群、固定变异步长、寿命解耦等对照层层递进，有效排除更简单的替代解释。

## 8. 不足与局限

### 8.1 实验覆盖局限

- **场景单一**：仅一套模拟身体动力学、一族可持续条件、20 参数控制器；未证明持续性组织的适应能推广到更大驱动力、不同身体或与空间位置无关的可持续条件。
- **未测试跨任务边界持续性**：持续种群–身体过程展示了控制器更替中的连续性，但未测试跨任务边界的持续性。
- **未测试个体层面自我修改**：适应发生在种群和谱系层面，而非单个控制器的自我修改；结果不证明个体控制器的自我保存、意识目标、规划、依赖记忆的目标、工具使用

等能力。它也不证明“人工本我”能够在单个智能体内部作为稳定组件，在单一生涯内产生目标导向的自我修改、元认知或工具使用。

- **未测试多智能体与开放环境**：实验在单一身体、单一虚拟培养皿和固定物理规则中运行，没有涉及多智能体竞争/协作、工具调用、外部资源获取、社会规范或开放世界中的长时程任务。
- **未测试安全属性**：论文提出的持久对齐边界、权限、身份、来源与硬约束均为架构主张，实验部分没有对应实现或压力测试；因此无法说明这些机制在真实智能体系统中是否足够、是否可被自适应过程绕过。

### 8.2 理论与机制局限

- **选择压力仍依赖环境结构**：虽然控制器不接收任务特定目标、奖励或梯度，但差分持续性本身仍由环境中的可持续条件定义。换言之，适应方向并非“无环境约束地涌现”，而是由“哪些状态使谱系延续更久”这一外部结构塑造。
- **粗引导叠加可能降低结论强度**：实验中存在弱比例粗引导命令，自适应控制器负责残差式修正。这使系统更容易找到可持续区域，也意味着结果不能直接说明纯从零开始、无任何外部引导时，同样的持续性组织是否仍能产生同等适应。
- **控制器容量极低**：20 个参数的线性控制器适合隔离“无通用推理”这一变量，但也限制了行为复杂度和泛化性。论文展示的是机制存在性，而非可扩展性。
- **“驱动力”概念仍偏功能性**：论文没有给出 id 的形式化定义、更新规则或可测量指标，也未说明如何将这种驱动力从简单种群持续性推广到具有记忆、规划、语言和工具使用能力的智能体。

### 8.3 对齐论证的局限

- **风险图多为概念性推断**：Table 1 中仅少数风险被标为 Demonstrated，多数为 Implied 或 Not tested。论文的主要安全贡献是提出“持久对齐边界”的必要性，而非证明某一具体防御有效。
- **未给出对齐失败案例**：实验没有展示自适应驱动力如何导致跨任务边界的不对齐、目标漂移、权限扩张或损坏状态持续。因此，风险主张与实验证据之间仍存在较大跳跃。
- **未讨论价值学习与规范冲突**：如果 id 通过后果和持续性适应，那么“何种持续性值得追求”本身可能涉及价值选择。论文未讨论如何避免系统学会利用环境漏洞、操纵后果通道或规避监督。
- **授权边界缺少实现细节**：论文主张某些控制应保持在自适应模型之外，例如不得扩大自身权限、铸造凭证、重定义来源、擦除行动记录、授权不可逆行动；但未说明这些约束由谁执行、如何防止 ego 或 id 影响执行层，以及如何验证约束未被篡改。

### 8.4 可复现性与报告局限

- **算力与运行环境未报告**：论文未说明硬件、软件栈、运行时间、代码与数据是否公开。虽然实验规模很小，但完整可复现性仍依赖实现细节。
- **统计功效有限**：独立重复单元为 3 个种子，推断性 n = 3；谱系之间共享世界、创始抽取和随机流，不能视为完全独立。固定步长对照中种子间差异很大，说明结论对随机性较敏感。
- **诊断指标未作为纳入标准**：作者计算了“可导航性诊断”但未据此筛选运行，World 2 仅满足 5 项诊断中的 3 项。这提高了结果报告的透明度，但也意味着不同世界之间的可比性有限。
- **证据等级标注是优点，同时也是边界**：论文明确区分 Demonstrated / Implied / Not tested，避免过度宣称；但从学术验证角度看，这正说明其安全与架构主张大多仍待后续工作检验。

## 9. 总体评价与启示

- **核心贡献**：论文最重要的贡献不是证明某个智能体系统已经具备“人工本我”，而是提出并隔离了一个可检验的问题：**自适应方向能否在不向控制器传递任务特定目标的情况下，由持续性组织产生？** 虚拟培养皿实验给出了肯定但有限的概念验证。
- **概念价值**：将“驱动力”与“通用推理”功能性分离，有助于重新审视持续智能体系统的控制问题。它提示：持续运行系统中的对齐对象不应只是单次输出或单条轨迹，而应包括跨任务边界保留的状态、权限、身份、来源和后果通道。
- **方法启示**：极简模拟、低容量控制器、差分持续性选择压力和多重对照，构成了一种低成本探索“能动性起源”的路径。未来可将其扩展到不同身体、非空间可持续条件、多智能体环境以及与大型推理模型耦合的 ego 层。
- **安全启示**：论文的风险判断具有前瞻性：使自适应能动性有用的持续性，也可能使失败、偏差和不对齐持续。若要将 id–ego 架构用于真实智能体，必须把授权边界、可审计性、权限最小化、不可逆行动审批和状态来源追踪作为系统级属性，而非仅依赖模型层对齐。
- **总体判断**：这是一篇概念驱动、实验克制、证据分级清晰的论文。它更像一篇提出研究纲领和最小机制证明的工作，而非完整解决方案。其最大价值在于问题设定与架构启示，最大不足在于实验规模小、场景单一、安全主张尚未实证。
