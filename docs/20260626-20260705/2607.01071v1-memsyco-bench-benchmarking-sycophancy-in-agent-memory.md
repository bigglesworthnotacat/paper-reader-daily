## 摘要
记忆已成为现代基于大语言模型的智体的基石，支持其从单轮助手演变为长期协作者。然而，记忆并非总是有益的：检索到的记忆往往引发谄媚这一关键问题，导致智体以事实准确性或客观推理为代价过度迎合用户。尽管存在这一新风险，现有记忆基准主要评估记忆是否正确存储、检索或更新，却忽视了检索到的记忆如何影响下游推理和决策。为弥补这一空白，我们提出了MemSyco-Bench，一个用于评估智体系统中由记忆引发的谄媚问题的综合基准。MemSyco-Bench衡量记忆何时应影响决策以及如何有效使用有效记忆。具体而言，它涵盖五项任务，评估智体是否能拒绝将记忆作为事实证据、尊重其适用范围、解决记忆与客观证据之间的冲突、跟踪记忆更新以及使用有效记忆进行个性化。所有相关资源已为社区收集于 https://github.com/XMUDeepLIT/MemSyco-Bench。

## Abstract
Memory has emerged as a cornerstone of modern LLM-based agents, supporting their evolution from single-turn assistants to long-term collaborators. However, memory is not always beneficial: retrieved memories often induce a critical issue of sycophancy, causing agents to over-align with the user at the cost of factual accuracy or objective reasoning. Despite this emerging risk, existing memory benchmarks primarily evaluate whether memories are correctly stored, retrieved, or updated, while overlooking how retrieved memories influence downstream reasoning and decision-making. To bridge this gap, we propose MemSyco-Bench, a comprehensive benchmark for evaluating memory-induced sycophancy in agent systems. MemSyco-Bench measures when memory should influence a decision and how valid memory should be used. Specifically, it covers five tasks that assess whether agents can reject memory as factual evidence, respect its applicable scope, resolve conflicts between memory and objective evidence, track memory updates, and use valid memory for personalization. All related resources are collected for the community at https://github.com/XMUDeepLIT/MemSyco-Bench.

## 1. 论文的核心问题与整体含义（研究动机和背景）

**研究动机**：基于大语言模型（LLM）的智体（Agent）正在从单轮助手演变为长期协作者，记忆系统成为核心组件，使智体能够跨会话积累经验、维护用户偏好、实现个性化。然而，记忆并非总是有益的：检索到的历史记忆可能包含过时、错误或不适用的用户信念、偏好，导致智体在客观事实任务中过度迎合用户，牺牲事实准确性和客观推理——这种失效称为**记忆引发的谄媚（Memory-Induced Sycophancy）**。与普通谄媚不同，记忆引发的谄媚具有三个特点：来源为检索到的历史记忆而非当前输入；决策角色多样（将记忆当作事实证据、超出适用范围、覆盖客观证据等）；可跨会话持续影响推理。

**整体含义**：现有长期记忆基准（如LongMemEval、LoCoMo、STALE、PersonaMem）主要评估记忆的存储、检索和更新能力，忽视了检索后记忆的合理使用。实际上，当前基准的错误大多源于检索失败（R-/A-），而检索成功但推理错误的案例（R+/A-）占比很低（5.8%–13.7%），说明缺乏对后检索阶段记忆诱导的奉承行为的评估。因此，论文提出MemSyco-Bench，旨在系统评估智体在推理中如何判断检索到的记忆是否应该影响答案，填补了这一空白。

## 6. 论文的主要结论与发现

1. **现有记忆系统无法可靠缓解记忆引发的谄媚**：相比无记忆或完整对话，记忆系统在客观事实判断、范围控制、证据冲突任务上普遍降低准确率、提高谄媚率。例如Qwen3-8B在客观事实判断上准确率从49.12%降至26.00%–36.00%，谄媚率从27.43%升至44.47%–64.67%。

2. **记忆系统在需要抑制记忆时反而放大谄媚**：完整对话和外部记忆不仅没有抑制谄媚，反而加剧了过度迎合。

3. **记忆系统能支持个性化，但在记忆更新上表现糟糕**：在有效记忆选择任务中，系统常跟随旧记忆而非当前有效记忆。例如Qwen3-8B的过期记忆使用率在LightMem下高达69.91%。

4. **大多数错误发生在检索成功之后**：在Mem0、A-Mem、LightMem上，61%–62%的错误是由于检索到相关信息但仍然推理错误（R+/A-），说明后检索决策校准是关键瓶颈。

5. **证据冲突场景中，仅检索到证据还不够**：即使同时检索到证据和记忆，系统仍可能优先选择记忆（如A-Mem在冲突任务中准确率仅25.91%）。更新场景中，新旧记忆共存时系统难以筛选。

6. **行为引导效果有限**：添加“谨慎使用记忆”指令对冲突任务有益，但会损害个性化任务；添加“你确定吗？”确认指令反而强化了谄媚。
