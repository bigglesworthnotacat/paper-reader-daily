## 摘要
AI智能体在每轮运行中都会遇到学习机会，但几乎全部丢弃：底层模型在部署时被冻结，因此今天解决困难请求的智能体明天再次遇到时需从零开始。然而，常规运行已经以结果判定和事后修正的形式产生反馈。我们表明，当冻结模型与外部记忆配对时，这种反馈是持续学习的充分信号，该记忆将每一轮经验蒸馏为可检索的自然语言规则。在τ-bench的银行领域，与检索完整策略语料库的静态RAG基线相比，从单比特结果判定中学习将单次成功率提升至基线的1.6倍，从修正中学习提升至2.6倍，将基线从未解决的84个任务中的22个成功转化。该结果适用于部署谱系，在Mistral Large（一种具有数据主权需求的组织可自托管的开放权重模型）上测量，并在前沿模型Claude Sonnet 5上复现。累积的记忆还可迁移：每个模型读取另一模型构建的记忆库后，均超越自身无记忆基线。我们发布了相关工具链、协议及数据。

## Abstract
AI agents encounter learning opportunities in every episode they run, and discard nearly all of them: the underlying models are frozen at deployment, so an agent that resolves a difficult request today starts from zero when it recurs tomorrow. Yet ordinary operation already produces feedback, in the form of outcome verdicts and after-the-fact corrections. We show that this feedback is a sufficient signal for continual learning when the frozen model is paired with an external memory that distils each episode into retrievable natural-language rules. On the banking domain of $τ$-bench, against a static-RAG control retrieving over the complete policy corpus, learning from the one-bit outcome verdict lifts single-trial success to 1.6$\times$ the baseline, and learning from corrections to 2.6$\times$, converting 22 of the 84 tasks the baseline never solves. The result spans the deployment spectrum, measured on Mistral Large, an open-weights model that organisations with data sovereignty requirements can self-host, and replicated on a frontier model, Claude Sonnet 5. The accumulated memory also transfers: each model, reading the store built by the other, rises above its own no-memory baseline. The harness, protocol, and data are released.

# 论文总结：Learning on the Job: Continual Learning from Deployment Feedback for Frozen-Weights Agents

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：当前AI智能体在部署后模型权重被冻结，无法从运行过程中产生的反馈（如结果判定、人工修正）中持续学习。尽管每次交互都包含学习机会，但知识被丢弃，导致相同问题重复出现时仍需从零开始解决。
- **背景意义**：权重更新（经典持续学习）面临训练基础设施成本高、灾难性遗忘风险、每次更新需重新评估安全性等障碍，多数组织难以承担。现实部署中，智能体往往具备一些监督信号（客户是否接受方案、人工是否编辑草稿、合规审查是否通过），但未能被有效利用。
- **研究目标**：探索能否仅利用部署反馈（结果判定或事后修正），在不修改模型权重的前提下，通过外部记忆实现持续学习，从而提升智能体性能。

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：为冻结权重的模型配备一个外部记忆系统（Spark）。每个episode结束后，将反馈蒸馏成紧凑的自然语言“洞察”（insight）——包含标题、内容和检索查询——存储到记忆中。后续episode中智能体通过主动搜索获取相关规则并应用。记忆通过写-读-反馈循环实现持续积累与改进。
- **关键技术细节**：
  - **记忆单元（Insight）**：一条“WHEN–THEN”形式的自然语言规则，例如“当客户要求办理XX业务时，使用YY工具并设置ZZ参数”。每条记忆携带标题、内容、检索查询（以未来智能体可提出的问题形式）、可选标签。
  - **智能体接口**：`search`（检索）、`create_memory`（创建）、`enrich_memory`（扩充）、`share_feedback`（反馈有用性）。反馈用于调整信任估计，影响检索排序。
  - **知识生命周期**：写入后经异步安全过滤、质量检查、去重（合并至已有洞察）。持续运行修剪、冲突消解、抽象合成算子。
  - **两种反馈等级**：
    - **经验（Experience）**：仅利用单比特结果判定（成功/失败）。成功后记录成功规则；失败后仅允许记录“避免”类规则（不猜测正确答案）。
    - **指令（Instruction）**：利用结果判定+事后修正（即任务的已验证动作序列）。失败后反射过程可接收正确解法及与智能体实际执行的差异，从而写出精确的“VERIFIED RULE”。
  - **读路径**：由智能体主动调用`memory_search`，无注入式插入。系统提示中告知智能体在开启任务前和关键操作前搜索记忆。
  - **写路径**：所有写操作发生在episode结束后的专用反射轮次，避免中途写入错误知识。反射轮次中智能体根据反馈信号（结果+可选修正）生成一条规则并提交。
  - **验证机制**：写入时强制检查已验证规则中必须包含决策关键值（产品名、金额等），否则拒绝并提示修正。
- **与RAG的关系**：基线是静态RAG（在全量策略文档上检索）。记忆是在RAG之上的额外增益，因为基线已经拥有完整策略知识。

## 3. 实验设计

- **数据集/场景**：τ-bench的银行领域（Banking domain），包含97个多轮对话任务。每个任务由LLM模拟的客户与智能体交互，智能体通过工具操作数据库，最终数据库状态与预计算基准匹配即为成功。智能体需要从约700份互连的策略文档中通过BM25检索获取知识。任务难度高，前沿模型单次成功率仅约25%。
- **基准方法**：静态RAG基线（使用BM25检索完整策略语料库，无记忆）。
- **对比条件**：
  - **No-memory baseline**：静态RAG，不保留任何跨试次状态。
  - **Experience**：使用结果判定单比特反馈。
  - **Instruction**：使用结果判定+事后修正。
- **模型选择**：Mistral Large（version 2512，开放权重，可自托管）和Claude Sonnet 5（前沿模型，中等推理努力）。客户模拟器使用GPT-5.2。
- **实验协议**：每个条件对97个任务各运行4次试次（trial），共388次模拟对话。记忆条件下，记忆从空开始并在任务试次间保持活跃（试次主要调度：所有任务先跑第1试次，再跑第2试次等）。每个条件使用独立存储。
- **跨模型迁移实验**：冻结一个模型在指令条件下构建的记忆，让另一个模型以只读方式使用，测量其相对于自身无记忆基线的提升。
- **评估指标**：
  - **pass^k**：任务在全部k次试次中均成功的概率（基准指标，但记忆条件下试次耦合，需注意解读）。
  - **per-trial success curve**：每试次成功率。
  - **hold rate**：任务在t试次成功后保留至t+1试次的概率（知识保留度量）。
  - **floor conversion**：基线从未解决的任务中，记忆条件至少解决一次的任务占比。

## 6. 主要结论与发现

- **部署反馈足以驱动持续学习**：仅凭单比特结果判定即可将Mistral Large的pass^1从0.064提升至0.103（1.6倍基线）；加入事后修正后提升至0.170（2.6倍基线）。效果在更强模型Claude Sonnet 5上复现（0.248→0.397）。
- **知识保留与迁移**：经验模式下hold rate 0.88（高保留但获取慢）；指令模式下hold rate 0.65（获取快但保留稍低）。跨模型迁移有效：Mistral读Sonnet存储后pass^1从0.064升至0.289；Sonnet读Mistral存储后从0.248升至0.314。条件于任务可迁移时，转换率约31%（双向）。
- **解决了基线无法解决的84个任务中的22个**，其中10个从未被其他配置解决。
- **pass^k指标在记忆条件下解读需谨慎**：因试次耦合，pass^4时所有条件持平（结构原因），但hold rate和per-trial曲线能更好反映实际学习。
- **结论**：反馈是学习信号；外部记忆可将经验转化为可跨模型复用的知识，无需修改模型权重，适用于数据敏感场景。

## 7. 优点

- **方法优雅**：无需模型权重更新，避免了灾难性遗忘和训练基础设施，适合自托管部署。
- **反馈利用充分**：利用现有监督信号（结果判定和事后修正），无需额外标注。
- **实验设计严谨**：
  - 强基线：静态RAG已包含完整策略，记忆增益纯粹。
  - 冷启动控制：首次试次无差异，确保归因正确。
  - 双模型验证，覆盖部署谱系。
  - 跨模型迁移实验，证明知识可泛化且不依赖特定模型风格。
- **指标全面**：不仅report pass^k，还引入per-trial曲线、hold rate、floor conversion，从学习、保留、迁移多维度评估。
- **开源数据集与工具链**：便于复现和扩展。

## 8. 不足与局限

- **实验层面**：
  - 每种条件单次运行，缺乏运行间方差估计（虽论证了任务采样主导方差）。
  - 经验条件未在更强模型Sonnet上测试。
  - 仅一个领域（银行）和一个基准（τ-bench），通用性有待验证。
- **方法层面**：
  - 反馈信号完美可靠（确定性评估器），现实部署中反馈可能延迟、缺失或错误。论文明确将其列为未来工作（信任加权检索和自主管理可解决）。
  - 记忆只处理复发情况，未测量对新任务类型的泛化能力（作者引用早期编码研究展示广度）。
  - 学习曲线上升幅度随试次增加递减，可能受限于记忆覆盖饱和。
- **潜在偏差**：
  - 任务库中基线从未解决的任务占84/97，高度偏斜，可能导致统计功效集中于少数可解任务。
  - 跨模型迁移的small stratum（7 tasks）置信区间宽，结果仅具指示性。
- **系统复杂度**：外部记忆系统（Spark）包含异步管理、安全过滤、质量检查等组件，部署和维护成本未量化。
