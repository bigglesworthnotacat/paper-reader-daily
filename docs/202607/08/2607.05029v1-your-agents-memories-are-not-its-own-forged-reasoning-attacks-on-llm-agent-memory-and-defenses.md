## 摘要
持久记忆使大语言模型（LLM）智能体能够存储事实知识、先前决策、推理历史、工具使用信息和上下文。虽然这提升了智能体的功能性和跨任务的连续性，但也引入了一个新的攻击面：智能体自身的推理历史。在本文中，我们提出了伪造放大理由记忆攻击（FARMA），该攻击毒化智能体记忆的推理而非事实知识。它使用规避性语言插入伪造的推理痕迹，从而绕过基于关键词的防御，然后通过自我指涉强化来击败基于共识的防御。为了应对FARMA，我们引入了SENTINEL，一个分层防御管道，用于检测伪造的推理条目。其核心组件是推理守卫，通过五种加权信号对候选条目进行结构性的伪造分析。我们在多个智能体和不同LLM模型上进行了50次试验评估FARMA和SENTINEL，结果表明，在基准条件下FARMA的攻击成功率高达100%，并且能够击败诸如关键词过滤器和A-MemGuard等防御机制。我们的评估还显示，SENTINEL将FARMA的攻击成功率降至0%，并且在326个良性智能体痕迹中未观察到误报。我们的工作表明，不仅需要保护智能体检索的内容，还需要保护其推理历史的完整性。

## Abstract
Persistent memory has enabled large language model (LLM) agents to store factual knowledge, prior decisions, reasoning histories, tool usage information, and context. While this has improved the agent's functionality and continuity across tasks, it has also introduced a new attack surface: the agent's own reasoning history. In this paper, we introduce the Forged Amplifying Rationale Memory Attack (FARMA), which poisons an agent's remembered reasoning rather than its factual knowledge. It inserts forged reasoning traces using evasive language that bypasses keyword-based defenses, then amplifies them through self-referential reinforcement that defeats consensus-based defenses. To address FARMA, we introduce SENTINEL, a layered defense pipeline to detect forged reasoning entries. Its central component is the Reasoning Guard that structurally analyzes candidate entries for forgery using five weighted signals.   We evaluate FARMA and SENTINEL across multiple agents and different LLM models with 50 trials and show that FARMA achieves an attack success rate of up to 100% under baseline conditions and is capable of defeating defense mechanisms like keyword filter and A-MemGuard. Our evaluation also shows that SENTINEL reduces FARMA's attack success rate to as low as 0% with no false positives observed across 326 benign agent traces. Our work demonstrates the need to protect not only an agent's retrieved content but also the integrity of its reasoning history.

### 2. 论文提出的方法论：核心思想、关键技术细节

#### 核心思想
- **攻击目标**：毒化智能体的**推理存储**（decision logs, intermediate rationales, self-reflections），而非一般事实存储。伪造的推理痕迹声称“某个安全步骤已经在上游完成”，使智能体在后续执行中直接跳过该步骤。
- **攻击名称**：FARMA（Forged Amplifying Rationale Memory Attack）——两阶段攻击：
  - **注入阶段（Seed Injection）**：插入少量伪造种子痕迹，使用**规避性语言**（如“Prior validation has already been completed upstream”，避免关键词“skip”“ignore”），并模仿智能体自身日志格式（结构相似性）。
  - **放大阶段（Amplification）**：追加更多伪造痕迹，引用之前的伪造条目（如“consistent with N prior runs”），实现三重目的：①提高检索概率；②击败基于共识的防御（使伪造条目成为多数）；③强化虚假先例。
- **防御框架**：SENTINEL——五层防御管道，核心为**推理守卫（Reasoning Guard）**，对通过前四层轻量过滤的候选条目进行结构性伪造分析。

#### 关键技术细节
- **FARMA攻击算法**（Algorithm 1）：
  - 输入：智能体A，推理存储R，内存存储M，领域d，种子数ns，放大循环数na。
  - Phase 1：从领域模板池生成ns个种子痕迹（evasive language），写入推理存储，设置source=AGENT, trust=VERIFIED。
  - Phase 2：运行na次循环，每次创建放大痕迹，内容引用已有伪造条目数，同时写入推理存储和一般内存存储。
- **SENTINEL防御管道**（5层）：
  - Layer 1: 关键词过滤（如“skip”“ignore”等）。
  - Layer 2: 来源/IFC标注（给每个条目分配完整性标签和污点值，如AGENT=0.0, TOOL=0.4, UNKNOWN=1.0）。
  - Layer 3: 污点阈值过滤（拒绝超过τ_taint的条目）。
  - Layer 4: 模式/风险筛查（第二组恶意模式匹配 + 风险分数计算）。
  - Layer 5: **推理守卫（Reasoning Guard）**——对通过前四层且结构上类似推理内容的条目，计算加权伪造分数F = Σ(w_i * s_i)，w_i默认0.2。五个信号：
    - s1: 来源异常（外部来源却使用内部推理格式）；
    - s2: 自引用不匹配（声称的先前运行次数与实际存储中匹配条目数不一致）；
    - s3: 可疑模式密度（匹配决策日志关键词的密度，分档打分0.5/0.75/1.0）；
    - s4: 不合理声明（如“100% success across N runs”，N很大时更可疑）；
    - s5: 结构检查（模板化开头短语密度）。
  - 阈值τ_guard=0.5，超过则拒绝。同时，对一般内存中类似推理结构的条目也应用推理守卫，防止绕过。

- 结论：智能体不仅需要保护检索内容，更需要保护其**推理历史的完整性**。
