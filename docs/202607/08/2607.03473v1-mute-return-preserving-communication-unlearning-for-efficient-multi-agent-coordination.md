## 摘要
智能体间通信对于在部分可观测性下协调多智能体强化学习（MARL）智能体以在合作博弈中有效执行至关重要；然而，现实世界的带宽限制要求稀疏交互。先前的方法主要通过优化信息论代理来解决这一权衡。我们认为这些统计代理从根本上与真实目标不一致：一条消息可能信息量很大，但与任务的联合回报无关。在这项工作中，我们提出了面向目标效率的消息遗忘（MUTE）框架，该框架将通信减少视为一个价值引导的机器遗忘问题。MUTE 使用基于注意力的估计器严格量化反事实消息价值，并系统地遗忘从无任何通信约束训练的策略中低价值消息的传输。这是通过一个双重目标机制实现的，该机制在保持原始联合策略回报的同时，强制实现通信稀疏性。我们推导了这种稀疏化引起的性能差距的理论上界，保证了受控的回报退化。我们还在各种复杂的多智能体环境中对 MUTE 进行了实证评估，在保持与最先进基线相当的性能的同时，实现了 80% 到 90% 的带宽减少。

## Abstract
Inter-agent communication is critical for coordinating Multi-Agent Reinforcement Learning (MARL) agents under partial observability to perform effectively in cooperative games; however, real-world bandwidth constraints demand sparse interactions. Prior approaches primarily address this trade-off by optimizing information-theoretic surrogates. We argue that these statistical proxies are fundamentally misaligned with the true objective: a message can be highly informative yet irrelevant to the joint return of the task. In this work, we propose Message Unlearning for Targeted Efficiency (MUTE), a framework that views communication reduction as a value-guided machine unlearning problem. MUTE rigorously quantifies the Counterfactual Message Value using an attention-based estimator, and systematically unlearns the transmission of low-value messages from a policy trained without any communication constraints. This is achieved through a dual-objective mechanism that enforces communication sparsity while preserving the return of the original joint policy. We derive a theoretical upper bound on the performance gap induced by this sparsification, guaranteeing controlled return degradation. We also empirically evaluate MUTE on various complex multi-agent environments, achieving 80% to 90% bandwidth reduction while maintaining performance comparable to state-of-the-art baselines.

- **核心问题**：在多智能体强化学习（MARL）中，智能体通过通信克服部分可观测性，但现实世界带宽有限，需在保持任务性能的同时大幅减少通信量。现有方法（如信息瓶颈、互信息最大化）优化的是信息论代理（如互信息），而非直接最大化联合回报，导致可能保留“信息量大但回报无关”的消息。
- **研究动机**：提出应从“联合回报”而非“统计显著性”出发，识别并消除冗余通信，同时保证原策略的回报不显著下降。
- **整体含义**：将通信压缩重新定义为“价值引导的机器遗忘”问题，而非传统的多目标平衡问题，开辟了新视角。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程
- **核心思想**：
  1. 先训练一个无通信限制的专家策略（使用MASIA框架），获得收敛的联合Q函数 \(Q^*_{tot}\)。
  2. 定义**反事实消息价值（CMV）**：比较一条消息被发送与被掩蔽时联合Q值的差异，衡量该消息对回报的边际贡献。
  3. 训练一个**消息价值估计器（MVE）**（基于自注意力网络），以一次性估计所有消息的CMV。
  4. 在**消息遗忘阶段**，通过双目标损失逐步“遗忘”低价值消息的生成：
     - **稀疏性损失** \(L_{\text{sparse}}\)：对MVE估计值低于自适应阈值 \(\lambda\) 的消息施加L1正则，抑制其生成。
     - **行为锚定损失** \(L_{\text{anchor}}\)：约束当前策略的个体Q值与冻结的专家策略Q值一致，防止因消息减少导致策略崩溃。
  - 最终优化目标：\(L(\theta, \psi) = L_{\text{sparse}}(\psi) + \beta L_{\text{anchor}}(\theta, \psi)\)。
- **关键技术细节**：
  - CMV定义：\(\Delta Q_i(\tau, m) = Q^*_{tot}(\tau, a) - Q^*_{tot}(\tau, \tilde{a})\)，其中 \(\tilde{a}\) 是在掩蔽消息 \(m_i\) 后重新采样其他智能体动作的联合动作。
  - MVE采用自注意力机制，满足排列不变性和上下文依赖。
  - 阈值 \(\lambda\) 由MVE预测值的指数移动平均缩放。
- **算法流程**（三阶段）：
  1. 预训练（2M步）：训练无通信限制的MASIA策略，获得收敛的Q函数。
  2. MVE训练（0.5M步）：从回放缓冲采样，计算CMV目标，训练MVE。
  3. 通信遗忘（1.5M步）：冻结MVE和专家Q值，优化上述双目标损失，逐步稀疏化消息生成器。
- **理论保证**：推导了性能差距上界（Theorem 4.2），表明在MVE误差和有界价值近似下，回报退化可控。

## 7. 优点
- **问题重新定义**：将通信压缩从“多目标平衡”转为“价值引导的机器遗忘”，创新性强。
- **直接优化回报**：使用反事实消息价值直接衡量对联合Q值的影响，而非互信息代理。
- **计算高效**：MVE用单次前向传播估计所有消息价值，避免了Shapley值的指数复杂度。
- **理论保证**：提供了性能退化上界，并验证了实际误差在界内。
- **广泛且严谨的实验**：覆盖多种难度环境、大量消融、AUC量化选择性、归一化效率图等。
- **实用性**：训练成本与MASIA相当，推理开销小，易于集成到现有CTDE框架中。

## 8. 不足与局限
- **CMV的局部性**：CMV只考虑掩蔽单条消息，未显式枚举所有消息子集，可能忽略高阶交互（如多条消息冗余）。作者指出行为锚定提供反馈，但理论上不完整。
- **评估标准单一**：主要使用“胜率”作为性能指标，未报告其他如任务完成效率、回合奖励曲线方差等。
- **基线调优**：部分基线（如SMS）在原始文献中可能使用更长训练步数，4M步对某些方法可能不足，导致对比略有偏差（但已尽力公平）。
