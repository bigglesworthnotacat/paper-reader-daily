## 摘要
尽管自主智能体的技能优化已经引起关注，现有方法依赖于复杂的流水线。这留下了一个基本问题未解决：什么构成技能优化的最小可行流水线，其中每个组件都有理论或经验必要性证明？我们通过零阶（ZO）优化形式化技能优化，将经典对应物（中心差分、信任区域）映射到近期文献。注意到与经典ZO中的盲目数值扰动不同，技能轨迹作为可解释的调试反馈。基于Claude Code哲学和PAC学习，我们建立了收敛和泛化的三个原则：基于文件系统的轨迹探索、共识属性挖掘和独立验证门控。消除冗余后，我们提出SkillOpt-Lite。它加速收敛并优于完整SkillOpt：在GPT-5.5上提升LiveMath +8.8分，在GPT-5.4-nano上提升+25.4分，使nano模型超越由SkillOpt优化的标准GPT-5.4。最后，我们将我们的框架集成到VSCode Copilot等生产编码智能体中，使开发者能够通过一行Vibe进化智能体技能。因为我们的框架将所有智能体组件简单视为标准的可编辑代码，这个最小流水线自然地泛化到完整框架优化（HarnessOpt）。在SpreadsheetBench上，HarnessOpt使GPT-5.4-nano达到0.7758的准确率，优于运行标准流水线的更大模型GPT-5.5（0.7620）。代码可在https://github.com/EvolvingLMMs-Lab/SkillOpt-Lite获取。

## Abstract
While skill optimization for autonomous agents has gained traction, existing methods rely on complex pipelines. This leaves a fundamental question unaddressed: What constitutes a minimal viable pipeline for skill optimization, where every component is justified by theory or empirical necessity? We formalize skill optimization via Zeroth-Order (ZO) optimization, mapping classical counterparts (central difference, trust regions) to recent literature. Noting that unlike blind numerical perturbations in classical ZO, skill trajectories serve as interpretable debugging feedback. Grounded in Claude Code philosophy and PAC learning, we establish three principles for convergence and generalization: file-system-based trajectory exploration, consensus attribute mining, and independent validation gating. Eliminating redundancies, we propose SkillOpt-Lite. It accelerates convergence and outperforms full SkillOpt: improving LiveMath by +8.8 points on GPT-5.5 and +25.4 points on GPT-5.4-nano, allowing the nano model to surpass standard GPT-5.4 optimized by SkillOpt. Finally, we integrate our framework into production coding agents like VSCode Copilot, enabling developers to evolve agent skills via one line of vibe. Because our framework treats all agent components simply as standard editable code, this minimal pipeline naturally generalizes to full harness optimization (HarnessOpt). On SpreadsheetBench, HarnessOpt enables GPT-5.4-nano to achieve 0.7758 accuracy, outperforming the larger GPT-5.5 running standard pipelines (0.7620). Code is available at https://github.com/EvolvingLMMs-Lab/SkillOpt-Lite.

### 2.1 核心思想
- **形式化映射**：将技能优化建模为零阶优化（Zeroth-Order Optimization），并映射经典概念（1 点估计、中心差分、坐标下降、信任区域、控制变量）到现有文献（如 Reflexion、SkillCat、SkillAdapter、SkillOpt 等）。
- **概念分歧**：经典 ZO 依赖盲目的数值扰动，而智能体技能优化本质是一种 **语言介导的程序编译**：每轮 rollout 产生可读的轨迹（执行日志、错误信息），可作为 **可解释的调试反馈**。
- **三大原则**（基于 PAC 学习理论和 Claude Code “万物皆文件”哲学）：
  1. **文件系统轨迹探索**：将每个轨迹存储为独立文件，允许优化器通过原始文件系统工具（如 ls, cat）去探索目录，而非加载大块数据到上下文。
  2. **共识属性挖掘**：优化器必须跨轨迹提取不变的结构性模式（而非过拟合单次异常），以降低稳定性系数 β_exp，防止泛化崩溃。
  3. **独立验证门控**：验证集必须严格独立于训练集，以消除 β_exp 对模型选择的影响，保证无偏估计。

### 2.2 SkillOpt-Lite 管线（算法流程）
1. **轨迹暂存**：每批 rollout 后，将每个轨迹（包括推理过程、环境状态、得分）作为独立文本文件写入磁盘。
2. **轨迹探索**：优化器模型（如 GitHub Copilot）利用 bash 工具列出目录、归类失败模式、选择关键文件阅读（受限于固定 token 预算）。
3. **共识挖掘与最小编辑**：读取多个失败轨迹，发现共性问题，然后生成最小化的代码 diff 或补丁（遵循信任区域约束）。
4. **验证门控**：应用补丁得到候选技能，在独立验证集上评估。若得分优于当前最佳，则接受并永久覆盖磁盘上的 `best_skill.md`；否则丢弃并记录日志。

### 2.3 扩展：HarnessOpt 管线
- 将同一模型扩展到完整的 **执行框架优化**（harness optimization）。通过检视训练集轨迹，诊断架构性缺陷（如工具缺失、循环策略问题），生成配置提案，经人工批准后，进入自动闭环进化阶段。
- 关键安全机制：允许列表（只改框架脚本）、沙箱验证（编译检查 + 烟雾测试 + 全验证集）、可逆回滚（git reset + 特征开关）。

5. **泛化到框架优化**：SkillOpt-Lite 的自然扩展 HarnessOpt 能解决模型特定瓶颈（如重复循环、结果验证不充分），并产生进一步增益。
