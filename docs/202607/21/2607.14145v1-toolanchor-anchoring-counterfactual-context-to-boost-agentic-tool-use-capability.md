## 摘要
工具增强的大语言模型智能体在长期任务中表现出色，但它们通常在固定工具集上进行后训练。当任务需要新工具时，这些智能体难以有效整合这些工具，且从头重新训练通常不切实际。我们将此类工具集扩展问题的核心障碍识别为行为惯性：即智能体在拥有新工具的情况下仍倾向于依赖熟悉工具和既定推理模式的趋势。我们证明，在关键决策点注入反事实锚定上下文可以打破这种惯性，通过激发被抑制的智能体能力来恢复失败的轨迹。为了推广这一见解，我们提出了ToolAnchor框架，该框架使用教师模型假设这些反事实上下文，通过学生模拟验证它们，并通过智能体后训练内化成功的干预。在通用AI助手（GAIA）、文本搜索（BrowseComp）和视觉搜索（VDR-Bench）任务上的广泛评估表明，ToolAnchor在扩展工具集下始终表现出具有竞争力的性能。我们的工作弥合了静态后训练与动态适应之间的差距，为可扩展的智能体强化学习开辟了新路径。

## Abstract
Tool-augmented large language model agents excel at long-horizon tasks, yet they are typically post-trained on fixed toolsets. When tasks demand new tools, these agents struggle to incorporate them effectively, and retraining from scratch is often impractical. We identify the core obstacle in such toolset expansion problem as behavioral inertia: the tendency of agents to fall back on familiar tools and established reasoning patterns despite having access to new ones. We demonstrate that injecting counterfactual anchor contexts at critical decision points can break this inertia, recovering failed trajectories by eliciting suppressed agent capabilities. To scale this insight, we propose ToolAnchor, a framework that uses teacher models to hypothesize these counterfactual contexts, verifies them via student rollouts, and internalizes the successful interventions through agentic post-training. Extensive evaluations across general AI assistant (GAIA), textual search (BrowseComp), and visual search (VDR-Bench) tasks demonstrate that ToolAnchor consistently exhibits competitive performance under expanded toolsets. Our work bridges the gap between static post-training and dynamic adaptation, charting a new path for scalable agentic reinforcement learning.

## 2. 论文提出的方法论

### 核心思想
通过教师模型对失败的智能体轨迹进行诊断，在关键决策点（锚定轮次）生成一种假设性的替代决策上下文，再通过学生验证和内化，使智能体学会在新工具集下做出正确决策，从而克服行为惯性。

### 三个阶段（文字描述流程）

1. **反事实锚定上下文假设阶段（Hypothesis）**
   - 收集基座策略 πθ 在扩展工具集下失败的轨迹 D_fail。
   - 使用多个教师模型（如 Gemini-2.5-Pro、GPT-5）对每条失败轨迹进行审查，依据四条准则（下游影响、路径重定向、战略杠杆、反事实潜力）选择一个候选锚定轮次 t*。
   - 在仅使用历史信息 H_{t*-1}（不依赖未来信息或正确答案）的条件下，教师生成一个替代的思考-动作对 (τ'_t*, a'_t*)，并由环境执行得到观察 o'_t*，形成候选锚定上下文 c* = (H_{t*-1}, τ'_t*, a'_t*, o'_t*)。
   - 多个教师产生多样化的候选上下文集合 D_anchor。

2. **反事实锚定上下文验证阶段（Verification）**
   - 学生策略 πθ 从每个候选锚定上下文 c* 恢复生成完整轨迹 H'_T = Rollout(πθ, c*)。
   - 通过**双重验证**：
     - 任务级评估器 J_task ：判断最终答案是否正确（Pass@3，即3次 rollout 中任一次成功即为通过）。
     - 锚定级评估器 J_anchor ：由评判模型检查该锚定上下文是否对最终成功有实质性贡献。
   - 只有同时通过两项验证的上下文才被保留为有效锚定上下文数据集 D_eff。

3. **反事实锚定上下文内化阶段（Internalization）**
   - **局部策略更新（锚定SFT）**：仅对验证通过的锚定轮次处的思考-动作对 (τ'_t*, a'_t*) 进行监督微调，损失函数为 L_SFT = -E[log πθ(τ'_t*, a'_t* | H_{t*-1})]。
   - **策略对齐与探索（后SFT智能体RL）**：在扩展工具集上应用 GRPO 强化学习，使用二元任务级奖励（正确/不正确），将内化的局部行为与原有的整体策略对齐，同时鼓励探索新的工具使用策略。

- **关键区别**：与传统的知识蒸馏或直接模仿教师轨迹不同，ToolAnchor 将教师建议视为假设而非真值，必须通过学生自身 rollout 验证后才用于训练，从而保持数据与学生的分布一致。

## 6. 论文的主要结论与发现

1. **行为惯性是工具集扩展的核心瓶颈**：后训练的智能体在面对新工具时，仍过度依赖原有工具，表现为工具调用频率失衡。
2. **反事实锚定上下文可恢复失败轨迹**：在关键决策点替换局部决策（而非整条轨迹）即可显著提升任务成功率（VDR-Bench 从 11% 提升至 23%）。
3. **验证机制至关重要**：教师假设必须经学生 rollout 验证，避免引入噪声监督；仅依赖未验证的锚定上下文效果差。
4. **锚定SFT + 智能体RL的组合最佳**：SFT 提供精确的局部指导，RL 对齐全局策略并促进探索，两者互补提升性能。
5. **通用性和可迁移性**：ToolAnchor 不仅增强了新视觉工具的使用，还同步提升了原有文本任务的性能（GAIA +3.6%，BrowseComp +1.6%），表明内化的有效上下文能强化整体智能体能力。

## 7. 优点

- **问题定义新颖**：明确将工具集扩展问题归因于行为惯性，并引入反事实锚定上下文这一概念，视角独特且实用。
- **方法论严谨**：
  - 教师假设-学生验证-内化的三阶段设计避免了直接模仿教师轨迹的噪声和分布漂移。
  - 双重验证（任务级+锚定级）确保了数据的质量，且锚定级评判从全局判断干预的实际贡献。
  - 锚定SFT仅对关键轮次进行局部监督，防止过拟合，再通过RL整合全局。
- **实验设计全面**：涵盖通用问答、文本搜索、视觉搜索三种场景，对比了专有模型（GPT-5、Gemini等）和开源基线，消融实验覆盖了各组件影响。
- **开源友好**：基座模型（Tongyi DeepResearch）代码、权重和工具描述公开，提升了可复现性。
- **参数高效**：仅在文本LLM基础上通过工具API扩展，无需多模态对齐或大规模预训练，即可在视觉搜索任务上取得竞争力。

## 8. 不足与局限

- **教师模型多样性有限**：当前仅使用 Gemini-2.5-Pro 和 GPT-5 两种教师，未来应引入更多样化的教师以提高锚定假设的覆盖率和鲁棒性。
- **验证上下文数量有限**：仅约32%的候选上下文通过验证，被过滤的上下文可能仍含有潜在有用的信息（如部分正确的推理方向），浪费部分数据。验证机制虽然保证了质量，但可能遗漏一些“弱信号”。
- **训练数据规模较小**：每个训练集仅1500条样本，对于需要广泛泛化的工具使用能力可能仍不足。论文未探讨更大规模数据下的效果。
- **未评估更多新工具类型**：仅增加了三种视觉工具，未涵盖如代码执行工具、数据库查询等更广泛的工具扩展场景。对新工具类型（如操作性工具）的适应能力尚未验证。
- **计算资源较高**：使用8块B200 GPU，对于普通实验室可能不便宜，但相对于从头训练已大幅节省。
- **长期稳定性未测试**：在连续多次工具集扩展（如顺序加入新工具）时，行为惯性是否累积，以及是否会出现灾难性遗忘，未作讨论。
- **潜在偏差**：教师模型本身可能存在对某种推理路径的偏好，导致锚定上下文覆盖不够均衡；评判模型（Qwen3-235B）作为评估者也可能引入偏差。
