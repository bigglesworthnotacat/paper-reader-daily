## 摘要
本文针对当前大语言模型（LLM）智能体应用中的关键技术挑战，包括长程规划、稀疏奖励归因及动态环境交互，通过设计与优化智能体工作流加以解决。所提架构基于核心人工智能范式的合成：视觉智能、语言智能、生成智能、图智能、多模态智能、强化智能与智能体智能。不同于依赖静态提示且缺乏稳健感知-行动循环的传统基线模型，本方法引入部分可观测马尔可夫决策过程（POMDP）路由机制。该机制通过内部自修正奖励模型在决策轨迹执行前进行评估得到增强。通过整合多模态输入与先进强化学习原理（如近端策略优化与值函数近似），智能体保持长期结构记忆并动态调整推理路径以缓解错误累积。在ALFWorld具身仿真环境与WebShop在线导航基准上的实验表明，任务成功率与轨迹效率相比主流基线（如标准ReAct框架）绝对提升24.5%。全面的消融研究证实了奖励驱动critic模块在抑制幻觉率方面的显著贡献。本研究将强化学习与基于图的记忆的理论基础与自主智能体工作流相衔接，最终架构为复杂多步自主系统中的人工智能技术开发提供了实用、可扩展的参考框架。代码开源于 https://github.com/01Amez/RLAW_Implementation。

## Abstract
This paper addresses key technical challenges in current large language model (LLM) agent applications, including long-horizon planning, sparse reward attribution, and dynamic environmental interaction, by designing and optimizing an intelligent agent workflow. The proposed architecture is based on the synthesis of core AI paradigms: Visual, Language, Generative, Graph, Multimodal, Reinforcement, and Agent Intelligence. Unlike conventional baseline models that rely on static prompting and lack robust perception-action loops, our approach introduces a Partially Observable Markov Decision Process (POMDP) routing mechanism. This mechanism is augmented with an internal, self-correcting reward model that evaluates decision trajectories before execution. By integrating multimodal inputs and advanced reinforcement learning principles (such as proximal policy optimization and value function approximation), the agent maintains long-term structural memory and dynamically adapts its reasoning pathways to mitigate error accumulation. Empirical experiments on the ALFWorld embodied simulation environment and the WebShop online navigation benchmark demonstrate a 24.5% absolute improvement in task success rate and trajectory efficiency over mainstream baselines like the standard ReAct framework. Comprehensive ablation studies confirm the significant contribution of the reward-driven critique module in suppressing hallucination rates. This research bridges theoretical foundations of reinforcement learning and graph-based memory with autonomous agent workflows. Ultimately, the resulting architecture offers a practical, scalable reference framework for developing artificial intelligence technologies in complex, multi-step autonomous systems. Code is available at https://github.com/01Amez/RLAW_Implementation.

#### 1. 核心问题与整体含义（研究动机和背景）

-   **核心问题**：当前基于大语言模型（LLM）的智能体在自主执行复杂、多步骤任务时面临三大挑战：
    - **长程推理退化**：早期的一个小错误或幻觉会沿着推理链不断累积和放大（“级联幻觉错误”），导致整个任务失败。
    - **缺乏长期记忆**：智能体难以维护对世界状态的准确结构性表示，容易在长时间交互中遗忘关键环境约束。
    - **缺少形式化目标**：传统LLM智能体只基于最大似然估计生成动作，缺乏明确的目标导向和内部评估机制，无法主动优化决策路径，容易陷入无限循环或无效操作。
-   **整体含义**：本研究旨在解决上述问题，通过将LLM智能体的决策过程形式化为一个部分可观测马尔可夫决策过程（POMDP），并引入强化学习（RL）中的奖励信号和自修正机制，构建一个更稳健、高效和可靠的自主决策框架（RLAW）。

#### 2. 方法论：核心思想、关键技术、算法流程

-   **核心思想**：将智能体视为一个POMDP中的演员-评论家（Actor-Critic）系统。主LLM作为 **“Actor”**，负责生成候选动作；一个轻量级的**“Critic”**模型（内部奖励模型）负责评估这些动作的合理性，只有通过Critic“审批”的动作才会被提交给外部环境执行，形成一个“提出-批评-执行”的闭环。
-   **关键技术细节**：
    - **POMDP路由机制**：将智能体与环境交互建模为7元组POMDP，定义了状态、动作、观测、奖励等，并利用图记忆（Graph Memory）来近似压缩的信念状态。
    - **图记忆模块**：使用图注意力网络（GAT）维护一个结构化的语义场景图，动态更新节点（实体/物品）和边（空间/功能关系），克服传统文本上下文的记忆局限。
    - **内部Critic模型**：一个经过微调（使用LoRA）的轻量级LLM，负责评估Actor提出的候选动作。它输出一个包含逻辑检查、安全检查、评分和解释的JSON格式结果。评分低于预设阈值（τ=0.7）的动作将被拒绝，并生成自然语言反馈，指导Actor重新生成。
-   **算法流程（文字说明）**：
    1.  **生成阶段 (Actor)**：在时间步t，Actor接收当前观测(ot)和图记忆(Mt)，生成一个候选内部思维链(zt)和动作(at)。
    2.  **批评阶段 (Critic)**：Critic评估候选动作(at)的合理性与目标一致性，输出内部奖励评分(R_critique)。
    3.  **执行判定**：
        - 若 `R_critique >= τ`（阈值），动作被批准，进入执行阶段。
        - 若 `R_critique < τ`，动作被拒绝，Critic提供反馈。Actor将反馈作为新的上下文，重新生成（zt, at）。此过程最多重复3次。
    4.  **执行阶段 (Action→Environment)**：通过Critic批准的动作(at)被真正执行，环境返回一个外部稀疏奖励(R_env)和新的观测(ot+1)。
    5.  **优化目标**：使用PPO算法的目标函数，结合内部奖励(R_critique)和外部奖励(R_env)共同优化Actor的策略参数。

#### 7. 优点

-   **方法论创新**：成功地将强化学习理论（PPO、值函数）与LLM的生成能力深度结合，为智能体的自修正提供了数学上严谨的框架，超越了此前的启发式方法（如Reflexion）。
-   **实验设计严谨**：实验覆盖了不同的复杂环境（物理仿真和数字界面），对比了多种强基线，并通过详尽的消融实验证明了各模块的必要性，结论可信度高。
-   **揭示重要洞察**：发现了“更聪明的小模型胜过更笨重的大模型”这一重要现象，为业内提供了极具价值的、可落地的工程指导，强调算法创新比堆叠算力更重要。
-   **实用性强**：代码全部开源，且通过4-bit量化可在单张消费级GPU上运行，降低了研究和部署门槛。

#### 8. 不足与局限

-   **延迟增加**：内部Critic模块的引入导致推理延迟约增加80%（从1.2s/步到2.15s/步），不适合对实时性要求极高的应用场景（如高速无人机）。
-   **上下文长度限制**：模型依然受限于Transformer的上下文窗口（4,096 tokens）。在极长任务中，即使有图记忆，历史信息和Critic反馈仍可能导致“注意力稀释”和“迷失在中间”的问题。
-   **Critic模型依赖**：Critic模块本身的性能至关重要。弱Critic可能导致频繁拒绝有效动作（陷入死循环）或批准无效动作。本文的实验未充分证明Critic在不同任务上的鲁棒性和泛化能力。
-   **环境局限性**：虽然模拟了部分可观测性，但实验环境（ALFWorld、WebShop）本质上仍是基于规则的模拟器，与真实世界中物理交互的复杂性和不可预测性还有差距。
-   **奖励设计**：内部奖励函数（R_critique）由另一个LLM生成，其准确性和公平性依赖于训练数据和Prompt设计，可能存在潜在偏差。
