## 摘要
检索增强生成（RAG）已成为将多模态大语言模型（MLLM）与外部知识结合的关键范式。最近的GraphRAG方法引入结构化实体关系图以改进检索与推理，但仍受限于将知识图谱视为离线构建的静态数据结构并进行单次查询。这种静态范式与知识密集型推理的交互式、迭代特性不匹配，造成三个瓶颈：（i）以文本为中心的分割阻碍跨模态推理，（ii）冻结的结构无法纳入新证据或纠正错误，以及（iii）僵化的单次检索缺乏自适应优化。为克服这些限制，我们提出EvoGraph-R1，一种自演化的GraphRAG框架，将知识图谱重新定义为通过智能体交互塑造的动态环境。我们将检索建模为马尔可夫决策过程（MDP），其中智能体观察图状态并执行动作：查询（GraphRetrieve）、扩展（WebSearch）、细化（GraphEdit）或终止（Answer）推理。这些动作重塑超图结构并生成反馈信号，指导后续演化。通过这一闭环，超图通过整合新证据、纠正错误和细化结构不断演化，以支持多跳推理。在多模态VQA和文本QA基准上的实验表明，与现有RAG基线相比，在准确性、覆盖率和可追溯性方面均有显著提升，确立了自演化知识图谱作为跨模态基本范式的地位。

## Abstract
Retrieval-augmented generation (RAG) has emerged as a critical paradigm for grounding Multimodal Large Language Models (MLLMs) in external knowledge. Recent GraphRAG methods introduce structured entity-relation graphs to improve retrieval and reasoning. However, they remain limited by treating knowledge graphs as static data structures built offline and queried in a single pass. This static paradigm misaligns with the interactive, iterative nature of knowledge-intensive reasoning, creating three bottlenecks: (i) text-centric fragmentation that impedes cross-modal reasoning, (ii) frozen structures unable to incorporate new evidence or correct errors, and (iii) rigid single-pass retrieval without adaptive refinement. To overcome these limitations, we introduce EvoGraph-R1, a self-evolving GraphRAG framework that reconceptualizes knowledge graphs as dynamic environments shaped through agent interactions. We formulate retrieval as a Markov Decision Process (MDP) where the agent observes the graph state and executes actions to query (GraphRetrieve), expand (WebSearch), refine (GraphEdit), or terminate (Answer) the reasoning. These actions reshape the hypergraph structure and generate feedback signals that guide subsequent evolution. Through this closed loop, the hypergraph evolves by integrating new evidence, correcting errors, and refining structure to support multi-hop reasoning. Experiments on multimodal VQA and text QA benchmarks demonstrate substantial improvements over existing RAG baselines in accuracy, coverage, and traceability, establishing self-evolving knowledge graphs as a fundamental paradigm across modalities.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：现有GraphRAG方法将知识图谱视为**静态结构**——离线构建、单次查询，无法适应知识密集型推理的交互式、迭代特性。导致三个瓶颈：
  - 文本中心分割：跨模态证据被压缩为孤立的文本元组，丢失长程与跨模态依赖。
  - 结构冻结：新证据无法整合，错误无法修正。
  - 刚性检索：单次检索无自适应优化，证据不足时无法调整策略或调用外部搜索。
- **整体含义**：需将知识图谱从**被动数据结构**重新定义为**主动推理基质**，使其能与推理过程**共同演化**，从而支持多跳、跨模态的复杂推理。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想
- 将检索建模为**马尔可夫决策过程（MDP）**，其中：
  - **环境状态**：多模态知识超图（实体、关系、视觉对象、结构组织）。
  - **动作空间**：四种动作：`GraphRetrieve`（查询）、`WebSearch`（外部搜索扩展）、`GraphEdit`（插入/更新/删除）、`Answer`（终止）。
  - **奖励**：轨迹级信号——结构正确性、答案质量、计算效率。
  - **策略**：通过强化学习（Group Relative Policy Optimization, GRPO）学习最优动作选择，平衡准确性与效率。
- 形成**闭环**：智能体观察图状态 → 选择动作 → 修改图结构 → 产生反馈 → 引导后续决策 → 图与推理共同演化。

### 2.2 关键技术细节

#### （a）多模态超图构建（初始环境状态）
- **文本子图提取**：使用MLLM提取器 \(\pi_{\text{ext}}\) 从文本中抽取n元关系超边（实体集、关系类型、置信度）。
- **视觉子图构建**：对每张图像生成场景描述并提取实体和关系，所有视觉信息挂载到图像锚点节点上，保持源可追溯。
- **跨模态融合**：通过实体解析函数 \(\phi\)（字符串相似度+嵌入相似度）合并匹配的文本与视觉实体，超边重新连接合并后的节点。
- **离线索引**：使用多模态编码器（如GME）将图元素嵌入共享语义空间，支持高效向量检索。

#### （b）智能体驱动的图演化（MDP交互）
- **状态**：\(s_t = (G_t, H_t, q)\)，其中 \(G_t\) 为当前超图，\(H_t\) 为动作历史，\(q\) 为查询。
- **动作定义**：
  - `GraphRetrieve`：查询当前超图（实体邻居、超边向量检索）。
  - `WebSearch`：当图中证据不足时，构造网络搜索查询并获取外部信息。
  - `GraphEdit`：插入新实体/超边、更新已有超边（纠正错误/解决冲突）、软删除（降低低质量元素置信度）。
  - `Answer`：终止推理，基于当前图状态生成答案。
- **状态转移**：动作 \(a_t\) 通过演化策略 \(\pi_{\text{evolve}}\) 修改图结构，形成 \(G_{t+1}\)，历史更新为 \(H_{t+1} = H_t \cup (a_t, r_t, G_{t+1})\)。

#### （c）强化学习优化
- **奖励函数** \(R(\tau)\) 包含三部分：
  - 结构奖励 \(R_{\text{struct}}\)：鼓励推理步骤格式正确，每步有效得0.5分，上限1.0。
  - 答案奖励 \(R_{\text{ans}}\)：计算预测答案与真实答案的token级F1重叠。
  - 整体奖励：\(R(\tau) = -\lambda \sum c(a_t) + R_{\text{struct}} + \mathbb{I}[R_{\text{struct}}=1.0] \cdot R_{\text{ans}}\)，其中 \(\lambda > 0\) 为效率系数。
- **策略优化**：使用GRPO，通过组内轨迹比较计算优势，稳定更新策略。
