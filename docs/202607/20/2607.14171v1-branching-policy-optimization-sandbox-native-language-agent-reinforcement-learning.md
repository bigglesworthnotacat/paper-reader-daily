## 摘要
强化学习已成为训练与可执行沙盒交互的大型语言模型（LLM）智能体的主导范式。PPO、RLOO和GRPO等最先进算法从其强化学习人类反馈（RLHF）中继承了轨迹拓扑结构：对于每个提示，从初始状态独立采样N条轨迹，并通过减去组基线计算优势。这种设计忽略了智能体沙盒的一个决定性特性：它们是确定性的、可快照的，并且可以从任何中间状态恢复。我们认为这一特性使得一种根本不同的轨迹拓扑结构成为可能：不是构造N棵深度为T的独立树，而是可以构造一棵具有N个叶子的单一树，其中同层节点共享前缀，从而共享方差。我们将这一思想实例化为分支策略优化（BPO），一种沙盒原生的强化学习算法，它（i）沿主干轨迹在高熵决策点自适应地对沙盒进行快照，（ii）在每个分支点分支出K个替代动作并执行到终止，（iii）根据同层节点的回报而不是独立提示计算每步优势。我们证明该估计量无偏，并且其方差严格低于轨迹级基线，减少量等于由前缀解释的回报方差部分。在WebShop、ALFWorld和SWE-bench Verified上，以Qwen2.5-7B和Llama-3.1-8B为主干模型，在相同计算量下，BPO相比GRPO和RLOO成功率高3.6-6.1个绝对百分点，梯度范数方差减半，并且使用少38%的策略更新即可达到最佳基线性能。

## Abstract
Reinforcement learning has emerged as the dominant paradigm for training large language model (LLM) agents that interact with executable sandboxes. State-of-the-art algorithms such as PPO, RLOO, and GRPO inherit their rollout topology from RLHF: for each prompt, N independent trajectories are sampled from the initial state, and an advantage is computed by subtracting a group baseline. This design ignores a defining property of agent sandboxes. They are deterministic, snapshottable, and resumable from any intermediate state. We argue that this property enables a fundamentally different rollout topology: rather than N independent trees of depth T, one can construct a single tree of N leaves whose siblings share prefixes, and therefore share variance. We instantiate this idea as Branching Policy Optimization (BPO), a sandbox-native RL algorithm that (i) adaptively snapshots the sandbox at high-entropy decision points along a backbone trajectory, (ii) forks K alternative actions per branch point and rolls out each to termination, and (iii) computes per-step advantages from sibling returns rather than from independent prompts. We prove this estimator is unbiased and has strictly lower variance than the trajectory-level baseline, with the reduction equal to the prefix-explained portion of return variance. On WebShop, ALFWorld, and SWE-bench Verified with Qwen2.5-7B and Llama-3.1-8B backbones, BPO improves success by 3.6--6.1 absolute points over GRPO and RLOO at matched compute, halves gradient-norm variance, and matches the best baseline using 38% fewer policy updates.

## 1. 核心问题与整体含义（研究动机和背景）

- **背景**：强化学习（RL）已成为训练大型语言模型（LLM）智能体与可执行沙箱（如代码、网页、操作系统环境）交互的主流范式。当前最先进的算法（如 PPO、RLOO、GRPO）均继承了 RLHF（基于人类反馈的强化学习）的轨迹拓扑结构：对每个提示（prompt）从初始状态独立采样 N 条轨迹，然后通过减去组基线（group baseline）计算优势。
- **核心问题**：这种设计忽略了智能体沙箱的一个关键特性——沙箱是**确定性的、可快照的、并且可以从任何中间状态恢复**。也就是说，沙箱环境允许在任意中间步骤保存状态、分支并继续执行，但现有方法没有利用这一特性，导致 N 条轨迹共享的“前缀”信息被浪费，方差高、计算效率低。
- **整体含义**：作者论证了沙箱的确定性特性可以催生一种截然不同的 rollout 拓扑结构：不是构造 N 棵深度为 T 的独立树，而是构造一棵具有 N 个叶子的单一树，其中 siblings 共享前缀，从而共享方差。这为沙箱原生 RL 算法设计提供了新的范式，有望显著提升训练效率。

## 2. 方法论：核心思想、关键技术细节、算法流程

### 核心思想
- **分支策略优化（BPO）**：利用沙箱的快照-恢复能力，在主干轨迹的**高熵决策点**进行分支，生成多个 sibling 轨迹，并基于 sibling 的回报计算无偏且低方差的优势估计。

### 关键技术细节
1. **rollout 树与兄弟基线优势（sibling-baseline advantage）**：
   - 每个 prompt 构建一棵根为 s₀ 的树，包括一条主干轨迹和 M 个分支点。
   - 每个分支点 t 处，恢复快照，采样 K 个动作（包括主干动作）并各自 rollout 到终止，得到 G_t^{(k)}。
   - 使用 leave-one-out 基线计算局部优势：
     \[
     \hat{A}_{\text{BPO}}(s_t, a_t^{(k)}) = G_t^{(k)} - \frac{1}{K-1} \sum_{j \neq k} G_t^{(j)}.
     \]
   - 对于分支点之前的步骤，通过折扣 λ 将局部优势向后传播。

2. **熵驱动分支调度（Entropy-driven branch scheduling）**：
   - 计算主干每一步的 token 级 Shannon 熵 Hₜ。
   - 在满足最小间距 Δₘᵢₙ（默认 64）的条件下，选择熵最高的 M 个步骤作为分支点。
   - 其动机：高熵点对应策略不确定性最大的步骤，分支可产生更多样化的回报，增大方差缩减潜力。

3. **树结构损失**：
   - 使用标准 PPO-clip 目标，但树上的每个 (s,a) 元组均贡献一项梯度，意味着梯度会按叶子数量隐式加权。
   - 损失函数：
     \[
     L_{\text{BPO}}(\theta) = -\mathbb{E}_{\mathcal{T}_x} \left[ \sum_{(s,a) \in \mathcal{T}_x} \min\left( \rho_\theta(s,a) \hat{A}, \text{clip}(\rho_\theta(s,a), 1-\epsilon, 1+\epsilon) \hat{A} \right) \right] + \beta\, \text{KL}(\pi_\theta \| \pi_{\text{ref}}).
     \]

4. **理论保证**：
   - **Theorem 1**：兄弟基线优势估计是无偏的。
   - **Theorem 2**：与 GRPO/RLOO 的轨迹级 leave-one-out 优势相比，BPO 的方差严格更小，减少量等于前缀可解释的回报方差部分，即 \(\frac{K}{K-1} \text{Var}_{\tau_{0:t}|s_0}(V^\pi(s_t))\)。
   - **Proposition 1**：在固定计算预算下，为了最小化梯度方差，应尽可能增加分支点数量 M 而保持 K 较小（例如 K=2 理想，但实证中 K∈{4,8} 更优）。

### 算法流程（文字说明，对应 Algorithm 1）
1. 对每个 prompt 并行执行：
   - 采样一条主干轨迹并记录每步熵。
   - 选择 top-M 高熵点（满足间距约束）作为分支点。
   - 对每个分支点：快照当前状态 → 恢复快照并采样 K-1 个 sibling 动作 → 分别 rollout 到终止 → 记录各 sibling 的回报。
2. 用公式 (3) 计算每个分支点的兄弟基线优势，再用公式 (4) 向后传播。
3. 使用公式 (5) 的损失函数更新策略参数 θ。
