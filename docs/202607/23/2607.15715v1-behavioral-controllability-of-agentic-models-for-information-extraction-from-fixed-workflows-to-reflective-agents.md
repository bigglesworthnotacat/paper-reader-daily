## 摘要
大型语言模型（LLM）代理越来越多地用于复杂的信息抽取任务，但尚不清楚反思和记忆等代理组件是否能比固定的LLM工作流程带来可观察且可控的改进。我们通过会议论文数据集抽取来研究这一问题，系统必须识别学术PDF中提到的数据集并生成结构化记录。我们将固定工作流程基线方法与反思型代理变体进行比较，并指定了一个优化的代理条件（S2），该条件通过更丰富的PDF工具和动态工具选择扩展了相同的任务。我们的评估侧重于过程级行为——包括工具执行、重试、反思、记忆使用、运行时和故障恢复——同时将抽取覆盖率和字段完整性作为次要结果度量。本文描述了代理机制何时改变系统行为，这些变化是否改善了任务完成情况，以及观察到的故障模式如何在相同的评估框架下推动优化代理设计。

## Abstract
Large language model (LLM) agents are increasingly used for complex information-extraction tasks, yet it remains unclear whether agentic components such as reflection and memory lead to observable and controllable improvements over fixed LLM workflows. We study this question through conference-paper dataset extraction, where a system must identify datasets mentioned in scholarly PDFs and produce structured records. We compare a fixed workflow baseline with reflective agent variants and specify an optimized agent condition (S2) that extends the same task with richer PDF tools and dynamic tool selection. Our evaluation emphasizes process-level behavior--including tool execution, retries, reflection, memory use, runtime, and failure recovery--while treating extraction coverage and field completeness as secondary outcome measures. The paper characterizes when agentic mechanisms change system behavior, whether these changes improve task completion, and how the observed failure modes motivate an optimized agent design under the same evaluation harness.

## 6. 主要结论与发现
- **RQ1（决策过程差异）**：固定工作流是单次流水线，无恢复机制；代理将每个步骤表示为带有观察、反思、学习和调整的动作，产生更丰富的行为轨迹，支持质量触发的重试。
- **RQ2（反思和记忆的影响）**：代理条件产生明显的过程变化（日志行数从S0的7084行增加到S1的50189行，反射提及近2000次，重试提及2222次）。但输出记录仅从158增加到165-168，增幅有限。LLM反思相比规则反思只多增加3条记录，其主要价值在于提供更具体的诊断建议。
- **RQ3（系统优化启发）**：观察到的失败模式（如链接发现率低、反思诊断不充分）直接驱动了S2的设计（更丰富的PDF工具、动态规划、专用接地工具）。
- **其他发现**：链接发现率在所有条件下均低于20%，表明这是一个独立于代理框架的瓶颈。

## 7. 优点
- **过程级评估框架创新**：提出“行为可控性”概念，并操作化为可观察性、可配置性、可复现性、可比较性。日志、元数据、清单等过程记录成为评估的核心，弥补了现有基准只重结果的不足。
- **细致的系统设计**：将代理行为分解为可追踪的动作、反思、重试、记忆注入等，每个环节都有明确参数，方便调控和复现。
- **案例研究具体生动**：三个案例清晰展示了正常执行、规则触发重试、LLM反思诊断的不同场景，有助于理解代理的优势和局限。
- **积极公开设计细节**：包括环境设置、提示模板、日志结构、输出模式等，有利于他人复现和扩展。

## 8. 不足与局限
- **实验覆盖不足**：仅单次运行，无多次重复，统计不可靠。仅有三个条件完成，消融实验太少（只对比了LLM反思）。S2设计缺乏数值验证。
- **缺乏黄金标准**：无法评估抽样的准确性（精确率、召回率），只能依赖记录数量和重合程度，存在验证偏差风险。
- **模型和任务单一**：仅使用`openPangu-Embedded-7B`一个模型，且任务局限在NeurIPS论文数据集抽取，结论的可迁移性存疑。
- **代理与提示策略混淆**：代理条件同时改变了架构、提示、重试策略，无法将改进归因于单一组件。
- **成本与复杂性**：代理条件需要更多LLM调用和日志处理，提高了运行时成本，且日志解读门槛高，对于简单批处理任务可能不实用。
- **PDF解析依赖**：结果强烈依赖于PDF解析质量和提取文本窗口，这些因素可能引入系统性偏差。
