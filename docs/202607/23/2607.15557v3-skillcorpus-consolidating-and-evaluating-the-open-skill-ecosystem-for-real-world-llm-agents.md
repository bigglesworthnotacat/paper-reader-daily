## 摘要
智能体技能，即将可重用的程序性知识打包成SKILL文件供LLM智能体使用，是扩展智能体能力的一种流行机制。公共仓库中托管着大量且不断增长的此类文件，但这些工件碎片化、冗余且质量参差不齐，其实际价值尚不明确。一个核心问题仍然悬而未决：如何将这些开源SKILL生态系统整合成一个可用语料库，以及它在何种程度上能提升真实世界智能体任务的表现。我们提出SkillCorpus，一个大规模聚合、整理、匹配和评估开放技能生态系统的框架。它通过多阶段管道从约821,000个爬取的技能中筛选出96,401个技能，并按16类分类法和三个质量维度（实用性、鲁棒性、安全性）进行组织，同时搭配一个微调的检索与选择栈来匹配任务相关技能。我们在三个基准测试（SkillsBench、GDPVal、QwenClawBench）、两个测试框架和两个开源基座上评估端到端性能，并进行前沿鲁棒性检查。整合SkillCorpus在所有三个基准测试中均取得一致提升，其中SkillsBench上提升最大（+7.5个百分点）。操作分析将提升归因于覆盖边界和框架边界。据我们所知，SkillCorpus是首个端到端说明经过整理、检索服务的社区语料库何时以及何时不能改善真实智能体任务的工作。数据集、模型和代码将在接收后发布。

## Abstract
Agent skills, SKILL files that package reusable procedural knowledge for an LLM agent, are a popular mechanism for extending agent capabilities. Public repositories now host them in large and growing numbers, yet these artifacts are fragmented, redundant, and uneven in quality, and their value in practice is unclear. A core question remains open, namely how to consolidate this open-source SKILL ecosystem into a single usable corpus, and what bounds its benefit on real-world agent tasks. We present SkillCorpus, a framework that aggregates, curates, matches, and evaluates the open skill ecosystem at scale. It filters ~821,000 crawled skills through a multi-stage pipeline into 96,401 skills organised by a 16-class taxonomy and three quality facets (utility, robustness, safety), and pairs them with a fine-tuned retrieval-and-selection stack that matches task-relevant skills. We evaluate end-to-end across three benchmarks (SkillsBench, GDPVal, QwenClawBench), two harnesses, and two open backbones with a frontier robustness check. Integrating SkillCorpus yields consistent gains across all three benchmarks, largest on SkillsBench (+7.5 pp). An operational analysis traces the gains to a coverage boundary and a harness boundary. SkillCorpus is, to our knowledge, the first end-to-end account of when a curated, retrieval-served community corpus improves real agent tasks, and where it does not. The dataset, models, and code will be released upon acceptance.

-   **核心问题**：开源社区中涌现了大量 LLM 智能体技能，但这些技能**碎片化、冗余且质量参差不齐**，其在实际任务中的价值尚不明确。论文旨在回答两个关键问题：

-   **研究背景**：LLM 作为智能体时，其能力受限于自身。将可重用的程序性知识外化为技能文件是一种流行且有效的范式。然而，现有社区技能库缺乏统一整理、质量管控和检索机制，导致其实际应用效果不稳定，有时甚至无法超越无技能的基线。

### 2. 论文提出的方法论

-   **核心思想**：提出 SkillCorpus 框架，通过一个端到端的流程，将碎片化的开源技能生态系统**整合、筛选、匹配**，最终服务于真实世界的智能体任务。
-   **关键技术细节**：框架包含四个阶段：
    1.  **聚合与筛选**：
        -   从 62 个来源（GitHub 仓库、列表、市场等）抓取约 82.1 万个原始技能文件。
        -   通过一个六阶段管道进行筛选：
            -   **阶段 1-2**: 基于结构（解析、长度/格式）过滤。
            -   **阶段 3**: **两级去重**。通过精确指纹（内容/名称）和语义嵌入（余弦相似度 > 0.9）剔除冗余，占总减少量的 64%。对边界案例使用 LLM 判决。
            -   **阶段 4**: 使用 LLM 评估工具对每个技能进行**三维质量评分**（见下）。
            -   **阶段 5**: **安全硬性门控**（排除注入、恶意代码等）和**开源许可过滤**（仅保留 OSI 批准的宽松许可）。
            -   **阶段 6**: 附加源先验、检索嵌入和索引。
        -   最终得到 **96,401 个活跃技能**。
    2.  **三维质量框架**：
        -   **效用**: 评估技能描述是否清晰、范围明确。
        -   **鲁棒性**: 评估技能主体内容是否与描述一致，内部连贯。
        -   **安全性**: 评估是否存在安全风险（注入、数据泄露等）。
        -   三个维度相对独立，其中安全性维度与另两个相关性低。
    3.  **分类与组织**：采用一个包含 16 个类别的单标签分类法，涵盖开发、数据、写作等，能够良好覆盖社区技能的分布。
    4.  **检索与选择栈**：
        -   **召回和重排**: 微调 Qwen3-Emb-0.6B 和 Qwen3-Rank-0.6B 模型进行候选召回和重排。在去重后的数据集上训练，提供更清晰的对比学习信号。
        -   **LLM 选择器**: 对重排后的 Top-K 候选，由一个 LLM 模型读取完整技能内容后，最终选择 0-2 个最相关的技能注入到智能体提示中，确保精确性和上下文预算。
        -   **（可选）查询重写器**: 将任务描述中的术语标准化。

        -   **GDPVal**: 220 个真实世界经济任务（法律、金融、设计等）。

-   **智能体框架（Harness）**：使用了两个符合 SKILL.md 标准的独立框架：OpenClaw 和 Raven。
-   **对比方法**：
    -   **无技能基线**：每个（框架，基座）组合下，不加技能。

### 6. 论文的主要结论与发现

-   **一致性改进**：集成 SkillCorpus 在所有三个基准测试上带来**一致的正面增益**，其中 SkillsBench 增益最大（平均 +7.5 pp）。
-   **性能边界**：增益受到**两个边界**的限制：
    1.  **覆盖率边界**：当语料中缺乏任务领域匹配的技能时，增益为零或甚微。增益大小与检索到的最高分技能的相关性正相关。
    2.  **框架边界**：不同的智能体框架对技能的利用程度不同。Raven 框架在需要执行-验证-修复循环的任务上（SkillsBench）优于 OpenClaw，因为它更完整地执行了技能内容。这意味着技能的效用是技能和框架的共同属性。
-   **语料筛选与检索栈均重要**：消融实验表明，无论是用原始语料替代筛选后语料，还是用现成模型替代微调检索栈，性能都大幅下降，表明两者都不可或缺。
-   **语料库的价值来源**：其价值主要源于**广覆盖**和**质量门控**（安全、许可），而非高质量评分对任务预测的直接驱动。高质量评分更多服务于去重和排序辅助。
-   **总结**：这是首个端到端证明，经过精心筛选和检索的社区技能语料库能够切实提升真实世界 LLM 智能体任务的表现，并明晰了其起作用的条件和限制。

### 7. 优点

-   **端到端框架**：提出了一个从原始社区技能到最终任务评估的完整、可复现流程，具有很强的实用价值。
-   **大规模开源资源**：释放了 96,401 个经过许可审计、可直接商用的技能，以及配套的微调模型和代码，这对该领域研究有重要贡献。
-   **深入的分析**：超越了简单的性能报告，深入分析了增益来源（覆盖、框架），并通过正面和负面案例（拯救与失误）直观展示了技能的工作原理。
-   **严谨的实验设计**：考虑了多种维度（基准、框架、基座），进行了统计显著性检验和消融研究，结论可信度高。

### 8. 不足与局限

-   **实验覆盖深度不均**：优先考虑了广度（多种组合），但在高基线 LLM 评判基准上，单次单元增益受噪声影响不显著，需要更多重复和种子来收紧单个单元的估计值。
-   **文本级技能评估**：对技能的质量和安全评估基于 LLM 对文本内容的评判，而非在沙盒中执行。这存在风险（漏判/误判）。属于设计上的权衡。
-   **评判偏见**：质量、安全、分类标签均来自单一 LLM 评判，未经人类黄金标注或替代模型交叉验证，评判偏见会传播到最终语料库中。
-   **基准和框架覆盖有限**：虽然选择了三个互补的基准和两个主流框架，但仍受限于英语主导的工作流和特定的框架/任务类型，外部有效性有待进一步验证。
-   **快照性质**：语料库是 2026 年第二季度生态系统的快照，社区仍在不断演变。虽然框架支持定期重建，但论文本身未研究时间动态。
