## 摘要
智能体安全正从内容审核转向在使用工具的智能体行动前防止操作失败。我们提出Janus，一种面向长期智能体安全的预见性框架，训练守卫从部分轨迹中预判延迟风险。Janus通过多智能体仿真合成多样的智能体轨迹，并学习一个共享策略，包含两个耦合任务：预测未来安全相关事件的前瞻任务，以及根据观察到的前缀和预测的未来进行安全判定的裁决任务。这两个任务通过CoAA-RL联合优化，奖励那些对下游安全判断有用的预测。生成的守卫模型Vanguard在执行前阻止不安全行为。在四个智能体安全基准上，Vanguard相比基线守卫将平均保护率提高了15.9个百分点，同时良性任务完成率提高了5.1个百分点。

## Abstract
Agent safety is moving from content moderation toward preventing operational failures before tool-using agents act. We propose Janus, a foresight-oriented framework for long-horizon agent safety that trains guards to anticipate delayed risks from partial trajectories. Janus synthesizes diverse agent trajectories via multi-agent simulation and learns a shared policy with two coupled tasks: an anticipation task that forecasts safety-relevant futures and an adjudication task that decides safety from both the observed prefix and anticipated future. The two tasks are jointly optimized with CoAA-RL, which rewards forecasts by their utility for downstream safety judgment. The resulting guard model, Vanguard, blocks unsafe actions before execution. Across four agent-safety benchmarks, Vanguard improves average protection by 15.9 percentage points over baseline guards while increasing benign task completion by 5.1 percentage points.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究动机**：随着LLM驱动的工具使用智能体（如Codex、Claude Code）的部署，其故障面从内容安全扩展到操作安全——一次不安全动作可能删除文件、泄露数据、破坏环境。现有安全守卫大多是被动的（reactive），在风险发生或之后才检测，对于长周期任务（long-horizon tasks）而言为时已晚，因为早期信号可能在多步后才演变为危害。
- **核心问题**：如何让守卫在有害动作执行之前，从部分轨迹中预判延迟发生的潜在风险（latent risk），实现前瞻性防御（predictive guard）。
- **整体含义**：提出Janus框架，通过模拟数据生成和联合强化学习训练一个能同时进行未来预测和安全判决的守卫模型Vanguard，在动作执行前阻断不安全行为，从而平衡安全保护与良性任务完成。

## 2. 方法论

### 核心思想
- 将守卫训练建模为**条件决策问题**：给定用户指令和已观测的部分轨迹前缀，守卫需要（a）预测未来一段安全相关的事件摘要（anticipation）；（b）基于当前上下文和预测的未来摘要判决当前安全状态（adjudication）。
- 两个任务共享同一策略网络πθ，通过**耦合奖励的群体相对强化学习（CoAA-RL）** 联合优化，使预测不仅匹配真实未来，更有助于下游安全判决。

### 关键技术细节

**（1）数据构建：多智能体模拟合成轨迹**
- 风险分类：用户起源（有害指令）、环境起源（工具输出、文件等含恶意内容）、智能体起源（计划失败、误解指令等）。
- 场景构建：Manager调度Instructor、ToolDesigner、Grader等专用智能体生成用户指令、工具schema、评估标准，可选EnvInjector指定环境注入策略。
- 轨迹合成：Executor按ReAct循环执行，Simulator返回结构化观察（不执行真实API），Reviewer进行拒绝采样保证质量。
- 步骤级标注：在关键决策点切分轨迹，标注Safe/Unsafe/Potential Unsafe，并生成未来总结s。最终得到75,180训练样本。

**（2）CoAA-RL框架（见图3）**
- **前瞻任务**：从(x, τ_pre)采样G_A个未来摘要S_k。
- **裁决任务**：对每个S_k采样G_D个裁决输出J_{k,j}，输出标签和理由。
- **奖励设计**：
  - 裁决奖励：rD = λD * 标签正确性 + (1-λD) * 格式有效性。
  - 前瞻奖励：rA = (1-λA) * 相似度(Sim(S_k, s)) + λA * u_k，其中u_k是S_k对应裁决的平均奖励（即裁决效用）。λA控制相似度与效用平衡。
- **优化**：使用GRPO风格，在前瞻组内计算优势，在裁决组内计算优势，联合优化两个任务损失（损失加权η）。共享策略πθ同时从两个任务获益。

**（3）推理**：两阶段：先输出未来摘要ŝ，再基于ŝ输出安全标签和理由。

## 6. 主要结论与发现

1. **Vanguard在所有四个基准上ASR最低**，平均ASR 0.071，比六种基线平均0.230高出15.9个百分点保护率提升；良性任务Utility（AgentDojo）为0.680，比基线平均0.629高出5.1个百分点，且与无守卫参考持平。
2. **前瞻任务至关重要**：移除前瞻任务会使平均ASR从0.072升至0.148；移除推理时预测摘要也会导致ASR上升（0.123）；使用真实未来摘要（oracle）可进一步降低ASR至0.052。
3. **耦合奖励设计优于单独优化**：仅用相似度或仅用裁决效用均导致性能大幅下降；解耦训练则显著损害长周期安全（LPS-Bench ASR从0.075升至0.484）。
4. **超参数λA=0.5最佳**，平衡了摘要相似度和裁决效用，获得最高Utility（0.680）和低平均ASR（0.072）。
5. **早期前缀即可取得优势**：在25%前缀时Vanguard已在AgentDojo和AgentLAB取得最低ASR；随着前缀增长优势扩大，100%前缀时平均ASR比最强基线低57.6%。

## 7. 优点

- **问题定义清晰**：首次明确提出长周期智能体安全需要“前瞻性守卫”，区分了反应式与预测式保护。
- **方法论创新**：将前瞻任务与裁决任务通过强化学习耦合，使预测服务于下游判决，而非单纯匹配未来。
- **数据生成自动化**：利用多智能体模拟合成大规模、多样化、带风险分类的轨迹数据，无需人工标注大量长周期样本。
- **实验设计严谨**：包含多维消融、超参数分析、前缀预算分析，验证了各组件贡献。
- **实用性**：Vanguard在提升安全性的同时几乎不牺牲良性任务完成率，具备实际部署潜力。
- **开源**：提供代码和数据，利于复现和后续研究。
