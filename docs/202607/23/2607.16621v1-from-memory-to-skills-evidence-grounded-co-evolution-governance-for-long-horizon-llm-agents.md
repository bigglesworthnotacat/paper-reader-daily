## 摘要
现有的面向长期地平LLM智能体的记忆系统通常将先前的轨迹作为被动上下文检索，而不是将其转化为可执行的能力。本文提出MSCE，一种无需训练的“记忆-技能协同进化”框架，它将智能体经验组织为基于步骤的轨迹、可重用的过程性策略和声明性环境认知。MSCE将具有正估计增益的、基于证据的L2策略固化为可调用的技能，这些技能保留证据链接、适用边界、决策指导、验证规则和可靠性估计。它进一步引入了反思加权价值回溯填充，通过密集的局部自我反思传播稀疏的终端反馈，从而产生经过证据校准的轨迹价值，以管理记忆和技能的演化。在EvoAgentBench和LoCoMo上的实验表明，MSCE显著优于最先进的技能增强和记忆驱动智能体基线，展现出强大的跨领域迁移能力和终身演化能力。

## Abstract
Existing memory systems for long-horizon LLM agents often retrieve prior traces as passive context rather than converting them into executable capabilities. In this paper, we propose MSCE, a training-free Memory--Skill Co-Evolution framework that organizes agent experience into grounded step traces, reusable procedural policies, and declarative environmental cognition. MSCE crystallizes evidence-backed L2 policies with positive estimated gain into callable skills that retain evidence links, applicability boundaries, decision guidance, verification rules, and reliability estimates. It further introduces reflection-weighted value backfilling, which propagates sparse terminal feedback through dense local self-reflections to produce evidence-calibrated trace values for governing memory and skill evolution. Experiments on EvoAgentBench and LoCoMo demonstrate that MSCE significantly outperforms state-of-the-art skill-augmented and memory-driven agent baselines, exhibiting strong cross-domain transferability and lifelong-evolution capabilities.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：现有LLM智能体的长期记忆系统大多将历史交互轨迹作为被动上下文检索，而不是转化为可执行的能力。例如，重复的插件安装、文件编辑等操作仍被拆解为步骤推理，导致大量重复思考和令牌消耗。同时，直接从噪声轨迹中提取技能容易过拟合，且终端反馈稀疏延迟，导致步骤级信用分配困难。
- **背景**：长时域、多步骤、用户特定的任务（如工具使用、文件编辑、应用交互）要求智能体具备长期记忆。现有方法分为事实记忆（存储原始交互）和经验记忆（存储反思、推理痕迹），但都缺乏将经验转化为可调用技能的能力。
- **整体含义**：MSCE通过记忆-技能协同进化，将组织好的经验（三级记忆层次）中的证据支持、正增益、稳定的过程性策略固化为技能，实现从被动记忆到主动技能执行的跨越，从而提升长时域任务效率与泛化能力。

## 2. 论文提出的方法论

- **核心思想**：构建三级记忆层次（L1痕迹、L2策略、L3环境认知），并通过反射加权值回溯填充将稀疏终端反馈转化为细粒度步骤价值信号，用于指导记忆和技能的演化；只有经过证据支持、正增益、稳定性检查的L2策略才能被固化为可调用的技能。

- **关键技术细节**：
  1. **三级记忆层次**：
     - **L1痕迹记忆**：存储每个交互步骤的（状态、动作、观察、自我反思、价值），作为可信证据基础。
     - **L2策略记忆**：从跨情景的L1痕迹中归纳出可重用的过程性策略，包含触发条件、过程描述、验证规则、适用边界、支持证据集。利用价值阈值和跨情景最小证据数来触发归纳。
     - **L3环境认知记忆**：抽象出关于环境的结构和约束的声明性知识（实体、规律、约束），链接到支持它的L2策略。
  2. **技能结晶与调用**：
     - 符合两个门控条件（保留支持证据且正增益 > 阈值；最近证据与当前触发/过程/边界一致）的L2策略被提升为技能。
     - 技能包含触发、过程、验证、边界、证据锚点、决策指导、可靠性估计。结晶后还需通过模式检查和覆盖测试。
     - 部署后通过平滑成功率估计可靠性，影响检索优先级。
  3. **反射加权价值回溯填充**：
     - 公式：\( V(f_{i,t}^{(1)}) = \alpha_{i,t} R_i + (1-\alpha_{i,t})\gamma V(f_{i,t+1}^{(1)}) \)，其中 \(\alpha_{i,t}\) 由反思质量评分得到（忠实、因果、可迁移、具体）。
     - 将稀疏终端反馈 \(R_i\) 借助密集自我反思分布到每个步骤，产生证据校准的步骤价值。
  4. **在线更新流程**：每集结束后异步执行：持久化L1→收到反馈后回溯价值→更新L2策略（关联/归纳）→触发L3抽象→检查技能资格→结晶/验证/部署。

- **公式与算法**：
