## 摘要
我们提出Agents-A1，一个35B混合专家智能体模型，通过缩放智能体广度达到万亿参数级别的性能。我们从两个角度研究智能体广度缩放：缩放长程轨迹和缩放异构智能体能力。为支持这一目标，我们构建了一个长程知识-行动基础设施，连接外部知识、行动、观察和验证器结果，生成平均长度为45K令牌的智能体轨迹。基于此，我们采用三阶段方案训练Agents-A1。首先，进行全领域监督微调，使基座模型与广泛智能体行为对齐。其次，训练领域级教师模型以捕获各领域的专业知识。第三，提出一种多教师领域路由的在线策略蒸馏方法，结合显著词汇对齐，提高跨不同领域的知识迁移效率，将六个异构领域统一到一个可部署的学生模型中。Agents-A1在长程智能体基准上取得了强大且广泛的表现。与具有1万亿参数的模型（如Kimi-K2.6和DeepSeek-V4-pro）相比，Agents-A1在SEAL-0（56.4）、IFBench（80.6）、HiPhO（46.4）、FrontierScience-Olympiad（79.0）和MolBench-Bind（56.8）上取得了领先结果，并在SciCode（44.3）、HLE（47.6）和BrowseComp（75.5）上保持高度竞争力。我们希望这项工作为社区提供一条使用35B智能体在长程任务上达到或匹配1T模型性能的实用路径。

## Abstract
We introduce Agents-A1, a 35B Mixture-of-Experts Agentic Model that reaches trillion-parameter-level performance by scaling the agent horizon. We investigate agent-horizon scaling from two perspectives: scaling long-horizon trajectories and scaling heterogeneous agent abilities. To support this goal, we build a long-horizon knowledge-action infrastructure that connects external knowledge, actions, observations, and verifier outcomes, producing agentic trajectories with an average length of 45K tokens. Based on this, we train Agents-A1 with a three-stage recipe. First, we perform full-domain supervised fine-tuning to align the base model with broad agentic behaviors. Second, we train domain-level teacher models to capture specialized expertise in each domain. Third, we propose a multi-teacher domain-routed on-policy distillation with salient vocabulary alignment to improve knowledge transfer efficiency across different domains, unifying six heterogeneous domains into one deployable student model. Agents-A1 achieves strong and broad performance for long-horizon agent benchmarks. Compared with 1T-parameter model such as Kimi-K2.6 and DeepSeek-V4-pro, Agents-A1 achieves leading results on SEAL-0 (56.4), IFBench (80.6), HiPhO (46.4), FrontierScience-Olympiad (79.0), and MolBench-Bind (56.8), and remains highly competitive on SciCode (44.3), HLE (47.6) and BrowseComp (75.5). We hope this work provides the community with a practical path for scaling the horizon using a 35B agent that can reach or match the performance of 1T models on long-horizon tasks.

## 2. 论文提出的方法论：核心思想、关键技术细节
- **核心思想**：通过构建一个长时程的知识-行动基础设施（Knowledge-Action Infrastructure）和一个三阶段的训练方案，让一个35B参数的MoE模型在长时程任务上达到万亿参数级别的性能。
- **关键技术细节**：
    1.  **长时程知识-行动基础设施**：
        - **知识-行动图 (KAG)**：这是核心数据基础设施。它不是一个传统的知识图谱，而是一个有类型的四元组 `G_d = (C_d, A_d, O_d, V_d)`，分别代表领域语料、行动空间、观察空间和验证器集。KAG通过链接的记录 `(s_t, a_t, o_t, v_t)` 来保存获得答案的完整过程（包括成功和失败的轨迹），提供了超越最终答案的“过程级监督”。
        - **自博弈图搜索与扩展**：通过“提议者-求解者-验证者”的循环来优化和扩展KAG。只有满足“可验证、有效、过程信息丰富、覆盖证据、无歧义”的候选任务才会被接受，从而保证数据质量。
    2.  **三阶段训练方案**：
        - **第一阶段：全领域监督微调 (Full-domain SFT)**：在平均长度为45K Token的多领域长时程轨迹上对基座模型进行SFT，使其具备广泛的智能体行为。
        - **第二阶段：领域教师模型训练 (Domain-level Teacher Training)**：针对不同领域（搜索、科学推理、指令遵循、工具调用）分别训练专门的教师模型，通过SFT+强化学习(RL)使其在各自领域达到高水平。
        - **第三阶段：多教师域路由在线蒸馏 (Multi-teacher Domain-routed On-Policy Distillation)**：这是整合能力、解决冲突的关键。它将多个领域教师的专业知识转移到一个学生模型中。
            - **域路由 (Domain-routing)**：每个训练样本按领域硬路由到对应的教师模型，避免混合不同教师的信号。
            - **显著词汇对齐 (Salient Vocabulary Alignment, SVA)**：核心创新点。它不是让学生模仿教师的整个词表分布，而是在教师模型选定的“显著词汇集”（top-k令牌）上对齐学生和教师的分布，使用截断的逆向KL散度作为损失函数。这提高了知识迁移效率并减少了不稳定因素。
            - **域归一化目标 (Domain-routed Normalized Objective)**：为了平衡不同领域间的差异，损失函数先计算每个领域内的平均损失，再对所有活跃领域取平均，防止高频或高损失领域主导模型更新。
