## 摘要
思维链（Chain-of-Thought, CoT）提升了大型语言模型（LLMs）在困难推理任务上的表现，但其生成的长篇自然语言推理过程与高效的机器推理并不匹配。我们提出通信语言符号路由（Communicative Language Symbolism Routing, CLSR），一种测试时框架，其中多个LLM智能体自主发明、演化并共享紧凑的语言符号框架（Language Symbolism Frameworks, LSFs），同时一个无隐变量路由器根据每个查询自适应地选择和组合这些语言，以优化准确率与token消耗的权衡。与优化表面指令的提示优化不同，CLSR将每个LSF视为一种可重用的符号协议，包含紧凑符号、使用规则和消息传递契约，并通过一个由正确性和token成本驱动的演化循环来改进它。在推理时，路由器可以调用单个低成本的LSF调用、集成多个LSF，或对更难的查询执行多轮LSF组合协议。在具有挑战性的基准测试中，与标准CoT相比，CLSR在保持准确率的同时将延迟导向的生成token数减少了3~6倍。我们还推导了任意符号系统下token成本的信息论下界，并证明在解释器可实现性前提下，多轮LSF协议有条件地包含程序执行流水线。代码已公开（https://github.com/pzqpzq/LSF_MDia）。

## Abstract
Chain-of-Thought (CoT) improves large language models (LLMs) on difficult reasoning tasks, but it often incurs long natural-language rationales that are poorly aligned with efficient machine reasoning. We propose Communicative Language Symbolism Routing (CLSR), a test-time framework in which multiple LLM agents autonomously invent, evolve, and share compact Language Symbolism Frameworks (LSFs), while a latent-free router adaptively selects and composes these languages per query to optimize the accuracy-token trade-off. Unlike prompt optimization that refines surface instructions, CLSR treats each LSF as a reusable symbolic protocol with compact symbols, usage rules, and a message-passing contract, and improves it through an evolutionary loop driven by correctness and token cost. At inference time, the router may invoke a single low-cost LSF call, ensemble multiple LSFs, or execute a multi-round LSF composition protocol on harder queries. Across challenging benchmarks, CLSR reduces latency-oriented generated token completion by $3\sim 6\times$ compared to standard CoT while maintaining accuracy. We further derive an information-theoretic lower bound on token cost under arbitrary symbolism and show that, under an interpreter-realizability premise, multi-round LSF protocols conditionally subsume program-execution pipelines. Code is publicly available (https://github.com/pzqpzq/LSF_MDia).

## 1. 核心问题与整体含义
- **研究动机**：标准思维链（CoT）生成冗长的自然语言推理过程，虽然提升了LLM的推理能力，但**效率低下**——许多token用于人类可理解的叙述性文字，而不是紧凑的逻辑推理。
- **核心问题**：能否让LLM自主发明新的符号语言来更高效地推理，而不是依赖人类设计的提示或程序？
- **整体含义**：提出**通信语言符号路由（CLSR）**框架，让多个LLM智能体通过**进化循环**自主发明、改进并共享紧凑的符号通信协议（称为LSF），路由器按需选择或组合LSF，从而在保持准确率的同时大幅减少token消耗。该工作**首次将多智能体符号通信引入LLM推理**，并提供信息论下界以解释效率优势。

## 2. 方法论
- **核心思想**：
  - 将推理过程从自然语言叙述转换为**可复用的符号协议**（LSF）。
  - 通过**进化算法**（选择+突变）迭代优化LSF，使其在正确性和token成本之间达到更好的权衡。
  - 在推理时，**路由器**（同为LLM）根据查询难度自适应选择：单LSF直接回答、多LSF集成（类似自洽性）、或多轮LSF组合（处理难题）。
- **关键技术细节**：
  - **LSF卡**：包含符号库（lexicon）、语法（grammar）、使用规则（constraints）、解释函数（mapping）、经验档案（profile：成本、准确率、失败模式）。
  - **进化流程**：
    1. *生成*：用训练子集的示例提示LLM发明初始LSF池。
    2. *评估*：每个LSF对下一个子集的查询生成答案，记录正确性与token成本。
    3. *选择与突变*：从所有答案中选择“高杠杆”（正确且token少）的轨迹，反馈给LLM生成下一代的LSF。
    4. *精英保留*：最优LSF直接复制到下一代。
  - **路由机制**：
    - 两阶段：先进行**类别路由**（选择与查询相关的LSF类别），再生成**协议计划**（指定模式、LSF列表、轮次、聚合方式、停止规则）。
    - 路由器输出格式为 `M:<mode>;L:<lsf-list>;R:<round-spec>;K:<n>;A:<agg>;S:<stop>`，仅消耗几十token。
- **优化目标**：在给定token预算B下最大化准确率，等价于求解约束优化问题。

## 6. 主要结论与发现
- CLSR**持续改善准确率–token帕累托前沿**：相比Raw CoT，生成token减少**3~6倍**，准确率保持甚至略有提升。
- 相比Token缩减基线（CCoT、CoD、SoT），CLSR更稳定：极端压缩方法常牺牲准确率，而CLSR通过可复用的符号协议和自适应路由保留推理质量。
- **进化深度**提升LSF的信息密度（每token携带更多任务相关信息）。
- **更多智能体**参与LSF进化提高池的多样性，从而提升下游准确率。
- 理论结果（定理3.2）表明：所需最小token数由信息下界决定，CLSR通过增加每token有效信息来突破CoT的效率瓶颈。
- 多轮LSF协议可**有条件地模拟程序执行**（定理3.3），无需外部解释器。

## 7. 优点
- **方法新颖**：首次将符号通信框架引入多智能体LLM推理，通过进化发现可复用的紧凑语言，而非手动设计提示或程序。
- **自适应计算分配**：路由器按查询难度选择单LSF、集成或多轮组合，实现实例级效率优化。
- **实验全面**：覆盖多种任务类型、多个骨干模型、多种基线，消融实验深入，验证了方法鲁棒性。
- **理论支撑**：提供信息论下界，解释LSF提升效率的原因，并证明CLSR在理论上包含程序执行流水线。
- **实用性强**：离线成本可被大量查询分摊，在线开销极低。

## 8. 不足与局限
- **离线计算昂贵**：LSF进化需要数天GPU计算，成本较高，尤其对于小规模应用。
- **依赖带推理过程的训练示例**：LSF生成需要一定数量的高质量QA+推理轨迹，可能限制在缺乏此类数据的领域使用。
- **可解释性降低**：紧凑的符号轨迹比自然语言更难被人类审计，可能增加部署风险。
- **跨域转移性能损失**：当LSF生成器与推理模型不同时，准确率下降（见表4），表明存在“方言不匹配”问题。

- **未探索跨模态、工具增强或多智能体交互**：作者将其列为未来工作，当前聚焦于纯文本LLM推理。
- **理论假设的局限性**：解释器可实现性（Interpreter Realizability）在复杂长链计算中可能不成立，限制了子sumption定理的适用范围。
