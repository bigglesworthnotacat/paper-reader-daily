## 摘要
自动化阿尔法挖掘固定评分函数并在其上变化搜索算法。针对固定评分器收敛的搜索会过度拟合评分器无法惩罚的任何内容，这是样本外泛化差距的主要原因。我们将评分函数与阿尔法因子一同视为搜索产物，并研究使这种联合搜索可行的条件。密封联合搜索（SJS）是一个框架：它是一组关于自主发现系统中信息流的结构性条件，可防止联合搜索陷入自我确认，同时保持评估器密封。条件涵盖角色分解、类型化的角色间通信、来源密封读取、版本化存储和基底局部提升。Agora对SJS进行了实证测试：五类LLM智能体通过三个信道通信，进化了八个技能库，其中阿尔法库基于AlphaGen算子构建。三位评估者撰写报告汇总成一份简报，传递分歧而非投票。我们在CSI 1000上运行Agora 100轮，并在对所有LLM输入密封的91天2026年留存期上进行评估。Agora实现了留存期夏普比率+1.87；最佳基线在有利种子下为+1.334，跨种子均值为-0.755。将Agora的两个指标预加载到冻结库消融中仅恢复+0.40的+2.25夏普差距，而添加PPO而不进行库进化则使差距恶化。这两个指标是涌现而非设计出来的。注意事项：单种子运行，空头集中信号，适用于多空策略。

## Abstract
Automated alpha mining holds the scoring function fixed and varies the search algorithm over it. A search that converges against a fixed scorer overfits whatever the scorer cannot penalize, a primary cause of the out-of-sample generalization gap. We treat the scoring function as a search artifact alongside the alpha factors and study what conditions make this joint search admissible. Sealed Joint Search (SJS) is a framework: a set of structural conditions on information flow in an autonomous-discovery system that prevent joint search from collapsing into self-confirmation while keeping the evaluator sealed. Conditions cover role decomposition, typed inter-role communication, provenance-sealed reads, versioned stores, and substrate-local promotion. Agora tests SJS empirically: five LLM agent classes communicate via three channels, evolving eight skill libraries, with alpha libraries built on AlphaGen operators. Three evaluators write reports aggregated into one brief, carrying forward disagreement instead of voting. We run Agora for 100 rounds on CSI 1000 and evaluate on a 91-day 2026 holdout sealed from all LLM inputs. Agora achieves holdout Sharpe +1.87; best baseline +1.334 at favorable seed and -0.755 cross-seed mean. Pre-loading Agora's two metrics into a frozen-library ablation recovers only +0.40 of the +2.25 Sharpe gap, and adding PPO without library evolution worsens the gap. The two metrics emerge rather than being designed. Caveats: single-seed run, short-side concentrated signal, intended for long-short.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：在自动化α挖掘（Alpha Mining）中，传统方法固定评分函数（scoring function），仅变化搜索算法。这导致搜索过程会过度拟合评分函数无法惩罚的模式，从而产生严重的样本外泛化差距（generalization gap）。作者认为，评分函数本身也应作为搜索的产物，与α因子一同被搜索和进化。
- **研究动机**：现有方法（遗传编程、强化学习、LLM提示等）无法解决评分函数固定带来的盲点。即使采用自进化系统（如Voyager、Eureka），也存在保持固定准则或频繁查询外部评估器导致的泄漏问题。作者提出**密封联合搜索（Sealed Joint Search, SJS）**框架，在保持外部评估器密封的前提下，让信号和评分函数协同进化。
- **整体含义**：通过信息拓扑的重新设计（而非改进搜索算法），使联合搜索过程能够避免自我确认（self-confirmation），提升泛化能力。该方法在A股α挖掘任务中验证，并拓展到其他自主发现领域。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 核心思想
- **密封联合搜索（SJS）**：一组结构条件，约束自主发现系统中的信息流，防止联合搜索崩溃为自我确认。
- **信息拓扑重定向**：将研究对象从搜索算法转向信息拓扑——角色、通信类型、存储状态、升级规则。泛化性由拓扑决定，而非任何参与者的行为。

### 2.2 五个结构条件（F1-F5）
| 条件 | 名称 | 说明 |
|------|------|------|
| F1 | 分解的提案（proposal decomposition） | 提议者和评估者为不同角色，无共享状态 |
| F2 | 类型化的角色间通信（typed inter-role communication） | 角色间通信通过类型化通道，禁止自由聊天 |
| F3 | 来源密封的基底（provenance-sealed substrate） | 每条记录标记数据分段，按角色和内容类型过滤读取 |
| F4 | 持久版本化制品存储（persistent versioned artifact stores） | 角色拥有的技能库，状态机：builtin/trial/accepted/rejected |
| F5 | 基底局部升级规则（substrate-local promotion rule） | 非自我判断、基于结果的升级规则（如|ρ|>0.3提升，<0.05降级） |

### 2.3 Agora系统实现
- **五个LLM智能体角色**：research-report（咨询）、alpha-miner（产生f）、evaluation-miner（产生g）、alpha-evaluator（3实例面板）、factor-metrics-evaluator（3实例面板）
- **三个类型化通信通道**：
  - 通道A：轮内定向建议（F1）
  - 通道B：跨轮简报（有界容量，F2）
  - 通道C：持久共享内存（LLM Wiki，F3，按角色过滤）
- **八个技能库**：operator, RL-network, RL-algorithm, reward（alpha侧，继承AlphaGen）；metric, topic, rubric, meta-rubric（评估侧）。其中metric库是唯一观察到进化的库。
- **密封评估**：外部评估器（后台回测）在运行前固定，对LLM不可见；训练段用于升级，测试段仅以分类桶反馈，holdout段完全密封。
- **升级规则**：metric指标与训练段Sharpe的Pearson相关性|ρ|>0.3提升，<0.05降级，最少3个观测值。

### 2.4 算法流程（文字说明）
每轮执行固定序列：
1. research-report发布建议（通过通道A，不同内容过滤后发给alpha-miner和evaluation-miner）
2. alpha-miner基于前一轮简报提出候选因子f（结合PPO种子池）
3. alpha-evaluator面板对训练段评分，写三份报告，汇总为简报（通道B）
4. evaluation-miner基于前一轮因子指标简报提出metric库操作
5. 候选因子在测试段重新评分，组合成投资组合并执行回测
6. factor-metrics-evaluator面板写三份报告
7. 编排器提交：优秀α保留、metric预测相关性更新、自动升级触发、Wiki更新

## 6. 论文的主要结论与发现

### 6.1 关键结果
- **Agora在91天holdout上实现组合夏普比率+1.87**，明显高于最佳单种子基线（B2 PPO +1.334）和跨种子均值（-0.755）。
- **两个涌现指标**（单调性评分v1和超额回撤惩罚v1）**不是由任何单一智能体产生**，而是通过跨轮聚合证据涌现。预加载这两个指标到冻结库仅恢复+0.40的夏普差距（占+2.25总差距的<20%），说明**指标的动态进化过程比静态预置重要得多**。
- **PPO单独添加到冻结库是负收益**（比冻结库差-0.80夏普），表明不同步进化评分函数和搜索算法是有害的。
- **Agora的信号集中在空头端**：多空年化收益+48.4%（底部十分位-27.39%，顶部十分位+6.46%），适合多空部署，不适合纯多头。
- **滚动窗口分析**：Agora前30个α在7/7个窗口上多空夏普为正，2026 holdout处于中位数水平，说明信号具有跨时间鲁棒性。
- **冻结库消融**(B6)夏普-0.379，而Agora+1.87，差值为+2.25，这是进化机制贡献的上界。

### 6.2 其他发现
- 八种技能库中只有metric库发生了有意义的进化（其余七种保持在builtin集）。
- 在遗传编程基线（B1）中，所有30个α收敛到同一代数类，导致符号反转（训练段正IC，holdout负夏普）。
- 单LLM迭代（B4）学会利用训练指标，holdout单调性反转。

## 7. 优点

- **方法创新**：提出密封联合搜索（SJS）框架，从信息拓扑角度解决联合搜索的自我确认问题，不依赖于特定优化器或LLM。
- **实验设计严谨**：
  - 明确的五条密封路径审计（附录A.4），确保holdout段不被漏泄。
  - 角色间使用类型化通道而非自由聊天，强制信息隔离。
  - 消融实验设计指向特定拓扑边缘（如禁止库进化仅保留通信通道），而非简单消融智能体。
- **生态价值**：开源所有代码、基线配置和日志，可复现性强。
- **跨领域潜力**：SJS条件不限于α挖掘，可迁移到自动定理证明、程序合成等自主发现任务。
- **发现了涌现行为**：两个指标不是设计出来的，而是系统在进化过程中涌现的，且静态预置效果远不如动态进化。
- **考虑了统计严谨性**：使用Newey-West HAC检验处理自相关，报告跨种子方差（尽管不完善）。

## 8. 不足与局限

### 8.1 实验覆盖不足
- **单种子运行**：Agora全系统仅运行1个种子，无法评估种子方差。作者承认这是“最重要被推迟的实验”。相比之下，B2在3个种子间夏普跨度达4.4个单位。
- **缺少直接F1消融**：未运行“单智能体进化”对照，无法直接检验角色分解（F1）的价值。作者在开放问题中列为最关键的缺失实验。
- **轮数混淆**：Agora运行100轮，冻结库消融（B6）仅5轮，尽管B6+增强在20轮后更差，但仍不能完全排除轮数差异。
- **跨领域未验证**：未在定理证明、程序合成等其他自主发现领域测试SJS。

### 8.2 应用局限
- **信号空头集中**：多空收益主要来自空头端，纯多头夏普疲弱（顶部十分位年化仅+6.46%）。限制了在只能做多市场中的实用性。
- **holdout窗口短**：仅91个交易日（约5个月），统计检验力有限。Newey-West HAC检验仅两个基线达到显著（B1和B7），其余对比p值高。
- **计算成本高**：单次Agora运行约60 GPU小时+4500次LLM调用，可能非实际生产系统的典型部署条件。

### 8.3 方法论局限
- **升级规则内部循环性**：metric升级使用训练段Sharpe（也是alpha-miner的优化目标），构成循环。作者承认这是结构性而非可消除的。
- **测试段泄漏风险**：虽然测试段数值被替换为四类分桶，但评估者仍积累了“何种指标与‘优秀’分桶相关”的信息，且监督信号信息量随轮数增加（信息论上界约2000 bits）。
- **指标标准性**：涌现的两个指标（单调性评分、超额回撤惩罚）在量化领域属于常规做法，非根本性创新；贡献在于证明了闭环涌现而非方法手段本身。

### 8.4 报告偏差
- 主要结果（+1.87 Sharpe）基于单一种子，而最强基线（B2）的跨种子均值为-0.755（负面），放大对比差异。需要更公平的多种子报告。
