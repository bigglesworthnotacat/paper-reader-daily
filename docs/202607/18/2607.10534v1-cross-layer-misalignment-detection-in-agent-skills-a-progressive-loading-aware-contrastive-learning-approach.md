## 摘要
大型语言模型（LLM）智能体越来越多地通过Agent技能进行扩展，这些可复用工件将自然语言元数据、程序化指令和运行时资源打包以供运行时使用。随着开源技能市场的发展，用户和智能体越来越依赖简短的元数据来选择第三方技能，这使得检测技能描述与其真实行为之间的不一致变得困难，我们将此问题称为跨层错位。为了解决这个问题，我们提出了渐进式加载感知层次对比学习（PL-HCL），这是一个基于LLM的框架，通过建模Agent技能的层次结构并学习跨层一致性来检测错位。利用包含超过264,000个开源技能的标准化语料库和一个人工验证的挑战集，PL-HCL将Macro-F1从未经调整基线的约0.45提升至所评估LLM骨干网络上的0.87-0.89。该方法为用户和运营商提供了有效的筛选工具，也为检测分层数字工件中的不一致性提供了设计原则。

## Abstract
Large language model (LLM) agents are increasingly extended through Agent Skills, reusable artifacts that package natural-language metadata, procedural instructions, and execution-time resources for runtime use. As open-source skill marketplaces expand, users and agents increasingly rely on brief metadata to select third-party skills, making it difficult to detect inconsistencies between a skill's description and its true behavior, a problem we call cross-layer misalignment. To address this issue, we propose Progressive Loading-Aware Hierarchical Contrastive Learning (PL-HCL), an LLM-based framework that detects misalignment by modeling the layered structure of Agent Skills and learning cross-layer consistency. Using a normalized corpus of over 264,000 open-source skills and a human-verified challenge set, PL-HCL improves Macro-F1 from approximately 0.45 for unadapted baselines to 0.87-0.89 across evaluated LLM backbones. This approach offers an effective screening tool for users and operators, as well as design principles for detecting inconsistencies in layered digital artifacts.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：大型语言模型（LLM）智能体通过可复用的 Agent Skills（代理技能）扩展能力，这些技能包含自然语言元数据、程序化指令和运行时资源。用户及智能体依赖简短的元数据选择第三方技能，但技能描述与其真实行为之间常存在不一致，即**跨层错位**（cross-layer misalignment）。例如，一个声称安全的工具可能暗藏提示注入、凭据泄露或恶意命令执行；反之，一个技能声称具备某功能却未在底层实现。
- **研究动机**：信任决策通常在技能完全加载或执行之前做出（基于元数据），而现有评估聚焦于运行时性能或单独的安全漏洞，缺乏对技能工件内部跨层一致性的预执行检查。这构成了一个未被充分研究的信任风险，威胁智能体系统的安全性。
- **整体含义**：旨在建立一个**预执行筛选能力**，在技能加载前检测其表面声明与深层行为证据是否一致，从而为技能市场、用户和安全分析师提供可扩展的信任评估工具。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：将每个技能包建模为分层工件 \( S = (M, I, R) \)，其中 \( M \) 为元数据层（用户界面声明），\( I \) 为指令层（面向智能体的程序指导），\( R \) 为资源层（脚本、配置文件、可执行文件等）。通过**渐进式加载感知层次对比学习（PL-HCL）** 框架，训练模型学习跨层一致性，即判断 \( M \) 是否被 \( I \) 和 \( R \) 支持。

- **关键技术细节**：
    1. **两阶段持续预训练（Two-Stage Continued Pretraining, CPT）**：采用课程式适应策略。
       - 第一阶段：使用短视图（\( M+I \)），4,096 tokens，训练基础LLM适应技能包的词汇、格式和表层结构。
       - 第二阶段：使用全视图（\( M+I+R \)），10,240 tokens，训练模型适应包含资源文件的完整上下文。
       - 损失函数为标准因果语言模型（CLM）损失：\[ \mathcal{L}_{\text{CPT}} = -\frac{1}{T}\sum_{t=1}^{T} \log p_\theta(x_t|x_{<t}) \]

    2. **渐进加载感知层次对比学习（PL-HCL）**：在CPT基础上，将跨层一致性转化为对比学习信号。
       - 构造正样本：同一技能的 \( (M_i, I_i, R_i) \)。
       - 构造两类负样本：
         - **交换负样本** \( N^A_i \)：替换元数据为另一技能的 \( M_j \)（\( j \neq i \)），模拟声明与行为不符。
         - ** corrupted 负样本** \( N^B_i \)：扰动原始元数据（如重写、篡改），模拟夸大或误导性声明。
       - 使用投影头将各层编码为嵌入 \( z_X \)，计算跨层相似度分数：
         \[ a_{\theta,\phi}(S) = \alpha_{MI} \text{sim}(z_M, z_I) + \alpha_{MR} \text{sim}(z_M, z_R) + \alpha_{IR} \text{sim}(z_I, z_R) \]
       - 对比损失（InfoNCE形式）：
         \[ \mathcal{L}_{\text{PL-HCL}} = -\sum_i \log \frac{\exp(a(P_i)/\tau)}{\exp(a(P_i)/\tau) + \exp(a(N^A_i)/\tau) + \mathbb{I}_{B_i}\exp(a(N^B_i)/\tau)} \]
       - 两子阶段：分别对应短视图和全视图，使模型渐进式地学习从表层到深层的证据关系。

## 3. 实验设计：使用的数据集、基准测试、对比方法

- **数据集**：
  - **训练语料**：从 SkillsMP（最大开源 Agent Skill 平台）及其关联的 GitHub 仓库收集，共264,937个标准化技能包。经 token 预算过滤后，248,473个技能包至少符合一个训练阶段。
  - **人类验证挑战集（Challenge Set）**：独立保留的1,444个技能（1,150对齐 + 294不对齐），其中不对齐技能进一步分为安全（196）、可疑（38）和恶意（60）。所有混淆集样本为真实世界技能，非合成扰动；由人工标注员两步验证（沙盒行为分析与声明对比），标注者间一致性97.2%。
- **基准任务**：预执行错位检测（二元分类：0=对齐，1=不对齐）。
- **评估指标**：准确率（Acc）、不对齐类F1（\( F1_m \)）、Macro-F1、AUC、平均精度（\( AP_m \)）。
- **对比方法**：
  - **基线LLM骨干**：Llama-3.1-8B、Foundation-Sec-8B、WhiteRabbitNeo-2-8B、RedSage-Qwen3-8B-DPO、Qwen-3-8B。
  - **提示设置**：零样本、2-shot、5-shot。
  - **模型变体**：
    - raw（无适应）
    - CPT-only（仅持续预训练）
    - CPT+PL-HCL（完整框架）

- **实验分组**：
  - E0（RQ2）：原始骨干对比，评估未适应的LLM。
  - E1（RQ3）：CPT效果，比较raw vs CPT-only。

## 6. 论文的主要结论与发现

- 基线LLM（包括一般和网络安全骨干）在不对齐类检测上表现极差（F1_m < 0.15），尽管准确率接近多数类基线，存在“多数类偏差”。
- 两阶段CPT提升了零样本性能（F1_m从~0.03升至~0.13），但CPT-only的Macro-F1仍低于0.52，表明格式适应不足以独立作为检测器。
- **PL-HCL带来最大的增益**：CPT+PL-HCL在Llama-3.1-8B上实现Macro-F1达到0.872（2-shot），Foundation-Sec-8B达到0.889（2-shot）。不对齐类F1从<0.15跃升至>0.78。
- 合成的负样本（交换/ corruption）成功迁移至真实的自然错位样本，表明模型学到了“声明-证据”一致性信号，而不仅仅是对恶意关键词的反应。
- 网络安全专用骨干（如Foundation-Sec-8B）在未适应时未展现优势，但在PL-HCL下表现出略优的性能（可能得益于其安全认知）。

## 7. 优点：方法或实验设计上的亮点

- **问题形式化新颖**：首次系统地将Agent技能中的跨层错位作为预执行评估问题提出，区分了恶意错位与良性错位（夸大声明）。
- **方法论原创性**：
  - 采用课程式两阶段持续预训练，模拟技能渐进加载过程。
  - 设计层次对比学习，将元数据、指令、资源分层编码并计算一致性分数，而非简单拼接。
  - 同时使用交换负样本和corruption负样本，覆盖不同类型的错位。
- **大规模真实语料构建**：从SkillsMP和GitHub构建超过26万标准化技能包，人工验证了挑战集，保证实验的可重复性和生态效度。
- **实验严谨性**：固定决策阈值、多指标报告、区分内在与外在评估、消融设计完整。
- **实践意义明确**：为技能市场提供预发布筛选、为用户提供客户端扫描、为分析师提供聚类与优先级排序，具备直接应用价值。

## 8. 不足与局限

- **评估范围局限**：仅聚焦**预执行、工件级别**评估，无法检测仅出现在运行时（如动态远程载荷、环境副作用）的错位。需要运行时沙盒与轨迹级评估作为补充。
- **数据来源单一**：主要来自SkillsMP和GitHub开源仓库，未涵盖封闭生态系统（如企业内部技能）或动态生成技能，可能存在结构或风险分布差异。
- **模型规模限制**：所有实验基于8B参数骨干（Llama-3.1-8B和Foundation-Sec-8B等），未探索更大模型（70B+）或更小模型（<8B）的性能与泛化。更大的模型可能具备更强的跨层推理能力，而更小模型可能需要不同的适应策略。
- **合成负样本的生态效度**：训练数据仅使用合成的交换/corruption负样本，虽然挑战集显示泛化，但仍有遗漏真实错位模式的可能（例如双重语义混淆、渐进式声明不一致）。
- **阈值与提示依赖性**：虽然固定决策阈值避免过拟合，但实际部署中需要基于验证集校准；提示设置（k-shot）的选择可能影响最终性能，论文未提供跨不同提示设置的稳健性分析。
