## 摘要
当今的LLM智能体陷入了一个尴尬的两难境地。用静态安全指令约束它们时，它们很少敢越雷池一步；给予工具和多智能体辩论的自由时，安全违规又接踵而至。我们不是强迫单个模型兼顾创造性与谨慎，而是将关注点分离到专门的角色中。一个破坏者生成非常规提议，一个验证者在工具网关处强制执行运行时检查，一个经纪人则引入遥远但相关的类比。失败不会被丢弃——它们通过MCTS被编译成紧凑的、带签名的约束补丁，我们称之为伤疤。这些补丁在本地缓存，并被未来的队列继承，将重复的失败转化为可重用的低成本运行时约束。在一个空间语义沙盒中（N=20次运行，p<0.01），我们的队列能够到达辩论失败的目标，验证者阻止了所有执行的违规行为，而伤疤通过避免冗余的验证者检查减少了15.1%的令牌消耗。此外，基于信用的通信分配分数（CAS）限制了出站带宽，在资源约束下将总体令牌成本降低了55.9%。

## Abstract
LLM agents today are caught in an awkward bind. Lock them down with static safety instructions and they rarely venture beyond the obvious; give them free reign with tools and multi-agent debate, and safety violations quickly follow. Rather than forcing a single model to juggle both creativity and caution, we separate the concerns across specialized roles. A Disrupter generates unconventional proposals, a Validator enforces hard runtime checks at the tool gateway, and a Broker pulls in distant but relevant analogies. Failures are not discarded -- they are compiled, via MCTS, into compact, signed constraint patches we call Scars. These patches are cached locally and inherited by future cohorts, turning repeated failures into reusable, low-cost runtime constraints. In a spatial-semantic sandbox (N=20 runs, p<0.01), our cohort reaches remote targets where debate fails, the Validator prevents all executed breaches, and Scars reduce token consumption by 15.1% by avoiding redundant validator checks. Furthermore, credit-based Communication Allocation Scores (CAS) restrict outbound bandwidth, reducing overall token costs by 55.9% under resource constraints.

### 2. 论文提出的方法论
- **核心思想**：设计一个由三种异质角色组成的智能体队列（Cohort）：
  - **破坏者（Disrupter）**：以高温度（1.2）生成非常规、高熵的提议，最大化行动多样性。
  - **验证者（Validator）**：以零温度（0.0）在工具网关处硬阻断不安全动作，执行运行时安全门控。
  - **经纪人（Broker）**：使用对比新颖性检索（Contrastive Novelty Retrieval, CNR）从外部知识库中引入与当前对话历史语义相异但与任务目标高度相关的类比知识，桥接结构洞。
- **关键技术细节**：
  - **对比新颖性检索（CNR）**：  
    `D* = arg max [λ·Sim(Emb(D), V_goal) - (1-λ)·Sim(Emb(D), V_history)]`，其中 `V_goal` 是任务目标嵌入，`V_history` 是对话历史嵌入。通过惩罚与历史相似的文档，迫使经纪人跨越同质领域。
  - **运行时约束记忆（Scars）**：执行失败后，利用 MCTS 在 AST 空间搜索最优约束规则，编译为带 Ed25519 签名的约束补丁（Scar）。补丁被本地缓存，后代队列自动继承，避免相同失败再次触发模型调用。
  - **通信分配分数（CAS）**：`K_i(t) = max(ε, K_i(t-1) + αR_i(t) - βC_i(t))`，用于按角色奖励和成本分配出站带宽。带宽分配采用软最大温度缩放：`Bandwidth_i(t) = Bmin + (Bmax - Bmin) * e^{K_i(t)/τ} / Σ_j e^{K_j(t)/τ}`，防止低信用智能体引发广播风暴。
- **算法流程**（以文字描述）：
  1. 加载已签名的 Scars 库。
  2. 初始化所有代理的 CAS 为 1.0。
  3. 每个步骤 t：
     - Broker 使用 CNR 检索外部知识库。
     - Disrupter 根据当前 CAS 分配到的令牌限额提出候选动作。
     - Validator 检查候选动作是否被 Scars 库或动态规则阻挡；若阻挡则记录并降低 Disrupter 的 CAS。
     - 若未被阻挡，则在沙盒中执行动作。成功则更新共享记忆并增加 Disrupter 的 CAS；失败则计算认知不平衡度，若超过阈值则调用 MCTS 编译新的 Scars 并签名。
