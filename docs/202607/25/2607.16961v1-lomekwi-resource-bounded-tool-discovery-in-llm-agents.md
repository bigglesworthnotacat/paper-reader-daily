## 摘要
现有的工具使用基准测试报告了复杂多步骤任务的单一成功率。受认知科学思想的启发，我们将工具使用与工具发现区分开来，并将后者分解为好奇心（模型发现构建工具所需部件的能力）、认知（模型发现创造工具过程的能力）和效率（模型在创造后使用工具的能力）。我们表明，该框架可以应用于现有的发现任务，如Voyager。此外，我们提供了证据表明认知与模型大小呈反比缩放，并引入并分析了一类证明这一点的组合博弈。我们还在一个旨在模拟现实世界任务的独立环境中进一步观察到了反比缩放现象。

## Abstract
Existing tool-use benchmarks report a single success rate for complex, multistep tasks. Inspired by ideas from cognitive science, we distinguish tool use from tool discovery and decompose the latter into curiosity (the model's ability to discover the parts needed to build the tool), recognition (the model's ability to discover the process of creating the tool), and efficiency (the model's use of the tool after creation). We show that this framework can be applied to existing discovery tasks, such as Voyager. In addition, we provide evidence that recognition inversely scales with model size, and we introduce and analyze a class of combinatorial games that demonstrates this. We further observe inverse scaling in a separate environment designed to emulate real-world tasks.

- **背景**：现有LLM工具使用基准只报告复杂多步骤任务的单一成功率，且通常已提供给模型现有工具或建造指令，无法评估模型**是否主动决定**建造工具。

## 2. 论文提出的方法论

- **核心思想**：将工具发现分解为三个概率：
  - 好奇心 \( C = \Pr(\text{hold}) \)：模型获得工具所需部件的概率。
  - 认知 \( R = \Pr(\text{build} \mid \text{hold}) \)：模型在拥有部件后决定建造工具的概率。
  - 效率 \( E = \Pr(\text{win} \mid \text{build}) \)：模型建造工具后成功解决问题的概率。

## 6. 论文的主要结论与发现

- **成功与各分量缩放趋势**：整体成功率S、好奇心C和效率E随模型增大而提升，但认知R出现**反比缩放**——较大模型反而更低频率地在拥有部件后建造工具。
- **反比缩放机制解释**：大模型过度自信于暴力破解路径，停止探索工具。在Recognition MCP中，随模型变大，工具调用次数减少，手动解题比例上升，导致认知下降。
- **U型缩放现象**：当提供“工具中有恰好一个有效”的先验提示时，认知恢复U型（最小/最大模型较高，中间模型较低），中间模型因高估自身解题能力而放弃工具搜索。
- **对现有基准的启示**：仅报告总成功率会掩盖认知赤字，因效率提升可补偿认知下降，造成假阳性的正向缩放。

## 7. 优点

- 创新分解框架：第一次将LLM工具发现细分为可测量组件，灵感来自认知科学，具有理论深度。
- 环境设计精巧：Lomekwi提供两种路径（暴力vs建造），允许独立测量C、R、E；Recognition MCP通过反事实打分隔离认知，避免混淆。
- 发现反比缩放和非单调缩放现象，挑战了“越大越好”的直觉，对构建自适应工具使用系统有重要指导意义。
- 统计方法严谨：使用Wilson置信区间和滚动级bootstrap，避免独立假设。
- 开源代码和日志，便于复现。

## 8. 不足与局限

- **实验覆盖有限**：主要基于两个自建环境，样本量中等（每模型180-几百episodes），未在更复杂的现实任务（如Minecraft等）上验证分解框架。
- **模型家族偏窄**：Claude只有3种规模，Qwen系列未包括更大（>70B）模型；未测试GPT-4等开放API模型，反比缩放现象的普遍性待验证。
- **认知反比解释基于间接证据**：归因于“过度自信”主要根据工具调用次数和代表性rollouts，未直接控制模型置信度；缺乏因果实验（如诱导模型先评估自身能力再选择路径）。
- **认知项的定义依赖“建造”事件**：在Lomekwi中，R = Pr(build|hold)，但“决定建造”可能受预算、历史等因素影响，未完全排除策略混叠。
- **对真实世界工具发现的推广性**：使用随机字母标签虽然消除先验，但可能使任务过于抽象，无法反映自然语言中的工具发现情境。
- **资源描述缺失**：未报告实验所需的计算资源，不利于成本评估和复现验证。
