## 摘要
随着大型语言模型（LLMs）在现实场景中的广泛应用，其输出结果的价值含义变得至关重要。然而，现有的评估基准存在两方面不足：一是对涉及多种价值冲突的日常场景中的价值困境覆盖不足，二是评估形式过于简单，无法有效评估LLMs的价值对齐。为解决这些问题，我们提出了D2VBench——一个基于158个手动标注的细粒度价值概念、通过LLMs与人类多阶段协作构建的包含10,000个真实日常困境实例的价值对齐基准。针对该基准的评估，我们提出了一种混合评估范式，将多项选择题与开放式问题相结合。我们对八个主流LLMs进行了全面评估。实验结果表明，D2VBench具有高可靠性和鲁棒性，能够有效反映LLMs在不同价值类别和维度上的对齐情况，为价值对齐研究提供了一种更真实、更细粒度的工具。数据集可在https://github.com/tjunlp-lab/D2VBench获取。

## Abstract
With the wide application of large language models (LLMs) in real-world scenarios, the value implication of their outputs is crucial. However, existing evaluation benchmarks suffer from insufficient coverage of value dilemmas in daily scenarios involving multiple value conflicts and simplistic evaluation formalisms that fail to assess LLMs' value alignment. To address these issues, we propose D2VBench, a value alignment benchmark comprising 10,000 instances of real daily dilemma scenarios constructed through a multi-stage collaboration between LLMs and humans, grounded in 158 manually annotated fine-grained value concepts. For evaluation on the benchmark, we present a hybrid evaluation paradigm that integrates multiple-choice questions with open-ended questions. We conduct comprehensive evaluations on eight mainstream LLMs. Experimental results demonstrate that D2VBench exhibits high reliability and robustness, effectively reflecting the LLMs' alignment across different value categories and dimensions, and providing a more realistic and fine-grained tool for research on value alignment. The dataset is available at https://github.com/tjunlp-lab/D2VBench.

## 2. 论文提出的方法论

### 2.1 核心思想
- 构建一个包含**10,000个日常困境实例**的数据集（D2VBench），每个实例涉及多个价值概念相互冲突的复杂场景。
- 设计一个**混合评估范式**：让LLM以开放题形式自由回答，然后由审判模型将回答映射到预定义的选项上，并基于五个维度的覆盖度计算量化评分。

### 2.2 关键技术细节

**数据集构建（四阶段）**：
- **阶段1（基础场景与角色定义）**：基于158个手动标注的细粒度价值概念（四级层次结构：类别→核心价值→子价值→规范性概念），利用LLM生成尽可能多的基础场景及其中可能出现的主要角色，用Sentence-BERT去重。
- **阶段2（价值困境创建）**：针对每个基础场景和其中一个主要角色，从第一人称视角构建包含明显价值冲突和复杂动机的现实场景。要求体现角色践行正向价值观时的内部挣扎和外部障碍（来源于身份冲突、文化惯性、人际压力、经济约束等多维因素）。人工验证并剔除不符合质量标准的实例。
- **阶段3（选项生成）**：基于困境场景，LLM生成四个可能的行动选项，要求全面覆盖所有潜在行为路径，不限于道德行为（包含被动退缩、妥协等）。同时融入现实约束（如害怕报复、节省成本）。
- **阶段4（人工精炼与理由库生成）**：人类标注者检查问题和选项的逻辑合理性，并补充违背普遍价值观的合理理由。针对每个选项，定义五个维度的**可解释性评分点**（理由库），每个维度平均约2.5~2.9个评分点。最终由专家审核定稿。

**评估方法（混合范式）**：
- **回答格式**：以开放题形式向被测LLM提问，要求其从五个维度（后果考虑、理性与正当性、风险权衡、责任归属、可行性与执行难度）自由阐述行动和理由。
- **审判模型**：选择GLM-4.6和Qwen3-Max作为两个独立的审判模型。它们将被测模型的自由回答映射到一个或多个逻辑一致的选项（不限制数量），然后检查回答在每个映射选项中覆盖了多少个预先定义的评分点。
- **对齐分数计算**：
  - 对每个选项：`Align-Score = TNRC / TNFO × 100`（TNRC：被测模型回答中覆盖的评分点总数；TNFO：该选项的总评分点数）。
  - 对每个实例：有一个由人类标注的**最符合普遍价值观的选项**（gold option），赋予其权重1.5，其他选项权重1.0。最终分数 = (Align-Score_gold×1.5 + ... + Align-Score_other×1.0) / (1.5 + ... + 1.0)。

1. **价值类别表现差异**：所有LLM在**生存安全**类别得分最高，其次是**社会秩序**，**文明进步**（如发展、仁爱、和谐）得分最低。说明模型在处理抽象、长期导向的价值时更困难。

4. **映射策略重要性**：多标签映射比单标签映射更能全面反映LLM的复合策略推理，提高了评估的准确性和区分度。
