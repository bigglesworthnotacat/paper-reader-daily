## 摘要
语言智能体依赖于跨交互的记忆。然而，大语言模型（LLM）有限的上下文窗口及其推理成本限制了单次可使用的记忆量。现有系统主要遵循两种策略：记忆保留和记忆整合。保留策略保持原始记录并保存精确细节，但在预算紧张的情况下，相关证据可能无法容纳；整合策略压缩并合并记录，提高每个标记的覆盖率，但有可能丢失对查询至关重要的细节。两种策略并非普遍适用。这引出了两个核心问题：何时应该用整合代替保留，以及应该选择哪个操作符——合并、抽象还是重写？我们通过将每个操作符的效用分解为对保留遗漏证据的覆盖效应和对已适配原始证据的带符号替代效应，来形式化这一决策。它们的平衡解释了为什么偏好行为会随相对预算压力而变化。我们通过离线抽象安全（OAS）实现了这一机制，这是一个轻量级学习器，利用预生成特征通过留出危害校正来估计行动效用。公开的LongMemEval和LoCoMo基准测试展示了相同的预算依赖模式。在LongMemEval上，在预算紧张时整合可将绝对准确率提高高达48%，而在预算宽松时保留更优；LoCoMo在更小的预算下复制了这种交叉，与其更短的证据一致。在两个数据集上，当需要压缩时，跨笔记抽象和合并通常优于局部重写。

## Abstract
Language agents depend on memory across interactions. However, the limited context windows of large language models (LLMs) and their inference costs constrain how much memory can be used at once. Existing systems mainly follow two strategies: memory retention and memory consolidation. Retention keeps raw records and preserves exact details, but relevant evidence may not fit under a tight budget; consolidation compresses and combines records, improving coverage per token but risking the loss of query-critical details. Neither strategy is universally preferable. This raises two central questions: when should consolidation replace retention, and which operator -- Merge, Abstract, or Rewrite -- should be selected? We formalize this decision by decomposing each operator's utility into a coverage effect on evidence omitted by retention and a signed replacement effect on raw evidence that already fits. Their balance explains why the preferred action changes with relative budget pressure. We implement this mechanism with Offline Abstraction-Safety (OAS), a lightweight learner that estimates action utilities from pre-generation features with held-out harm calibration. The public LongMemEval and LoCoMo benchmarks show the same budget-dependent pattern. On LongMemEval, consolidation improves absolute accuracy by up to 48% under tight budgets, whereas retention is preferable under loose budgets; LoCoMo replicates this crossover at a smaller budget, consistent with its shorter evidence. On both datasets, cross-note abstraction and merging generally outperform local rewriting when compression is necessary.

### **论文深度分析与总结**

#### **1. 核心问题与整体含义**

- **研究动机与背景**：大语言模型（LLM）驱动的智能体在长期交互中需要依赖记忆。然而，LLM有限的**上下文窗口**和**推理成本**限制了单次交互可使用的信息量（即“预算”）。现有记忆管理系统主要采用两种策略：
    - **记忆保留 (Retention)**：保存原始记录，保证细节准确，但在预算紧张时可能无法容纳所有相关证据。
    - **记忆整合 (Consolidation)**：通过压缩、摘要等方式生成紧凑记录，提高信息覆盖率，但可能丢失关键细节（如时间戳、更正信息）或引入错误。
- **核心研究问题**：既然这两种策略各有利弊且不普遍适用，论文旨在解决以下两个耦合问题：
    - **何时 (When)**：什么情况下应该使用整合策略来替代保留策略？
    - **如何 (Which)**：如果需要整合，应该选择哪种具体的操作符？论文研究了三种：**Merge（合并）**、**Abstract（抽象）** 和 **Rewrite（重写）**。

#### **2. 方法论：核心思想、技术细节与公式**

- **核心思想**：将记忆管理形式化为一个**预算依赖的联合决策问题**。决策的关键在于平衡“覆盖效应”和“替换效应”，而预算压力决定了二者之间的权衡点。
- **关键技术与算法流程**：
    1.  **问题形式化**：
        - 定义动作集 `A = {retention, Merge, Abstract, Rewrite}`。
        - 定义**整合增益 (Consolidation Gain)** `Δo(z) = uo(z) - uret(z)`，即操作符 `o` 带来的回答效用 `u` 相对于保留策略的变化。
    2.  **理想化机制模型**：
        - 为分析决策边界，提出一个代理效用 `UB(M)`，将信息贡献量化为有符号的保真度 `φ`。
        - 提出**命题1**：一个操作符 `o` 的效用变化 `ΔUB,o` 可分解为：
            - **覆盖效应 (Coverage Effect)** `CB,o`：对保留策略**遗漏**但新整合记录能**覆盖**的新证据带来的正面增益。
            - **替换效应 (Replacement Effect)** `RB,o`：用整合记录**替换**原有适配的原始证据时带来的**带符号**影响。如果整合记录保真度低于原记录，则为负向影响。
        - 核心结论：当预算紧张时，`CB,o` 起主导作用，整合更优；当预算宽松时，`RB,o` 的负向影响显著，保留更优。
    3.  **OAS（离线抽象安全学习器）**：
        - **解决问题**：理想模型中的效用是反事实的，部署时无法获知。OAS通过**离线学习**来估计这些效用。
        - **流程**：
            1.  **离线标注 (Labeling)**：在训练数据上，对每个实例，评估保留和所有整合操作符的真实效用 `ua(z)`。
            2.  **特征化 (Feature Map)**：从预生成特征（如归一化预算、标记压力、保真度拟合分数、查询类型等）中提取11维特征向量 `ψ(z)`。
            3.  **效用回归 (Utility Regression)**：使用**岭回归**为每个动作 `a` 训练一个线性预测器 `μ̂a(z)`，直接学习从特征到真实效用的映射。
            4.  **决策规则**：部署时，选择预测效用最高的动作，即 `π̂(z) = arg max μ̂a(z)`。这同时解决了“何时”保留和“如何”整合的问题。
            5.  **风险控制校准**：引入一个**校准阈值** `τsafe,B`，只有当预测出来的最佳整合优势 `s(z)` 超过该阈值时，才执行整合。该阈值通过在一个留出验证集上进行零危害约束来选取，以控制有害替换的发生。

#### **6. 主要结论与发现**

1.  **预算依赖性策略选择**：记忆策略的选择并非固定，而是取决于**相对预算压力**。预算紧张时，整合（Consolidation）显著优于保留；预算宽松时，保留优于整合。这一交叉现象在LongMemEval和LoCoMo上均被证实。
2.  **操作符差异**：当需要压缩时，**跨笔记操作符（Abstract和Merge）普遍优于局部重写操作符（Rewrite）**。虽然Abstract和Merge之间没有明确的全局最优，但两者在覆盖面和解码效果上均优于局部改写。
3.  **机制验证**：分层分析（Table 1）验证了理论机制：当部分证据无法装入预算时（提示“未能覆盖”），所有整合操作符都能带来显著增益；而当所有证据都能装入时（提示“负面替换”），整合操作符反而会降低效用。
4.  **OAS学习器的有效性**：OAS通过低容量线性学习器，能够根据预生成特征（主要是预算压力）学习到何时整合和选择何种操作符，并在受控实验中**显著提升**了效益，同时通过校准有效地**降低了有害替换**的风险。
