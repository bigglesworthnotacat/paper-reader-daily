## 摘要
记忆对于使基于 LLM 的智能体在长时程交互中保持连贯、个性化的行为至关重要。然而，现有记忆系统有一个根本局限：它们从不主动测试自身记忆，只有在真实查询暴露出缺陷后才进行修复。这种反应式范式意味着，每一次检索失败都对应着一次真实交互，而代价已经付出。我们提出 MemDream，一个能够为 LLM 智能体实现自探测记忆演化的框架。我们的框架周期性地进入离线“梦境”循环；在其中，三个专门智能体（Dreamer、Analyst、Consolidator）会在失败发生之前协同探测、诊断并修复记忆图。通过组相对策略优化（Group Relative Policy Optimization）训练的策略学习哪些修复操作能带来持久的检索改进，而一种软衰减机制则提供由相同预期信号驱动的可逆遗忘。在 LoCoMo 和 MemoryAgentBench 上的实验表明，与最强的反应式演化基线相比，MemDream 在 LoCoMo 上将答案 F1 提高了 4.5 个点，并在 MAB 上取得了高 9.1 个点的总体得分。

## Abstract
Memory is essential for enabling LLM-based agents to maintain coherent, personalized behavior over long-horizon interactions. However, existing memory systems share a fundamental limitation: they never proactively test their own memory, repairing it only after real queries expose weaknesses. This reactive paradigm means every retrieval failure corresponds to a real interaction in which the cost has already been paid. We propose MemDream, a framework that enables self-probing memory evolution for LLM agents. Our framework periodically enters offline dream cycles where three specialized agents (Dreamer, Analyst, Consolidator) collaboratively probe, diagnose, and repair the memory graph before failures occur. A policy trained via Group Relative Policy Optimization learns which repair operations produce durable retrieval improvements, while a soft decay mechanism provides reversible forgetting driven by the same anticipatory signal. Experiments on LoCoMo and MemoryAgentBench demonstrate that MemDream improves answer F1 by 4.5 points on LoCoMo and achieves a 9.1-point higher overall score on MAB over the strongest reactive-evolution baselines.

## 1. 核心问题与研究动机

- **背景**：基于 LLM 的智能体需在长时程（long-horizon）多轮交互中积累、保留与检索信息，记忆决定其响应连贯性与行为一致性。但记忆可能出错，智能体的可靠性取决于它能否在失败到达用户之前修正记忆。
- **核心痛点（反应式范式）**：现有记忆系统从不主动测试自身，只在真实查询暴露缺陷后才修复。这意味着**每一次检索失败都对应一次已付出代价的真实交互**。
- **既有工作三条路线及其局限**：
  - 结构化记忆架构（分层/图结构）：丰富了检索，但组织方式预先固定；
  - 多阶段检索流水线（稀疏+稠密+重排）：提升精度，但不改变存储的记忆内容；
  - 自演化记忆方法（反思、自我提问、RL 学习 ADD/UPDATE/DELETE 策略）：多依赖已观测失败，属反应式。
- **记忆的三类失效模式**：碎片化（相关信息散落在无连接节点）、冗余（内容重叠）、陈旧（过时信息与近期交互冲突）。
- **核心洞察**：记忆系统应"测试自己"。受睡眠期记忆巩固（memory consolidation）启发，MemDream 在离线"梦境循环"中主动探测、诊断并修复记忆图，将不可观测的未来查询分布转化为可训练的修复信号。

## 2. 方法论

### 2.1 整体框架
- **层次化记忆存储** $G=(V,E)$，三层结构：
  - **STIM**（短期交互记忆）：缓冲近期 page，LRU 淘汰；
  - **MTEM**（中期情景记忆）：按会话分组，含会话级元数据；
  - **LTSM**（长期语义记忆）：压缩知识条目。
- 每个节点 $v$ 携带内容嵌入、实体集合、访问统计与检索权重 $w_v \in [0,1]$；边连接共享实体、同会话或被合并的节点。
- **检索**：对稠密检索器与 BM25 做 RRF 融合并按节点权重加权：
  $$s(v,q)=\Big(\sum_{i\in\{\text{dense,BM25}\}}\frac{1}{k+\text{rank}_i(v,q)}\Big)\cdot w_v$$
  再经 cross-encoder 重排取 Top-k。
- **形式化目标**：学习策略 $\pi: G \mapsto G'$，最大化对未来可能查询分布 $Q$ 的期望检索成功率 $\mathbb{E}_{q\sim Q}[\text{Success}(q,\text{Retrieve}(q,G'))]$。因 $Q$ 未知，梦境循环学会从中采样，把不可观测分布变成可训练信号。

### 2.2 三智能体梦境循环（共享 Llama-3.1-8B 骨干 + 独立 LoRA）
- **Dreamer（探测）**：
  - 节点弱点分数 $\phi(v)=\lambda_1(1-\frac{\deg(v)}{\max_u \deg(u)})+\lambda_2\max_{u\in N(v)}\cos(e_v,e_u)+\lambda_3\frac{t_{now}-t_v}{T}$，分别刻画连通性缺失、冗余、陈旧；
  - 将超阈值目标节点 $v^\star$ 与"桥接伙伴" $u^\star$ 配对：$u^\star=\arg\max_{u:(u,v^\star)\notin E}\mathbb{E}_{q\sim Q(v^\star)}[\mathbb{1}[\{u,v^\star\}\subseteq \text{Retrieve}(q,G)]]$（按**共检索性**而非嵌入相似度配对）；
  - 生成整合 $\{v^\star,u^\star\}$ 的前瞻性查询；**期望答案直接从目标节点存储内容逐字复制**（非模型生成），防止追逐幻觉目标；
  - 训练：先 SFT（memory state → 有效查询对），再 GRPO（奖励为检索成功）。
- **Analyst（诊断）**：沿两轴分类失败——**节点内/节点间** × **召回/精度**，四类：
  - buried（节点内·召回）、scattered（节点间·召回）、redundant（节点间·精度）、noisy（节点内·精度）；
  - 每类对应一种修复：extract / synthesize / merge / prune；输出受影响节点 id 与处方操作，**最严重者优先**；该分类在两轴上完备。
- **Consolidator（修复）**：
  - extract：把冗长页面转为结构化节点；merge：合并相似节点并保留边连通性；synthesize：生成带溯源边的摘要节点；
  - **prune 采用软衰减而非硬删除**：$w_v \leftarrow \gamma \cdot w_v$，$\gamma=0.2$；
  - **可逆恢复**：$w_v \leftarrow \min(1.0, w_v + \eta\cdot \text{success\_count}_v)$；
  - **收敛准则**：$\frac{1}{|D|}\sum_{q\in D}\text{F1}(q,G)\ge \tau$ 或 $t\ge T_{max}$，每轮处理不同分区。

### 2.3 GRPO 训练
- **每智能体奖励**（固定权重、可解释项之和）：
  - $r_D = w_{disc}r_{disc}+w_{down}r_{down}+w_{cov}r_{cov}$（判别性、下游影响、覆盖度）；
  - $r_A = w_{act}r_{act}+w_{div}r_{div}+w_{size}r_{size}+w_{struct}r_{struct}$（可执行性、修复类型多样性、规模适中、结构良好）；
  - $r_C = w_{qa}r_{qa}+w_{cov}r_{cov}+w_{temp}r_{temp}+w_{concise}r_{concise}$（QA-F1、覆盖、时序线索、简洁）。
- **GRPO 目标**：$L_{GRPO}=-\frac{1}{N}\sum_{i=1}^{N}A_i\log\pi_\theta(a_i|s)$，$A_i=\frac{r_i-\bar r}{\sigma_r+\epsilon}$；仅高于组均值的 rollout 获得正梯度（更难课程）。
- **三阶段训练**：① SFT（GPT-4.1 教师数据）；② 各智能体独立 GRPO；③ Dreamer 与 Consolidator **联合微调**（Analyst 冻结），联合奖励 $r_{joint}=\frac{1}{|D_{new}|}\sum_{q\in D_{new}}[\text{F1}(q,G')-\text{F1}(q,G)]$，梯度只流向 Dreamer 与 Consolidator。
- **部署**：模型参数固定，梦境循环只更新外部记忆；在线交互不等待梦境完成（异步）。
