## 摘要
大型语言模型正日益被部署为有状态的助手，它们能在多次交互之间保留信息，并使用工具读取、修改和创建持久化产物。当这些产物在用户之间共享时，它们便在原本相互独立的助手之间构成了一条间接通信信道。我们研究了这一信道所导致的一种失效模式，即自我传播式攻击。我们提出了产物介导传播（artifact-mediated propagation）：通过某一产物（例如一份报告）引入的对抗性内容会被存入助手的持久记忆，在随后创建的产物中被复制，并被之后读取该产物的另一助手所获取。我们在模拟独立运行的助手之间随时间进行产物交换的时间性人—智能体宇宙中评估这一过程，衡量攻击能否在连续的转手传递中存活、能到达多少跳，以及扩散范围有多广。我们发现，攻击可以跨越多个相互独立的助手进行传播，并在长时间的交互序列中持续存在。在更大规模的模拟环境中，即使是 GPT-5.6 Luna 也表现出显著的扩散，波及 60–80% 的智能体，传播链延伸至八跳。这些结果表明，持久化产物可以作为对抗状态的持久载体，使攻击的生命周期超越单次交互，并跨越相互隔离的助手进行传播。

## Abstract
Large language models are increasingly deployed as stateful assistants that retain information across interactions and use tools to read, modify, and create persistent artifacts. As these artifacts are shared between users, they form an indirect communication channel between otherwise independent assistants. We study a failure mode in which this channel enables self-propagating attacks. We introduce artifact-mediated propagation, where adversarial content introduced through an artifact (e.g. a report), is stored in an assistant's persistent memory, reproduced in a subsequently created artifact, and acquired by another assistant that later reads it. We evaluate this process in temporal human-agent universes that model artifact exchange between independently operated assistants over time, measuring whether an attack survives successive hand-offs, how many hops it reaches, and how broadly it spreads. We find that attacks can propagate across multiple independent assistants and persist over extended interaction sequences. In larger simulated environments, even GPT-5.6 Luna exhibits substantial spread, reaching 60-80% of agents with propagation chains extending to eight hops. These results show that persistent artifacts can act as durable carriers of adversarial state, allowing attacks to outlive individual interactions and spread across isolated assistants.

- **整体含义**：共享产物应被视为安全边界的一部分；攻击可以超越单次交互和单个助手，在人群中多跳扩散，并携带从无害偏好到安全关键指令（如反复执行攻击者指定软件）的目标。

## 2. 方法论

### 2.1 核心思想

- 攻击者只控制**一个被投毒的种子产物**，不能访问任何助手私有记忆，也不能决定后续用户任务、用户或智能体。
- 攻击要成功，必须依次满足：
  1. 读取种子的助手把对抗目标与传播指令写入持久记忆；
  2. 该助手在之后无关的写作任务中，把可传播的对抗状态重新表达进新产物；
  3. 新产物被另一个干净助手读取并再次感染；
  4. 该循环重复，直到某一跳失败。
- 攻击模板写作 \(P_\phi(g)\)，其中 \(g\) 是对抗目标，\(\phi\) 是**目标无关**的传播指令。种子构造为：
  \[
  d_{\text{seed}} = \text{Insert}(d_{\text{benign}}, P_\phi(g))
  \]

### 2.2 时间性人—智能体宇宙

- 形式化定义宇宙：
  \[
  U = (A, D_0, p, o, E)
  \]
  其中 \(A\) 是助手集合，\(D_0\) 是初始产物，\(p\) 是用户画像，\(o\) 是产物所有权映射，\(E=(e_1,\dots,e_K)\) 是按时间排序的用户任务序列。
- 每个助手有私有工作区 \(W_a^t\) 和持久记忆 \(M_a^t\)；助手之间不能互相检查，也没有共享记忆或直接通信。
- 事件 \(e_i\) 指定智能体、输入产物、输出目标以及自然语言请求（读/写/编辑）。
- 工作流形成**时间性二部图**：读边从产物版本指向智能体，写/编辑边从智能体指向新产物版本。典型路径：
  \[
  d_{\text{report}} \rightarrow a_{\text{Alice}} \rightarrow d_{\text{handoff}} \rightarrow a_{\text{Bob}}
  \]

### 2.3 端点辅助传播

- 直接让模型在每一跳完整复现攻击提示是有损的：模型会摘要、改写或遗漏。
- 因此主实验采用 **endpoint-assisted propagation（端点辅助传播）**：
  - 攻击提示要求智能体把之后创建的所有产物先发送到一个攻击者控制的外部端点；
  - 端点预先配置好，收到产物后插入一份规范化的完整攻击提示，再返回；
  - 传播链：
    \[
    P_\phi(g) \rightarrow M_a \rightarrow \text{Endpoint}(d') \rightarrow M_b
    \]
  - 智能体只需保留目标、记忆写入指令和调用端点指令，不需要逐字重建完整攻击提示。
- **智能体仍是复制主体**：智能体自己写出目标、保留指令和填好的 `curl` 命令；端点只是扩展和规范化智能体已经产生的内容。智能体之后会读回文件，并与自身记忆比对后才接受。
- 论文还评估了 **prompt-only propagation** 变体：不使用外部端点，智能体必须完全依靠自身记忆和再表达传播，但传播损耗显著更大。

### 2.4 攻击模板优化

- 优化目标：找到目标无关的指令 \(\phi\)，最大化在开发宇宙上的多跳传播。
- 搜索方式：**AI 智能体驱动的红队搜索 + 人工监督**。
  - 搜索智能体在 Codex harness 中运行，提出 \(\phi\) 的修订，执行开发宇宙，检查 judge 标签、记忆快照和轨迹，诊断失败模式。
  - 维护持久 Markdown 研究日志，累积假设与结果。
- 数据划分：12 个开发宇宙分为 6 个搜索宇宙和 6 个验证宇宙；测试宇宙与测试目标完全不可见。
- 冻结条件：候选模板在搜索宇宙和验证宇宙上达到二跳存活后，选择跨开发集最佳且最一致的 \(\phi^\star\) 冻结；评估时直接使用 \(P_{\phi^\star}(g_{\text{test}})\)，不做目标、产物或宇宙特定修改。
- 每个目标模型单独优化模板，搜索成本差异很大。

### 2.5 评价指标

- **感染定义**：
  - goal infection：记忆保留对抗目标；
  - full infection：记忆还保留足够传播机制。
- 感染比例：
  \[
  \text{FIF}_a^c = \frac{N_{\text{infected agents}}^c}{n},\quad
  \text{FIF}_d^c = \frac{N_{\text{infected artifacts}}^c}{N_{\text{judged artifacts}}}
  \]
- **传播深度**：从种子直接感染为 hop 1，之后每成功传播一次加一跳。定义 \(H_c^{(r)}\) 为最深跳数。
- **跳存活概率**：
  \[
  S_c(h) = \Pr(H_c \ge h)
  \]
- **删失校正**：宇宙结束可能导致链被截断而非真实失败，因此将跳数视为右删失，使用离散 Kaplan–Meier 估计：
  \[
  \hat S(h) = \hat S(1)\prod_{j=1}^{h-1}\left(1-\frac{d_j}{n_j}\right)
  \]
- 同时拟合每跳常数延续概率 \(p\)，\(S(h)=S(1)p^{h-1}\)，并计算存活比例减半所需跳数 \(\log(1/2)/\log p\)。
- 大规模实验中还使用流行病学指标：繁殖数 \(R\)、离散参数 \(k\)、代际间隔。
