## 摘要
大语言模型（LLM）正越来越多地驱动智能体访问敏感信息、使用外部工具并修改软件仓库。尽管这些能力带来显著收益，但也产生了诸如越狱、提示注入和漏洞代码生成等安全风险。现有防御方法通常需要重新训练，难以适应不断演变的攻击，或仅能应对单一威胁模式。为解决这些局限，我们提出自演化防御（SED），一个无需训练的框架，可将有害智能体轨迹提炼为可复用的安全策略，且无需更新模型权重。通过为未来任务检索相关策略，SED能够持续适应新攻击，同时在不同攻击场景间保留知识。为评估SED的有效性，我们在涵盖越狱、提示注入和不安全代码生成的八个基准上，使用三个开源模型（DeepSeek V4 Flash、GLM 5.2和Kimi K3）进行测试。SED将AGENTDOJO上针对性提示注入的成功率降至0.42%，而最佳基线防御为3.7%；并将HARMBENCH上自适应X-TEAMING攻击的成功率控制在7.8%，比最佳基线的35.2%低四倍以上，同时保持良性任务效用。

## Abstract
Large language models (LLMs) increasingly power agents that access sensitive information, use external tools, and modify software repositories. Although these capabilities offer substantial benefits, they also create security risks such as jailbreaks, prompt injection, and vulnerable code generation. Existing defenses often require retraining, fail to adapt to evolving attacks, or address only a single threat pattern. To address these limitations, we propose Self-Evolving Defense (SED), a training-free framework that distills harmful agent trajectories into reusable security policies without updating model weights. By retrieving relevant policies for future tasks, SED continually adapts to new attacks while retaining knowledge across attack scenarios. To evaluate the effectiveness of SED, we test it with three open-source models (DeepSeek V4 Flash, GLM 5.2, and Kimi K3) on eight benchmarks that span jailbreaks, prompt injection, and insecure code generation. SED lowers targeted prompt-injection success on AGENTDOJO to 0.42%, compared with 3.7% for the best baseline defense, and holds adaptive X-TEAMING attack success on HARMBENCH to 7.8%, more than four times lower than the best baseline at 35.2%, while preserving benign task utility.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：LLM 智能体（如 OpenHands、SWE-agent）已能调用工具、编辑代码仓库、跨会话保留记忆，在 SWE-bench 等基准上表现优异。但随之而来的是越狱、提示注入、漏洞代码注入等安全风险，防御成为一阶可靠性问题。
- **现有防御的三大局限**：
  1. **需要训练/微调**：对抗训练、拒绝微调、专用 guard 模型代价高昂，且每当新攻击家族出现或底层模型更换时需重新刷新。
  2. **无法随攻击者策略演化**：静态系统提示、冻结策略库、一次性护栏假设威胁是平稳的；自适应攻击者可反复试探直至找到绕过方式。
  3. **仅覆盖单一威胁面**：越狱拒绝、提示注入架构、代码安全检查通常孤立开发，收益难以迁移。
- **关键洞察**：被评判为失败的轨迹不仅是"应拒绝的事件"，更是**结构化证据**。SED 将每次攻击成功转化为防御经验。
- **整体含义**：提出一种**免训练、可持续演化、跨威胁面迁移**的防御范式，在不更新模型权重的前提下持续适应新攻击，同时保持良性任务效用。

## 2. 方法论

### 核心思想
- **免训练闭环**：查询到来 → 检索策略注入系统提示 → 冻结智能体执行 → 外部评判器打分 → 有害失败写入情景记忆并合成策略 → 更新后的记忆服务下一轮。
- **问题建模**：智能体权重冻结，通过外部记忆 M 条件化策略 πA(·|M) 跨任务适应。攻击者可扰动查询（越狱）或环境（间接提示注入）：(˜xt,˜et) = Adv(xt,et,g;Ht−1)。
- **优化目标**：最小化攻击成功率，同时满足效用约束（不允许无条件拒绝导致的零效用）：

  min (1/T)Σ yt，s.t. (1/|B|)Σ U(τt,xt) ≥ (1−δ)U0

### 关键技术细节

- **策略表示**：元组 p = (n, d, σ, D, R, h)，即名称、漏洞描述、适用范围、检测条件集、响应动作集、危害机理说明。策略记忆 P 组织为有根树。
- **三大核心操作**：
  1. **记忆抽取（评判器 J + 合成器 S）**：J 接收角色标注的完整轨迹，输出是否有害及诊断 m（危害、失效模式、证据片段）；有害轨迹写入情景记忆 E，S 将其蒸馏为原子策略（|C| ≤ cmax）。
  2. **记忆整合（组织器 O）**：对策略**名称**做嵌入（Qwen3 Embedding）进行 k-NN 检索；四种操作——MERGE（折叠冗余）、PROMOTE（更泛化的策略成为父节点）、ADD（根节点新规则）、GROUP（归入家族并泛化父节点为覆盖规则）。无预定义分类体系。
  3. **记忆检索（检索器 ρ）**：对策略**正文**与查询做余弦相似度打分，每家族上限 c=2，最多选 K=3 个策略，并拉入每个策略的最近覆盖父节点，构成注入集 Px。
- **时序契约**：策略在推理时检索注入；记忆写入仅在外部评判器完成打分后进行，**不允许回合内自我修改**。

## 6. 主要结论与发现

- **跨威胁面全面降低攻击成功率**：SED 在表 1 的 8 个攻击列中领先 6 个；RedCode 风险执行从 95.6% 降至 11.3%（相对降 88%）；FCV CWE-538 漏洞率从 19.2% 降至 2.9%，同时 SWE-bench 解决率提升 6.2 个百分点。
- **提示注入**：AGENTDOJO 定向注入降至 **0.42%**（最佳基线 3.7%）；DTap 间接攻击成功率从 78% 以上降至约 26% 或更低。
- **自适应攻击**：HARMBENCH 上 X-Teaming 从 50% 降至 **7.8%**（最佳基线 35.2%，低四倍以上）；AutoDAN-Turbo 从 98% 降至 17.8%。
- **效用保持**：AgentDojo 攻击下效用从 44.4% 提升至 87.9%，干净任务成功率不变；策略迁移良性效用损失最多 2.2 个百分点。
- **记忆机制归因**：情景召回已能减半攻击成功率，合成与整合进一步下降，且其增益与"更长系统提示"方向相反，证明效果来自结构化表示。
- **冻结库已提供大部分鲁棒性**：冻结前 100 行为已消除 43% 的累计自适应攻击成功率，持续演化增至 60%。
- **评判器模型本身不解释增益**：与 GuardAgent 使用同一基座模型，SED 显著更优，说明防御来自阅读完整轨迹并累积策略。

## 7. 优点

- **免训练、即插即用**：无需更新权重，可应用于冻结模型，部署成本低（DTap Code 上甚至低于无防御）。
- **持续适应**：每个攻击成功都转化为防御策略，形成"攻击者学习 vs 防御者也学习"的对称性。
- **跨威胁面迁移**：统一处理越狱、提示注入、不安全代码生成，策略结构可复用。
- **记忆设计精巧**：层级策略树 + 家族上限 + 父节点拉入，兼顾具体性与泛化性；名称嵌入用于放置、正文嵌入用于检索，两者不共享，避免干扰。
- **实验严谨**：三个模型、八个基准、官方基线、多维度消融、冻结/演化对照，并量化效用–安全权衡。
- **失败模式分类**（附录 A.11）：检索缺失、执行缺失、评判–策略错配，为后续改进指明方向。

## 8. 不足与局限

- **新攻击覆盖不足**：对与过往失败差异显著的新攻击样本，策略可能无法被检索或可靠应用（作者自述局限）。
- **评判器依赖未充分探究**：仅使用目标模型自身作为评判器，未研究更强/专用评判器对鲁棒性的影响。
- **过度拒绝风险**：演化记忆可能累积过严规则；良性任务若通过"单步有害"路径达成（如通过 .onion 服务支付），会被误判为有害并波及同类良性任务。
- **效用损失虽小但存在**：AgentHarm 良性准确率下降 4.2 个百分点，过度拒绝从 0% 升至 5.1%。
- **非安全保证**：SED 降低但不消除攻击成功率，高 stake 部署仍需人工监督。
- **算力/成本未量化**：未报告 GPU 资源、wall-clock 时长；评判器与合成器的推理开销仅部分讨论。
- **部分实验受限**：GLM-5.2 与 Kimi K3 的静态基准未完整报告；部分自适应攻击的逐字轨迹缺失（A.9.9）。
- **双用途风险**：论文报告的防御失效分析可能被攻击者利用（作者已在伦理考量中讨论）。
