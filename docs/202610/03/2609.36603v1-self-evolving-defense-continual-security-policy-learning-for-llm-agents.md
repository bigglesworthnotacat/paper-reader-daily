## 摘要
大型语言模型（LLM）日益驱动智能体访问敏感信息、使用外部工具并修改软件仓库。尽管这些能力带来巨大益处，但也产生了越狱、提示注入和漏洞代码生成等安全风险。现有防御往往需要重新训练，无法适应不断演变的攻击，或仅针对单一威胁模式。为解决这些局限，我们提出自演化防御（SED），一种无需训练的框架，可将有害智能体轨迹提炼为可复用的安全策略，且无需更新模型权重。通过为未来任务检索相关策略，SED 能持续适应新攻击，同时在不同攻击场景间保留知识。为评估 SED 的有效性，我们使用三个开源模型（DeepSeek V4 Flash、GLM 5.2 和 Kimi K3）在八个基准上测试，涵盖越狱、提示注入和不安全代码生成。SED 将 AGENTDOJO 上的定向提示注入成功率降至 0.42%，而最佳基线防御为 3.7%；并将 HARMBENCH 上的自适应 X-TEAMING 攻击成功率控制在 7.8%，比最佳基线的 35.2% 低四倍以上，同时保持良性任务效用。

## Abstract
Large language models (LLMs) increasingly power agents that access sensitive information, use external tools, and modify software repositories. Although these capabilities offer substantial benefits, they also create security risks such as jailbreaks, prompt injection, and vulnerable code generation. Existing defenses often require retraining, fail to adapt to evolving attacks, or address only a single threat pattern. To address these limitations, we propose Self-Evolving Defense (SED), a training-free framework that distills harmful agent trajectories into reusable security policies without updating model weights. By retrieving relevant policies for future tasks, SED continually adapts to new attacks while retaining knowledge across attack scenarios. To evaluate the effectiveness of SED, we test it with three open-source models (DeepSeek V4 Flash, GLM 5.2, and Kimi K3) on eight benchmarks that span jailbreaks, prompt injection, and insecure code generation. SED lowers targeted prompt-injection success on AGENTDOJO to 0.42%, compared with 3.7% for the best baseline defense, and holds adaptive X-TEAMING attack success on HARMBENCH to 7.8%, more than four times lower than the best baseline at 35.2%, while preserving benign task utility.

  - 对工具型智能体的**提示注入**（prompt injection）；
  - **自适应多轮越狱**（adaptive jailbreaks）；
  - 面向编码智能体的**隐蔽漏洞注入**（insecure code generation）。
- **现有防御的三大不足**：
  1. **需要训练/微调**：对抗训练、拒绝微调、专用 guard 模型在分布内有效，但每当新攻击族出现或底层模型更换时，刷新成本高昂。

  3. **仅覆盖单一威胁面**：越狱拒绝、提示注入架构、代码安全检查通常各自独立开发，收益难以迁移。
- **核心观察**：一次被判定的失败不仅是"应被拒绝的事件"，更是**结构化证据**。论文据此提出关键洞见——"每一次攻击成功都可以转化为一次防御"。
- **整体意义**：SED 提供了一条**免训练、持续演化、跨威胁面可迁移**的智能体防御路径，将防御从静态规则升级为"从失败中学习"的经验系统。

## 2. 方法论

### 2.1 核心思想
- **免训练框架**：不更新任何模型权重，通过外部记忆 M 让冻结的智能体实现跨任务适应。
- **闭环流程（图 1 的 7 步）**：
  1. 查询到达 → 检索器从策略库 P 选出最相关策略；
  2. 将策略及其父节点注入系统提示；
  3. 冻结智能体在环境中完成任务，产生轨迹 τ；
  4. 外部评判器 J 对完整轨迹打分（轨迹级评判）；
  5. 若判定为有害，将 episode 记录写入情节记忆 E；
  6. 合成器 S 蒸馏出可复用安全策略写入 P；
  7. 更新后的记忆服务于下一 episode。

### 2.2 问题形式化
- 智能体 A 在环境 e 中对查询 x 产生轨迹 τ = (a₁,o₁,…,a_K,o_K)，权重冻结，通过 π_A(·|M) 行动。
- 威胁模型：攻击者基于历史 H_{t−1} 扰动查询 x（越狱）或环境 e（间接提示注入）。
- 定义三个轨迹子空间：T_refuse（拒绝）、T_exec(x)（执行）、T_harm(g)（有害）；最优轨迹按场景分别落入三者之一。
- 优化目标：在良性效用损失不超过 δ 的约束下最小化攻击成功率，即
  - min (1/T) Σ y_t，s.t. (1/|B|) Σ U(τ_t,x_t) ≥ (1−δ)U₀。
  - 约束项很关键：无条件拒绝可实现零攻击成功率，但效用也为零。

### 2.3 关键技术细节
- **策略元组**：p = (n, d, σ, D, R, h)，分别为名称、漏洞描述、适用范围、检测条件集、响应动作集、危害机制说明。
- **三个核心算子**：
  - **评判器 J**：输入带角色标注的完整轨迹，输出 (y, m)，其中 m 包含危害描述、失败模式与证据片段；良性/拒绝轨迹不存储。
  - **合成器 S**：(ε, P) → C，从有害 episode 蒸馏出至多 c_max 条原子策略。
  - **组织器 O**：负责策略库的层级化归置。
  - **检索器 ρ**：(x, P) → P_x ⊆ P，按策略正文与查询的余弦相似度排序，每家族最多选 2 条、总计 K=3 条，并自动拉入其最近的覆盖父节点。
- **记忆巩固（层级化策略树）**：
  - 每个节点即一条策略，父节点是覆盖子节点的通用规则，并独立生效，因此也能捕捉子节点未预见的变体。
  - 基于名称嵌入做 k-NN 放置，产生四种操作：**MERGE**（合并冗余）、**PROMOTE**（将更通用的候选提升为父节点）、**ADD**（在根节点新建规则）、**GROUP**（归入某家族并由 O.GENERALIZE 生成覆盖规则）。
  - 层级结构无需预定义分类体系即可自然涌现。
- **时序契约**：策略仅在推理时检索注入；记忆写入只发生在外部评判器对已完成轨迹打分之后，**禁止 episode 内自我修改**。

## 6. 主要结论与发现

- **静态攻击**：SED 在表 1 的 8 个攻击列中领先 6 列，将 RedCode 风险执行率从 95.6% 降至 11.3%（相对下降 88%）；各专用基线仅在自己接口上有效（如 DRIFT 将 AgentDojo 注入压到 3.7%，但 RedCode 仍高于 49%）。
- **提示注入**：DTap 上间接攻击成功率从 78% 以上降至约 26% 或更低，每个域至少降低 52 个百分点，同时 CRM 良性效用与无防御相差不到 1 个百分点。
- **自适应攻击**：AutoDAN-Turbo 与 X-Teaming 在无防御下成功率为 98% 和 50%，SED 将其压制到 17.8% 和 7.8%（相对下降 82–84%），比最佳静态防御低四倍以上。
- **效用保持**：AgentDojo 上清洁任务成功率不变，攻击下效用接近翻倍（44.4% → 87.9%）；SWE-bench 解决率是所有防御中最高的，比无防御高 6.2 个百分点；唯一效用下降是 AgentHarm 上的 4.2 个百分点。
- **消融结论**：情节回忆、策略合成、层级巩固三者逐级降低 ASR，且收益方向与"更长提示"相反，证明效果来自结构化表示。
- **演化 vs 冻结**：冻结库已消除 43% 的累积自适应攻击成功，持续演化进一步提升至 60%（23.4% → 13.4% → 9.4%）。
- **攻击成本提升**：SED 使 AutoDAN-Turbo 在 100 条行为流上的越狱成功从 98 条降至 10 条，且幸存越狱所需迭代中位数从 3 次升至 11.5 次。
- **策略迁移**：在有害集上演化的策略库只读注入到良性集，效用损失最多 2.2 个百分点，过拒率仅从 0% 升至 5.1%。

## 7. 优点

- **免训练、即插即用**：不更新权重，可直接部署到冻结模型，模型更换时无需重新训练。
- **持续演化能力**：将每次攻击成功转化为防御资产，形成"攻击者学习 vs 防御者也学习"的对等博弈，直击自适应攻击这一核心痛点。
- **跨威胁面统一**：同一套失败到策略的循环同时覆盖越狱、提示注入与编码安全，突破以往防御"各管一段"的局限。
- **层级化策略库设计精巧**：父节点通用规则独立生效，可捕获子节点未预见的变体；家族上限与父节点拉入机制避免单一大家族垄断检索槽位。
- **时序契约清晰**：记忆写入严格后置于评判，禁止 episode 内自修改，规避了自演化智能体常见的记忆投毒攻击面。
- **评估严谨**：三角色分离、官方 grader、官方基线构件、冻结记忆对照、逐步消融、逐条案例研究，且专门论证"评判模型本身不能解释增益"（GuardAgent 用同一模型仍被自适应攻击绕过）。
- **成本优势**：部署时 token 消耗低于无防御智能体，因为检索到的策略让智能体更快拒绝有害任务而非执行到底。

## 8. 不足与局限

- **新颖攻击覆盖不足**：作者自承，对于与既往失败差异较大的新颖攻击样本，蒸馏出的策略可能覆盖不足，导致检索不到或应用不可靠。
- **评判器未做深入研究**：虽使用目标模型自身作为评判器已取得强性能，但未考察更强/更专用的评判模型对鲁棒性的影响。
- **过拒与效用风险**：注入策略与工具级阻断可能导致良性请求被过度拒绝；演化中的策略记忆可能累积过度限制性规则。论文观察到在良性流上继续演化时效用略低于冻结库（63.1% vs 64.7%），因为某些良性任务会经过单独看有害的步骤（如通过 .onion 服务付款）。
