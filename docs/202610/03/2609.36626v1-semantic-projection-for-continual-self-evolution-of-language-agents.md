## 摘要
语言模型智能体日益依赖持久化的自然语言技能，以在冻结的模型参数之外进行适应。然而，当一项共享技能从非平稳、异构的任务流中被反复修订时，针对新任务的改进可能覆盖早期任务所需的流程。在持续学习中，正交梯度下降（OGD）通过将新任务的梯度投影到一个局部保持先前预测的子空间，来解决类似的干扰问题。然而，自然语言技能修订既没有梯度，也没有可用于执行这种投影的规范向量空间。我们提出语义范围投影演化（Semantic-Scope Projected Evolution, SSPE），它将梯度投影的功能原理从参数空间迁移到行为空间。SSPE将无约束的技能修订视为一个候选更新，识别其可能干扰的已习得能力，并利用观察到的性能提升与退化来构造兼容的修订，而不是仅仅拒绝该更新。这使单个共享技能能够在潜在和重复出现的任务上下文中演化，而无需向演化模型暴露语义领域身份。在受控合成任务流和异构真实智能体基准上，相较于强技能演化基线，SSPE提升了最终跨域能力并缓解了遗忘。演化后的技能在迁移到不同的执行器模型后仍保持最强的平均性能。这些结果确立了语义投影作为一种有望实现语言智能体稳定且自适应自进化的原则。

## Abstract
Language-model agents increasingly rely on persistent natural-language skills to adapt beyond their frozen model parameters. When a shared skill is repeatedly revised from a non-stationary, heterogeneous task stream, however, improvements for new tasks can overwrite procedures needed for earlier ones. In continual learning, Orthogonal Gradient Descent (OGD) addresses analogous interference by projecting a new-task gradient onto a subspace that locally preserves prior predictions. Natural-language skill revisions, however, have neither gradients nor a canonical vector space in which such a projection can be performed. We introduce \emph{Semantic-Scope Projected Evolution} (SSPE), which transfers the functional principle of gradient projection from parameter space to behavior space. SSPE treats an unconstrained skill revision as a proposed update, identifies acquired capabilities with which it may interfere, and uses the observed gains and regressions to construct a compatible revision rather than merely rejecting the update. This enables one shared skill to evolve across latent and recurring task contexts without exposing semantic domain identities to the evolution model. Across controlled synthetic streams and heterogeneous real-agent benchmarks, SSPE improves final cross-domain competence and mitigates forgetting relative to strong skill-evolution baselines. The evolved skill also retains the strongest average performance after transfer to a different executor model. These results establish semantic projection as a promising principle for stable and adaptive self evolution of language agents.

- **研究背景**：语言模型智能体越来越依赖持久化的自然语言技能（procedural skill）来适应冻结模型参数之外的任务；这类技能可检查、可修订、可跨任务甚至跨执行器模型复用，是理想的"演化目标"。
- **核心痛点**：当同一个共享技能从**非平稳、异构任务流**中被反复修订时，针对当前任务的改进可能覆盖、矛盾或降级早期任务所需的流程，导致**程序性灾难性遗忘（procedural catastrophic forgetting）**。
- **现有方法不足**：
  - 现有文本优化器（诊断轨迹、聚合反馈、验证编辑、剪枝、维护优化器状态）多在同一任务分布内开发；

- **类比灵感**：持续学习中的**正交梯度下降（OGD）**通过把新任务梯度投影到对先前预测敏感方向的正交补空间，在保留有用进展的同时不改变受保护行为。但自然语言技能**既无梯度，也无规范向量空间**（无减法、无内积，嵌入空间正交不代表行为兼容）。
- **整体含义**：论文主张把 OGD 的功能原理从**参数空间迁移到行为空间**，提出以观察到的行为冲突作为建设性反馈来"修复"技能修订，而非简单拒绝。

## 2. 方法论：SSPE（Semantic-Scope Projected Evolution）

### 核心思想
- 把一次**无约束的技能修订**视为"当前梯度/候选更新"，通过**能力记忆 + 选择性历史审计**识别潜在干扰，再用**语义投影**（LLM 推理算子）构造既保留当前收益、又满足历史约束的兼容修订。
- 与 OGD 的类比：当前梯度 ↔ 无约束修订；受保护输出敏感度 ↔ 能力胶囊与审计任务；与保护方向对齐 ↔ 实测历史退化；正交投影 ↔ 基于观察冲突的修订；零投影步 ↔ 显式不更新。

### 关键技术细节
- **流式设定**：任务分批到达 $B_t=\{x_{t,i}\}$，当前技能固定执行轨迹 $\tau_{t,i}\sim\pi_\theta(\cdot|x_{t,i},S_t)$，获得奖励 $r_{t,i}$；批结束后由外部过程更新 $S_{t+1}=U(S_t,B_t,F_t)$，基础模型参数 $\theta$ 冻结。
- **能力评估**：$J_c(S)=\mathbb{E}[R]$，候选技能对能力 $c$ 的影响 $\Delta_c(S';S_t)=J_c(S')-J_c(S_t)$，负值即为干扰。
- **能力记忆**：记忆算子 $\Gamma$ 将当前批记录为不可变 micro-capsule，并关联为 capability capsule $h$；每个确认胶囊指向不透明的审计任务库 $V_h$。记忆只总结行为，**不提出文本、不编辑技能**。
- **无约束提案**：$( \hat S_t,\hat\sigma_t)=P(S_t;B_t,Y_t,D_t,\mu_t)$，$\hat\sigma_t$ 预测拟修复、受影响能力、排除范围与不确定性，仅用于路由。
- **风险路由**：风险算子 $\rho_t(h)=R(\hat S_t,\hat\sigma_t;M_t,h)$，审计**最高风险/最不确定**的能力，并在可用时加审一个**随机预测安全**的能力以探测假阴性；审计集 $A_t=S(\rho_t;H_t)$，审计库 $V_t=\{V^{cur}_t\}\cup\{V_h:h\in A_t\}$。
- **准入准则**：硬优先效用 $U_V(S)=(H_V(S),Q_V(S))$，候选须在当前库上词典序提升、且对任一选中历史库**无净硬损失**：
  $$S'\in K_t \iff U_{V^{cur}_t}(S')\succ_{lex}U_{V^{cur}_t}(S_t),\ H_{V_h}(S')\ge H_{V_h}(S_t)\ \forall h\in A_t$$
- **迭代语义投影**：若候选不可接受，累积证据 $\Omega^{(k)}_t=(\hat\sigma_t,\rho_t,\{(S^{(j)}_t,E^{(j)}_t)\})$，由 LLM 算子构造 $S^{(k+1)}_t=\Pi_{sem}(S^{(k)}_t;S_t,\Omega^{(k)}_t,M_t)$，最多 $K_{proj}$ 轮；**首个可接受候选即提交**，否则保留父技能。
- **算法流程（Algorithm 1）**：执行当前技能 → 提取证据与语义动量 → 记录/巩固能力证据 → 形成无约束提案 → 风险评审与审计路由 → 配对评估 → 若不可接受则循环语义修复 → 接受或保留 → 封存可审计状态。

## 6. 主要结论与发现

- **真实异构流**：SSPE 留下最强最终技能，平均 77.50%，优于 SkillGrad（74.06%）、SkillOpt（73.13%）、Static（72.50%）；BFCL 提升最大（65.00%，+20.00 vs 无技能），DocVQA 也最好（95.00%）。但并非每个 benchmark 都均匀提升（SpreadsheetBench 无技能最强，SearchQA SkillOpt 最强）。
- **跨模型迁移**：GPT-5.4 演化的技能迁移到 GPT-4.1 后，SSPE 仍平均最强（63.75%），BFCL 与 DocVQA 优势明显，说明学到的是**可移植的程序性指导**而非对演化模型特异性的利用。
- **消融**：移除历史证据后整体优势消失；增大投影预算 $K_{proj}$ 不提升（默认 $K_{proj}=1$ 最强），更大预算产生更多候选但**首轮之外无额外兼容更新被提交**，GPT-4.1 重复实验同样排序。
- **受控合成**：SSPE 相对 SkillGrad 平均遗忘降低 **55.84%**，final macro +0.3211、累计 prequential 奖励 +0.09345、有害更新率低 0.3899；但即时当前能力增益低 0.02864（**超出预注册容忍损失 0.02**），揭示真实的稳定性–可塑性权衡。
- **总体结论**：历史证据提供必要约束，而**语义投影使这些约束具有建设性**——不是拒绝干扰更新，而是利用观察到的冲突构造兼容更新。

## 7. 优点

- **概念迁移有深度**：将 OGD 的"投影"从参数空间迁移到行为空间，把验证从终端 accept–reject 门转化为建设性修复反馈，是自演化智能体的新原则。
- **无需领域身份**：演化模型不接收 benchmark 名称、领域计数或标注的分布变化，具备部署友好性。
- **可审计性**：能力胶囊、不可变证据、封存状态、配对执行评测，形成可追溯的技能演化记录。
- **双轨验证**：受控合成隔离干扰机制 + 真实异构流验证实用性，互相补充。
- **跨模型可迁移性**：冻结技能换执行器后仍保持最佳平均，支持"可复用程序性指导"的解释。
- **公平性控制较好**：任务提示、工具、评分器、批次顺序共享，held-out 密封，受控实验配对世界。

## 8. 不足与局限

- **流的开放性不足**：当前持续流只含有限域、按组到达，实际部署可能是开放式、结构更松的域序列。
- **任务顺序固定**：主要实验采用固定顺序，未研究替代顺序、循环序列、交错流的鲁棒性。
- **因果性受限**：$K_{proj}$ 各设置为独立不可 seed 的 lineage，只能选默认停止预算，不能声称更深投影本身有害。
- **合成实验的抽象性**：模拟器不执行真实 prompt，不代表原生 SkillGrad/SkillOpt/SSPE 文本行为，只能作机制证据而非排行榜。

- **稳定性–可塑性权衡**：即时当前能力增益损失超出预注册容忍阈值，未建立对原生文本优化器的全面优越性。
- **定性案例为事后选择**：BFCL 案例是观察评测后挑选，仅作说明而非因果证据。
- **算力信息缺失**：未报告 GPU 型号、数量、时长，复现成本与资源需求不透明。
